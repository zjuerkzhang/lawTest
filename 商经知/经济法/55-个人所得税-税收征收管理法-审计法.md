
## 第一部分：讲稿知识点的提纲（完整版）

> **说明**：以黑色水笔【实心方块】标识讲授者重点强调，以空心方块【空心方块】标识展开。超出主题的概念以脚注保留。


### 一、个人所得税——居民与非居民个人区分

**【实心方块】分类标准（二选一）**
- 住所标准：在中国境内有住所 → 居民个人
- 居住时间标准：无住所但一个纳税年度内累计居住满183天 → 居民个人

**【实心方块】核心要点（与国籍无关）**
- 居民个人：属人原则 → 境内＋境外全部所得交税
- 非居民个人：属地原则 → 仅中国境内所得交税

**【空心方块】讲授者特别举例**
- 外国歌星在中国住满183天 → 居民个人，境外租金也要交税（有优惠但不改变定性）
- 中国人卖房移民美国，当年不足183天且无住所 → 非居民个人，但受雇中国公司远程办公取得的工资因来源于境内仍需交税

> 【注释】与**国际税法**中的税收管辖权概念相通，法考中属于国际经济法范畴，此处仅作联想。


### 二、综合所得（居民个人核心税目）

**【实心方块】四大类项目**
1. 工资薪金
2. 劳务报酬
3. 稿酬
4. 特许权使用费（知识产权相关）

**【实心方块】计税规则**
- 一年合并计税，3%~45%超额累进
- 最高档：超过96万元部分 → 45%

**【空心方块】应纳税所得额计算五步**
1. **实际收入→收入额**（各项目比例不同）
   - 工资：100%
   - 劳务报酬：80%
   - 特许权使用费：80%
   - 稿酬：56%（80%×70%）
2. **减除费用**：每月5000/每年60000（2018年提高后的标准）
3. **专项扣除**：社保、公积金
4. **专项附加扣除**：赡养老人、子女教育、住房贷款利息/租金、大病医疗、继续教育
   - **讲授者提示**：法考通过后取得证书，次年可扣3600元/年
5. **其他扣除**（公益性捐赠等）
→ 得出应纳税所得额，按税率计算

**【空心方块】预扣预缴与汇算清缴**
- 平时预交，次年3月1日~6月30日汇算清缴，多退少补
- 讲授者警告：不可耍心眼，个税APP记录所有收入，该补不补有罚款滞纳金

**【例题1】斜杠青年王母**：预交15万，应缴25万 → 补10万
**【例题2】自由职业者李某**：预交17万，应缴10万 → 退7万


### 三、非居民个人

- 无综合所得，无汇算清缴，一次一清


### 四、代扣代缴

- 单位代扣代缴，可获2%手续费

### 六、个税税收优惠（考试重点）

**【实心方块】减征——口诀“残孤烈灾减个税”**
- 残疾人、孤老、烈属、严重自然灾害地区
- 与企税联动：残疾人工资企税加计扣除，残疾员工本人个税减征

**【实心方块】免征——口诀“特奖国债救济款”**
- **特奖**：省部军级以上单位及外国政府/国际组织颁发的科教文卫体环奖金（发奖机关级别必须高）
- **国债**：利息
- **救济款**：保险赔款、抚恤金等（用生命健康换来的钱）

**【例题3】外卖小哥**：市政府奖2万❌，公司奖1万❌；体育总局奖全红婵2万✅
**【例题4】奥运冠军**：体育总局发奖金✅，红旗公司奖汽车❌


### 七、纳税申报与反避税

- 主动申报情形：现金收入、两处以上收入、境外所得、需汇算清缴
- 反避税：关联交易不符合独立交易原则、低税率地区无合理经营需要 → 税务机关有权调整
- 例：控股股东不分红而由公司为其购房购车 → 视同分红缴20%个税


### 八、税收征收管理法（程序税，相对弱化）

**【实心方块】考点一：税务登记**
- 开业、变更、注销登记
- **外出经营登记**：在异地经营累计超过180天，应在当地办理税务登记

**【空心方块】考点二：税款征收**
- **延期缴纳**：因不可抗力或确实没钱（发完工资社保后无钱交税）可申请，**仅适用于纳税人，不适用于扣缴义务人**
- **核定征收**（对查账征收的补充）：
  - 适用情形：①无账可用或账不完善；②未按时申报，经责令限期申报仍不报；③计税依据明显偏低且解释不通
  - 后两种有前置程序（责令申报/要求解释）
- **税收调整**：违反独立交易原则可调整

**【实心方块】考点三：税款征收保障制度**
- **代位权、撤销权**：税务机关类比债权人，可代位追索或撤销损害税收的财产转让行为（与民法相同）
- **税收优先权**：
  - 税 > 罚款、罚金、普通债权
  - 税与有担保债权 → 按**发生时间先后**排队，无固定优先顺序
- **离境清税**：未结清且不提供担保 → 税务机关通知出入境管理部门阻止出境

**【空心方块】考点四：追征期限**
| 原因 | 期限 | 后果 |
|---|---|---|
| 税务机关算错 | 3年内 | 只补不罚（无滞纳金） |
| 纳税人算错 | 3年（10万以上可延至5年） | 补＋滞纳金 |
| 偷逃骗税（恶意） | 无限期 | 补＋滞纳金 |

规律：纳税人自己问题→又补又罚；税务机关问题→只补不罚。

**【实心方块】考点五：税收保全 vs 强制执行（高频对比）**
| 对比项 | 税收保全 | 强制执行 |
|---|---|---|
| 适用时间 | 纳税期**前**（预防） | 纳税期**后**（处罚） |
| 性质 | 预防措施 | 惩罚措施 |
| 适用对象 | 生产经营纳税人 | 所有欠税纳税人（含扣缴义务人） |
| 前置程序 | 限期缴纳 → 发现转移财产 → 要求担保 → 不提供担保 | 限期缴纳 → 仍不缴纳 |
| 审批 | 税务局长审批 | 税务局长审批 |
| 措施 | 查封、扣押（金额相当） | 划拨存款、拍卖变卖财产 |
| 生活必需品 | 不得保全/执行（唯一住房若为豪华别墅可置换后执行，古玩字画、机动车等非必需品可执行） |

**【空心方块】考点六：纳税争议与处罚争议**
- **纳税争议**（该不该交、交多少、何时交）：先交税 → 复议前置 → 不服再诉讼
  - 全经济法复议前置仅两处：①经营者集中禁止/附条件批准；②纳税争议
- **处罚争议**（保全、强制执行、滞纳金等）：可复议也可诉讼，无前置


### 九、审计法（每年一题，重点突出）

**【空心方块】审计机关**
- 国务院设审计署，总理领导，横纵交织管理

**【实心方块】审计职责——两个字“国资”**
- 与国钱相关：政府预算、财政拨款、政府投资、国企投资等
- 专项审计调查、风险隐患通报
- **审计管辖**：按财政财务隶属关系或国资管理关系确定管辖；有争议协商不成 → 上级指定

**【实心方块】审计权限（每年必考）**
- **查询账户**：可查被审计单位账户，也可查必要个人账户
- **资料保全**：发现销毁/篡改资料可制止，情节严重可封存
- **冻结存款（高频）** ：审计机关**不能自行冻结**，必须**申请人民法院**冻结
  - 对比：税务机关可自行冻结（税务机关负责收税，需要武器；审计机关只负责查账监督，动手需找法院）
- **纠正措施**：发现问题要求纠正，建议有关部门协同

**【空心方块】审计程序**
1. 预通知：一般提前3天；特殊情况可不通知（县级以上审计机关负责人批准）
2. 审计组调查（查询、保全，冻结需法院）
3. 审计组出具**审计组审计报告**（工作结论，非正式文件） → 与被审计对象沟通，听取书面意见
4. 将报告＋书面意见报送审计机关
5. 审计机关出具**审计机关的审计报告**（正式公文）
6. 需处理则出具**审计决定**（**送达生效**）
7. 审计决定有错：上级可撤销或责令自行改正

**【实心方块】审计法总结图（讲稿第323页）**
> 国资定范围 → 预通知（特殊情况可突击）→ 调查（查询、保全、冻结需法院）→ 审计组报告沟通 → 报送审计机关 → 审计报告/决定（送达生效）→ 纠正错误

### 切片1：个人所得税导言
最后回到第四节的个人所得税，它关乎每个人的切身利益。咱们怎么缴个税、交多少呢？宏观逻辑跟企业所得税类似，也是两个板块。一个呢先把纳税个人分成了居民和非居民。

### 切片2：居民个人与非居民个人的认定标准
居民个人和非居民个人的分类标准有两个：第一个是住所——在中国境内有没有“家”？如果有住所，直接认定为居民个人。如果没有住所，则看一个纳税年度内的累计居住时间——是否达到183天【修正“一八三天”】。这两个标准是“或者”的关系：要么有住所，要么居住时间够183天，或者两个都够，都能认定为居民个人。以居民个人出现之后，属人原则：境内加境外全部收入向中国交个税。注意：区分标准不要求国籍是中国人，看的是住所和居住时间。

### 切片3：举例——外国人成为居民个人
比如有个歌星是外国人（比如布朗），在中国开巡回演唱会，2024年度累计居住了200天。虽然他是外国人，但算居民个人。他在中国演唱会的收入要交个税，在国外房子的租金也要交个税。很多同学容易拧巴——外国人来自国外的收入要不要向中国交税？再次强调：纳税跟国籍无关，跟身份属性相关。既然够183天是居民个人，无论收入来自哪里都要向中国交个税，只不过有些优惠而已。

### 切片4：举例——中国人成为非居民个人
反过来，有没有可能既无境内住所、居住时间也不够183天？比如中国人张三，2024年2月变卖境内所有资产（意味着没有境内住所），举家移民美国再也没回来。2024年他在中国只有一个多月，无住所且不够183天 → 非居民个人。属地原则：仅来源于中国境内的收入需要交税。比如他受雇于中国甲公司，人在美国远程办公，中国公司给他发10万工资，这部分来自中国境内的收入要交个税。

### 切片5：综合所得的四大类
区分完居民和非居民后，纳税规则不同。居民个人在个税法改革后有“综合所得”的概念，包括四大类：①工资薪金 ②劳务报酬 ③稿酬 ④特许权使用费（知识产权相关，如专利许可费、剧本许可费等）。综合所得纳税的基本规则：一年合并计税，四项收入打包为总数，按3%~45%超额累进分段计税。最高档：超过96万的部分适用45%税率【修正“九十六万”】。

### 切片6：应纳税所得额的计算——收入额
四项实际收入先算“收入额”（个税法专用概念）：
- 工资：100%计入收入额
- 劳务报酬：扣除20%成本，80%计入收入额（1万劳务按8000交税）
- 特许权使用费：同上，80%计入收入额（1万特许权费按8000交税）
- 稿酬：先扣20%成本，再打7折优惠 → 56%计入收入额（1万稿酬按5600交税）

### 切片7：减除费用（基本扣除）
收入额之后减除“费用”：每月5000元/每年60000元（2018年个税法改革提高后的标准）【修正“一八年”】。工薪阶层按月扣5000，自由职业者按年扣6万，总数相同。如果工资连5000都不够，直接不用交税——“不配交税”其实是收入低的体现。

### 切片8：专项扣除与专项附加扣除
**专项扣除**（法定扣除）：社保和公积金——个人缴纳的部分在税前扣除。
**专项附加扣除**：赡养老人、子女教育、住房贷款利息/住房租金、大病医疗、继续教育。这些方面的支出可以定量扣除（具体扣多少不用背，是会计的活）。

### 切片9：继续教育附加扣除的实操提示
跟每位同学有关的是：法考通过后取得证书，在次年计算个税时，继续教育附加扣除中可扣减3600元。“蚊子苍蝇都是肉”，别忘申报。

### 切片10：汇算清缴——多退少补
综合所得是一年合并计算，但财政需要现金流，所以平时每月/每次先预交，年底算总账，多退少补——这叫“汇算清缴”。办理时间为次年3月1日至6月30日。单位作为扣缴义务人会帮员工做扣缴。

### 切片11：汇算清缴例题1——补税情形
一专多能的斜杠青年（如高校老师同时兼职律师、写书、有专利），各项收入单独看都不高，预交税率不高，但合并后总额大、税率档次高。比如王母全年预交15万，但按合并总收入计算应缴25万 → 汇算清缴补税10万。

### 切片12：汇算清缴例题2——退税情形
自由职业者李某，2024年4月一次性取得高额劳务报酬，预交17万个税，但全年仅此一笔收入，年度汇算应缴10万 → 汇算清缴退税7万。

### 切片13：汇算清缴的实操警告
不要想“该补税就不做汇算清缴”来耍心眼——个人所得税APP里每一笔收入都有记录，该补不补会有罚款和滞纳金。“纳税是天朝子民无上的荣耀。”

### 切片14：非居民个人与代扣代缴
**非居民个人**：无综合所得、无汇算清缴，一次一清。
**代扣代缴**：单位代员工统一交税，简化税务机关工作。扣缴义务人可取得2%手续费。

### 切片15：其他所得类型税率
- 经营所得（个体工商户等）：5%~35%超额累进
- 股息红利、偶然所得（彩票）、财产租赁、财产转让：20%比例税率

### 切片16：税收优惠——减征“残孤烈灾减个税”
**减征范围**——口诀“残孤烈灾减个税”：
- 残：残疾人
- 孤：孤老
- 烈：烈属
- 灾：严重自然灾害地区
与企税联动：白象公司残疾人工资在企税中加计扣除；残疾员工本人的工资在个税中减征。

### 切片17：税收优惠——免征“特奖国债救济款”
**免征范围**——口诀“特奖国债救济款”（免交个税）：
- **特奖**：省部军级以上单位及外国政府/国际组织颁发的科教文卫体环等方面的奖金（发奖机关级别必须高）
- **国债**：国债利息
- **救济款**：保险赔款、救济金、抚恤金（用生命健康换来的钱，不征税）

### 切片18：特奖的例题辨析
杭州外卖小哥见义勇为：杭州市政府奖2万 ❌（不够省部军级）；外卖公司奖1万 ❌。对比：体育总局奖全红婵2万 ✅（部委级）。奥运冠军：体育总局发奖金 ✅；红旗公司奖励汽车 ❌（公司不是发奖机关）。

### 切片19：纳税申报与反避税条款
**纳税申报**：税务机关已掌握的收入由单位代扣代缴；现金收入、两处以上收入、境外所得、需汇算清缴的需主动申报。
**反避税条款（纳税调整）**：关联方交易不符合独立交易原则、将企业设在低税率地区无合理经营需要等，税务机关有权调整。例：控股股东不分红而由公司为其购房购车 → 视同分红，按价格缴纳20%个税。税是红线，不能触碰。

### 切片20：税收征收管理法——税务登记
税收征管法相对弱一些。税务登记：开业要登记，现几证合一较快捷。变更和注销登记同理。特别注意外出经营：在异地经营累计超过180天，应在当地办理税务登记。

### 切片21：税款征收——核定征收与延期缴纳
**延期缴纳**：因不可抗力或确实没钱（发完工资社保后无钱交税）可申请，**只适用于纳税人，不适用于扣缴义务人**。
**核定征收**（对“查账征收”的补充）：无账可用、账目不完善、被责令申报仍不申报、计税依据明显偏低且解释不通等情况适用。有前置程序：责令申报/要求解释→仍不能→核定征收。

### 切片22：税款征收保障制度——代位权、撤销权、税收优先权、离境清税
- **代位权/撤销权**：税务机关类比债权人，税类比债权。纳税人怠于追索欠款或无偿转让财产损害税收安全的，税务机关可代位追索或撤销转让行为。
- **税收优先权**：税优先于罚款罚金、普通债权；税与有担保债权按发生时间先后排队，无固定优先顺序。
- **离境清税**：未结清税款且不提供担保 → 税务机关通知出入境管理部门阻止出境。

### 切片23：税款追征期限
- **税务机关原因**（算错）：3年内补缴，无滞纳金
- **纳税人原因**（算错）：3年内补缴＋滞纳金；10万元以上可延至5年
- **偷逃骗税**（恶意）：无限期追征
规律：纳税人自己的问题→又补又罚；税务机关的问题→只补不罚。

### 切片24：税收保全与强制执行
**税收保全**（纳税期前，预防措施）：
- 发现纳税人有逃税嫌疑 → 限期缴纳 → 限期内转移财产 → 要求提供担保 → 不提供担保经局长审批 → 查封扣押（金额相当）
- 到期缴税→解除保全；到期不缴→转为强制执行

**强制执行**（纳税期后，处罚性质）：
- 未按时交税 → 限期缴纳 → 不交经局长审批 → 划拨银行存款或拍卖查封财产

**共同限制**：本人及所扶养家属生活必需物品不适用（唯一住房若为豪华别墅可置换后执行；古玩字画、机动车等非必需品可执行）。

### 切片25：纳税争议与处罚争议
**纳税争议**（该不该交、交多少、何时交）→ 先交税 → 行政复议前置 → 不服再诉讼。全经济法有两个复议前置：①经营者集中禁止/附条件批准；②纳税争议。
**处罚争议**（保全、强制执行、滞纳金等）→ 可复议也可诉讼，无前置要求。

### 切片26：审计法——审计机关、审计职责、审计权限与程序
**审计机关**：国务院设审计署，在总理领导下，横纵交织管理。

**审计职责**：用“国资”二字概括——凡是与国家钱相关的地方皆可审计（预算、财政拨款、政府投资、国企投资等）。**专项审计调查、风险隐患通报**。**审计管辖**：按财政财务隶属关系或国资管理关系确定；有争议协商不成 → 上级指定。

**审计权限（考试重点）**：
- 查询账户：可查被审计单位账户，也可查必要个人账户
- 资料保全：发现销毁/篡改资料可制止，情节严重可封存
- **冻结存款（高频考点）** ：审计机关需冻结存款时，必须申请人民法院冻结，不能自行冻结。——与税务机关可自行冻结对比（税务机关负责收税需要武器；审计机关只负责查账监督，需动手的找法院）
- 纠正措施：发现问题要求纠正，建议有关部门协同

**审计程序**：
- 预通知：一般提前3天；特殊情况可突击审计（县级以上审计机关负责人批准）
- 审计组出审计报告（工作结论，非正式文件）→ 与被审计对象沟通并听取书面意见 → 报送审计机关 → 审计机关出审计报告 → 需处理则出审计决定（**送达生效**）
- 审计决定有错：上级可直接撤销或责令自行改正

**审计法总结**：能审的范围用“国资”锁定；流程：预通知/突击→调查（查询、保全、冻结需法院）→报告→决定送达生效→发现错误纠正。一年一个题，在这能拿分。
