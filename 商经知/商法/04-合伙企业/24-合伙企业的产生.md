# 一、讲稿知识点的提纲

## 【第一部分】合伙企业法的总体定位与宏观框架

### 1.1 合伙企业法的考试地位

- 合伙企业法在商主体法中排第二，但考察分值远低于公司法
- 基本在客观题中考查，约3-5题，5分左右
- 考点集中、重点明确、难度较低
- 可以与公司法进行对比学习，形成映射关系

### 1.2 合伙企业的宏观逻辑框架（产生—运行—变更—消亡）

> 📌 **注释**：讲授者将合伙企业视为有“生命”的主体，按照生命轨迹搭建学习逻辑。

- **产生环节**：需要“人”（合伙人）、“钱”（出资）、“文件”（合伙协议）
- **运行环节**：事务执行规则、与第三人的关系、债务清偿
- **变更环节**：人的进出（入伙、退伙）、份额结构调整
- **消亡环节**：解散—清算—注销

### 1.3 各环节重要程度分布（与公司法的对比）

| | 公司法 | 合伙企业法 |
|---|---|---|
| 产生 | 重要 | 不重要 |
| 运行 | 重要 | **最重要（波峰）** |
| 变更 | 重要 | **最重要（波峰）** |
| 消亡 | 重要 | 不重要 |

> 📌 **注释**：合伙企业法的**核心考点集中在“运行”和“变更”两个环节**，需重点准备。


## 【第二部分】合伙企业概述（第一节）

### 2.1 合伙企业的概念与分类

**法律依据**：《合伙企业法》第2条规定，合伙企业是指自然人、法人和其他组织依照本法在中国境内设立的普通合伙企业和有限合伙企业。

- **普通合伙企业**：由普通合伙人组成，合伙人对合伙企业债务承担**无限连带责任**
- **有限合伙企业**：由普通合伙人和有限合伙人组成，普通合伙人承担无限连带责任，有限合伙人**以其认缴的出资额为限**承担责任

### 2.2 普通合伙企业的核心特征——“四共”

> 📌 **注释**：四共 = 共同出资 + 共同经营 + 共享利润 + 共担风险

| 对比维度 | 公司 | 普通合伙企业 |
|---|---|---|
| 法律人格 | 独立法人 | 非法人组织 |
| 责任形式 | 股东有限责任 | 普通合伙人**无限连带责任** |
| 决策机制 | 按出资比例 | **一人一票**（看人头） |

### 2.3 有限合伙企业的核心特征——“两合”

> 📌 **注释**：两合 = 普通合伙人（无限连带）+ 有限合伙人（有限责任），两者缺一不可。

- 至少应有一个普通合伙人（GP）
- 至少应有一个有限合伙人（LP）
- 合伙人总人数不超过50人

### 2.4 特殊的普通合伙企业

**适用主体**：以专业知识和专门技能为客户提供有偿服务的专业服务机构，如**律师事务所、会计师事务所、破产清算事务所**等。

**核心规则**（《合伙企业法》第57条）：

- **普通债务**（如房租、水电、工资）：全体合伙人承担无限连带责任
- **特殊债务**（因一个或数个合伙人的**故意或重大过失**造成）：
  - 过错合伙人承担**无限连带责任**
  - 其他合伙人**仅以在合伙企业中的财产份额为限**承担责任（防火墙）

**例题**（讲授者原例）：
> 兴民商场律师事务所是一家采取特殊普通合伙企业设立的律师事务所。曾军、郭昌是其中两名合伙人。一次曾军主办、郭昌辅办的诉讼代理业务中，因二人的重大过失而泄露客户商业秘密，导致该所对客户应承担巨额赔偿责任。
>
> 问：以下说法正确的是？
> - A. 客户可向该所主张全部赔偿责任 ✅（律师事务所是直接债务人）
> - B. 客户可向曾军主张无限连带责任 ✅（曾军是过错合伙人）
> - C. 客户可向郭昌主张补充赔偿责任 ❌（郭昌也是过错方，应承担无限连带，不是补充责任）
> - D. 客户可向该所其他合伙人主张连带责任 ❌（其他合伙人有防火墙）

**职业风险基金**：可通过购买保险等方式化解个人承担过重责任的风险。


## 【第三部分】合伙财产与税收

### 3.1 合伙财产的性质

- 合伙企业是**非法人组织**，**没有独立法人资格**，**没有独立财产**
- 合伙企业账面上的财产**不属于合伙企业所有**，而属于**合伙人共有**
- 共有性质为**共同共有**

### 3.2 合伙企业的税收——“单层纳税机制”

**法律依据**：《合伙企业法》第6条规定，合伙企业的生产经营所得和其他所得，由合伙人分别缴纳所得税。

| | 公司（双层纳税） | 合伙企业（单层纳税） |
|---|---|---|
| 第一层 | 企业交25%企业所得税 | **不交企业所得税** |
| 第二层 | 股东再交所得税 | 合伙人直接交所得税 |

> 📌 **注释**：这正是合伙企业存在的核心价值——省去25%的企业所得税，这也是投资者甘愿承担无限连带责任的重要原因。


## 【第四部分】合伙企业的产生（设立）

### 4.1 “人”——合伙人资格

**（一）普通合伙人 vs 有限合伙人——行为能力要求**

| | 普通合伙人 | 有限合伙人 |
|---|---|---|
| 自然人担任 | **需要完全民事行为能力** | **不要求行为能力** |
| 理由 | 需参与经营、承担无限连带责任 | 仅为财务投资者，不参与经营 |

> 📌 **注释**：无民事行为能力人或限制民事行为能力人（如“小疯子、小啥子、小孩”）可以做有限合伙人，但不能做普通合伙人。

**（二）普通合伙人的禁止主体——“两国两公以上市”**

**法律依据**：《合伙企业法》第3条规定，国有独资公司、国有企业、上市公司以及公益性的事业单位、社会团体不得成为普通合伙人。

> 📌 **注释**：“两国”= 国有企业 + 国有独资公司；“两公”= 公益性的事业单位 + 社会团体；“以上市”= 上市公司。

**立法理由**：这些主体背后代表国家利益、社会公共利益或公众投资者利益，不宜承担无限连带责任，以防国有资产流失、公共利益受损。

**例题**（讲授者原例）：
> 张某、甲（上市公司）、乙（普通公司）三人一起设立合伙企业。
>
> **分析思路**：
> 1. 甲是上市公司 → 不能做普通合伙人 → 甲只能是**有限合伙人**
> 2. 既然存在有限合伙人 → 该合伙企业只能是**有限合伙企业**
> 3. 乙是普通公司 → 做普通合伙人或有限合伙人均可（无限制）

### 4.2 “钱”——出资

**（一）普通合伙人的出资**

> 📌 **注释**：因普通合伙人承担无限连带责任，出资多少、形式如何都不重要——无论财产在合伙企业还是合伙人手里，最终都要拿来还债。

- **无任何要求**：形式无要求、数量无要求、认缴实缴无要求
- 非货币出资（所有权或使用权）需全体合伙人协商定价或第三方评估
- **可以用劳务出资**（《合伙企业法》第16条）

**（二）有限合伙人的出资**

- 承担有限责任 → 出资是债权人受偿的物质保障
- **不得以劳务出资**
- 可用货币或其他可变现执行的非货币财产出资

**例题**（讲授者原例）：
> 张某、甲（上市公司）、乙（普通公司）设立有限合伙企业。合伙协议约定：甲向合伙企业派10名员工过来干活，不领工资，用10名员工的劳动折抵甲对合伙企业的出资。问：该约定是否有效？
>
> **结论**：**无效**。甲是上市公司 → 只能是有限合伙人 → 有限合伙人**不得以劳务出资** → 约定违法。

### 4.3 “文件”——合伙协议

**法律依据**：《合伙企业法》第19条：

- **生效**：经全体合伙人签名、盖章后生效
- **修改/补充**：应当经全体合伙人一致同意；但合伙协议另有约定的除外
- 登记仅具对抗效力，不影响生效

> 📌 **注释**：合伙企业法对合伙人的自治授权比公司法对章程的授权更为宽泛。

**名称要求**（《合伙企业法》第15条）：
- 普通合伙企业：标明“普通合伙”字样
- 特殊普通合伙企业：标明“特殊普通合伙企业”字样
- 有限合伙企业：标明“有限合伙”字样
