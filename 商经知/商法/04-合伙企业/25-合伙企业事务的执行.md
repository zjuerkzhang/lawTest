# 合伙企业事务执行——讲稿整理


## 第一部分：讲稿知识点的提纲

### 一、总体框架：有限合伙企业中事务执行权的分配

**1. 基本逻辑：权责匹配**

有限合伙企业由普通合伙人（负无限连带责任）和有限合伙人（负有限责任）组成。连带责任更重，因此管家大权（代表合伙企业签合同、执行事务）应交由责任更重的普通合伙人执行，而非责任更轻的有限合伙人。

> **结论**：有限合伙企业由普通合伙人执行合伙事务，有限合伙人不执行合伙事务、不对外代表合伙企业。

**2. 学习策略**

有限合伙企业中事务由普通合伙人执行，因此执行规则与普通合伙企业相同。本部分以普通合伙企业为立足点展开。

> **注释**：讲授者在此处将普通合伙人与公司的“股东会—董事会—高管”结构进行了类比——执行事务合伙人≈董事/高管，非执行事务合伙人≈股东。此为理解性类比，便于非科班学员建立认知框架，但两者法律性质有本质区别。


### 二、考点一：合伙事务执行

**（一）底层逻辑：普通合伙人的同等事务执行权**

每一位普通合伙人均承担无限连带责任，身份地位相同，因此**每一位普通合伙人对执行合伙事务享有同等的权利**——不论财产份额大小。

> **例题1（讲授者自编）** ：甲、乙、丙、丁四人成立普通合伙企业卖水果。协议约定由丙、丁执行事务，甲、乙不执行。问：该约定是否合法？
>
> **分析**：合法。全体合伙人协商一致，可以将事务执行权委托给一个或数个合伙人。甲、乙并非被“剥夺”权利，而是自愿将执行权委托给丙、丁，形成委托关系。

**（二）执行人与非执行人的划分**

1. **执行事务合伙人（执行人）**
   - 类比：公司中的董事、高管
   - 定位：受托执行事务，在被授权范围内行事
   - 义务：照章办事、勤勉尽责

2. **非执行事务合伙人（非执行人）**
   - 类比：公司中的股东（背后的投资人/金主）
   - 定位：不执行事务，保留监督权
   - 权利：监督执行、查阅账簿、撤销委托

3. **共同身份**：无论执行人还是非执行人，都是普通合伙人——先有普通合伙人身份，才有执行权，才可能通过约定委托给他人。

**（三）越权执行的规则——“内外分开”原则**

> **核心规则**：合伙企业对合伙人执行合伙事务以及对外代表合伙企业权利的限制，不得对抗善意第三人。

> **例题2（讲授者自编）** ：甲、乙为普通合伙人，协议约定由甲、乙共同执行事务，且单笔合同金额不得超过20万元。乙擅自单独与A公司签订30万元合同。问：合同是否有效？
>
> **分析**：有效。乙虽违反内部协议越权，但A公司作为善意相对人无从知晓内部限制，应受保护。外部合同有效；内部可向乙追责。

**（四）异议权（★★★★★高频考点）**

1. **异议主体：只有执行事务合伙人享有异议权**

   - 非执行人不了解具体业务，提不出有效异议
   - 执行人之间相互监督，有能力和机会发现问题

   > **法条依据**：《合伙企业法》第29条——“合伙人分别执行合伙事务的，执行事务合伙人可以对其他合伙人执行的事务提出异议。”

2. **异议程序（内部流程）**

   （1）提出异议 → 应当**暂停**该项事务的执行

   （2）**单挑**：异议方与被异议方沟通协商
   - 如达成合意 → 按合意纠正或终止
   - 如无法达成合意 → 进入下一步

   （3）**群殴**：召开合伙人会议
   - 过半数合伙人支持哪方，按哪方意见执行

3. **内外分开（重要）**

   如果合同已经对外签订，内部异议**不能当然影响外部合同的效力**。内部追责与外部合同效力分开处理。

   > **命题提示**：讲授者明确表示“每年考题里边一两个选项，总之是有的”。

**（五）非执行人的权利与义务**

1. **三项权利**
   - 监督权：监督执行事务合伙人的执行情况
   - 查账权：有权查阅合伙企业会计账簿等财务资料
   - 撤销委托权：可以决定撤销对执行事务合伙人的委托

2. **一项义务**
   - 按约定不执行事务，不得擅自介入
   - 若越权执行 → 内外分开，外部合同有效（相对方善意），内部追责

> **例题3（讲授者自编）** ：甲为非执行事务合伙人，趁乙、丙（执行人）不在，代表合伙企业与B公司签订合同。B公司不知内部约定。问：合同是否有效？
>
> **分析**：有效。甲越权执行，但B为善意相对方，合同有效。内部可向甲追责。


### 三、考点二：第三人经营管理（聘任经营管理人员）

**（一）聘任程序**

聘任合伙人以外的人担任经营管理人员（如店长、总经理），须经**全体合伙人一致同意**。

> **注释**：一致同意包括明示同意和默示同意（知情且不反对即推知同意）。

**（二）法律关系**

- 类比：公司中的总经理
- 性质：委托代理关系
- 授权范围内行事，越权则内外分开

> **法条依据**：《合伙企业法》第35条——“被聘任的合伙企业的经营管理人员应当在合伙企业授权范围内履行职务。超越授权范围履行职务，或者在履行职务过程中因故意或者重大过失给合伙企业造成损失的，依法承担赔偿责任。”


### 四、考点三：经营决策机制（事务决议机制）

**（一）一般决议规则**

- **有约定**：按合伙协议约定的表决办法
- **无约定**：**一人一票** + **全体合伙人过半数**通过

> **注释**：一人一票是合伙企业“人合性”的体现——不论出资多少，每人一票。与公司的“资本多数决”（按出资比例表决）不同。

**（二）特别决议事项——一致同意（★★★★★高频考点）**

讲授者归纳为 **“三三一”结构**：

| 类别 | 具体事项 | 法条依据 |
|------|---------|---------|
| **属性（三）** | 改变合伙企业名称 |  |
| | 改变经营范围 |  |
| | 改变主要经营场所的地点 |  |
| **资产（三）** | 处分合伙企业的不动产 |  |
| | 转让或处分知识产权和其他财产权利 |  |
| | 以合伙企业名义为他人提供担保 |  |
| **人事（一）** | 聘任合伙人以外的人担任经营管理人员 |  |

> **记忆口诀**：改名改地改范围，卖房卖地卖专利，担保请人（店长）。

> **例题4（讲授者自编）** ：张三被聘为水果店店长（经营管理人员），做了以下事情：（A）调整水果摆放布局；（B）招聘两名销售人员；（C）向第三方借款；（D）用水果店店面做抵押借款。问：哪些需要全体合伙人一致同意？
>
> **分析**：D需要一致同意（处分不动产）。A、B、C属于一般经营事项，在授权范围内可自行决定。


### 五、考点四：竞业禁止与自我交易

**（一）普通合伙人**

| 行为 | 规则 | 法条依据 |
|------|------|---------|
| **竞业禁止** | **绝对禁止**——不得自营或同他人合作经营与本合伙企业相竞争的业务 |  |
| **自我交易** | **相对禁止**——除协议另有约定或经全体合伙人一致同意外，不得同本合伙企业进行交易 |  |

**（二）有限合伙人**

- 有约定按约定
- 无约定时：**无限制**（竞业禁止和自我交易均可为）

> **命题陷阱提示（讲授者特别强调）** ：
>
> 同一选项在不同问法下结论完全不同——
>
> **情形一（协议有约定）** ：协议约定上市公司甲（有限合伙人）不得竞业/不得自我交易 → 约定**有效**（尊重自治）
>
> **情形二（协议无约定）** ：问“甲能否竞业/自我交易” → 法律**允许**（无约定时无障碍）

> **注释**：上市公司不得成为普通合伙人，因此在本讲所有例题中，上市公司身份自动锁定为有限合伙人。


### 六、考点五：有限合伙人的权利

**（一）知情权（查账权）**

| 主体 | 账簿查阅权限 |
|------|------------|
| 有限公司股东 | 可查阅（不可复制） |
| 股份公司股东 | 需满足持股3%+180天，可查阅 |
| 普通合伙人 | 可查阅 |
| **有限合伙人** | **仅限涉及自身利益的范围**可查阅 |

> **命题陷阱（讲授者特别强调）** ：
>
> - ❌ “甲无权查账”——错误，涉及自身利益时可查
> - ❌ “甲有权查账”——错误，无关自身利益时不可查
>
> **正确表述**：甲对**涉及自身利益**的账簿有权查阅。

**（二）派生诉讼（代表诉讼）**

执行事务合伙人怠于行使权利时，有限合伙人可**以自己的名义**提起诉讼，为合伙企业利益维权。

> **类比**：类似公司股东代表诉讼——均以自己名义作为原告。

**【开场与总领】**

嗯，各位，以后来到我们第三节，一下子跃升到考试的重心，各位要提示重点符号。合伙运行。首先来讲是推动运行的一个结构问题啊，就像公司中会有推动运行的组织机构，这里边呢会有推动合伙企业运行的一个事务执行规则。因为它毕竟是个组织，它也需要落实到有某些人去代表合伙企业对外交易，实施法律行为签合同，对吧？所以呢这样一个代表关系，权限设置等等相关的权利义务也是需要解决的一个问题。

而这个呢，其实从底层逻辑上虽然和公司会有不同，但是有很多很多制度是可以类比使用的。别忘了公司里边花了那么大力气学的内容啊，可以作为一个对比的角度来为合伙企业呢打好基础就可以了。

**【考点一：合伙事务执行——总体逻辑】**

那么首先呢先看看考点一，合伙事务执行。各位咱们先不看书，回到这里思考宏观的一个问题啊。我们讲有限合伙企业里边，至少一个有限合伙人负有限责任，至少一个普通合伙人负连带责任。各位，有限责任吗？连带责任吗？你必然知道连带责任是更重的，而权责利的匹配统一是基本原则吧。那你想在一个有限合伙企业里边，我们会把管家大权——代表合伙签合同、拿钥匙的权利——是交给责任更重的普通合伙人来执行，还是交给责任更轻的有限合伙人来完成？当然是责任越重权利越大吧，道理就在这。

你要是把这么大的权利交给有限合伙人好吗？他随便签合同，随便任意妄为，反正签了合同闯了祸，你们负连带责任，那很可能就会不公平不诚信。所以我们讲啊，把管家大权——签合同、执行事务的权利——交给普通合伙人。前面说了，有限合伙人只是财务投资者，他不代表合伙企业，不执行事务，只投资分红就可以了。体会这一点啊。

所以既然有限合伙企业里边也是有普通合伙人去执行事务，所以这个执行的规则就跟我们普通合伙企业一样。所以这一部分呢，这一考点咱们就以普通合伙企业为立足点展开就可以了啊。那么先做一下我们这个内容的提示。

**【普通合伙人的同等事务执行权】**

那么首先，普通人执行事务又回到底层逻辑。每个普通合伙人大家都是身份地位一样的无限连带责任的承担者。所以每一位普通合伙人都是无限连带责任。那么我们承担责任的时候，权利应该也是同等的——结论：普通人有同等事务执行权。

回到一个故事里啊，比如说咱们有四小只，大家可能都不陌生，是很好的朋友啊。这里边呢有左宁一个，戴鹏一个，亲爱的佳哥一个，还有西西一个。那么咱们四个呢，一定是非常志同道合，彼此信任，过命的交情，咱们才能一起去开合伙企业啊。因为一旦达成一个合伙团队，那真的是你我同生共死的状态啊。所以此时充分的人合性信任基础，咱们搭建了这么一组，开合伙企业卖水果吧，水果店就这么产生了，没有问题啊。

好，那么接下来咱们四个都是普通人，小知的水果店业务如何来执行呢？是不是交给协议来约定啊？可不可以约定，我们谨慎起见，小知每一段生意，每一笔合同，咱们四个人协商一致，共同执行事务可以吧？当然，这样做的好处就是谨慎有余，但是呢弊端就是效率不足呗。你想啊，什么事儿都四个人签合同，四个签字，那哪那么容易凑到一起？尤其是大家彼此上课的时候啊，今天着急签合同，我今天上课手机关了，签不了了，签了也不合适。

那可不可以咱们协商一致，通过协议约定呢？我们每个人单独去执行事务，分别执行，每个人充分信任，分别独立执行，可以没关系啊。

而实务中最多、考试也最常见的一种是，我们通过协议的约定呢，把执行分给不同的角色，把合伙人分成不同的团队。

**【执行人与非执行人的划分——类比公司结构】**

那你比如说，首先呢，左宁就提出来说：“哎呀，我哪有时间去管水果店这些琐碎的事情啊，我这么忙，我要讲课呀，我要出去做公开课呀，我还要回家陪家里人呢。”所以他就以陪伴家人、自己很忙为由，说不能管水果店的业务，那我们都理解他，说没问题，左宁就不用执行了啊。

那李佳一听就疯了，说：“我也很忙的呀，我除了和大家一样的讲课、写书、讲义之外呢，我还要打理我的微博，跟我的微博粉丝们互动啊，对吧？所以我也没有时间管水果店这些琐碎的事务。”说好，你也别执行了吧。

就这样呢，咱们彼此理解的基础上呢，那我们的合伙事务执行就落给了小新和我两个人的身上，咱俩就做这些小知的具体业务了呗。所以这个业务的安排由我和小新来执行，另外两位不执行。请问这个协议是不是咱们大家协商一致的结果？当然。所以既然是协商一致，有没有说，因为这个约定咱们就剥夺了左宁和李佳的事务执行权，因为违法无效，对他们有侵权损害？这些都谈不上，谁也没欺负谁，咱们都是彼此同意的安排结果啊。这点呢首先认定它的合法性。

然后在这个基础上，你理解一下，相不相当于咱们通过这样一个约定和权限分配的方式呢？好比是左宁和李佳，把他们手里执行事务的那份权利委托给了我们俩去执行，其实彼此之间呢形成了一个委托的关系。那这个委托关系呢，你很熟啊，在公司里面是不是也学到过——比如说公司通过股东会决议选出董事，甚至董事会选出高管，给他一定授权，那么这种情况下不是也是形成了委托的关系吗？所以这里是几乎类似的啊。

那就可以把左宁和李佳这两位叫非执行人，就类比于公司中的股东，他们就可以甩手了啊。那以后呢，时不常呢去监督一下我们俩干得好不好，完之后呢听听报告之类的，查查账之类的，也就可以了，他就不用天天去水果店管这些细碎的事务，特别类比于甩了手的股东们，只当背后的那个投资人、那个金主。而咱俩干活的呢，特别类比于公司中的董事和高管，在被授权的范围之内，咱们就开始干这些权限内的事务呀，签合同啊，招人啊，谈判啊等等。从这儿来理解啊，因为你公司学了那么多东西，在这里呢一旦借力过来类比使用，你掌握这里的时候会更省事一点啊。

好，来感受呢，这两个叫执行人，那两个叫非执行人。而执行人呢类比于董事高管的，是受托执行事务的范畴；而非执行人就类比股东、背后金主的范畴啊。而我们要说，别管执行人还是非执行人，他们共同的身份及上位概念都是普通合伙人。因为只有你先是普通合伙人，你才有执行权，你有执行权，你才有可能通过约定而委托给别人，你才成为非执行人吧。这点要先和有限合伙人区分开啊。

好，那这个逻辑出现之后呢，同学你回到我们第九十八页当中，我们来看一下这个小的表格，这个常常被考到啊。

**【执行人的权限与越权规则】**

那么在普通合伙人里边，像刚才说了，基于我们的约定呢，分成执行人一波和非执行人一波两个团队。而两个团队呢分别会有不同的使命或者职权。那么各自会有什么样的权利和义务呢？

先看执行这一波，像他类比公司中的董事和高管。首先基于受托，那么一定是在合伙协议约定的受托范围内，照章办事吧。哎，让你干啥你干啥，让我们签合同，我们签合同吧。那么有基本的命题规则就是：有授权一定有人越权，有要求必定有人不听话。

可以想想越权啊，在公司这边是不是也学过，法定代表人或者某些董事、某些高管超限越权的事儿，这里是类似的哈。你想想，你比如说我们协议约定，由我和小新两个人共同执行事务，并且金额锁定在二十万以内。那么接下来小新就不听话了，擅自没有经过我的同意，没有共同协商，他一个人代表小知对外和A签订一个三十万的合同。各位，严格意义上来讲，他既没和我协商，也超出了协议的金额授权，他是不是超限越权了？没有错。

那么小新越权，可是他违反的是咱们内部的合伙协议的约定，这是个约定限制。而作为相对方呢，A人家有没有义务或者有没有途径知道我们内部的限制？人家没有这样的责任。所以A被推定为善意相对人。那既然A是善意的，就算你小新越权了，也要保护相对方的利益吧，所以合同是有效的，没错。内外分开，反复强调啊。外部呢，相对方善意而合同有效；内部如果确实是有损失，也可以向小新追责就可以了。基本是这样的层次啊。

**【异议权（一）：主体】**

然后呢还有一个很大的问题就是我们的括号二项叫异议权，同学们重点符号，这考的非常非常的多啊。那么这个异议呢两个层面。

首先呢从异议主体上来讲。那么想异议主体的时候吧，咱们要先去看一下到底它的过程是什么样的，什么叫异议、怎么提呢？大家好比这样，你比如说呢我就是代表小知签合同这件事务执行事项哈，这件事儿的事前、事中、事后分分钟钟的，旁边好比一双眼睛，时时刻刻盯着盯着盯着我。然后呢，以及在整个的过程中发现问题、挑出毛病、找出问题。各位，发现问题挑毛病找问题，而且时时刻刻盯着我的事务执行——你来观察一下这种事儿谁有能力做到？

剩下他们仨排查一下啊。左宁有没有这份能力？左宁叫非执行人，他在干嘛呀？他在陪家里人呢，是不是啊？所以呢，这时候呢，他根本就没有介入小知的业务领域里边，他不知道这个合同该怎么签，他没有这个能力，也没有这个经历。那李佳同样的，他在微博打理微博、跟粉丝互动着呢，他哪知道水果店里业务该怎么做呢？那我的合同什么时候签的、怎么签的、该不该签，他根本就提不出问题。

所以结论：只有谁？执行人之间——小新他是有这份能力和机会的，因为他呢也是处于执行序列当中，他在这个生意环境中，他知道小知该不该签那个合同、该怎么签、我签的合不合理、价格合不合适、该不该买等等。这种情况下，他既有能力，也有这个经历，能够看得到这些问题，成为提出异议的主体，对不对？结论：能够有异议权的只有执行人，那么非执行人是没有这份权利的。这考了好多遍啊，你只有理解了你才能真的把它掌握好。

**【异议权（二）：程序】**

那第二讲呢，就是关于异议提出之后的程序如何进行啊。因为毕竟是我执行业务的时候，是由其他合伙人提的异议，各位要注意这是一个内部的流程。那么接下来是有一个内部的处理规则啊。

既然小新提了异议了，各位你一定要注意呢，我们要彼此尊重，千万不能一意孤行。我说你爱提不提吧，我完全不理你，我接着该怎样怎样，那是不可以的啊。所以异议之后呢，应当暂停下来我的业务执行的想法或动作。

那么暂停之后呢，咱们就开始进行单挑。那我和小新就开始彼此说明白：我为什么要这么去做这个想法，甚至推动这项投资；那小新肯定会说他的担忧在哪里，我这样做的不利或者不当性在哪里吧。咱俩先单挑。

那单挑的结果无外乎两个结果吧。要么呢，我就从了吧，我认为小新说的有道理，是我考虑不周了啊。所以一旦形成了合意，我认可了小新的异议之后呢，那我就要改呀，立即马上就把我的方案进行纠正，或者干脆这件事情觉得不能做，咱们就结束吧。这件事儿结束就OK了，没有问题啊。

那么反过来呢，如果不能形成决议，咱俩是死活不让步了。我坚持认为我这么做是有道理的，而小新呢也不能被我说服。这时候呢有了冲突，说明单挑解决不了了，咱俩的智慧已经无法解决这样的重大疑难问题了，那咱们就群殴吧——是把所有的合伙人拉过来，哎呀，咱们应该把左宁、李佳都叫来，你俩别休息了啊。这次呢，我们就会把合伙人们拉过来召开一个合伙人的会议，因为人多了，见仁见智嘛，智慧呢也就更大了，是不是啊？

所以经过我们大家的一致讨论完之后呢，看看相对多数的集体智慧。如果合伙人会议上过半数站我，觉得问题不大，小新小题大做了，我们就会恢复事务执行，按我的想法继续就可以了吧。如果过半数的合伙人的集体智慧站小新，觉得我确实做的不太妥当，考虑不太周到，可能会对合伙企业有损失，那么咱们就按照小新的意见呢，把这件事情纠正或者终止下来就可以了吧。

相当于是我执行的时候，如果有人提出了异议，咱们就应该走这么一个集体决策或者是征求集体智慧的过程。先来单挑，如果有结论就OK了，如果有冲突，我们再群殴——合伙人会议来决策，根据合伙人会议的终极智慧，这是一个过半数决策的过程哈。那看看到底过半数合伙人站哪儿，如果站我呢，就按我的想法恢复执行；如果站小新，按小新的想法纠正或者终止，这件事就结束了。

同学们啊，这是一个异议的流程。

**【异议权（三）：内外分开】**

但是这个流程你冲击量刚才说的是一个内部关系，内部走是可以的。但是你要想啊，有没有可能，我在这件事情的执行过程中，你就走的非常非常靠前的时候，比如说我都已经为了这项投资的业务跟相对方签合同了——注意，有了外部关系就不一样了啊。我以小知的名义和对方签了一个投资合同，到这儿的时候，小新才提出异议了。就算咱们内部流程该怎么走怎么走下去，也没有问题，去讨论也可以。但是要不要因为咱们内部的异议，就说外部的合同就要受到影响、合同就要被解除掉、合同就要终止掉？那可不敢啊，同学们。

因为影响到了外部的相对方，尤其是善意相对人的时候呢，这个合同已经签了，已经生效了，就不能单纯地受到咱们内部异议的一个必然影响，这个效力是不能受影响的啊。那回头就想着，内部异议有什么结论了，那回头这个合同你要认可，接下来需要承担责任的——承担这样一个内外分开就可以了啊。

所以呢，同学说，那如果合同确实是内部异议、确实我失败了、按照小新说应该纠正应该终止，现在来不及了呀。那如果来不及了，合同也履行了，那此时可能会认定我执行事务不当，此时呢，合伙企业承担此合同责任之后呢，可以内部向我追究责任，落实到这个角度也是有可能的啊。

就想说这个异议呢，作为其他的合伙事务执行人，您也要非常非常的敏感且警醒，要提的话要尽快尽早，这样提完之后呢，可能及时止损是更好的。如果提的太晚了，引入第三方利益的时候呢，可能就相对麻烦了一点。这一点呢，希望有一个内外分开的逻辑啊。

关于异议两点：一个是只有执行人才有这份权利；第二提完之后是个内部的处理流程来关注它啊。

**【非执行人的权利与义务】**

后续呢，这个义务就是董事高管的勤勉义务是类似的，咱们就不多说了。

那么回头去看那两个非执行人啊，类似于公司中的股东们。那既然你已经委托给他人去执行事务了，你们就可以享个清闲呀。所以呢保留三项权利：

一为监督，他不会完全放手的，毕竟我们俩再怎么执行，产生的将来的结果还是由他们一起负连带责任的吧，因为他有责任，所以他不会完全放手啊，会有监督。那么想监督的一个核心的工具是什么？是不是查账？说常看到合伙企业来，说看看咱干的好不好呀，把账拿过来捋一捋吧。哎，这个查账执行是一个很重要的监督工具啊。

之后呢，他们可不可以撤销委托？说我们自己拿回去执行权，自己亲自管，自己执行业务。当然，因为委托你知道双方是自由的，你们其他合伙人可以把执行权委托给我们，分分钟你也可以撤销委托自己执行嘛，对吧？所以在这里撤销委托跟公司中的无因解除有点类似，他们是有权利做的啊。

那么义务要观察一下，非执行人是不是要按照协议约定，您不执行事务了，您就享个清闲。如果你非得到合伙企业来掺和，你导致我们无所适从，其实也会对我们的经营造成干扰吧。

考虑一个场景听着啊。那天左宁这个非执行人啊，他就天天的在家陪孩子陪家人啊，他也会有点烦躁了。左宁说：“小知，我来休息一下吧，或者换换环境吧，可以你来玩一下。”没有问题。结果呢左宁在小知来的时候，正好那天呢我和小新都不在店里，哎来客户B准备跟小知谈一个大合同。这时候呢左宁那份主人翁的责任心就被燃起来了啊，他说：“来来来，跟我谈吧。”

那以后呢，人家B又不知道你们内部的一个协议安排、权利分配呀，所以左宁说能代表小知跟他人签，人家就信啊。而且呢左宁长得样子又一副特别忠厚老实可靠的模样，对不对？所以呢关键问题是呢，左宁呢他也能拿出小知的章跟人把这个合同一签，那B自然是可以相信的。

结论：左宁代表小知跟B签合同回来，各位。首先第一层次，左宁什么人？按照咱们协议的安排，他是一个非执行人。请问非执行人还该不该执行事务？不该执行。可是他越权，他执行了，而B是善意相对方。这边是越权的，那边是善意的，那么合同有没有效？当然，内外分开。所以合伙企业先和B的合同签完、履行完成义务。至于内部呢我们再看吧，如果真的有损失，那你可以找左宁的麻烦嘛，内部追责，是不是就可以了？反复反复强调：内外分开四个大字。一旦你核心卡住这个之后，很多内容的理解呢就比较轻松一点了啊。

啊，这个问题呢，我们就看到了。所以稍微总结一下啊：咱们把普通人分成两拨，根据约定来安排委托关系，受托的这一方呢类比董事高管叫执行人，那委托出去的这一方呢类比股东叫非执行人。那么执行人受托执行事务产生的后果，当然大家一起负责啊。如果有越权了，内外分开，认定外部合同行为有效，内部呢我们再有追责。

一个极大的重点叫异议，两个层面：一个是异议主体，只有执行人才有此权利，非执行人是没有的；那么另外一个是程序，它是一个内部的处理规则，对吧？有人提了异议呢，我们就暂停，然后呢先双方再讨。如果呢有合意了最好，没有，那我们就继续多人会议，根据会议结果再出结论。要么呢按照执行方的恢复，要么按照非执行方呢，我们就终止或者是纠正就可以了啊。当然如果真的异议晚了，合同都已经签完了，你才异议，那么内部的异议不能当然影响外部的合同，这时候呢很可能会产生内部对执行人的追责及后果就可以了啊。

义务中勤勉不多说。

那么非执行人呢，三项权利：监督执行、查账、撤销委托，特别好啊。义务呢是按照约定不执行事务，不该执行事务。如果你非的执行了，哎，内外分开，外部的合同是有效的，相对方推定为善意，内部再追责就可以了。

这个比较呢，我之所以会反复一次，是因为它真的很重要啊，几乎每年考题里边一两个选项，总之是有的。

**【考点二：第三人经营管理（总经理）】**

第二个层面呢，叫第三人的经营管理，同学们旁边写上三个字叫总经理。哎，前面说的是股东和董事的类比关系，对吧？这里呢是类比公司中的高管——总经理的关系了啊。

同学想，咱们小知水果店运营当中，我和小新有没有可能也很忙啊？那我们要去暑期面试了呀，我们没有时间管水果店的业务的时候，那怎么办呀？哎，咱们是不是可以请一个店长过来管水果店的具体经营？没问题，就像公司请个总经理一样。

那首先，咱们水果店要请个店长，那一定是深得我们一致的信任，因为我们会把管家大权几乎都交给他的，对吧？所以他来的程序是全体合伙人的一致同意。

注意，这一致同意的事务当中有两种方式啊。一种很明显，那么就是真真正正的明示表示同意，没问题。还有一种可能是推知同意的或者默示同意的啊。你比如说，我和小新两个人就把张三请过来当咱们水果店的店长。同学想啊，只有我们两个合伙人的意见，张三那个店长当没当上？还没有，因为他没有一致同意的保障啊。这时候张三也不知道，就先歇着，不干活。干着活的时候呢，哎，那天呢左宁和李佳这两位大爷也发现了张三的存在，说：“咱们水果店新招一个店长啊？”然后呢我们就说：“啊对对对，是是，稍微介绍一下。”当他俩知道这件事情之后呢，没有反对。各位，成年人的世界，不表态也是一种态度，非常的好啊。那么知情不反对，是不是等于同意？没错。因为他知情没有反对的行为，我们就推知他俩同意了呀。这一刻，张三那个店长当没当上？当成了。因为有我们俩的明示同意，那哥俩的默示同意了，符合了一致同意的要件，他就可以当店长了，是不是？

然后你来分析店长和合伙企业的关系吧，是不是也是我们给他一定的授权？说：“张三呀，一个人决定签五万以内的合同，不用汇报啊。如果超了五万块的还是要慎重一点的，经过我们合伙人会议以后咱们再做。”好，经常会有这样的授权。那么张三本该听话，可是呢，如果他听话，不就没矛盾没题目了吗？之所以有题目有矛盾有纠纷，是因为有授权就必有越权呀。

张三就不听话了，所以擅自代表小知和C签一个十万的合同，超限越权。此时此刻是不是又内外分开？因为你是水果店的店长，C当然有理由相信你能代表水果店跟我签，我就签呀。谁知道你超了内部权限签了呢？所以先把外部的合同认可为有效，内部呢，我们可以对有故意或重大过失的张三来追责，这点的逻辑也是一样的啊。

它完全也是委托代理的法律关系，类比公司中的总经理就完事儿，同学们啊，非常简单。那么从考试中的重点呢，把委托关系呈现，那绝大多数的分数我们就拿到了。那另外就是那个来的路啊，是一致同意才能来，这程序关注一下啊。

**【考点三：经营决策机制（事务决议机制）】**

那第二部分呢，我们就看一下关于合伙的经营决策问题，就是事务决议的机制啊。因为你公司里边也会有那些股东会、董事会的一些决议机制问题吧，这个呢也是通过合伙人会议来呈现的。

那么他会分一般事项决议和特别事项决议啊，其中特别事项决议更重要。那么一般决议呢，首先从机制上应该怎么开会、怎么做表决呢？是看协议的自治，有约定按约定；没有约定，我们更多的是法定的规则。所以法定规则的时候呢，首先我们遵循的是一人一票，人头决议。这前面咱们也解释过了，也是合伙企业之所以能存在的安身立命之根本点之一。所以呢，一人一票的基础上，一般事项咱们要过半数表决通过就算集体智慧。

那同学会问说：“老师，什么叫一般事项需要过半数呢？”我说我不知道。就开始质疑说：“希希老师，天大的脸就说不知道呢？专业性呢？”因为我真的不知道，不是因为我不够专业，是因为真的无穷列举。每个合伙企业的经营事项不一样，那么他的一般事项也是不一样的呀。但是咱们都知道一个相反的概念，叫特别事项。所以呢，不是特别的，剩下就是一般的嘛。哎，从这个层次上呢，反向的论证也是一样的啊。就像咱们有些股东会特别决议的时候不也一样吗？那资本、章程、合并、分立、解散、变更公司形式是大事，是特别事项，三分之二以上特别决议；除这些事儿之外，别的事项就一般事项嘛，所以股东会上过半数嘛，道理是一样的啊。

这里呢，我们也需要重点地把特别一致决议事项要准备和掌握清楚。

那么这个特别事项，咱们分两大类。一类叫经营中的事项——哎，企业开门做生意，在经济环境里边，我们会产生相关的一些重点细节。这个呢，重点符号提示，最后每年都有命题。第二大类是企业整个的生命环节的路程当中，可能运行环节、变更环节也会有一些需要一致同意的具体事项。那个呢，我们现在不要求背，遇到哪个事项时呢，大概能够回忆一下就可以啊。

咱们先从经营期间大事儿说起，同学们啊。经营事项中的期间大事儿呢，这个是劳烦大家背一背的，刚才说了，因为它每年都会有命题，每年都会有考试。背下来之后呢，我们就可以高效地准确做题。

好，看到案例里边有这样一个具体场景嘛，马上能联想，它属于经营事项中的期间大事儿。当然背七个呢有点困难，咱们可以给它合并统一一下，精简一下啊，分成一个三三一的结构。第一个三呢是属性层面，第二个三呢是资产层面，最后一个一呢是人事层面啊。

这样呢，你背七个不好背，背三个就好背了，是不是啊？而且像属性这种的，基本你不用背，题中之意。同学们，任何主体的商业属性都一样——叫名称、地点、经营范围，地点有时候叫住所，其实呢含义一样啊。所以对合伙企业，如果改变它的名称，改变它的地点，改变它的经营范围，自然就属于是一致决议事项了，没有问题。

爱考的重点是中间的资产的三项啊。它呢其实更多涉及到的是合伙企业的一个关乎生死存亡的重大资产的处分行为。那你比如说呢，你卖呀、质押了等等这些事儿。卖什么呢？一类是卖房卖地——这个东西呢一旦卖完，可能合伙就无处安身了啊。再呢，知识产权——像知识产权这类的财产权利，因为知识产权呢好多时候也是企业安身立命的一个根源性的东西吧。那你就随随便便卖掉，那可能也要了合伙的命。还有一个很大的重点是，以合伙企业财产为他人提供担保——这个呢其实从重要程度和危机程度来讲，跟公司一样吧。在公司也学过了，一旦一个组织为别人做担保，好比要了他的命一样。好嘛，担保额度大，死的又快，是不是？好好解释呢，如果你用你的财产为别人提供担保，那一旦对方还不了，你就要被拉入深渊和泥潭了呀。这件事慎重一点啊，经过大家一致同意，咱们再做。

好，这是一个重要的重点。人事呢，刚才说了，是不是请总经理或店长之类的呀？哎，经营管理人员，注意是请经营管理人员啊，是那个头头脑脑们，可不是普通员工。哎，这点还是一个基本的认识。

好，那么有这样一个基本解释之后呢，就能够知道七件经营事项：他们是三个属性、三个资产、一个人事。属性层面是改名、改地、改范围；资产层面是卖房、卖地、卖专利，还有担保；人事层面，请店长。

哎，这样一个基本的，连着我们的逻辑、连着我们的法条制度和实务场景，基本上呢一遍两遍就搞定了啊。像老师让背的，我不会干巴巴让你背。什么叫技术流啊？我总不能说法条就在这儿吧，“叭叭背吧孩子们”——我们很多叫技术流啊。所以呢，就算是需要背的，咱们一定是有一些技巧来帮助大家简化你的这种负担啊。

**【例题：经营事项的识别】**

好，为什么要让背他呢？其实就是为了解决这类问题，经常啊几乎每年都会有所涉及。

说一个水果店，刚才说了啊，咱们不是请张三过来做了店长了吗？给他做了授权，说五万元以内的合同他决定。那张三新官上任啊，就开始大刀阔斧地进行业务改革。他做了这么几件事情，你来判断张三的所作所为是否合法呢？或者他能不能一个人决定做这些事儿呢？

A选项，他上来就改变了一下水果店的这个布置。他说：“你看你们这些合伙人老板们，怎么都没审美呀？你看这大片香蕉挨着榴莲好吗？又串味又串手，所以那一片顾客进来都不去，所以卖的不好。”这样他调了一下——这边是香蕉挨着苹果、挨着葡萄、挨着桃子、挨着西瓜，这边放榴莲。哎，确实呢赏心悦目，给整个耳目一新的感觉啊，销量变好了。请问，身为一个店长，被授权全权处理水果店的经营事项，他能不能调整一下水果店的摆放？当然。

第二呢，他请了两个能说会道、面容姣好的女孩子当销售人员，之后呢确实是推销得更好了，卖的更好了。请了俩员工，可以帮助。当然。

第三呢，他要过节了，就要准备更多的一个库存，这时候呢水果店没那么多现金啊，想由水果店向第三方做一笔借款借钱。请判断，身为一个店长能不能代表水果店向A借钱？那你排查：借钱负债这件事情，是不是改变水果店的名称、地点、经营范围的属性？没有。有没有处分水果店的不动产、卖专利、给别人担保？没有。有没有再请店长？没有。那你排查，他不属于经营其他事项之一，就属于一般事项啊。所以呢，既然是授权执行事务，他们就可以自己做呀，没有特别决议之要求，他就可以做了。A、B、C都是OK的。

D选项听着。这个A身为债权人说：“水果店有借钱给我，可怎么保证还给我呢？”这时候张三就想着用水果店的店面去做抵押，做这笔借款。请判断，张三可不可以用水果店的店面去抵押给别人？这可不行。立马你明白，因为店面是不动产，抵押呢是处分之行为啊，所以相当于处分了不动产啊，看到没有？哎，这种情况属于一致决议法定事项，身为经营管理人员、身为部分个别的合伙事务执行人都不能单独的擅自行为吧？哎，提示到这点就可以了啊。这种题每年都要考上一两个选项，我们准确跳出来就OK了。

当然呢，我们说一致决议的除了经营期间大事重点掌握之外，还会有其他的一些在运行环节下或变更环节下的一些事项啊。这个呢，它要么影响到合伙人的一些人合性啊，要么影响到整个的合伙的结构，可能也比较慎重一些啊。那这部分不用背，因为这么多内容背下来是没有意义的。那我们是学到具体制度的时候呢，会再匹配它就可以了。

你比如说我们前面学过的，像补充修改合伙协议啦，像后续要学到的啊，普通人要自我交易，甚至普通人要把份额进行转让啊、质押以及合伙企业整体的增资减资、合伙人的身份变化等等等等。现在咱们就不都打开它说了，免得你有负担啊。知道除了经营这重大事项要重点掌握背诵的程度之外呢，其他也会有一些需要一致决议事项，因为它就不属于经营事项范围了。我们就是遇到哪个环节下的哪个制度匹配一下就可以了啊。大概是这种关系。

**【综合例题：牛刀小试】**

一起来做一个题，同学们啊。看这个最底下这个牛刀小试，这是一个关于事务执行综合化的一个题目。

要求甲乙丙共同设立一个市风装修工作室，属于普通合伙——知道普通合伙是四共啊，全体合伙人共同出资、共同经营、共享利润、共担风险。那么协议约定由甲执行事务，乙丙不参与合伙事务执行。

暂停，立即马上把合伙人分了两个团队：一个执行人、一个非执行人。立马打一个表格：这个甲身为执行人，可以被授权执行事务。因为他只有一个执行人，别人没有人对他异议的机会吧，所以异议价值是提不到的。那么义务就是勤勉，前面说了。乙和丙的非执行人，他们就可以监督执行、查账，甚至撤销委托。同时，乙丙身为非执行人呢，一定要固守自己的本分，不应该执行事务。如果一旦你越权执行了，咱们就内外分开，外部合同有效，内部追责的逻辑吧。所以看到这个题干，题目里面出现这句话，他只能往这个方向考。这个表格在脑海中要有一个固定的模式啊。

那么工作室经营不善面临困境，丙指定的李——他有一批原材料，对工作室的业务非常重要——但是丁要求预付一百万定金，并知道了一个商业信息。这时候呢，丙就此事项征询乙和甲的意见。乙觉得有利可图、有前景，说可以做，同意了；甲坚决反对。那就说明要不要从丁那儿签订合同买这批材料呢？三个合伙人是有不同意见的。

但是呢你往回推推啊。这个从丁那儿签合同买原材料这件事情，属不属于我们全体合伙人一致同意的期间大事之经营事项？排查一下：属于改变合伙企业的名称、地点、经营范围——三属性？不是。卖房卖地卖专利做担保——资产三方面？不是。是人事？当然不是。那你排查发现，他不是一致决议经营事项，是不是？所以不需要大家一致同意。严格来讲呢，是甲，你作为事务执行人代表合伙说做就做了，是这个问题啊。

那最后呢，丙代表工作室和丁就签了这个合同啊。注意，丙什么人？非执行人。好，说明他不该签，他签了合同。可是呢，案情中有没有说明丁的主观状态如何？应该推定为善意。体现了一个非执行人执行事务的行为后果，对不对？那你知道内外分开了呀，所以外部合同有效，内部对丙追责呗。结论自然，其中有数，然后找到正确的。

哎，乙和丙这两位非执行人可不可以撤销对甲的执行事务的委托？当然，非执行人是委托方嘛，当然可以撤销委托了，是不是？

丙呢，必须经甲乙一致同意，工作室才能跟丁签订这份合同——没有这么严格啊，这属于一般性事项啊，要不要执行人被授权做，要不要被授权的那个总经理、经营管理人员来做？哎，如果需要开会决议的话，那是过半数，那也不需要一致同意啊，所以B是错的。

所以工作室对该份合同事后追认的，该合同有效。那言外之意，如果不追认就无效？没有这说法，不需要你追认，因为丁是善意相对方，所以丙代表工作室和丁签的合同是有效的，没错。我们要保护丁的认知利益和交易秩序的稳定啊。是不是大家想A和D两个？

就这种题就是已经挺难的题了，因为它是多选嘛。你能感受到合伙企业真的很友好，合伙企业法没有纠纷点。同学们，所以咱们只要顺着思路走过来，用两个多小时的时间，这五分——手拿把掐——到我们的手里来是没有任何问题的啊。

**【考点四：竞业禁止与自我交易】**

好，翻过来我们去看一下第三个，关于合伙人的竞业行为及自我交易的限制。这个我们就打开了啊，把有限合伙人拿过来做对比，因为他们俩呢在合伙企业的身份、地位、权利都不一样，所以法律对他们的行为约束也是不一样的。

首先竞业，同学们想，那无外乎就是一个人可以同时两个以上有竞争关系的主体间都有一些瓜葛了不？你想普通人啊，普通人是什么？四共——咱们是生死与共的一个团队、一个整体，密不可分吧。那如果你去随便变得三心二意的，你去别的同业竞争对手那里去投资，都很难相信你能置身中正，你怎么能公平对待我们这个团队跟合伙呢？所以人性不值得考验，法律来禁止它。普通人不能三心二意，必须绝对忠诚。所以结论是：普通人做竞业行为是被绝对禁止的。

而自我交易，同学们啊，这个我们在公司法里面就不断在强化这个问题，无论是说董事高管的自我交易啊、关联交易等等，我们都有提到过。那自我交易无外乎是合伙人跟自己的合伙企业做生意吧，你把你家的产品卖给合伙企业呀，你家的汽车租给合伙企业——都有可能。那自我交易唯一担心的点就是“监守自盗”嘛。可是你也知道，他未必真的可能产生这个不利后果呀，他也可能双方都是很诚信的，那以后呢双方共赢的效果发生也说不定。所以自我交易不是一刀切的被禁止，而是有一个程序的保障——全体合伙人的一致同意。哎，这也算在合伙运行当中需要其他人一致同意的具体事项啊。

那如果现在呢，比如说呢，我准备把我们家的仓库租给咱们水果店里边去当个仓库。那我这个仓库呢质量又很好，价格又很公道，租是不是租啊？我也没有白挣合伙企业的钱呀。这个交易呢其实对双方都不亏。那我征求他们哥仨意见，他们同意我就能做，做了也没有任何的问题。

这样结论：竞业是被绝对禁止的，自我交易呢相对禁止——这是我们对普通人的限制啊。

那么有限人就没所谓了。说白了，有限人跟合伙关系好远好远，十八千里哒。他只是单纯的财务投资啊，他投资分红不管事儿，不代表合伙、不执行事务。那你既然跟合伙没有过多的瓜葛，法律管你干啥？什么竞业了、自我交易了，想做做呗。除非你合伙协议有个细化的特别约定，那就按照你的约定尊重就好了。

所以呢我们对有限人的行为规制：有约看约定，没约定没限制、无障碍，随便做什么——自我交易、竞业行为都是可以的啊。

这样一个小对比，帮大家解决这个问题啊。看到有限合伙人后呢我们就讲：有约定看约定，无约定时无障碍。

好，这个问题呢还是回到会做题上啊。哎，这个制度呢我大概梳理之后，同学们掌握它应该问题不大，甚至背下来都是很轻松的。可是题怎么考呀？你来观察啊。

回到我前面那个题你还记得？有一个张三、一个上市公司甲、一个普通乙公司开合伙企业的故事，对不对？好，那么首先呢从这个层面上你已经明晰呢，这个甲因为是上市公司，所以他的身份只能是有限合伙人。好，没有问题啊。

现在我先做第一个命题角度。听着，这个合伙协议约定了如下事项，请判断是否合法呢？问协议的约定的性质。

A选项，我说这个上市公司甲呀，不能实施竞业行为。B，上市公司甲呢，不能进行自我交易行为。哎，这是我们在协议中的约定事项，判断这两个约定合不合法？

那你看到的思路什么？甲确定是上市公司，只能是有限合伙人，身份锁定。那么有限合伙人出现以后呢，在协议中约定——要求不能竞业。OK不？尊重自治，有约定看约定。B约定不能自我交易，有约定看约定。是不是俩约定都是有效的？哎，做正确的判断啊。

然后看另外一种命题角度了。前期是一模一样的哈，还是那个自然人张三、上市公司甲跟普通的乙公司开合伙企业。A确定了，甲是一个有限合伙人。然后我就说这个合伙企业呢，协议没有特别的约定啊，特别强调了一下，没有特别约定。那怎么依法判断呢？下列表述是否合法，做一个根据法律规定的辨别和判断。一模一样两个选项：A甲不能竞业，B甲不能实施自我交易。

思路是一样的，不着急同学们啊。同样你首先看到的是甲的身份叫有限合伙人，选项里边考到的点是对他的竞业和自我交易两行为规制，对不对？然后你掌握的知识是：对有限人竞业、自我交易，有约定看约定，无约定时无障碍。所以你的认知是无障碍，法律是允许他们做的。而A说不让做竞业——错了；B说呢不让做自我交易——错了。看到了没？

所以他问的角度立足点不一样的，相同的一个选项结论就不一样了。哈，这个问题——同学说：“这不是靠文字游戏吗？”不不不不不，这不叫文字游戏同学们。要重视这种题，在合伙企业法里面特别容易考到这种题，它其实就是个语文逻辑问题。哎，这个内容难吗？本质不难的，可是你一定要把逻辑顺过来，咱们能准确地判断。人家关于约定就尊重自治，如果没有约定呢，就按法律规定来匹配。哎，这样一个点我们就能消化透。

所以这个题会做了，基本上关于有限人的行为规制就不再会出错了，希望大家有代入的感觉啊。

**【考点五：有限合伙人的权利】**

好，这个呢，看第四个板块是关于有限人啊。我们讲，虽然是这个数值，我们更多的是以普通合伙企业普通人的相关权利义务为切入点，但是毕竟呢，整个的合伙企业类别里边不是还有有限合伙企业、有限合伙人吗？所以咱们就做一个插入点，插进里头来啊，知道咱们的一个结构安排。

那么有限人虽然只是财务投资，不代表合伙、不执行事务，但不意味着他什么都不能做。所以呢法律给了他一些可为之事，所谓有可为、有可不为的状态啊。

那么有限人能干什么呢？来看三个大方面啊。

首先一个知情。这里边呢针对的资料不同，其实知情的范围也不一样，类似于像股东知情的范围是不是也不太一样。来交叉一下。在公司当中你比如说有限公司股东啊，如果你是非核心的资料，那想看什么看什么，没问题哈。如果是核心的账簿和凭证的时候呢，咱们讲要满足一些要求——身份要对、要求要对、目的正当，哎限制要高了一点。

那么有限人类似的你来看啊。如果是非核心的，比如说经过审计的财务报告，这玩意几乎是公开的资料，那直接给吧，没问题。

第二个很重要，表示一下啊。那么你要想了解一下有限合伙的账簿，这个呢毕竟承载了企业的秘密，所以要予以警防。对账簿的东西呢，合伙要保密，合伙人要知情，所以怎么警防呢？做了一个边界。那么如果是有限人涉及自身利益范围内的账簿，你就有权去查。那反过来，如果呢与你利益无关的范围，咱就不要再查了吧。哎，这个细节和边界啊，看清楚啊。

关于这个账簿的问题呢，其实命题的时候在这儿呢考的还蛮多，而且那个逻辑很缜密，各位来观察一下啊。这个点呢特别容易成为一个命题的模板，是一个底层的关系。

你比如说还是刚才的张某、一个上市公司甲、一个普通的乙公司一起开了一个合伙企业A。那在这个背景里边呢，我就注意这么两个选项听着。

A选项，我说这个上市公司甲呢不能查阅合伙企业的账簿——直接给了一个否定，账簿不让查。B呢绝对给了个肯定权利，说甲有权查阅合伙企业的账簿，其他什么也没说。直接给了这么两个绝对性的说法，你做什么判断？

第一个来啊。那首先确定甲上市公司身份是有限合伙人。完成后呢，A选项我说甲无权查账或不能查账——你的判断是错的，没问题啊。因为你要说他不能查账，我要说万一合伙企业账簿跟他有关系呢，那你说不能查就错了。那你说反过来说吧，甲有权查账——同样是错的。你要敢说他有权查账，那我就说合伙企业账是跟他没关系的呢一部分，那你的逻辑也是错的。

所以你发现没：对有限合伙人对账簿的知情查阅范围的时候呢，一定要在**有无利害关系**的边界下去讨论。如果没有这个边界前提，你就泛泛地说他有权无权查、或能查不能查，都是不可以的，都有逻辑漏洞啊。这个问题希望大家呢有所掌握。

那当然呢我们对于账簿这个东西呢稍微总结一下啊。我们刚才也大概提了一下公司当中股东的情况，它其实呢真是应用跟我们一路了，毕竟呢作为任何商业主体的投资人，对企业运行情况的了解都是必然的。所以从公司中股东就要知情查账，到合伙里边合伙人也要知情查账，那么他们到底统一的规则是什么呢？我们慢慢去梳理和总结一下啊。

它其实无外乎呢就这么几类角色吧：首先是有限公司的股东，然后呢是股份公司的股东，然后呢是合伙企业里边的普通合伙人，是刚刚讲到的啊，有限合伙企业的有限合伙人。

简写一下啊。那么这个背景里边，首先对于账簿——甚至呢我们公司里特别强调了一个凭证问题，合伙企业法律对凭证没有提，就是说目前还没有在立法的视野当中。那么合伙中的凭证几乎就没有考试的价值了啊。所以咱们以账簿为例，因为它体现了企业的经营的秘密，那么有双方的这种均衡。作为股东也好、合伙人也好，要知情；作为公司或合伙企业也好呢，我们要保密。如何起到均衡的作用呢？体会。

有限公司股东看到啊，他毕竟呢是人合为主的公司，是一个封闭的，所以股东和公司关系相对要紧密一点。所以呢我们给到了他对于账簿的知情权利是查阅，没有问题。你说印了带回家是不可以的。而股份公司的股东呢，我们身份还提了要求啊，是说你要单独或合计持股到百分之三，同时呢时间要满足到一百八十天以上，你才能——但也只能查，你说印了带回家自然也是不可以的啊，绝对不让复制。

而普通合伙人刚学过了，不管是执行事务的还是非执行人，知情都是核心权利。所以普通人呢对于账簿的查账肯定是没有问题啊。关于能不能印这个点呢，立法没有定论，一般法律不干涉，合伙协议约定吧，约定呢要给印就印了，一般也不会有此约定。如果没有明确约定的时候，一般类比有限公司的股东，账也是不让印的，基本上只能查啊。

那么有限合伙人呢，他就更繁琐一点了，先提出一个边界和前提是是否与之利益相关。那么如果是利益相关的范围之内，我们只能是让查，印自然是不可以的啊，毫无争议。那么反过来，如果是合伙企业中与之利益无关的，此范围之外的部分呢——那范围之外的自然是与你无关呀，查也不行，印自然也不行啊。还是这个脉络啊。

这样的简单归纳和总结，你就能观察到：一个投资人跟组织的关系越紧密，我们赋权的权利会越大一点。你比如说有限公司股东跟普通合伙人——那如果一个投资人和组织关系远一点，那么给的相关权利要小一点啊。你比如说股份公司股东，你比如说有限合伙人。能体会吧？哎，大概这样一个细节和规律，看一下是必要的啊。好，这期的问题比较重要，咱们就多说两句。

嗯，后边呢继续了，看有限人能干的几个经营建议——这考的少，简单一看啊。

第三一个，诉讼要稍微说一下喽。哎，两个层面啊。那第一点呢，就是说我如果有限人自身的利益在合伙企业里边被损害、被欺负，那我肯定会反抗嘛，谁害我告谁嘛，没问题啊。

重点是第二个，注意标示一下：是当合伙企业被欺负了，那执行事务的合伙人呢又麻木，此时有限人看不下去了，他是不是可以伸张正义、跳起来代表合伙企业起诉维权？这点类似以公司中的股东代表公司起诉是一样的。强调那个名义——就谁做原告的问题啊。那公司里的股东代表公司来去告，是股东自己为原告吧？这里边一样，有限合伙人呢代表合伙企业去起诉维权，也是以合伙人自己的名义来进行的。谁告？谁自己当原告。这点逻辑是没问题的啊。

所以呢，其实整个的有限人可为之事呢，我们做了一些些的准备啊，来梳理出这么几个板块。重要的是在知情里边呢，第二项关于查账的权利要求；再有就是诉讼里边呢，第二项代表诉讼。哎，这两点的细节看清楚就好啊。
