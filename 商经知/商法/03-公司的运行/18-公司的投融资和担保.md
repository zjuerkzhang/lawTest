# 一、讲稿知识点的提纲


## 专题：公司的投资与担保（《公司法》第15条为核心）


### 第一部分：公司投资——相对轻松，考得少

**一、公司投资的基本规则**

- **原则**：《公司法》对公司投资没有过多限制，交给公司自治。
- **决策机构**：由公司章程规定——股东会或董事会决议即可。
- **投资对象**：法律原则上不干涉公司投向哪里、投多少、以什么身份承担什么责任。

**二、投资的特殊限制（与其他法律的衔接）**

- **问题**：普通公司能否投资到合伙企业，作为普通合伙人承担无限连带责任？
- **原则**：《公司法》不禁止，但《合伙企业法》有特别限制。
- **两类特殊公司禁止作为普通合伙人**：
  - **国有独资公司**——代表国家利益
  - **上市公司**——代表公众股东利益（几十万、上百万股民）
- **理由**：一旦作为普通合伙人被连带追责，背后是国家利益或公众利益受损，风险不可控。
- **结论**：除这两类特殊公司外，其他普通公司可以投向合伙企业做普通合伙人。


### 第二部分：公司担保——重中之重，常考常新

**一、担保的风险认知**

- **担保是高风险行为**：业内戏称“要想搞死一家公司，就给它搞个担保”——被担保人不能还债，担保人就要替其背锅。
- **担保合同的特殊性**：这是法定代表人**唯一不能仅凭身份就直接签**的合同。
  - 其他合同（购销、采购、人事等）：法定代表人可以代表公司签，即使违反章程越权，相对方也可能被推定为善意，合同仍可能有效。
  - **担保合同**：法定代表人的签字必须匹配**公司集体决策**的法定文件。

**二、担保的两种类型与决策机构**

**（一）非关联担保**——为“外人”担保（如为第三方A公司向银行贷款提供担保）

| 维度 | 内容 |
|------|------|
| 风险特征 | 仅有商业风险（外部风险），风险相对“小了一丢丢” |
| 法律管制 | 较松 |
| 决策机构 | **章程规定二选一**：股东会决议 **或** 董事会决议均可 |
| 实务建议 | 建议在章程中约定由**股东会决议**，更稳妥（担保直接关乎股东利益）；若授权董事会，应设额度等边界约束 |

**（二）关联担保**——为“家里人”担保（如为大股东张三向银行贷款提供担保）

| 维度 | 内容 |
|------|------|
| 风险特征 | **内忧外患**：外部商业风险 + 内部被大股东控制、绑架公司、伤害其他股东的风险 |
| 法律管制 | 更严 |
| 决策机构 | **只能由股东会决议**，董事会无权 |
| 特殊规则 | 被担保的关联股东**必须回避**表决；由其他出席会议的股东所持表决权**过半数通过** |
| 立法目的 | 防止大股东安插自己人进董事会“小弟替大哥办事”，切实尊重中小股东意志 |

**三、法定代表人越权担保——核心考点**

**（一）越权的两种类型**

1. **违反意定限制**（违反章程、股东会决议等内部规定）
   - 例：章程规定法定代表人只能签100万以内合同，超过需董事会批准；法定代表擅自签200万采购合同。
   - 后果：相对方不知情的，可被推定为**善意**，合同**有效**（内部追责另算）。
   - 依据：《民法典》第504条。

2. **违反法定限制**（违反《公司法》第15条的担保决议程序）——**担保场景的核心**
   - 担保必须走法定流程、拿公司决议，法定代表人不能仅凭身份签。
   - **关键区别**：相对方**不能**说“我不懂法所以我是善意”——商事领域推定各方知法守法。
   - 相对方要主张自己是**善意**，必须**主动举证证明**自己做了合理审查。

**（二）越权担保的效力与公司责任**

| 情形 | 担保合同效力 | 公司责任 |
|------|-------------|----------|
| 法代越权 + 相对方**证明善意** | **有效** | 公司**承担**担保责任 |
| 法代越权 + 相对方**非善意**（且公司不追认） | **对公司不发生效力** | 公司**不承担**担保责任 |
| 法代越权 + 相对方**明知决议伪造** | 无效 | 公司**无任何责任**（银行与法代恶意串通，自己解决） |

**（三）公司不追认时的过错责任（缔约过失）**

- 非善意情形下，担保合同对公司不生效，但公司是否要承担**缔约过失责任**？
- 银行（债权人）有过错：未进行审查。
- 公司可能也有过错：选任了“三拍老板”（遇事拍胸脯、出事拍大腿、搞不定拍屁股走人）做法定代表人，监管不力。
- 法庭可能据此判公司承担一定过错责任（与《民法典》缔约过失责任一脉相承）。

**（四）何为“善意”——合理审查的两个层次**

**层次一：找到“适格决议”（严格）**

- **关联担保**：只能找**股东会决议**（找董事会决议不行）。
- **非关联担保**：需先看**公司章程**，看章程把担保事项授权给哪个会，再找对应的决议。
- **核心**：该找哪个找哪个，**没找不行，找错了也不行**。

**层次二：对适格决议进行审查（形式审查，不过于苛责）**

- 审查标准：**合理审查**（比形式审查严一点，但比实质审查松一点）。
- 不看的内容：签字是否真实、决议是否伪造、额度是否超章程、股东会是否实际召开——**银行看不出来也不可苛求**。
- **但如果决议表面就有漏洞**（如关联担保中被担保股东也签字了——该回避未回避），银行仍不质疑的，**不构成善意**。

**（五）善意的判断——例题场景**

讲授者给出了**5个递进场景**，帮助判断银行是否构成善意：

| 场景 | 银行的做法 | 是否善意 | 理由 |
|------|-----------|---------|------|
| ① | 只看法定代表人就签担保 | ❌ 非善意 | 担保不同于一般合同，不能仅凭法代身份 |
| ② | 看到**董事会决议**就签（关联担保） | ❌ 非善意 | 找错了决议——关联担保应找股东会决议 |
| ③ | 看到股东会决议，但**被担保股东也签了字** | ❌ 非善意 | 表面漏洞——该回避未回避，“过犹不及” |
| ④ | 看到股东会决议，其他股东都签字，形式审查过关 | ✅ 善意 | 适格决议找到，形式审查过关即可 |
| ⑤ | 决议是伪造的（公司没开过会），但银行看不出来 | ✅ 善意 | 实质审查不可苛求，不影响善意认定 |

**四、无需决议的例外情形（担保解释规定）**

| 情形 | 理由 |
|------|------|
| ① 金融机构或担保公司做担保 | 专门干这个的，天天做担保，不可能每笔都开会 |
| ② 公司为**全资子公司**提供担保 | “独生孩子”——母公司对子公司的爱不计回报，不用决议 |
| ③ 三分之二以上有表决权的股东在担保合同上签字 | 实质上的股东同意，效力优于股东会决议 |

**五、一人有限责任公司为股东担保——特殊规则**

**（一）基本规则**

- **不需要、也不能按《公司法》第15条走决策流程**。
- **理由**：
  1. 第15条的目的是保护**其他中小股东**利益——一人公司没有其他股东，不需要保护；
  2. 若强行适用：唯一股东=被担保人→需回避→无人能做决议→制度失灵。
- **结论**：一人公司为股东担保，**直接有效，不用决议**。

**（二）内嵌的约束机制——智慧所在**

- 一人公司为股东担保后，若公司因承担担保责任导致无力清偿其他债务：
  - 债权人可主张：股东（张三）与公司财产**混同**。
  - 一人公司人格否认的**举证责任倒置**：股东须证明公司财产独立于自己财产。
  - 证明不了的，股东对公司债务承担**连带责任**。
- **逻辑闭环**：让你担保（有效），但每做一笔担保就留一个把柄——若还不上债，举证责任倒置可能让你承担连带责任——风险太大，股东自己就不敢乱担保了。


### 第三部分：与其他制度的衔接

- **股东代表诉讼**：法定代表人（董事、高管）越权担保损害公司利益，公司怠于追究时，股东可代位起诉。
- **决议效力**：担保决议可能存在瑕疵（伪造、程序违法等），涉及决议效力认定。
- **缔约过失责任**：担保合同不生效时的过错分担。

**【段落二：公司投资规则】**

首先简单了解一下投资，这个呢其实我们看总结就可以了。对于公司投资呢，公司法没有过多的限制，交给公司自治。公司章程规定股东会或董事会决议了，你就投，至于投哪儿，投多少，做什么身份承担什么责任，法律是不干涉的，至少公司法是不干涉的。当然咱们会有个和其他法律的衔接，在这里边啊。因为一家公司呢，我能不能投资到一个合伙企业里边去当一个普通合伙人，被合伙企业承担连带责任呢？原则上说公司法不干涉，投就投呗。但是合伙企业法里边有一些特别的限制，有那么俩特别的公司，一个叫国有独资公司，一个叫上市公司同学们。你想啊，这个国有独资公司和上市公司它背后代表谁的利益呀？国有独资公司背后代表的是国家利益，而上市公司呢，作为公众公司背后是几十万、上百万的公众股东利益，对不对？因为他背后的利益规格太高了，咱们敢不敢这样的主体呢去搞到一个普通合伙企业里边，不是水果店。[修正：原文“不是水果店”为口语跳跃，删去] 然后呢，水果店闯祸了，导致他们承担连带责任，这样一连带了不得了，连带的背后就是国家利益受损，公众利益受伤，那我们哪承受得了？所以为了这样的不可控的风险发生，我们在这里做了一个源头的判断啊。这当国有独资公司、上市公司，你不能去投向普通合伙人，做普通合伙人。那除了这两种特别公司之外，别的普通的公司，那想投投呗。普通合伙人，那除了这两种特别公司之外，别的普通的公司，那想投保呗，就这么个原则，可合伙起来衔接一下就好了啊，知道他的背景，其他没有。

**【段落三：担保的风险与特殊性】**

然后重点来看一下担保同学们，啊重点说好啊，担保这个东西吧，前面我们大概提了一点点，各位你分析你说，一个公司呢给别人做一担保，这件事情对公司呢是个风险还是个利好，天大的风险，什么啊，业界那个开玩笑的说法是，你要想搞死一家公司，你就给他搞个担保，一般担保额度越大死的越快。虽然有一点点戏谑，[修正：原文“细谑”改为“戏谑”] 但是也不免真实，因为你要给别人做担保之后，因为被担保的债务人单方不能还债，你就要替他背锅，很有可能搭上你的身家性命，那时候呢就是一个急要命的风险了对吧？那么对担保咱们非常慎重啊，公司法十五条呢严格的规定了，担保的决策流程成为了法代，[修正：原文“法贷”改为“法代”] 唯一不能直接靠自己替公司签的合同。你想别的什么购销合同啊，采购合同啊，人事合同啊，那些合同其实法代呢你是能代表公司签的，就算你违反了你家章程，超限越权了，那么相对方也很可能会被推至为善意，那时候的合同也是能被认定为有效的啊，但是担保呢要相对慎重了好多，对法定代表人而言呢，你单纯这个身份，你的签字是不能直接签担保合同的，你一定要匹配上一个公司的集体决策，这样一个法定文件才可以。

**【段落四：非关联担保与关联担保的区分】**

**【段落五：越权担保——违反意定限制 vs 法定限制】**

好，这就是我们关于担保中的所有内容同学们。[修正：原文“担保中的所有同学们”改为“担保中的所有内容同学们”] 那点呢很有意思，但它没有特别的难，和民法呢会有点几米交叉。我们放民法放我们这儿考都是有可能的。稍微回忆一下，首先咱们知道法代越权担保呢，根据相对方是不是善意，举证的公司责任是不一样的。只有相对方证明了善意时，公司才会负担保责任。如果是非善意，公司没有担保责任，当然前提没有追认啊，可能会有缔约过失[修正：原文“第一个过失”改为“缔约过失”] 带来的一定过错。哎这样一个份额。当然如果是法代越权是通过伪造决议而银行又是明知的情况下，那好公司既没有担保责任也没有缔约过失[修正：原文“第一个过失”改为“缔约过失”] 这些的要求。那么一个细节的要点就是对方要不要被证明善意这个结论怎么得出呢？哎，这个善意的证明有两个层次了，是这么个逻辑哈。第一个呢，我们要求是找到这家公司的适格决议，这部分呢非常严格，该找什么找什么，该看什么看什么。一旦决议适格之后，下一步呢，对决议本身呢，不过分苛责，基本形式审查差不多就可以了啊。那么紧随其后呢，咱们就会有间接的一些，比如说和公司法里的股东代表诉讼啊，甚至呢，其他一些制度的衔接，也做了一点点的例外情形，不需要决议的。哎，刚才说像金融机构的，像母公司对全资子公司的，甚至三分之二以上有表决权的股东签过字的，这种可以豁免决议的细节。最后一个智慧制度，一人有限公司对股东做担保的特殊规则，两边的这种内嵌的约束呢，还是蛮有值得期待的一个地方。嗯，这个问题说完呢，我们后边那个债券其实没有什么可考的，我们就不再多展开了啊，这样整个公司运行就告一段落了。
