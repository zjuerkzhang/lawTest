# 一、讲稿知识点的提纲

> **阅读说明**：以下提纲基于讲稿内容整理，结合《企业破产法》相关条款进行验证和补充。标注“【讲稿原文】”的内容直接引自讲稿；“【法条依据】”为根据搜索结果补充的法律条文；“【注】”为讲稿中提到的超出主题范畴的概念说明。


## 第一部分：管理人制度（对应《企业破产法》第22-29条）

### （一）管理人的指定

**1. 指定主体与时机**

- 管理人由人民法院指定。
- 法院裁定受理破产申请的，**同时**指定管理人。【讲稿原文】“管理人是法院受理破产案件的同时就指定出来的。”

**2. 法院的管理人名册制度**

- 法院事先建有管理人名册（“管理人库”），具备资质的社会中介机构（律师事务所、会计师事务所等）和个人通过评选、招标等方式入库。
- 指定方式包括：按顺序轮候、随机（抽签/摇号）、竞争方式、接受推荐方式等。
- 特别重大或复杂的案件，可单独招标指定。【讲稿原文】“有些案件呢可能比较特别，他就在这里边呢可能去挑选一些，或者呢单独的被某个案件去招标一个都是有可能的。”

**【法条依据】** 《企业破产法》第22条；《最高人民法院关于审理企业破产案件指定管理人的规定》。

### （二）管理人的更换与报酬

**1. 更换**

- 管理人由法院指定，更换也由法院决定。
- 债权人会议认为管理人不能依法、公正执行职务或有其他不能胜任情形的，**可以申请**法院更换；但最终是否更换由法院决定。【讲稿原文】“管理人要辞职啊换人啊……肯定也是管法院来决定的。”

**2. 报酬**

- 管理人的报酬由法院确定。
- 债权人会议对报酬有异议的，有权向法院提出。
- 报酬根据债务人最终清偿的财产价值总额，按一定比例（分段递减）确定。【讲稿原文】“你是根据管理规模的一定比例提取你的管理费的啊。”

**【法条依据】** 《企业破产法》第22条、第28条；《最高人民法院关于审理企业破产案件确定管理人报酬的规定》。

### （三）管理人聘用工作人员

- 管理人**经法院许可**，可以聘用必要的工作人员。【讲稿原文】“管理人允不允许被找到帮手，或找多少个帮手，花多少钱，这时候呢是要法院许可你才能做的。”
- 理由：管理人每多花一分钱，相当于剥夺债权人的利益。【讲稿原文】“你每多花一分钱，都相当于是剥夺债权人的一丝丝利益。”
- 聘用人员包括：为继续营业事务的人员（原企业经营管理人员等）和协助处理专业事务的人员（会计师、律师等）。

**【法条依据】** 《企业破产法》第28条。

### （四）管理人的任职资格（消极条件）

【讲稿原文】“首先你有能力足够的专业，对吧？再有就是中立，人品要过关。”

**不得担任管理人的情形包括**：

1. **专业能力不足**：因故意犯罪受过刑事处罚、曾被吊销相关专业执业证书等。【讲稿原文】“故意犯罪呀，或者是说呢被嗯这个吊销过职业证书，这种的就说明你没有能力呀。”
2. **缺乏中立性/有利害关系**：与本案有利害关系。【讲稿原文】“如果你本身就是个债权人，让你当这家公司的管理人，你想想你会把这些钱倾斜性的分给谁呀？那肯定先分给自己嘛。”
3. **其他影响独立公正履职的情形**。

**【法条依据】** 《企业破产法》第24条；《最高人民法院关于审理企业破产案件指定管理人的规定》。

### （五）管理人的职责

【讲稿原文】“那他就是个大管家了，承接员啦，董事高管手里的相关的人财物啊，账啊账啊等这些。”

- 接管债务人的财产、印章和账簿、文书等资料；
- 调查债务人财产状况，制作财产状况报告；
- 决定债务人的内部管理事务；
- 决定债务人的日常开支和其他必要开支；
- 在第一次债权人会议召开之前，决定继续或者停止债务人的营业；
- 管理和处分债务人财产；
- 代表债务人参加诉讼、仲裁或其他法律程序；
- 提议召开债权人会议等。

**【法条依据】** 《企业破产法》第25条。

### （六）【讲稿延伸】为什么说管理人是“法律人的职业天花板”？

> 【注】以下内容为讲授者根据个人经验的延伸讲解，非法考核心考点，但有助于理解管理人制度的实践意义。

【讲稿原文】“做管理人是咱们法律人的一个职业天花板，好比是一个铀精矿一样，因为这一块业务呢相对比较省心，然后呢钱又多又安全。”

**优点分析**：

1. **报酬可观**：按管理规模（动辄千万甚至过亿）的一定比例提取报酬。
2. **安全性高**：管理人掌控债务人财产，自己给自己发报酬，不存在“干了活收不到钱”的风险。【讲稿原文】“你拿着这些钱给咱自己发工资的时候……他一定不会出现说钱拿不到的情况。”
3. **专业门槛高**：非商法领域的法律人难以介入，竞争少。【讲稿原文】“你只有做商法的孩子们，你才有可能做这块业务呀。”
4. **职业尊严**：管理人是专业“大管家”，客户因不懂而难以质疑。【讲稿原文】“你是那个最专业的专业大拿，别人都不懂。”

**对比一般诉讼业务**：

| | 一般诉讼业务 | 管理人业务 |
|---|---|---|
| 收费方式 | 先收一半，尾款看结果 | 按管理规模比例提取 |
| 风险 | 结果不好客户不付尾款 | 钱在自己手里，无收款风险 |
| 专业壁垒 | 低，竞争激烈（低价竞标） | 高，别人做不了 |


## 第二部分：破产费用与共益债务（对应《企业破产法》第41-43条）

### （一）基本概念区分

| | 破产费用 | 共益债务 |
|---|---|---|
| **定义** | 为**破产程序本身**付出的费用 | 为**全体债权人共同利益**而发生的债务 |
| **发生时间** | 受理后发生（但有例外，见下文） | 受理后发生 |
| **是否必然存在** | **每个案件必有**【讲稿原文】“每个案件里边势必会有破产费用” | **不一定有**【讲稿原文】“可能没有公益债务，这是有可能的” |
| **判断标准** | 程序性保障 | 实体性关系，体现共同利益 |

**【法条依据】** 《企业破产法》第41条（破产费用范围）、第42条（共益债务范围）。

### （二）破产费用的具体范围

【讲稿原文】“你比如说我们有诉讼费，甚至呢公告、鉴定、拍卖等等这些费用。”

根据《企业破产法》第41条，破产费用包括：
1. 破产案件的诉讼费用（案件受理费、公告费、送达费等）；
2. 管理、变价和分配债务人财产的费用（财产保管费、鉴定费、拍卖费等）；
3. 管理人执行职务的费用、报酬和聘用工作人员的费用。

### （三）共益债务的具体范围

根据《企业破产法》第42条，共益债务包括：
1. 因管理人或债务人请求对方履行双方均未履行完毕的合同所产生的债务；
2. 债务人财产受无因管理所产生的债务；
3. 因债务人不当得利所产生的债务；
4. 为债务人继续营业而应支付的劳动报酬和社会保险费用等；
5. 管理人或者相关人员执行职务致人损害所产生的债务；
6. 债务人财产致人损害所产生的债务。

【讲稿举例】“受理重整之后啊，为了能够让大家回来干活，为了共同活下去产生的这个职工的债务嘛，给职工发的工资嘛，那当然就是公益债务了。”

### （四）【讲稿延伸】执行转破产与清算转破产中的费用处理

> 【注】“执行转破产”（简称“执转破”）为民诉法与破产法衔接的程序，讲授者提示“稍加重视”，但非破产法核心考点。

**【讲稿原文】“听过一个词叫‘直转破’吗？执行转破产的。”**

**执行转破产的启动条件**：
- 执行法院发现债务人资不抵债；
- **债权人或债务人一方同意**即可转破产（二选一授权）【讲稿原文】“如果A同意这边就可以转，或者书店同意这边也可以转，是或者的关系，一方同意就能转了啊。”

**费用处理规则**：
- 执行程序中已产生的鉴定费、公告费、拍卖费等，若结果为破产程序所用，即使发生在受理前，也**认定为破产费用**。【讲稿原文】“用人结果就得管人费用嘛。”

**清算转破产**同理：清算程序中已产生的相关费用，若结果为破产程序所用，也作为破产费用处理。

### （五）清偿规则（核心考点！）

**【法条依据】** 《企业破产法》第43条。

**基本规则：破产费用和共益债务由债务人财产随时清偿**。

**【讲稿原文】“好比公路费用的存在，是在整个程序中飘着不还的，随着发生，随时清偿。”**

**具体清偿规则（分三种情况）** ：

---

**情况一：财产足以覆盖两者**

【讲稿举例】破产费用10万，共益债务50万，合计60万；债务人财产80万。

**规则**：两者**同时足额清偿**，无先后顺序。【讲稿原文】“既然都够还，两个都能同时还掉，那就还呗，没有先后顺序。”

---

**情况二：财产不足以清偿两者，但足以清偿破产费用**

【讲稿举例】破产费用10万，共益债务50万，合计60万；债务人财产50万。

**规则**：
1. **破产费用优先于共益债务**清偿；
2. 先还破产费用10万 → 剩余40万；
3. 共益债务内部**按比例**清偿（C和D各占50%，各分20万）。

**【讲稿原文】“破产费用要优先于公益债务……为什么呢？破产费用是程序的保障，是最基础的东西。”**

---

**情况三：财产连破产费用都不足以清偿**

【讲稿举例】破产费用10万（A=5万，B=5万），共益债务50万；债务人财产8万。

**规则**：
1. 共益债务**一分钱也拿不到**；
2. 破产费用内部**按比例**清偿（A和B各得4万，各占80%）；
3. 程序终结。【讲稿原文】“公告鉴定这些钱都交不起啦，管理人员工资也发不动了，那肯定这程序就走不下去了。”

---

**清偿规则总结表**：

| 财产状况 | 清偿规则 |
|---|---|
| 财产 ≥ 破产费用 + 共益债务 | 两者同时足额清偿，无顺序 |
| 破产费用 ≤ 财产 < 破产费用 + 共益债务 | 先破产费用（足额）→ 剩余按比例清偿共益债务 |
| 财产 < 破产费用 | 共益债务不还 → 破产费用内部按比例清偿 → 程序终结 |


## 第二部分补充：破产债权 vs 共益债务的区分标准

【讲稿原文】“区分老债或新债、破产债权或公益债务的标准呢，最重要的一个是产生债的原因所发生的时间。”

| 判断标准 | 破产债权（老债） | 共益债务（新债） |
|---|---|---|
| **时间** | 受理**前**产生 | 受理**后**产生 |
| **利益属性** | 体现**个别债权人**的个别利益 | 体现**全体债权人**的共同利益 |

**【注】** 破产债权和共益债务的区分是破产法的重要基础概念，讲稿中将其作为辅助判断因素提及。

那么第一个层面是共益债务，刚才我们大概解释过，哎它容易混的概念是破产债权，你还记得啊，区分老债或新债、破产债权或共益债务的标准呢，最重要的一个是产生债的原因所发生的时间。如果受理前的叫老债为破产债权，受理后的为新债叫共益债务。另外一个辅助判断点是这笔债的依托标的。如果体现某个体债权人个别利益的，那么是破产债权。如果体现大家共同利益的，那为共益债务也是可以判断的因素啊。所以呢一个时间点一个利益的呈现，那这时候如果受理后发生的，且体现大家共同利益的，那就是共益债务了。像刚才我们说的那个，嗯受理重整之后啊，为了能够让大家回来干活，为了共同活下去产生的这个职工的债务嘛，给职工发的工资嘛，那当然就是共益债务了，呈现它。那具体的几个类型就不用背了，知道性质就可以了啊。

那完了以后我们接下来一百二十七页上面吧，它就有一个关于破产费用和共益债务的清偿。当然这个清偿的时候呢，首先从属性上来讲，它们都是那种随时发生、必须及时清偿的这种要求啊。当然呢如果这个书店呢，确实钱足够多，它俩都能被还上，那就没有争议了呗。这时候如果万一钱不够多，它俩不能全部清偿的时候，也会有一个前后啊顺序啊等这种小的分配规则啊。那咱们作为小的故事呢，同学们先这样简单了解一下吧。


**【段落十九：清偿规则——情况一（财产充足）】**

你比如这一天算下来呢，哎我们发现书店的破产费用是十万块钱，由两项组成，其中A呢是五万，B也是五万。完了共益债务呢，有发生五十万，由两项组成，C是二十五，D是二十五，大概是今天发生了这两笔钱，大概的一个规模和这种分类是这样的啊。那么接下来，就来看看今天结算下来书店有多少钱呢？那我们来看根据书店财产的规模不同，这两个被清偿的要求也是不一样的啊。那么第一种情况，同学们分析，如果那么会发现书店特别有钱，你比如说呢，我们现在呢是有八十万之多的，而这两笔权益要求加一块不是一个十万一个五十万吗？一共才需要六十万呀，我有八十万呢，足足的够哈。所以既然都够还，两个都能同时还掉，那就还呗，没有先后顺序，谁发生谁还，随之发生，随之清偿就可以了，没有所谓的顺序啊，要求等这些啊。那么因为你有足够多的钱，说实话啊，我们经常会有一个说法，说小孩子才做选择呢，成年人呢，我就可以都要。那为什么小孩子才做选择？是因为小孩子没有经济独立性啊，他要那种零花钱是父母给他的，是不是啊？所以呢，有的时候他就不能完全按照自己的心愿来。那成年人你不是有自己的经济自主权吗？只要咱们的经济自主权能够覆盖住我们的欲望，那可不是都能要吗？它是这个逻辑。所以这也是一样的。那么现在需要六十万，那你有八十万，那都给呗，这点呢就没有更多的考量了啊。


**【段落二十：清偿规则——情况二（财产仅够破产费用）】**

第二个情况你要注意，比如说书店今天结算下来发现咱们只有五十万的钱，而那两个要都还的话呢，是需要六十万之多的，咱没有能力两个都还掉，那么此时就要有一个先后顺序了。此时一旦有两个不能同时还掉的时候，有先后顺序的时候呢，我们的破产费用要优先于共益债务各位啊。为什么费用优先呢？道理很简单，破产费用前面说过，是不是每个案件里边必然会存在的程序性的保障？而共益债务呢，毕竟是受理后发生的实体的关系了，只有程序能保障了，程序往下走，你才有可能后续发生实体的关系，这是啊。你想想嘛，如果呢，你的管理人没挣工资，他早就撂挑子了，程序就到此结束了，还有什么产生后边要不要去找工人回来呀，给他们去要不要发工资，这事儿根本就不可能发生了。你不会交诉讼费，程序根本就启动不了，后续根本没有任何的可能性，对不对？所以因为破产费用是程序的保障，是最基础的东西，是每个案件必然会存在的。而共益债务呢，是在程序中才会发生的，而且不是每个案件都有的。哎从属性上来讲，破产费用要更优先一些。那么此时呢，我们就要先看一下啊，既然破产费用呢更优先，我们就先把这十万块钱还掉。完之后呢，剩下了四十万。而共益债务呢，你会发现它是一共有五十万之多呀。现在相当于是五十万的共益债务，只有四十万的钱可供C、D两个权利人去分。那C也好，D也好，他们都有共益债务，那么都同为共益债务，C、D之间，还有没有什么优先劣后？那就没有了吧，没有就按比例嘛。所以此时呢，按比例的时候呢，我要会算算数啊。那么他们俩呢，其实是各占整体的二分之一，因为整体是五十，各二十五嘛，占二分之一吧。这占二分之一的话，相当于是C和D共享这四十万剩余的钱。那么每个人分多少呀，就按照你比例分了。所以C分二分之一的二十万，D分二分之一的二十万啊，钱一分完了吧，是不是？所以当这个债务人的财产不能够把两个板块都还完的时候，我们先还破产费用，剩下的还共益债务。既然共益债务呢已经不够了，里边有几个项目的话，内部之间是地位平等按比例的要求啊。


**【段落二十一：清偿规则——情况三（财产连破产费用都不够）】**

那么还有极致的情况是第三，你如果今天折算下来，发现书店一共就区区八万块钱了。你别说去还共益债务了，那破产费用它都不够。那破产费用都不够，首先来讲共益债务就一分钱还不了啊。那么还破产费用吧，而破产费用里边是由A、B两项组成的呀，那算比例了，一共十万，各五万，比例分别是二分之一，没有问题啊。这相当于是A、B能够享有八万，那么折算下来A就是八万的二分之一得四万，B呢也是八万的二分之一得四万。就他俩一人四万，相对公平分喽。完之后，这事儿就结束了。这个程序也就终结了，同学们啊，因为走不动了呀。接下来呢，那公告鉴定这些钱都交不起啦，管理人员工资也发不动了，那肯定这程序就走不下去了。既然我们的破产程序到此也就结束了，哎，大概是这个脉络啊。


**【段落二十二：破产费用与共益债务考点的总结】**

所以呢，关于破产费用和共益债务，其实重要的考点是前一板块去识别、去判断是不是破产费用，是不是共益债务啊。如果是的话呢，核心属性叫随时清偿。第二层次呢，如果考的深了一点、细了一点，可能会考到一些细节到底怎么还，那咱们是根据债务人财产的规模不一样，而清偿的规则也不一样的。如果俩都包得住，那么就没有顺序了，随时发生随时还，谁也不用等谁。如果呢，今天结算下来发现就包不住了，破产费用会优先于共益债务。而破产费用里边如果有两项以上组成，共益债务里头两项以上组成的时候呢，项目和项目之间属性相同的，地位相同，按比例。哎，这个点的规则记住了啊。好，简单了解一下就可以了。这是我们的破产费用和共益债务这个小板块。
