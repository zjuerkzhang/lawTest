# 一、讲稿知识点的提纲

> **说明**：以下提纲基于讲稿内容整理，黑色加粗为讲稿核心知识点，*斜体*为补充的法律条文注释（基于《行政复议法》2023年修订版）。


## （一）行政复议与行政诉讼的关系（讲稿开篇）

**1. 行政复议与行政诉讼的相同之处**

复议与诉讼“绝大部分内容一样”，根植于行政实体法，具有内在体系感与关联性：

- **受案范围**：核心根植于“具体行政行为”理论——具体行为，诉讼和复议都能受理；非具体行为（如内部行为），诉讼和复议都不能受理
- **原告/申请人**：内容100%一样，根植于“相对人和相关人”理论
- **被告/被申请人**：内容99%一样，根植于“行政主体”理论
- **行政行为成立（尤其是不作为）** ：实体法、诉讼法、复议法多次串联讲解

**2. 行政复议与行政诉讼的差异**

不能百分之百相同，存在差异。本章最后有汇总表格（讲稿第325-326页），以“理解+背诵”的方式掌握。


## （二）第一节：行政复议的受案范围

**核心结论**：诉讼和复议的受案范围**完全一样**。

**特别注意**：内部行为（如公务员被开除）——**不能诉讼，也不能复议**。

- *【法条注释】《行政复议法》第二条：公民、法人或者其他组织认为行政机关的行政行为侵犯其合法权益，可申请行政复议。内部行为不属于“行政行为”范畴。*
- 内部行为的救济途径是“内部化的”——申诉、复核等，不是复议（复议是“民告官”）。


## （三）第二节：行政复议参加人与复议机关

### 1. 行政复议的“出场人物”——名词对应

| 诉讼中的角色 | 复议中的对应角色 | 说明 |
|---|---|---|
| 原告 | **申请人** | “代被子的”——申请行政复议的人 |
| 被告 | **被申请人** | “代被子的”——作出被复议行政行为的机关 |
| 法院（居中裁判） | **复议机关** | 审理复议案件的机关 |
| 第三人 | **第三人** | 与案件有利害关系的其他人 |

- *【法条注释】《行政复议法》第十六条：申请人以外的同被申请行政复议的行政行为或者案件处理结果有利害关系的公民、法人或其他组织，可以作为第三人参加复议。*
- **务必分清**：“被申请人”是被告（告谁）；“复议机关”是类似于法官的审理机关（找谁告）。先确定告谁，再确定找谁。

### 2. 申请人

**核心结论**：与行政诉讼的原告**完全一样**。

### 3. 被申请人

大部分内容与诉讼被告一样（授权、委托等），但存在**两个例外**：

#### 例外一：经批准的行为

- **例题**：区人社局报经区政府批准后，以自己名义罚款某企业20万。
- **诉讼规则**（看名义）：看最终文书上盖谁的章——盖区人社局的章 → 被告是**区人社局**。
- **复议规则**（看上级）：谁是批准机关（上级）谁做被申请人——批准机关是**区政府** → 被申请人是**区政府**。
- **法理**：如果复议也看名义，被申请人是区人社局，复议机关就是区政府——等于让区政府审理自己事先批准过的案件，**不公正**。所以复议只能“看上级”。
- **口诀**：经批准的行为——诉讼看名义，复议的被申请人是上级。

- *【法条注释】《行政复议法》第十九条：作出行政行为的行政机关或者法律、法规、规章授权的组织是被申请人。对于经批准的行为，根据《行政复议法实施条例》第十三条，批准机关为被申请人。*

#### 例外二：共同行为告漏了

- **诉讼规则**：公安局和教育局共同处罚，只告了公安没告教育 → 法院通知追加，不加才列为第三人。
- **复议规则**：**直接追加**，没有诉讼那么啰嗦。
- **法理**：复议机关（“爹”）很强势，发现自己的“崽子”闯祸了，直接抓过来。

- *【法条注释】《行政复议法》第十九条第二款：两个以上行政机关以共同的名义作出同一行政行为的，共同作出行政行为的行政机关是被申请人。*

### 4. 第三人

- **核心规则**：与诉讼一样——**第三人不参加复议，不影响案件审理**。
- 原告不来 → 视为撤诉；被告不来 → 缺席审判；第三人不来 → 不影响审理（变相的缺席审判）。

### 5. 复议机关（核心重点）

**三大句话、三套规则**：

#### 第一句话：地方的案子归政府

**核心规则**：现在所有“地方”（省市县乡，不含中央/国务院）的案子，**集中到政府手中**——县政府、市政府、省政府来审。

*【法条注释】《行政复议法》第二十四条：县级以上地方各级人民政府统一行使行政复议职责，管辖下列案件：（一）对本级人民政府工作部门作出的行政行为不服的；（二）对下一级人民政府作出的行政行为不服的；（三）对本级人民政府依法设立的派出机关作出的行政行为不服的；（四）对本级人民政府或者其工作部门管理的法律、法规、规章授权的组织作出的行政行为不服的。*

具体包括：

| 被申请人类型 | 复议机关 | 例题 |
|---|---|---|
| 本级政府的工作部门 | 本级政府 | 县公安局 → **县政府**；市公安局 → **市政府**；省公安厅 → **省政府** |
| 下一级人民政府 | 上一级政府 | 县政府 → **市政府**；市政府 → **省政府** |
| 政府的派出机关 | 设立该派出机关的政府 | 街道办（区政府设立）→ **区政府** |
| 政府/部门管理的授权组织 | 管它的政府 | 北工大（北京市政府直属）→ **北京市政府** |
| 派出机构 | 本级政府 | 派出所罚款 → **县政府**（不是公安局） |

- **特别注意**：派出机构（如派出所）的复议机关是**本级政府**（县政府），不是设立它的部门（公安局）。
- **省部级自我管辖**：省政府的行政行为 → 复议机关是**省政府自己**（不找国务院，“儿子这么大了，不要打脸”）。

#### 第二句话：全国的事务归部委

部委作为复议机关。

*【法条注释】《行政复议法》第二十四条第二款：省、自治区、直辖市人民政府同时管辖对本机关作出的行政行为不服的行政复议案件。*

| 被申请人类型 | 复议机关 | 例题 |
|---|---|---|
| 部委自己的行为 | 部委自己 | 教育部行为 → **教育部**；国家税务总局行为 → **国家税务总局**（不是国务院） |
| 部委设立的派出机构 | 设立它的部委 | 财政部驻山西监管局 → **财政部** |
| 部委管理的授权组织 | 管理它的部委 | 中国政法大学（教育部附属）→ **教育部** |

- **注意**：“部委”是广义概念，包括部级单位（教育部、公安部）和直属机构（国家税务总局、国家市场监管总局、国家体育总局）。

#### 第三句话：还有两类是例外（更重要）

**例外一：垂直领导机关**

*【法条注释】《行政复议法》第二十七条：对海关、金融、外汇管理等实行垂直领导的行政机关、税务和国家安全机关的行政行为不服的，向上一级主管部门申请行政复议。*

- **什么是垂直领导**：一般行政机关是“双重领导”（如省公安厅既归省政府管，也归公安部管）。但垂直领导机关是“糖葫芦”——从中央直接垂到地方，**只有一个上级**，地方不能插手。
- **包括**：海关、金融、外汇管理、**税务**、国家安全机关。
- **最核心出题的**：**税务局**（国务院→国家税务总局→省税务→市税务→县税务）。
- **规则**：县税务局不予退税 → 复议机关是**市税务局**（不是县政府）。

**例外二：司法行政部门（司法局）**

*【法条注释】《行政复议法》第二十八条：对履行行政复议机构职责的地方人民政府司法行政部门的行政行为不服的，可以向本级人民政府申请行政复议，也可以向上一级司法行政部门申请行政复议。*

- **规则**：县司法局的行为 → 复议机关有两个选择——**县政府** **或者** **市司法局**。
- **法理**：县政府的复议案件实际由司法局审理。如果是县司法局自己做的行为被复议，再交给县司法局自己审自己，**不公正**。所以增加“市司法局”作为选择。

### 6. 复议机关与复议机构的区别

- **复议机关**：相当于“法院”——最终拍板、盖章的机关（如县政府、市政府）。
- **复议机构**：相当于法院的“行政审判庭”——复议机关内部实际审案子的内设机构（如县司法局代表县政府审理复议案件）。


## （四）代理人与代表人（讲稿扫尾部分）

### 1. 代理人

- 可以委托 **一至二名** 代理人。
- 可以是律师，也可以是基层法律服务工作者或其他代理人。
- 形式要求：提交**书面授权委托书**（委托权限、委托内容）。
- **例外**：无法书面委托的情况下，允许**口头委托**。

### 2. 代表人

- **诉讼**：原告10人时，选 **2-5名** 代表人（“二五一十”）。
- **复议**：申请人5人时，选 **1-5名** 代表人（“一五得五”，复议谐音“一”）。
- 代理人/代表人的行为对被代表人产生法律效力。
- 撤回案件等重大事项，需征得被代表人同意。

### 3. 法律援助

- 符合法律援助条件的申请人，法律援助机构应依法提供法律援助。
