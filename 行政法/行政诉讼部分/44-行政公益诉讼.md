# 一、讲稿知识点的提纲


## （一）公益诉讼的基本概念与类型识别

**1. 什么是公益诉讼**
- 为公共利益提起的诉讼。

**2. 民事公益诉讼与行政公益诉讼的识别——看被告**
- **民事公益诉讼**：被告是公司、企业或普通个人（如张三李四）。
  - 举例：企业排污，告这个企业 → 民事公益诉讼。
- **行政公益诉讼**：被告是行政机关。
  - 举例：企业排污，不告企业，告监管单位（如生态环境局）监管不作为 → 行政公益诉讼。

**【注释】**
- 民事公益诉讼与行政公益诉讼的区分标准是“被告主体性质”，这是法考中的重要识别方法。
- 《行政诉讼法》第25条第4款确立了行政公益诉讼制度：人民检察院在履行职责中发现生态环境和资源保护、食品药品安全、国有财产保护、国有土地使用权出让等领域负有监管职责的行政机关违法行使职权或不作为，致使国家利益或社会公共利益受到侵害的，应当向行政机关提出检察建议。


## （二）原告资格——行政公益诉讼与民事公益诉讼的核心区别

**1. 民事公益诉讼的原告（有顺序，两人）**
- **第一顺序**：社会团体（如环保联合会、消协）。
- **第二顺序（备胎）** ：检察院。
- 社会团体不起诉时，检察院才能提起。
- 立法理由：被告是老百姓，检察院作为国家机关“官告民”有大欺小之感，所以检察院不愿冲在最前面，立法上将其安排在第二顺位。

**2. 行政公益诉讼的原告（唯一）**
- **只有检察院**，没有社会团体什么事。
- 立法理由：被告是行政机关，检察院作为宪法规定的法律监督机关，维护公共利益，告行政机关不需要遮遮掩掩。
- 本质：**“官告官”** ——检察院（官）告环保局、教育局等行政机关（官）。

**【注释】**
- “官告官”是行政公益诉讼的典型特征，也是法考中的重要考点。
- 民事公益诉讼中检察院是“第二顺位”，行政公益诉讼中检察院是“唯一主体”——这一对比是法考选择题的常见陷阱。


## （三）程序规则——诉前程序

**1. 民事公益诉讼：公告程序**
- 有公告期（30天）。
- 目的：通过公告期体现社会团体的优先顺位——30天内环保联合会等先去，不去才轮到检察院。

**2. 行政公益诉讼：检察建议（前置程序）**
- **没有公告**（因为只有检察院一个原告，不需要排序）。
- **不能直接起诉**，必须先发检察建议。
- 目的：“官告官留一线”，尽量不要直接撕破脸。

**【法条依据】**
- 《最高人民法院、最高人民检察院关于检察公益诉讼案件适用法律若干问题的解释》规定：在提起行政公益诉讼前，检察机关应当向行政机关提出检察建议，督促其依法履行职责。
- 检察建议是提起行政公益诉讼的**必经程序**。


## （四）程序规则——检察建议后的流程

**第一步：发检察建议**
- 例：环境问题，环保局不抓 → 检察院向环保局发检察建议：“你得管管。”

**第二步：行政机关回应（两个月内）**
- 行政机关应当在收到检察建议书之日起**两个月内**依法履行职责，并书面回复人民检察院。
- 如果行政机关履行了职责 → 事情了结，不再起诉。

**第三步：行政机关不履行 → 提起诉讼**
- 如果行政机关不履行（不给面子）→ 检察院提起行政公益诉讼。


## （五）起诉期限

- **六个月**：行政公益诉讼的起诉期限为六个月。
- 讲稿中提到“起诉期就六个月”。

**【注释】**
- 关于起诉期限的具体适用，实践中存在一定争议：经检察建议督促后行政机关积极作为的，检察机关应当在知道或应当知道作出行政行为之日起六个月内提起；行政机关仍然不作为的，有观点认为不受起诉期限限制。法考中一般掌握“六个月”的基本规则即可。


## （六）例题

**题目**（讲稿中的真题）：

> 某公安局发现一公司没有取得林地合法征用手续，用挖掘机开采公路，损坏植被。公安局作出两个行为：①恢复原状；②罚款三万元（又管又罚）。公司交了罚款后结案。检察院发现不对——“以罚代管”，恢复还没做呢。于是发检察建议，要求公安局管这事（恢复原状）。检察建议发出后，公安机关不履行职责。检察院起诉。

**问题**：下列说法正确的是？

- **A. 这是行政公益诉讼** ✓
  - 理由：告的是公安局（行政机关），“官告官”。

- **B. 民间组织不起诉，检察院才能来** ✗
  - 理由：这是行政公益诉讼，只有检察院，没有民间组织什么事。如果是民事公益诉讼才这样。

- **C. 检察建议是起诉的前置程序** ✓
  - 理由：行政公益诉讼必须先发检察建议（“官告官留一线”）。

- **D. 起诉期为六个月** ✓

**答案：ACD**

**【段落一：公益诉讼的基本概念与识别】**

下面我们来看非常小的一个专题——公益诉讼。公益诉讼在选择题里历史上考过两次，不太重要，因为内容也不多，很好得分。

那么公益诉讼呢，实际上是为了公共利益提起的诉讼。但是有两种公益诉讼，你们学民诉的都会学，学行政的时候也会学。大家说怎么识别是民事还是行政呢？很简单嘛，就是你看被告就知道了呀。如果被告是一个公司、**[修改：原文“假公司”]** 一个企业、张三李四——一个普通的老百姓这样的人——那就是民事的呀。比如说一个企业排污，我告这个企业，那就是民事的。如果是行政的呢，这个被告一看就是个行政机关嘛。比如还是刚才的故事，企业排污，如果是行政的话，不告企业，告的是那个监管单位——生态环境局监管不作为。那这个就是行政的，很好识别。


**【段落二：原告资格——民事公益诉讼 vs 行政公益诉讼】**

那接着他们俩有什么区别呢？看原告资格。原告资格这里我没有只守住我的一门三分店啊，只讲行政，民事的也一定给大家说说。

你们民事的公益诉讼，它的提出者原告是有两人的，有顺序的。优先第一顺序的是我们所说的社会团体，比如说环保联合会、消协这样的社会团体。那么社会团体不起诉的时候，才轮着来检察院。等于民事的公益诉讼，检察院呢是第二顺位的选择，备胎。

但我行政的呢，检察院就是唯一选择，只有我。


**【段落三：原告资格差异的立法理由】**

大家说为什么两学科不一样？很简单，民事只有俩，是因为被告是个老百姓。你检察院作为一个国家机关，动不动诉老百姓——官告民——有点以大欺小的感觉，会丧失群众基础的。所以检察院不愿意提起。那么不愿意提又不能直接不让提怎么办呢？立法上就优先社会团体。比如说环境污染了，要诉这个企业，就说环保联合会你们要不要去？你们先去，你们不去，我再来。他其实是检察院躲在后面的，立法者把他当做备胎。检察院的立法思路有很强的——他其实是自己甘做备胎，他不愿意冲在最前面。优先社会团体，其次检察院，这是民诉。

但行政只有检察院，为什么？因为我的被告可不是老百姓了，是个行政机关。我检察院在这儿用不着遮遮掩掩。我检察院在宪法里叫法律监督机关，我维护公共利益，我去告一个教育局，告一个卫健委，告一个生态环境局，我用得着遮遮掩掩吗？所以行政法里检察院就成为了公益诉讼的唯一提出的原告。那么这个时候相当于一种全新的诉讼类型，叫做**官告官**。检察院这个官去告环保局、去告教育局那个官——叫官告官。你记住了官告官，就知道了行政公益诉讼的原告和被告了。


**【段落四：程序规则——公告 vs 检察建议】**

好，那接下来程序。这两个学科都不能直接起诉。民诉是以公告为前提的。为啥？因为民诉有两个人。比如说环境污染，优先社会团体，其次检察院，那你怎么体现谁先谁后啊？公告期啊。公告期三十天，三十天之内优先你环保联合协会，你先去，你去了你就去，你不去啊，我再来。通过公告期把社会团体的优先和检察院的靠后这个顺序呢就理得很顺，就不至于打起来冲突。民诉因为有两人，所以有公告。

但是呢，行政只有一个人——检察院，所以行的话这里有没有公告啊？没有。那没有的话，那能直接起诉吗？不能，要检察建议——“官告官留一线，尽量不要撕破脸”，对吧？所以要检察建议。


**【段落五：检察建议的具体流程】**

什么叫检察建议？你往上看看细节。比如说环境问题，环保局不抓，那于是呢我们就找到了这个环保局，提检察建议说：“环保局啊，你得管管啊，环境问题你得抓呀。”

结果你提了检察建议，如果他要履行了职责，两个月内履行了职责，那就罢了。

第三步，如果他不履行呢？你“官告官留一线”，你检察院好心给了他出面{[原文“出面”不通顺，保留原意]}的面子，他不尊重你怎么办？那就起诉——**[修改：原文“休告老娘不客气”改为“提起诉讼”]** 不客气了，我再来提起公益诉讼，那就大人不让了{[原文“大人不让”为口语表达，保留]}，好吧？

这就是公益诉讼的考点。来看一下下一页的真题。我说公益诉讼考过两次，两次都是一个题干，就这个，这是一个值得案例改编的。

说一个公安局发现啊，一个公司没有取得林地的合法征用手续，用挖掘机开采公路，把人家植被都给损坏了。公安局做了第一个行为是恢复原状，第二个行为是罚款三万元——又要恢复又要罚，这叫又管又罚。结果公司交了罚款之后呢，这个结案了。检察院发现不对呀，你这叫以罚代管啊，你只交了罚款，那恢复还没恢复呢。于是就发了检察建议，说公安你怎么不管呢，这得恢复原状啊。结果发了检察建议呢，公安机关不履行职责。那不履行职责去起诉。

正确的是：

**A. 这是个行政的公益诉讼。** 对，因为被告他是告那个公安局的嘛，官告官。

**C. 检察建议是起诉的前置程序。** 对的呀。民诉是俩人，所以要公告理顺先后；行政就得检察建议，官告官留一线，对吧？

**D. 起诉期六个月。** 现在法律起诉期就六个月，没什么。D正确。
