# 1、知识提纲与考点分析

## （一）知识提纲

### 专题：共同犯罪的结合问题

#### 一、共同犯罪与身份犯的结合

**1. 核心概念**

| 概念 | 含义 |
|------|------|
| 定罪身份（真正身份犯） | 只有具有特定身份的人才能构成该罪的正犯（实行犯） |
| 正犯 | 包括直接正犯和间接正犯 |
| 共犯 | 包括教唆犯和帮助犯 |

**2. 基本规则**

- 有身份 → 可构成正犯（直接正犯、间接正犯）
- 无身份 → **不能**构成正犯，但**可以**构成教唆犯、帮助犯
- 特殊身份是对**正犯**的限定，不是对**共犯**的限定

**3. 复杂情形处理**

> **【注】** 我国刑法总则对共犯与身份问题**没有一般性规定**。以下为刑法理论通说及司法实践中的处理规则。

双方均有身份且身份不同时：**分别从各行为人角度分析**其构成的罪名 → 各人可能触犯多个罪名 → **想象竞合，择一重罪论处**。

> **【传统理论观点】** 传统理论认为共同犯罪应定同一罪名，可能导致罪刑不相适应。现代通说认为共同犯罪不要求罪名相同，各定各的罪。

#### 二、共同犯罪与不作为犯的结合

**1. 基本规则**

- **先找出作为义务人**（相当于“定罪身份”）
- 只有作为义务人才能构成真正不作为犯的**实行犯**
- 无作为义务者只能构成**帮助犯**

**2. 作为义务的来源**

根据实质的二来源说：
- ①对**危险源**的监管义务
- ②对**法益对象**的保护义务（特定关系、特定领域）

**3. 先行行为的判断**

看先行行为是否**导致他人陷入危险状态**。如果是，则有作为义务。

#### 三、实行过限

**1. 核心规则**

- 判断标准：是否**超出共同故意的范围**
- 超出 → 不负**故意**责任；如有过失 → 负**过失**责任
- 实行过限者只能是**实行犯**

**2. 两种类型**

| 类型 | 说明 |
|------|------|
| 共同实行犯中的过限 | 某实行犯多干了超出共同故意的事 |
| 教唆犯/帮助犯+实行犯中的过限 | 实行犯多干了超出教唆/帮助范围的事 |

**3. 包容评价思维**

**杀人故意可以包容评价为伤害故意**——杀人的故意中蕴含了伤害的故意。

#### 四、共同犯罪与认识错误的结合

**1. 分析路线图**

**两个对象两条线**：
- 对象一：**预定目标** → 分析对该目标的犯罪形态
- 对象二：**实害对象** → 分析对该对象的犯罪形态
- 整体一个行为 → 想象竞合，择一重

**分析顺序**：先分析**正犯（实行犯）** ，再分析**共犯（教唆犯/帮助犯）** 。

**2. 观点展示**

在打击错误问题上存在两种学说：
- **具体符合说**：正常办事，实事求是
- **法定符合说**：特事特办，过失可“置换”为故意

**3. 共犯人成为被害人（乌龙案）**

- **共犯人（教唆犯/帮助犯）成为被害人**：对实害对象这条线**不用负责**（角色冲突）
- **正犯（实行犯）成为被害人**：对实害对象这条线**不用负责**；帮助犯根据**共犯从属性原理**也无罪

#### 五、核心原理总结

- **共同犯罪的本质**：“一起制造违法事实”（不要求罪名相同）
- **共犯从属性原理**：实行者无罪 → 教唆者/帮助者也无罪
- **分析顺序**：先正犯，后共犯

## 第一部分：共同犯罪与身份犯的结合

**1.1 基本概念回顾**

那接下来我们就看第十节，共同犯罪的结合问题。这一节主要讲的是：把共同犯罪作为一个平台，把我们此前学的许多知识点嫁接到这个平台上进行综合考察。这一块是高频考点。

我们先看第一个结合——**共同犯罪与身份犯的结合**。这里面主要考的是**定罪身份**，也就是**真正身份犯**。

关于定罪身份这一块，我们回顾一下以前的知识点：有定罪身份的那种真正身份犯里面，**只有有身份的人才有资格构成这个罪的实行犯（正犯）** 。你比如说，只有国家工作人员才有资格构成贪污罪的实行犯，也就是正犯——这个正犯既包括直接正犯，也包括间接正犯。【修正：原文此处有重复】

换句话说，如果没有这个身份的人，比如说官员的妻子，他是不可能构成贪污罪的正犯（不可能构成直接正犯，也不可能构成间接正犯）。这一点一定要注意。

**【例题1】**

有一个妻子，她要求丈夫去贪污。她丈夫是官员，丈夫不愿贪污，妻子一怒之下把菜刀一摔：“必须给我贪污，不贪污砍了你！”丈夫被妻子的淫威所迫，就去贪污，最终沦为妻子敛财的工具。

**问**：这个妻子是不是构成贪污罪的间接正犯？

**分析**：不是。因为间接正犯也是正犯，要构成贪污罪的正犯，就必须要有国家工作人员这个身份。妻子没有这个身份，她就不可能构成正犯，不可能构成间接正犯。她构成的是**教唆犯**——引起他人犯罪。

但是，妻子虽然不能构成贪污罪的正犯（实行犯），可不可以构成贪污罪的**教唆犯、帮助犯等共犯**呢？**可以**。要构成教唆犯、帮助犯，不要求有身份。

> **【注释】** 讲授者在此引入了“直接正犯”“间接正犯”“教唆犯”“帮助犯”等概念。直接正犯是指亲自实施犯罪实行行为的人；间接正犯是指利用他人作为工具实施犯罪的人（被利用者通常不具有刑事责任能力或无犯罪故意）；教唆犯是指引起他人犯罪意图的人；帮助犯是指为他人犯罪提供帮助的人。

**1.2 复杂情形：双方均有身份且身份不同**

做题要分类型：一种是一个人有身份、一个人没身份；最难的是**两个人都有身份，而且身份还不一样**。我们就分析这种最复杂的情况。如果这个会分析，那就很简单。这一块的分析没有什么特殊的知识点，只是正常分析。

**【例题2——标准案例】**

有一个**投保人**和一个**民营保险公司的经理**（民营保险公司经理说明他不是国家工作人员）内外勾结，一起骗本公司的保险金，骗出来以后把钱对半分。

**问**：怎么办？

**分析**：

**从投保人角度分析**：
- 投保人首先构成**保险诈骗罪**的实行犯（保险诈骗罪也是身份犯，身份是投保人、被保险人或受益人）
- 公司经理构成保险诈骗罪的**帮助犯**（共犯）

**从公司经理角度分析**：
- 公司经理构成**职务侵占罪**的实行犯（如果是国家工作人员则构成贪污罪）
- 投保人构成职务侵占罪的**帮助犯**（共犯）

**总结**：
- 投保人触犯两个罪：保险诈骗罪的实行犯 + 职务侵占罪的帮助犯。整体是一个行为，构成两个罪 → **想象竞合，择一重罪论处**。假如保险诈骗罪的实行犯更重，最终定保险诈骗罪的实行犯。
- 公司经理也触犯两个罪：职务侵占罪的实行犯 + 保险诈骗罪的帮助犯。想象竞合择一重。假如职务侵占罪的实行犯更重，最终定职务侵占罪的实行犯。

**1.3 传统理论的困境**

传统理论认为：共同犯罪就是共同得犯罪，共同得犯罪就是**相同的犯罪**——两个人既然构成共同犯罪，最终定的罪名必须定**同一个罪名**。

那这个同一个罪名是按谁的身份来定呢？看谁的身份更特殊、地位更高。比如公司经理地位更高一点，就按他的身份来定——大家都定**职务侵占罪**。

**问题**：对投保人来说，本来应该定更重的保险诈骗罪的实行犯，现在只能定职务侵占罪的帮助犯，**不当的轻纵了他，没有做到罪刑相适应**。

这个问题怎么产生的？就是因为传统理论认为共同犯罪一定要定相同的罪名，把共同犯罪理解成“相同的犯罪”，总是追求相同性。如果我们知道**共同犯罪不是相同的犯罪**，而是一起制造违法事实，各定各的罪无所谓，那就没问题了。


## 第二部分：共同犯罪与不作为犯的结合

**2.1 基本思路**

做这种题的思路：**先找出作为义务人**，作为义务人就相当于是一个“定罪身份”。然后根据他到底干了什么来判断。

**【例题3——遗弃罪】**

狗蛋因车祸高位截瘫瘫痪在床，妻子小芳含辛茹苦照顾。时间长了小芳受不了，把村里的狗剩叫来，说：“狗剩哥，你能不能帮我把狗蛋用小推车推到马路边扔了？”狗剩欣然前往，把狗蛋扔在马路边了。

**问**：怎么处理？

**A项**：狗剩构成遗弃罪的实行犯，小芳构成遗弃罪的教唆犯。

**B项**：小芳构成遗弃罪的实行犯，狗剩构成遗弃罪的帮助犯。

**答案**：**B项**。

**分析**：遗弃罪是**真正的不作为犯**，其犯罪主体必须是有作为义务的人（有抚养义务的人）。只有小芳有抚养义务（相当于定罪身份），只有她有资格构成遗弃罪的实行犯。狗剩没有这个身份，不是抚养义务人，没有资格构成遗弃罪的实行犯。

遗弃罪既然是真正的不作为犯罪，不作为犯罪不要求积极举动，只要求**不履行义务**。小芳让狗剩把人扔了，这就是不履行抚养义务——这就是**不作为的实行行为**。所以小芳才是遗弃罪的实行犯（正犯）。狗剩虽然忙得满头大汗，只能构成遗弃罪的**帮助犯**。

**【例题4——强制猥亵罪】**

小芳在厨房做饭，狗蛋瘫痪在床睡觉。狗剩来串门，走进卧室亲吻熟睡的狗蛋。狗蛋被亲醒，让狗剩滚，狗剩还在亲。狗蛋喊：“老婆，赶紧来救我！”小芳进卧室一看，竟然不阻止，靠在门框边袖手旁观。

**问**：小芳和狗剩怎么处理？

**分析**：
- **狗剩**：构成**强制猥亵罪**，作为方式。
- **小芳**：作为妻子，有阻止狗剩的义务。不履行阻止义务，就是不作为。这种不阻止就是帮助了狗剩的犯罪行为。小芳构成狗剩强制猥亵罪的**不作为方式的帮助犯**。

**2.2 先行行为与作为义务**

考试在这一块还喜欢考**作为义务的来源根据**。我们在讲不作为犯的时候讲过**实质的二来源说**：①对危险源的监管义务产生作为义务；②对法益对象的保护义务产生作为义务（包括特定关系、特定领域）。

在共犯与不作为犯结合的场合，常考的是**先行行为**。判断标准：**看先行行为有没有导致他人陷入危险状态**。如果有，就有保护义务（既包括保护人身法益，也包括保护财产法益）。

**【例题5——先行行为】**

狗蛋和铁牛商量去教训小芳，两人一起把小芳打成重伤。打成重伤后，狗蛋说撤吧，铁牛说：“我不撤，我现在想强奸。”狗蛋不阻止，在旁边袖手旁观。

**问**：两人怎么处理？

**分析**：
- **铁牛**：前面构成**故意伤害罪**，后面构成**强奸罪**，两罪并罚。
- **狗蛋**：首先和铁牛构成故意伤害罪的共同犯罪。狗蛋前面去打小芳的先行行为，导致小芳陷入危险状态（打成重伤），所以狗蛋对小芳有保护义务，有阻止铁牛强奸的义务。不阻止，构成强奸罪的**不作为方式的帮助犯**。

所以狗蛋和铁牛构成两个罪的共同犯罪：故意伤害罪的共同犯罪 + 强奸罪的共同犯罪。在强奸罪里面，铁牛是作为方式的实行犯，狗蛋是不作为方式的帮助犯。


## 第三部分：实行过限

**3.1 基本概念**

实行过限是**高频考点**。它指的是：两个人商量一起干A罪，结果在干的过程中，其中一个人多干了一个B罪。问题就是：另一个人要不要为B罪负责（背锅）？

**判断标准**：看实行过限的行为有没有**超出共同故意的范围**。如果超出了，不负故意责任；但如果对此有过失，可以负过失责任。

实行过限中，多干事儿的那个人只能是**实行犯**。主要出现在两种类型：①共同实行犯（共同正犯）；②教唆犯/帮助犯 + 实行犯。

**3.2 类型一：共同实行犯中的实行过限**

**【例题6——盗窃+强奸】**

狗蛋和铁牛商量一起盗窃小芳家。狗蛋在客厅偷，铁牛在卧室偷。铁牛在卧室偷的时候发现小芳在睡觉，情不自禁强奸了小芳。

**问**：狗蛋对铁牛的强奸罪要不要负责？

**分析**：**不用负责**。共同故意的范围是“入户盗窃”，强奸已经超出了共同故意的范围。所以狗蛋不背这个锅。

**3.3 类型二：教唆犯+实行犯中的实行过限**

**【例题7——伤害+杀人】**

狗蛋教唆铁牛去教训小芳：“你可以把他打得遍体鳞伤，但不能要他命。”铁牛去打小芳，小芳激烈反抗，铁牛只能使大招，抱起小芳猛摔到地上，小芳死亡。铁牛已有杀小芳的故意。

**问**：铁牛和狗蛋怎么处理？

**分析**：
- **铁牛**：构成**故意杀人罪**的实行犯（既遂）。
- **狗蛋**：不能选A项（故意杀人罪的教唆犯），因为狗蛋没有教唆杀人，杀人超出了共同故意的范围。但狗蛋对小芳的死亡有没有过失？**有**。狗蛋说“可以打成遍体鳞伤但不能让他香消玉殒”，说明已经预见到可能出人命，但轻信能够避免——这是**过于自信的过失**。所以狗蛋最终定**故意伤害罪（过失致人死亡）** 。【修正：原文此处有重复】

**【例题8——帮助犯+实行犯中的实行过限】**

狗蛋帮铁牛望风，铁牛进去伤害小方。小方战斗力爆表，铁牛使大招把小方劈死。

**问**：狗蛋怎么定？

**分析**：
- A项：狗蛋定故意杀人罪既遂（帮助犯）——❌
- B项：狗蛋只是故意伤害罪——❌
- C项：狗蛋是**故意伤害罪（过失致人死亡）** ——✅

狗蛋对死亡结果不负故意责任（没有帮助杀人的故意），但对死亡有过失（帮人去伤害，至少认识到可能出人命），所以定故意伤害罪（过失致人死亡）。

**3.4 引申问题一：不作为角度的补充分析**

**【例题9——盗窃+强奸（不作为角度再分析）】**

狗蛋和铁牛盗窃小芳家，铁牛在卧室强奸小芳。前面我们从实行过限角度分析了——狗蛋不用负责。但还要从**不作为**角度再分析：狗蛋看到铁牛强奸时无动于衷，有没有阻止义务？

**分析**：要看狗蛋的先行行为有没有让小芳陷入危险状态。狗蛋的先行行为是**盗窃**——对财产法益产生危险，手段平和，没有暴力，并没有让小芳这个人陷入危险状态。所以狗蛋没有阻止义务，不构成强奸罪的不作为帮助犯。

**结论**：两个角度分析完，狗蛋对铁牛的实行过限行为不负责任。

**3.5 引申问题二：实行不足**

**【例题10——杀人未遂+伤害既遂】**

狗蛋帮铁牛去杀小方，在外望风。铁牛进去后，小方主动答应做铁牛女朋友。铁牛说不杀你了，但为了给狗蛋一个交代，把小方两颗门牙打掉（轻伤）。

**问**：狗蛋怎么处理？

**分析**：
- **铁牛**：定**故意伤害罪**（轻伤既遂），实行犯。
- **狗蛋**：能不能定故意伤害罪的帮助犯？客观上有帮助行为（望风）。主观上只有帮助杀人的故意，没有帮助伤害的故意。但这里要用**包容评价思维**：**杀人可以包容评价为伤害，杀人的故意也可以包容评价为伤害的故意**。狗蛋有帮助杀人的故意，至少蕴含了帮助伤害的故意。所以狗蛋构成**故意伤害罪的帮助犯（既遂）** 。


## 第四部分：共同犯罪与认识错误的结合

**4.1 基本说明**

这一块不难，主要是“烦”。没有什么新知识点，只是把认识错误的知识在共犯平台上展示。

**4.2 类型一：共同正犯中的认识错误**

**【例题11——打击错误（不同构成要件间）】**

甲乙商量把在博物馆工作的丙干掉，两人来到博物馆开枪。甲打偏了，把旁边的文物打碎了；乙也打偏了，什么都没打中。

**问**：甲怎么处理？

**分析**：甲是**打击错误**，而且是**不同构成要件间的打击错误**（预定目标是“人”，实害对象是“文物”）。按两个对象两条线分析：

| 对象 | 罪名 |
|------|------|
| 预定目标（丙） | 故意杀人罪（未遂） |
| 实害对象（文物） | 过失损毁文物罪 |

甲构成两个罪，**想象竞合，择一重罪论处**。

**4.3 类型二：教唆犯+实行犯中的认识错误**

**【例题12——杀手认错人】**

狗蛋教唆乔峰去杀段王爷。乔峰埋伏在段王爷下班路上，看到一个身影以为是段王爷，三拳两脚打死。事后发现是阿朱（认错人了）。

**分析路线图：两个对象两条线**

**先分析实行犯乔峰**：
- 对预定目标（段王爷）：段王爷不在现场，杀段王爷**未着手** → 故意杀人罪的**犯罪预备**
- 对实害对象（阿朱）：对象认错不重要（故意杀人罪只要求认识到是个人就行） → 故意杀人罪**既遂**
- 整体一个行为，想象竞合 → 最终定**故意杀人罪既遂**

**再分析教唆犯狗蛋**：
- 对预定目标（段王爷）：跟着实行犯走 → 犯罪预备
- 对实害对象（阿朱）：狗蛋对阿朱的死亡有**过失**（过于自信的过失），属于**打击错误**

**观点展示**：
- **具体符合说**：正常办事。狗蛋对段王爷构成故意杀人罪（犯罪预备），对阿朱构成过失致人死亡，想象竞合择一重。
- **法定符合说**：特事特办。过失“置换”为故意，狗蛋对阿朱也定故意杀人罪既遂，想象竞合择一重，最终定**故意杀人罪既遂**。

**4.4 教唆犯与间接正犯之间的认识错误**

记住一个结论：**在教唆犯和间接正犯之间产生认识错误，定教唆犯**。

教唆犯是A，间接正犯是A+B。在A和A+B之间产生认识错误，保证在A的范围内可以做到主客观相一致，所以定教唆犯。

**4.5 类型三：共犯人成为被害人（“乌龙案”）**

**（1）共犯人（教唆犯/帮助犯）成为被害人**

**【例题13——渔网案】（2019年考过）**

帮助犯甲帮实行犯乙去盗窃丙的渔网。乙拿着甲的工具去盗窃，湖面上有好多渔网，乙认错了，把甲自己的渔网偷回来了。

**分析**：

**先分析实行犯乙**：
- 对预定目标（丙的渔网）：丙的渔网在现场但乙没看到 → **未着手** → 盗窃罪的**犯罪预备**
- 对实害对象（甲的渔网）：对象错误不重要（盗窃罪对象是“他人的财物”即可） → 盗窃罪**既遂**
- 整体一个行为，想象竞合 → 最终定**盗窃罪既遂**

**再分析帮助犯甲**：
- 对预定目标（丙的渔网）：跟着实行犯走 → 犯罪预备
- 对实害对象（甲的渔网）：**不用负责**（甲就是被害人，犯罪人和被害人角色冲突）
- 最终甲只构成对丙渔网的**犯罪预备**

**【例题14——教唆强奸反成被害人】**

乙女教唆甲男去强奸丙女。甲男去了，恰好丙女不在宿舍，乙女在宿舍睡觉。甲男误将乙女当丙女强奸了。

**分析**：

**先分析实行犯甲男**：
- 对预定目标（丙女）：丙女不在现场 → **未着手** → 强奸罪的**犯罪预备**
- 对实害对象（乙女）：对象错误不重要（强奸罪对象是“妇女”即可） → 强奸罪**既遂**
- 想象竞合 → 最终定**强奸罪既遂**

**再分析教唆犯乙女**：
- 对预定目标（丙女）：跟着实行犯走 → 犯罪预备
- 对实害对象（乙女）：**不用负责**（乙女是被害人）
- 最终乙女构成强奸罪的教唆犯（**犯罪预备**）

> **【注意】** 网上有人说乙女无罪——这个结论**武断**。乙女至少对丙女构成犯罪预备。

**（2）正犯（实行犯）成为被害人**

**【例题15——自己撬自己车】**

甲参加新郎乙的婚宴，吃到一半要走，发现摩托车丢了。乙说给你撬一辆，甲说好并帮乙找工具。乙拍了一辆摩托车要撬，甲说“别撬这辆，撬旁边那辆”。乙撬开新车让甲骑走。第二天甲发现——昨晚撬的就是自己的摩托车。

**分析**：

**实行犯是乙，帮助犯是甲**。预定目标是“他人的摩托车”，实害对象是乙自己的车。

**先分析实行犯乙**：
- 对预定目标（他人的车）：已经着手撬了，但自动放弃 → **实行阶段的犯罪中止**
- 对实害对象（自己的车）：**不用负责**（自己把自己的东西撬了）
- 最终：对他人车构成**犯罪中止**

**再分析帮助犯甲**：
- 对预定目标（他人的车）：跟着实行犯走？注意——犯罪中止要**亲力亲为**。甲说“别撬那辆，撬这辆”，也是自动放弃 → 也是**犯罪中止**
- 对实害对象（乙的车）：实行犯乙对这条线无罪，根据**共犯从属性原理**（实行者无罪，教唆者/帮助者也无罪）→ 甲也无罪
- 最终：甲对他人车构成**犯罪中止**

**【例题16——追捕者案】（德国真实判例）**

甲乙约定共同入户抢劫丙家，约定如果主人丙追赶就开枪打死他。两人抢劫后逃跑，甲发现有人追赶（实际上是以【即乙】），开枪射击，把乙打伤了（没打死）。丙当时在现场但甲没看到。

**分析**（两人都是实行犯）：

**分析甲**：
- 对预定目标（丙）：丙在现场但甲没看到 → 杀丙**未着手** → 故意杀人罪**犯罪预备**
- 对实害对象（乙）：开枪想杀乙但没打死 → 故意杀人罪**未遂**

**分析乙**：
- 对预定目标（丙）：按照**部分实行全部负责**原则 → 犯罪预备
- 对实害对象（乙）：**不用负责**（乙是被害人）
- 最终乙只构成对丙的**犯罪预备**


## 第五部分：共同犯罪大总结

**5.1 核心原理**

共同犯罪不是“共同去犯相同的罪”，而是 **“一起制造违法事实”** ——八个字概括。

- **一起制造**：要有意思联络
- **违法事实**：法益侵害事实

**5.2 四大角色**

| 角色 | 说明 |
|------|------|
| 共同正犯 | 一起通过实行行为制造违法事实 |
| 间接正犯 | 引起 + 支配（主要是通过欺骗形成支配力） |
| 教唆犯 | 故意**引起**正犯制造违法事实 |
| 帮助犯 | 故意**促进**正犯制造违法事实 |

**5.3 共犯从属性原理**

**如果实行者无罪，教唆者、帮助者也无罪。**

**5.4 各节要点回顾**

| 主题 | 要点 |
|------|------|
| 共犯与身份 | 分别分析，想象竞合，正常处理 |
| 共犯与不作为 | 作为义务的判断（特别是先行行为） |
| 实行过限 | 看是否超出共同故意范围；超出不负故意责任，看是否负过失责任 |
| 共犯与认识错误 | 先分析正犯，再分析共犯；两个对象两条线 |

**5.5 分析路线图**

破解共犯与认识错误问题的路线：**先分析正犯，再分析共犯；分析时都是“两个对象两条线”** 。
