# 1、敲诈勒索罪知识提纲（法考备考用）

## （一）刑法条文

**《中华人民共和国刑法》第二百七十四条**

敲诈勒索公私财物，数额较大或者多次敲诈勒索的，处三年以下有期徒刑、拘役或者管制，并处或者单处罚金；数额巨大或者有其他严重情节的，处三年以上十年以下有期徒刑，并处罚金；数额特别巨大或者有其他特别严重情节的，处十年以上有期徒刑，并处罚金。

## （二）犯罪构成要件

| 要件 | 内容 |
|------|------|
| **犯罪主体** | 一般主体，年满16周岁且具备刑事责任能力 |
| **主观方面** | 直接故意，具有非法占有公私财物的目的 |
| **客观方面** | 实施恐吓行为→使对方产生恐惧心理→对方基于恐惧交付财物→行为人取得财物 |
| **犯罪客体** | 复杂客体：公私财物所有权 + 他人人身权利或其他权益 |

## （三）核心知识点详解

### 1. 行为公式（四步曲）——必背

① 带着非法占有目的实施恐吓行为 → **（成立）**
② 使对方产生恐惧心理
③ 对方基于恐惧心理交付财物
④ 行为人取得财物 → **（既遂）**

**【注意】** 只要实施①，犯罪即成立；①→②→③→④完整实现，才既遂；③断裂（非基于恐惧交付），即使取得财物也是未遂。

### 2. 恐吓/胁迫/威胁的含义

**定义**：以恶害相通告——你若不答应我的要求，我会对你施加恶害。

**注意**：威胁的内容必须是对**被害人**施加恶害。如果是以“我自杀”相威胁（对自己施加恶害），不属于敲诈勒索罪的恐吓行为。

**恐惧心理的程度要求**：必须达到让人“很害怕”的程度。轻微的不便（如不给身份证）不构成。

### 3. 与抢劫罪的区分（高频考点）

| 区分维度 | 抢劫罪 | 敲诈勒索罪 |
|----------|--------|------------|
| **核心标准** | 完全剥夺意志自由 | 部分剥夺意志自由 |
| **被害人状态** | 没得选，只好给 | 有的选，但最好给 |
| **暴力胁迫程度** | 压制反抗 | 足以产生恐惧即可 |

**注意**：不要用“当场性”来区分——抢劫可以当场，敲诈也可以当场。两罪是**程度之分**，抢劫可以包容评价为敲诈。

### 4. 与行使权利的区分（重点）

**判断标准**：有无**非法占有目的**
- 有**事实依据** + 有**法律依据** → 无非法占有目的 → 不构成敲诈罪
- 无事实依据 或 无法律依据 → 可能有非法占有目的

**例题对比**：
- ✅ 冰淇淋吃出异物 → 索赔精神损害赔偿 → 有事实+法律依据 → 不构成犯罪
- ❌ 索要“青春损失费/分手费” → 无法律依据 → 可能构成犯罪

### 5. 与诈骗罪的关系

- 两罪**可以想象竞合**（一个行为同时触犯两罪），择一重罪论处
- **不构成敲诈的情形**：编造“第三方”会施加恶害，被害人恐惧的是第三方而非行为人 → 只构成诈骗罪

**【关键逻辑】** 敲诈罪要求“我（行为人）对你施加恶害”；如果只是编造“别人会对你施加恶害”，只构成诈骗。

# 2、讲稿切分与整理（按逻辑顺序分段）


## 第一部分：敲诈勒索罪的行为公式（四步曲）

**（一）四步曲概述**

敲诈勒索罪的行为公式也是四步曲。第一步，带着非法占有目的实施一个恐吓行为；第二步，使对方产生恐惧心理；第三步，对方基于恐惧心理而交付财物、处分财物；第四步，行为人因此取得财物。

只要实施了第一步，敲诈罪就已经成立了。如果顺利实施到第四步并取得财物，敲诈罪就既遂了。完整的第四步就是既遂条件。但如果中间有一个因果链条断裂，那就不是既遂。【*注：讲授者在此处引入了“因果链条”的概念，用于分析敲诈勒索罪的既遂与未遂问题。*】

**（二）第一步：成立条件——恐吓行为**

**【修改说明】** 原文中“那不法要求如果是要钱，哎那这就是敲诈勒索罪了，明白吧？啊就是这样。法要求，如果是要钱，哎，那这就是敲诈勒索罪了，明白吧？啊，就是这样。”存在明显的重复，已删除重复部分。

恐吓与三个词语含义相同：恐吓、胁迫、威胁、敲诈。【*注：讲授者在此处将“敲诈”也列为同义词语，但在刑法学理中，“敲诈”通常是对行为的整体描述而非威胁手段本身，此处可理解为讲授者为了便于记忆而作的简化表述。*】

胁迫的行为模型：以恶害相通告——你若不答应我的要求，我会对你施加恶害，由此让你对我产生恐惧心理。然后你基于恐惧心理，满足了我的不法要求。这个不法要求如果是要钱，那就是敲诈勒索罪。

**【例题1】前男友裸照案**
男朋友跟女朋友提出分手，给女朋友打电话说：“我手里有咱们当年那些不堪入目的照片，三天内给我打十万元，不打十万元，我就把这些照片曝光。”问：这个前男友够不够成敲诈勒索罪？

答：构成。这就是在恐吓、威胁、胁迫、敲诈。

**【例题2】捡身份证索财案（真题考点）**
小芳不小心把身份证掉在大街上，狗蛋捡到了，给小芳打电话说：“三天内不给我十万元，我就不给你身份证。”问：狗蛋够不够成敲诈勒索罪？

答：不构成。虽然这也是谈条件，但敲诈勒索中的恐吓、威胁、胁迫要求达到让人产生恐惧心理的程度。不给身份证不至于让人产生像裸照曝光那样的恐惧心理，挂失补办即可。因此不构成敲诈勒索罪，按行政处罚或民事侵权处理即可。

## 第二部分：既遂条件——因果链条的断裂

**（三）既遂条件的核心：第三步**

既遂条件主要考因果链条有没有断裂，最核心的是看第三步——对方是否基于恐惧心理而交付财物。

**【例题3】“陈浩南”案（因果链条断裂）**
狗蛋给铁牛打电话：“限你三天内给我打十万元，不打十万元，我就卸你一条腿，有你的好看。”铁牛接电话后对手下说：“我的真名叫陈浩南，只有我敲诈别人，从来没有人敢敲诈我。查一下这家伙是谁，这么有种，是个人才，给他打十万元。”于是就打了十万元。

问：狗蛋构成敲诈勒索罪的既遂吗？

答：不构成既遂，构成敲诈勒索罪未遂。理由：狗蛋的敲诈罪已经成立（第一步已实施），但缺少了第三步——铁牛不是基于恐惧心理交付财物，而是基于欣赏的心理。因果链条断裂，取得钱财不算敲诈罪的既遂，只能算未遂。拿到钱的环节算赠与。【*注：此处讲授者将“赠与”作为一个民事法律概念引入，用于说明行为人取得财物但缺乏刑法上因果关系的法律评价。*】

**【例题4】配合警方抓捕案（主观题高频考点）**
狗蛋给小方打电话：“我手里有你裸照，三天内把钱放到指定地点，五万元，不放到话，我就把你裸照曝光。”小方报警，警方让其配合，把钱放到指定地点引诱狗蛋上钩。小方照做后离开，五分钟后果蛋出现，刚要取钱时被埋伏的警察抓获。

问：狗蛋构成敲诈罪的既遂还是未遂？

答：未遂。

**【修改说明】** 原文中“那这个未遂我要问大家啊，你要给我说理由啊，啊客观题你可能能选对说是未遂。说理由啊，啊客观题你可能，能选对说是未遂”存在重复和语句不通，已整理。

追问：理由是不是“狗蛋还没拿到钱就被抓，所以当然是未遂”？

答：这个理由不准确。如果把案情改成——狗蛋拿到钱后警察才出现，狗蛋逃跑成功，钱也拿到手了——是不是就既遂了？答案还是未遂。

真正的理由：缺少了敲诈罪的第三步——小方不是基于恐惧心理交付财物，而是基于配合警方抓捕的心理交付财物。所以在第三步一打叉，就注定了敲诈罪只能是未遂，即使拿到钱财也只能是未遂。（**主观题考点**：必须掌握这一底层原理，不能只背结论。）


## 第三部分：敲诈勒索罪与抢劫罪的区分

**（四）错误的区分标准：当场性**

**【修改说明】** 原文中“抢劫的确要求当场取得财物，但是敲诈是不是只能日后取得财物啊，不能当场取得财物啊？你如这样理解我就问你”语句略有不通，已调整。

有些同学用“抢劫要求当场取得财物，敲诈勒索不能当场取得财物”来区分两罪——这个标准是半桶水，只对了一半。

**【例题5】黑社会收保护费案（反驳“当场性”标准）**
黑社会到门店收保护费，说：“限你三天内把钱打到我的账上，不然有你的好看。”店老板说：“我现在就给钱。”黑社会老大说：“不行，说三天后就三天后。你现在给我打钱，你是害我——我学过刑法的，当场取钱就成了抢劫，那是很重的罪。”

问：如果黑社会老大当场收钱了，是不是就变成抢劫了？

答：不是，依然是敲诈。敲诈勒索也可以当场取钱。所以“当场性”这个标准无法区分抢劫和敲诈。【*注：此处讲授者的观点与部分传统刑法理论存在差异。传统观点认为抢劫罪通常要求当场取得财物，而敲诈勒索罪可以当场也可以事后取得。讲授者此处强调的是“当场性”不能作为两罪的本质区分标准，但并未否认两罪在“当场性”上可能存在程度差异。*】

**（五）正确的区分标准：被害人意志自由被剥夺的程度**

真正的区分标准只有一个：**被害人意志自由被剥夺的程度**。

- **抢劫罪**：完全剥夺被害人的意志自由，压制你的反抗——**没得选，只好给**。
- **敲诈勒索罪**：只剥夺一部分意志自由，没有压制反抗，保留了一定的选择自由——**有的选，但最好给**。

**【例题6】黑社会收保护费（应用区分标准）**
- 说“现在就给钱，现在不给钱，我就把你店给砸了”→ 抢劫（店老板没得选）
- 说“三天后不给钱，我就砸你的店”→ 敲诈勒索（店老板还有得选）

**核心原理**：抢劫与敲诈的区分没有本质区别，是**程度之分**。抢劫可以包容评价为敲诈（本科生与硕士生的关系）。【*注：“包容评价”是刑法理论中的概念，指重罪可以包含轻罪的构成要件。讲授者用“本科生与硕士生的关系”作比喻，意在说明抢劫罪的成立条件更为严格，能够成立抢劫罪的行为通常也符合敲诈勒索罪的构成要件。*】


## 第四部分：敲诈勒索罪与行使权利的区分

**（六）标准案例：冰淇淋店吃出异物案**

男朋友请女朋友在哈根达斯（**修改说明**：原文中讲授者口误说成“阿迪达”，后自行纠正为“哈根达斯”，此处保留纠正后的正确表述）吃冰淇淋，女朋友吃出一个小布条。男朋友很生气，给店家说：“精神损害赔偿十万元，否则的话网上曝光。”店家报警，男朋友被以涉嫌敲诈勒索罪抓获。

问：够不够成敲诈勒索罪？

答：不构成。敲诈勒索罪的成立条件有两个要件：（1）有无非法占有目的？（2）有无实施恐吓行为？

判断有无非法占有目的——看索赔有没有**事实依据**和**法律依据**：
- 事实依据：有（确实吃出了异物）
- 法律依据：有（民法上有精神损害赔偿的诉权）

只要有事实依据和法律依据，就有索赔的权利，就没有非法占有目的。至于要钱多还是少，是漫天要价还是讨价还价的问题，不能因为漫天要价就说有非法占有目的。【*注：此处讲授者引入了民法上“精神损害赔偿”和“诉权”的概念，属于民法范畴的延伸知识点。*】

**（七）对比案例：小三索要分手费/青春损失费案**

男明星养小三六年，后要分手。小三要求青春损失费（分手费）一千万，男明星不给。小三说：“不给的话，我就把咱们多年来的照片、视频网上曝光。”男明星报警，小三被抓。

问：小三够不够成敲诈罪？

第一步：有无非法占有目的？
- 事实依据：似乎有（确实陪了六年）
- 法律依据：没有（民法上没有“分手费”“青春损失费”的诉求）

→ 有非法占有目的。

第二步：有无恐吓行为？
- “不给钱就把不堪入目的视频曝光”→ 是恐吓行为，会让人产生恐惧心理

→ 满足了敲诈罪的第一步，构成敲诈勒索罪。

**【修改说明】** 原文中“那这时候呢也你也不能说我要一个什么所谓的换个名目叫精神损害赔偿啊，明白吧？啊他只能叫什么分手费呀或者是什么青春损失费啊。”语句不通，已整理。

**【知识点澄清】** 冰淇淋店案与小三案的区别：冰淇淋店案有侵权行为（吃出异物），可以主张精神损害赔偿，有法律依据；小三案是自愿的包养关系，不构成侵权，不能主张精神损害赔偿，没有法律依据。

**（八）重要提示：判断罪与非罪的唯一标准**

**【修改说明】** 原文中关于女演员咨询的叙述较长且较为口语化，但包含了重要的知识点（“以自杀相威胁”不构成敲诈勒索罪），已保留核心内容并适当精简。

判断有罪无罪的唯一标准是**刑法规定的构成要件**，而不是道德标准。不能因为某个人“很渣”就认为对方不构成犯罪，也不能因为“知三当三”就认为构成犯罪。

**【例题7】以自杀相威胁索财案**
女演员找大老板（前男友）要钱，说：“你如果不给钱，我就上吊自杀。”大老板很怕出人命，给了钱。

问：女演员构成敲诈勒索罪吗？

答：不构成。因为敲诈勒索中的恐吓/胁迫是指“你若不答应我的要求，**我对你施加恶害**”。而女演员说的是“**我对自己施加恶害**”（自杀），这不属于敲诈勒索罪的恐吓行为，不构成敲诈勒索罪。【*注：讲授者此处通过“自杀威胁”的案例展示了敲诈勒索罪中“恐吓行为”的边界——威胁的内容必须是对**被害人**施加恶害，而非对行为人自己。*】


## 第五部分：敲诈勒索罪与诈骗罪的关系

**（九）两罪可以想象竞合**

敲诈罪和诈骗罪不是A与非A的对立排斥关系，它们完全可以想象竞合。【*注：想象竞合是指一个行为同时触犯两个以上罪名，择一重罪处罚。*】

**【例题8】PS裸照敲诈案**
狗蛋给女明星打电话：“我手里有你的裸照，三天内不给我三万元，我就把裸照曝光。”女明星说：“我洁身自好，不可能有这种裸照。”狗蛋说：“不相信见面验证。”验证后女明星信了，给了三万元。实际上裸照是PS的。

问：狗蛋构成哪些罪？

答：既构成敲诈勒索罪（不给钱就曝光裸照，让人产生恐惧心理），又构成诈骗罪（骗了女明星）。整体是一个行为，两罪想象竞合，择一重罪论处。

**【例题9】“会所小王”电话敲诈案（实务案例）**
男的收集当地官员的电话号码，让女的挨个打电话：“我是会所的小王呀，最近很缺钱，你得给我打钱，不给我打钱，当时咱们干的那些事儿我可是偷拍了，到时候曝光。”

问：这对男女构成什么罪？

答：既构成敲诈勒索罪，又构成诈骗罪。想象竞合，择一重罪论处。

**（十）只构成诈骗罪、不构成敲诈勒索罪的情形（真题考点）**

**【例题10】编造黑社会报复案（真题）**
狗蛋得知铁牛与黑社会老大有过节，骗铁牛说：“你把黑社会老大得罪得不轻，人家过两天要来卸你一条腿。你给我五千块钱，我帮你摆平，我认识那个黑社会老大。”铁牛害怕，给了五千块钱。实际上黑社会老大并没有报复计划。

问：狗蛋构成什么罪？

答：只构成诈骗罪，不构成敲诈勒索罪。

理由：铁牛确实产生了恐惧心理，但**不能反推**——只要被害人产生恐惧心理，犯罪人就一定构成敲诈勒索罪。敲诈勒索罪要求“以恶害相通告”——**你若不答应我的要求，我（或我派人）对你施加恶害**。

在本案中，铁牛恐惧的是“黑社会老大要卸他一条腿”，而不是恐惧狗蛋要对他做什么。狗蛋没有以“我对你施加恶害”来威胁铁牛，所以不构成敲诈罪，只构成诈骗罪。
