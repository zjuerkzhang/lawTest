#### 职务侵占罪与财产犯罪总结 备考提纲

##### 一、 职务侵占罪（《刑法》第271条）

**1. 基本概念**
公司、企业或其他单位的工作人员，利用职务上的便利，将本单位财物非法占为己有，数额较大的行为。

**2. 行为模型：A（实行行为）+ B（特殊要件）**

| 要件 | 内容 | 说明与考点 |
| :--- | :--- | :--- |
| **A 实行行为** | 侵占、盗窃、诈骗 | 多数说。即行为本身符合这三个罪之一的构成。 |
| **B1 主体** | 单位职员（非国家工作人员） | 若是国家工作人员，定**贪污罪**。本质是“非国家工作人员贪污罪”。 |
| **B2 对象** | 本单位财物 | 通常指非国有单位的财物。 |
| **B3 方式** | **利用职务便利** | **核心考点**。必须同时满足：<br>1. **职务**：具有**管理性**（如总监），不包括**劳务性**（如装卸工）。<br>2. **利用**：必须是**实质利用**（利用职权），不包括**形式利用**（仅利用环境便利）。 |

**3. 核心考点与例题**

| 考点 | 关键判断 | 例题结论 |
| :--- | :--- | :--- |
| **“职务”的认定** | 管理性 vs 劳务性 | 装卸工偷货物→**盗窃罪**（非职务侵占）。 |
| **“利用”的认定** | 实质利用 vs 形式利用 | 财务总监利用身份进仓库偷零件→**盗窃罪**（形式利用）。 |

> **【注释】**：讲授者提到“挪用资金罪”会在后续与“挪用公款罪”一起总结，“拒不支付劳动报酬罪”是纯正的不作为犯罪。这些超出本节主题，但属于财产犯罪章节的普通罪名。

##### 二、 财产犯罪通用核心问题总结

**1. 既遂标准：取得控制（占有）说**

| 财物类型 | 场景 | 既遂时点 | 理由 |
| :--- | :--- | :--- | :--- |
| **小件物品** | 公共场所、商场 | 装入口袋 | 无搜身权 |
| | 超市（未布控） | 装入口袋 | 无搜身权 |
| | 超市（已布控） | 拿出收银台 | 已布控，失主仍可控 |
| | 入户盗窃 | 出户门 | 主人有控制权 |
| | 在户内（保姆/客人） | 装入口袋 | 主人对保姆/客人无搜身权 |
| **大件物品** | 商场 | 出商场大门 | 才置于自己实际控制下 |
| **空间距离** | 藏于秘密地点 | 藏匿完成时 | 不要求财物随身，既遂不可逆 |

> **【主观题考点提示】**：既遂标准常考“观点展示”。例如“保姆藏戒指案”，多数说认为藏匿时既遂，少数说可主张未遂。考试时需能陈述两种观点及理由。

**2. 数额问题**

| 财物档次 | 价值范围（约） | 保护程度 | 涉及的罪名/行为 |
| :--- | :--- | :--- | :--- |
| **第一档（数额较大）** | 2000元左右 | **完整保护** | 所有财产犯罪 |
| **第二档（数额不大）** | 100-300元 | **有限保护** | 抢劫罪；特殊类型盗窃罪（入户、多次、携凶器、扒窃） |
| **第三档（数额很小）** | 几元至几十元 | **不保护** | 治安处罚或民事赔偿 |

**3. 数额问题上的核心原则与误区**

- **原则：主客观相一致原则**。数额（较大/巨大/特别巨大）的认定，既要看客观价值，也要看行为人主观认识。

| 情形 | 主观认识 | 客观价值 | 结论 |
| :--- | :--- | :--- | :--- |
| **主观价值低** | 数额很小（如豆角） | 数额巨大（40万） | **不构成犯罪**（主客观不一致） |
| **客观未得逞** | 数额较大（华丽提包） | 数额很小（100元） | **构成盗窃罪（未遂）**（有危险性） |
| **对象认识错误** | 数额巨大（3万珠宝） | 数额较大（3千珠宝） | **多数说**：既遂（3千）+未遂（3万），择一重刑 |

**4. 特殊财物的价值认定**

| 财物类型 | 价值认定 | 法律后果 |
| :--- | :--- | :--- |
| **购物卡（不记名）** | 卡内金额 | 普通盗窃即构成盗窃罪（数额较大）。 |
| **银行卡（记名）** | 卡本身属第二档财物 | 1. 普通盗窃不构成盗窃罪。<br>2. 抢劫或特殊类型盗窃可构成。<br>3. 使用卡内资金，定信用卡诈骗罪。 |
| **违禁品（毒品）** | 按非法交易行情估价 | 达到数额标准，可定盗窃罪。 |

**5. 犯罪数额的时间认定**

| 数额类型 | 认定时点 | 特点 |
| :--- | :--- | :--- |
| **犯罪所得数额（既遂数额）** | **行为时/犯罪时** | **固定不变**。如受贿100万，即使全赔了，仍按100万认定。 |
| **犯罪所得收益数额** | **案发时** | 以案发时实际收益为准。赚了多少算多少，赔了则不计。 |

**【讲稿正文】**

**主题：职务侵占罪与财产犯罪总结**

**一、 职务侵占罪的行为模型（A+B公式）**

好，那接下来我们看第八节，职务侵占罪。这个罪我们说了，是一个类似综合性的罪名。为了把这个罪讲清楚，我给大家画了一个图表，总结一下这个罪的行为公式。

这个罪呢，你就记住有一个 **A加B** 的行为模型。
- **A是实行行为**。多数说认为实行行为有三个：侵占、盗窃、诈骗。少数说认为实行行为只有一个，就是侵占。[此处以多数说为准]。
- 在这三个罪（A）的基础上，多了个 **B要件**，就升级成了职务侵占罪。

B要件一共有三个：
1.  **B1 行为主体**：是单位的职员，但不能是国家工作人员。如果是国家工作人员，构成贪污罪。所以职务侵占罪可以理解为非国家工作人员的贪污罪。
2.  **B2 行为对象**：是单位的财物，这个单位往往不是国有单位。财物可以包括财产、行李等。
3.  **B3 行为方式**：要求“利用职务便利”。这是考试最喜欢考的点，里面有两个核心考点。

**（一）考点一：对“职务”的理解（缩小解释）**
这个“职务”要狭义理解，只包括具有**管理性**的职务，不包括纯粹的**体力性劳务**。
- **举例**：财务总监、人力资源部部长的职务算；装卸工、搬运工不算。

**例题1（劳务 vs 职务）**
> 某物流公司有个装卸工，他在装卸货物时，悄悄将其中一件货物拿回家。问如何处理？
> **分析**：
> - 行为A（实行行为）：盗窃。
> - B1（主体）：是公司职员，打勾。
> - B2（对象）：是公司财物，打勾。
> - B3（方式）：装卸工是纯粹体力劳动，不具有管理性，不符合“职务”要求，打叉。
> **结论**：升级不了职务侵占罪，只能构成普通**盗窃罪**。

**（二）考点二：对“利用”的理解（实质利用 vs 形式利用）**
这个“利用”必须是**实质利用**，不能是**形式利用**。
- **实质利用**：利用自己的职权。例如，财务总监登录公司账户，将钱划到自己账上。这构成**职务侵占罪**。
- **形式利用**：容易接近目标、熟悉环境等。例如，财务总监利用身份进出仓库，偷走零部件。这属于形式利用。

**例题2（形式利用）**
> 某民营公司财务总监，利用身份大摇大摆走进后勤仓库，趁库管员不备，偷走一个珍贵零部件。
> **分析**：
> - 行为A：盗窃。
> - B1（主体）：是公司职员，打勾。
> - B2（对象）：是公司财物，打勾。
> - B3（方式）：他只是利用了“容易进入场所”的便利，是形式利用，打叉。
> **结论**：升级不了职务侵占罪，只能构成**盗窃罪**。

> **【讲授者补充】**：职务侵占罪还有很多具体问题（如行为对象、行为主体等），会放在后面讲财产性利益时再渗透。财产犯罪最重要的七大罪名讲完了。第九节的几个普通罪名（故意毁坏财物罪、挪用资金罪、拒不支付劳动报酬罪）不集中讲了，大家自己看，后续讲到相关罪名时会再遇到。

**二、 财产犯罪的既遂标准总结（取得型犯罪）**

接下来讲第十节，财产犯罪的既遂问题。取得型财产犯罪（盗窃、诈骗、抢劫等）的既遂，要求实现“非法占有目的”，即对财物建立自己的占有，也就是取得控制，将财物置于自己的实际控制范围内，排除他人支配。这个“取得控制”的标准在考试中考查较多。

**（一）小件物品的既遂认定（因场所不同而不同）**

1.  **公共场所（大街、公交车、商场）**：小偷将小件物品（如戒指）装进自己口袋，即告既遂。因为普通公民或商场工作人员对小偷没有搜身权。
2.  **超市**：
    - **一般情况**：小偷将小件物品装进自己口袋，即使没出收银台，也既遂。
    - **例外（已布控）**：如果超市人员已经布控，小偷装进口袋不算既遂，拿出收银台才算既遂。`[原音频此处略有重复，已合并整理]`。
3.  **入户盗窃**：小偷在主人家里将小件物品装进口袋，不算既遂。**出了主人家的家门**才算既遂。因为主人对进入家中的小偷有控制权和搜身权。
4.  **在主人家里（保姆、客人盗窃）**：保姆或客人在主人家里盗窃小件物品，装进口袋即算既遂。因为主人对保姆、客人也没有搜身权。

**（二）大件物品的既遂认定**
> **例题**：狗蛋在商场盗窃一台大空调，已拖出格力空调专柜范围，但未出商场大门即被抓。
> **结论**：未遂。因为大件物品拖出商场大门才算置于自己的实际控制之下。

**（三）空间距离问题（既遂不要求财物一定在手上）**
- **原理**：主人对财物的占有可以是松弛占有，允许有一定空间距离。犯罪人只要将财物置于自己的实际控制范围（如秘密地点），即使有一定距离，也算既遂。
- **例题1（火车扔窗外）**：
> 左宁老师在火车上偷了李佳老师的手机，扔到车窗外一个预定的秘密草丛中。到站后去找，手机已不见。
> **结论**：**盗窃罪既遂**。因为扔到秘密地点时即已建立占有，既遂后不可逆转为未遂。

- **例题2（院墙内外）**：
> 狗蛋从小方家盗窃皮箱，扔到院墙外僻静处，自己翻墙出去后发现皮箱不见了。
> **结论**：**盗窃罪既遂**。扔到院墙外隐蔽处时即已既遂，院墙是干扰项。

> **【实物型观点展示提示】**：主观题可能考观点展示。上述“唯定论”是多数说，你需能翻转出少数说（如认为未遂），并说明理由。例如保姆将戒指藏到卫生间墙壁夹缝，准备下周拿走，第二天即被发现。多数说认为藏匿时即既遂；少数说可认为其未最终控制财物，系未遂。

**三、 财产犯罪的数额问题总结**

**（一）财物的三个档次与刑法保护力度**

1.  **第一档次（数额较大，约2000元左右）**：**完整保护**。所有财产犯罪（盗窃、诈骗、抢劫等）都保护。
2.  **第二档次（数额不大，但有限保护，如300元自行车）**：**有限保护**。并非所有罪名都保护，常考的主要是**抢劫罪**和**特殊类型的盗窃罪**（入户、多次、携带凶器、扒窃）。
3.  **第三档次（数额很小，如一根葱）**：**刑法不保护**，可由治安管理处罚或民事赔偿处理。

> **【纠正误区】**：
> - **误区一**：“抢劫一分钱也构成抢劫罪。” **不准确**。抢劫罪也有数额要求，要求达到第二档次的财物。
> - **误区二**：“特殊类型盗窃没有任何数额要求。” **错误**。也要求达到第二档次的财物。如两年内偷三次葱，不值得定罪。

**例题3（多次盗窃的数额要求）**
> 某男生一星期偷了7次外卖（鸭血粉丝汤，每碗15元）被抓。
> **结论**：不构成盗窃罪。因为多次盗窃也要求对象是第二档次财物（约百元以上），15元的鸭血粉丝汤属于第三档次，刑法不保护。

**（二）特殊财物——银行卡与购物卡的价值认定**

- **购物卡（不记名、不挂失、无密码）**：偷到即等于偷到卡内资金。
> **例题**：温云云偷了杜洪波一张内有3000元的购物卡。
> **结论**：构成**盗窃罪（数额较大）**。因为可自由支配卡内资金，相当于现实占有了3000元。

- **银行卡（记名、可挂失、有密码）**：偷到卡不等于偷到卡内资金。
> **例题**：温云云偷了杜洪波一张内有3000元的银行卡。
> **结论**：
> 1.  不构成普通盗窃罪（数额较大）。因为不能排他支配资金。
> 2.  银行卡属于**第二档次财物（有限保护）**。若通过抢劫或特殊类型盗窃（入户等）取得，可定抢劫罪或盗窃罪。
> 3.  若普通盗窃后使用卡内资金，在“使用”环节定**信用卡诈骗罪**（后续课程内容）。

**（三）数额问题上的主客观相一致原则**

> **【重要原则】**：数额（较大、巨大、特别巨大）不仅是客观要素，也要求主客观相一致。

- **误区一（只看客观）**：只要客观上数额巨大就定罪量刑，不考虑主观认识。
> **例题（天价葡萄案/太空豆角案）**：农民工偷了价值40万的高科技实验豆角当宵夜。
> **分析**：主观上认为只值十来块钱（数额很小），客观上是数额巨大。主客观不一致。
> **结论**：不构成盗窃罪。民事或行政处罚即可。

- **主观认识高于客观价值（未遂）**：
> **例题**：狗蛋在商场盗窃一名穿着华丽女士的提包，以为内有贵重物品，实际只有100元现金。
> **分析**：客观上未偷到数额较大财物，但主观上有盗窃数额较大财物的故意，客观上有盗窃到数额较大财物的可能性（危险性）。
> **结论**：成立**盗窃罪（未遂）**。

- **认识错误与观点展示（珠宝店案）**：
> **例题**：甲意图盗窃珠宝店3万元珠宝，手伸进柜台（已着手），因认错对象，拿走了旁边3000元珠宝。
> **分析**：一个行为，对象不同。
> **结论（多数说/司法解释）**：构成**盗窃罪（数额较大）既遂**（针对3000元）与**盗窃罪（数额巨大）未遂**（针对3万元），择一重刑论处。
> **结论（少数说）**：只定**盗窃罪（数额较大）既遂**，不承认数额巨大有未遂。`[少数说忽略了对3万元财物制造紧迫危险的评价]`。

**（四）违禁品与犯罪所得收益的数额认定**

- **违禁品（如毒品）**：按非法交易的行情节估价，达到相应数额即可定罪量刑。
- **犯罪所得数额 vs 犯罪所得收益数额**：
    - **犯罪所得数额**：以**犯罪时/行为时**为准，固定不变。
    - **犯罪所得收益数额**（如用赃款炒股赚的钱）：以**案发时**为准。
> **例题**：官员受贿100万，用此款炒股，案发时赚了10万。
> **认定**：受贿罪既遂数额为100万（行为时）。犯罪所得收益为10万（案发时）。收益赔了则为0，但不影响100万犯罪所得数额的认定。
