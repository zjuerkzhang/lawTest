## 各罪核心要点

### 一、妨害公务罪（第277条第1款）

| 要点 | 内容 |
|------|------|
| 行为方式 | 以暴力、威胁方法阻碍国家机关工作人员依法执行职务 |
| 时间要件 | **正在执行**的公务（执行完毕后报复→故意伤害罪） |
| 主观要件 | 明知是公务人员正在执行公务 |
| 认识错误 | 不知是警察→不能定妨害公务罪/袭警罪；有伤害故意→定故意伤害罪 |
| 假想防卫 | 不知是警察+正当防卫心理→假想防卫，有过失定过失犯罪，无过失无罪（2013年主观题考点） |
| 罪数原则 | 前罪 + 妨害公务罪 → **两罪并罚** |
| 罪数例外 | 前罪为①走私、贩卖、运输、制造毒品罪 或 ②组织、运送他人偷越国（边）境罪 → **结合犯**，前罪加重处罚 |

### 二、袭警罪（第277条第5款）

| 要点 | 内容 |
|------|------|
| 与妨害公务罪关系 | **法条竞合**：妨害公务罪是一般罪名，袭警罪是特殊罪名→特殊法优于一般法 |
| 警察范围 | 公安机关、国家安全机关、监狱、法院、检察院的司法警察等；**不包括辅警** |
| 暴力袭击 | 要求造成**轻微伤或以上后果** |
| 对物暴力 | 砸警车足以危及人身安全→袭警罪；不足以危及人身安全→故意毁坏财物罪+妨害公务罪（想象竞合） |
| 暴力威胁 | 不构成袭警罪→构成妨害公务罪 |
| 轻微冲突 | 轻微肢体冲突、辱骂→不构成犯罪 |

> 📌 **2025年最新司法解释：** “两高”《关于办理袭警刑事案件适用法律若干问题的解释》（2025年1月18日起施行）明确了“暴力袭击”的认定标准。

### 三、公文证件印章类犯罪（第280条）

**1. 伪造、变造、买卖国家机关公文、证件、印章罪**

| 要点 | 内容 |
|------|------|
| 保护法益 | 国家机关公文、证件、印章的**公共信用** |
| 主观要件 | 要求有**非法使用的目的** |
| 伪造 | 有形伪造（无权限者伪造）+ 无形伪造（有权限者伪造虚假内容） |
| 买卖 | 包括卖、买、为卖而买 |

**2. 伪造公司、企业、事业单位、人民团体印章罪**

| 要点 | 内容 |
|------|------|
| 保护范围 | 只保护**印章**，不保护公文、证件 |
| 典型情形 | 伪造高校毕业证→定**伪造事业单位印章罪**（因为毕业证上必有印章图案） |

**3. 伪造、变造、买卖身份证件罪**

| 要点 | 内容 |
|------|------|
| 与国家机关证件罪关系 | **法条竞合**，特殊法优于一般法 |
| 身份证件范围 | 身份证、护照、社会保障卡、驾照、户口本（多数说）；**不包括**学生证、工作证 |
| 买卖 | 买身份证**自用**也构成犯罪 |

**4. 盗窃、抢夺、毁灭国家机关公文、证件、印章罪**

| 要点 | 内容 |
|------|------|
| 抢劫问题 | 法条无“抢劫”，但抢劫可**包容评价**为抢夺→定抢夺国家机关公文罪 |

**5. 冒名顶替罪**

| 要点 | 内容 |
|------|------|
| 行为 | 盗用、冒用他人身份，顶替三个事项：上大学资格、公务员录用资格、就业安置待遇 |

### 四、招摇撞骗罪（第279条）

| 要点 | 内容 |
|------|------|
| 公式 | 冒充国家机关工作人员 + 招摇撞骗 |
| 国家机关 | 不要求真实存在，要求**足以使一般人相信** |
| 冒充 | 扩大解释：老百姓冒充官员、下级冒充上级、上级冒充下级都算 |
| 撞骗 | 骗名誉、感情、工作、**钱**都行 |
| 与诈骗罪关系 | 骗钱时→**想象竞合，择一重罪**（法考观点） |
| 冒充警察 | 招摇撞骗罪**从重处罚** |
| 冒充军人 | **冒充军人招摇撞骗罪**（独立罪名，军人包括武警） |
| 冒充军警抢劫 | 抢劫罪**加重处罚** |

### 五、聚众斗殴罪（第292条）

| 要点 | 内容 |
|------|------|
| 本质 | 不法对不法，不正对不正（狗咬狗） |
| 与正当防卫区分 | 看谁先动手、看地点 |
| 法律拟制 | 聚众斗殴中**过失致人死亡**→定**故意杀人罪** |
| 首要分子责任 | 只要出人命，双方首要分子都要对故意杀人罪负责 |

### 六、寻衅滋事罪（第293条）

| 要点 | 内容 |
|------|------|
| 行为方式 | 随意殴打；追逐拦截辱骂恐吓；强拿硬要或任意毁损；公共场所起哄闹事 |
| 主观 | 要求**流氓动机**（寻求精神刺激） |
| 与故意伤害罪关系 | **想象竞合**，择一重罪，不是对立排斥关系 |

### 七、聚众扰乱社会秩序罪（第290条）

| 要点 | 内容 |
|------|------|
| 聚众 | 必须是**主动聚集、组织、纠集**众人，围观群众多≠聚众 |

### 八、高空抛物罪（第291条之二）

| 要点 | 内容 |
|------|------|
| 高空 | 二层楼（约3米）以上 |
| 抛物 | **空对地**（从空中往地上/井下扔），不是“抛物线” |
| 主观 | **故意**；过失→过失致人死亡罪等 |
| 情节 | 要求**情节严重** |
| 与以危险方法危害公共安全罪 | 扔砖→不构成；扔炸弹/泼硫酸→构成（想象竞合） |

# 3、讲稿切分与整理


## 第一段：本讲总览

好，那今天我们来看第二十二讲，妨害社会秩序犯罪啊。这一讲它的一个特点是什么呢？也是罪名数量特别多，但是呢它还不如人家经济犯罪——经济犯罪罪名数量特别多，但是人家有一个王者罪名，就是信用卡诈骗罪。咱们这一讲呢还没有一个级别能达到人家信用卡诈骗罪那个重要的程度的罪名。那这一讲呢它的罪名之间贫富差距特别大，有些罪名考的就特别少，有些罪名相对还能多一点。那这一讲呢重点罪名是三节的罪，第一节就是扰乱公共秩序犯罪，第二节妨害司法犯罪，还有一节就是毒品犯罪，相对来说比较重要。

那我们就先看第一节扰乱公共秩序犯罪。那这一节罪名呢也是数量特别多，但是呢这一节有许多罪名是二线罪名，需要你还得注意一下，但大多数都是三线罪名了。好，那我们就这一块一般都是给大家汇总着去复习，抓里面的要点。


## 第二段：妨害公务罪——基本构成与时间要件

第一个妨害公务类的犯罪，那第一个罪名就叫妨害公务罪，那就是以暴力、威胁的方法阻碍国家机关工作人员依法执行公务，那就构成妨害公务罪。

那这里面的一些要点我们书上给大家都画了图表，比如说妨害的第一个是**正在执行的公务**。你看我们考试该怎么考呢？

**【例题1】** 狗蛋跟小芳发生了一些纠纷，人家警察在派出所给两个人调解完了，两个人也签了字了。那狗蛋心里总是有点愤愤不平，结果看人家警察要回办公室呢，就踹人家一脚，一下把人给踹趴下了，一下都踹成轻伤了。现在问狗蛋定不定妨害公务罪啊？

**分析：** 这时候不定，因为那个调解活动已经执行完毕了，这时候你踹人家泄私愤，定的是**故意伤害罪**。


## 第三段：妨害公务罪——认识错误问题（故意伤害罪情形）

接下来考试在这块还可以给你考什么？考一个**认识错误问题**。这一块有两个问题，一个是故意伤害罪，一个是假想防卫。假想防卫考过了，故意伤害罪没考，因为是认识错误，稍微有点复杂。我们来看书：

**【例题2】** 甲看到自己的朋友乙跟一个人丙在那打架，甲想我是好朋友啊，我要两肋插刀，就上前帮忙，一起把人家丙打成了轻伤。实际上人家丙是便衣警察，正在抓捕乙。现在就问这个甲怎么处理？

**分析：** 他现在涉嫌两个罪：

- **妨害公务罪**：客观要件打勾（客观上妨害了警察执行公务），但**主观要件打叉**（他主观上不知道要妨害公务，没想到是警察），所以不能定妨害公务罪，也不能定袭警罪。
- **故意伤害罪**：客观要件打勾（把人打成轻伤了），**主观要件也打勾**（他有伤害人家的故意），所以要定**故意伤害罪**。


## 第四段：妨害公务罪——认识错误问题（假想防卫情形）

那再看假想防卫的问题。假想防卫这个是考过了：

**【例题3】** 甲误以为乙在追杀丙，我要见义勇为，所以就把人家丙打成重伤。实际上人家丙是便衣警察，正在追捕乙，是在执行公务。那这时候甲又涉嫌两个罪：

- **妨害公务罪/袭警罪**：客观要件打勾（客观上妨害了警察执行公务），但**主观要件打叉**（他不知道这是警察在执行公务）。
- **故意伤害罪**：客观要件打勾（把人打成重伤了），但**主观要件打叉**（他主观上没有故意伤害罪的犯罪故意，他是正当防卫的心理）。

由于客观上没有不法侵害，这属于**假想防卫**。假想防卫不可能故意为之，有过失定过失犯罪，没过失就无罪处理。

> 📌 **考点提示：** 2013年主观题考过这个点，大家把这一块要掌握好。


## 第五段：妨害公务罪——罪数问题（原则与例外）

妨害公务罪这一块还有一个问题就是**罪数问题**。我们要注意：

**原则：** 如果你先犯一个前罪，然后执法人员对你执法，你把人给打了，犯妨害公务罪——**两罪并罚**。

**例外（结合犯）：** 前罪加妨害公务罪 = 前罪加重处罚，不再两罪并罚。这样的前罪只有两种：
1. **走私、贩卖、运输、制造毒品罪**
2. **组织、运送他人偷越国（边）境罪**

除了这两个之外，其他任何前罪加妨害公务罪，都要**两罪并罚**。

> 💡 **讲授者的学习方法提醒：** 不要死记硬背大量正常情形，要掌握原理。纷繁复杂的结论里面，要找哪些是符合正常原理的（原则），要背的是例外和特殊的。比如记住了“前罪加妨害公务罪 = 前罪加重处罚”只有两个前罪，除此之外一律数罪并罚，完事儿。

**【例题4】** 狗蛋犯走私普通货物、物品罪，又犯妨害公务罪，罪数上怎么处理？——**两罪并罚**。走私犯罪很多，只有**走私毒品罪**才是例外。

**【例题5】** 狗蛋犯非法持有毒品罪，又犯妨害公务罪，罪数上怎么处理？——**两罪并罚**。毒品犯罪很多，只有四个动词（**走私、贩卖、运输、制造**）加一个名词（**毒品**）才是例外。

> 💡 **讲授者的记忆方法强调：** 有的知识点，要么不记它，把它扔掉；要记就把它记清楚，不要记模棱两可的东西。模模糊糊的记忆不具有建设性，还具有破坏性。


## 第六段：袭警罪——与妨害公务罪的关系

好，接下来我们要说袭警罪。袭警罪因为有新的司法解释，所以还是比较重要的。

首先，袭警罪和我们刚才学的妨害公务罪是什么关系？结论是**法条竞合关系**：妨害公务罪是一般罪名，袭警罪是特殊罪名。触犯袭警罪必然触犯妨害公务罪。两个都触犯了，**特殊法优于一般法**，优先认定为**袭警罪**。

如果既构成妨害公务罪又构成袭警罪，优先定袭警罪。如果定不了袭警罪，可以定妨害公务罪。


## 第七段：袭警罪——警察的范围

袭警罪里面的警察种类，司法解释明确了：包括**公安机关、国家安全机关、监狱、法院、检察院的司法警察**等，警种基本不限制。

但**不包括警务辅助人员（辅警）**。如果辅警在执行公务，你打他，不定袭警罪，但可以定**妨害公务罪**。

如果正式警察带着辅警执行公务，你把两人一起打了，就定一个**袭警罪**整体处理。


## 第八段：袭警罪——暴力袭击的认定

警察必须是**正在执行公务**（时间要件）。

暴力袭击的方式：要求造成**轻微伤或以上后果**。比轻微伤还轻的，不值得定罪。

如果把人打成**重伤**：一方面构成袭警罪，一方面构成故意伤害罪，**想象竞合，择一重罪**——肯定定故意伤害罪（重伤）。

**【对物暴力的问题】** 不打警察，但砸警车：
- 如果警车上坐着警察，砸警车足以危及人身安全 → 定**袭警罪**
- 如果警车停在偏僻地方没人 → 不定袭警罪，但可以定**故意毁坏财物罪**，同时如果妨害了公务，可以定妨害公务罪，与故意毁坏财物罪**想象竞合**

**【轻微冲突/辱骂】** 与警察发生轻微肢体冲突，或只是辱骂两句，情节轻微危害不大，不定袭警罪。

**【暴力威胁 vs 暴力袭击】** 袭警罪要求**暴力袭击**，不包括“以暴力相威胁”。比如拿砍刀威胁警察“不走开我砍你”——不构成袭警罪，但构成**妨害公务罪**（因为妨害公务罪既包括暴力，也包括以暴力相威胁）。


## 第九段：公文证件印章类犯罪——总论

第二类的犯罪就是关于公文证件印章类的犯罪。这一块有一个**基础罪名**，是一个霸王级别的选择性罪名：**伪造、变造、买卖国家机关公文、证件、印章罪**（三个动词 × 三个名词）。

这类犯罪保护的**法益**是：国家机关公文、证件、印章的**公共信用**。侵犯公共信用才可能构成此罪，要求有**非法使用的目的**。

**【例题6】** 狗蛋二十五岁屡次相亲失败，女方嫌他太嫩。他一怒之下伪造了一个户口本，把自己的年龄从二十五改成三十五，给人家看。要不要定罪？——**不需要**。因为这不算是非法使用。非法使用是指拿户口本领护照、骗贷等；只是想显得年龄大一点，不算。


## 第十段：伪造——有形伪造与无形伪造

**伪造**包括两种：

**1. 有形伪造**：没有制作权限的人去伪造（电线杆上贴的办证小广告）。

**2. 无形伪造**：有制作权限的人伪造虚假内容的文件。

**【例题7】** 狗蛋收买户籍警察，让人家给自己做一个户口本，信息全是假的（名字假、性别假、照片是胡歌）。这个户口本算不算伪造的？——**算**。出自警察之手不代表就是真的户口本，依然算是伪造的，这叫**无形伪造**。

**【例题8】** 狗蛋不是收买警察，而是给户籍警察提供虚假材料，把警察骗了，警察给他制作了一个内容全是假的证件。怎么办？——警察不构成犯罪（没有伪造的故意）；狗蛋定**伪造国家机关证件罪**，但他不是亲自伪造，所以是**间接正犯**。


## 第十一段：伪造印章

伪造印章包括两种情况：
1. **私刻公章**（伪造印体）
2. **伪造印章的图案**（比如用电脑在假公文上设计一个印章图案）

两种都算伪造印章。


## 第十二段：变造与买卖

**变造**：小修小补，考的少。

**买卖**：既包括**卖**，也包括**买**。买包括买来自用，也包括买进为了卖出（中间商）。

> 📌 **注意：** 买卖这个动词在刑法中出现于两个主要罪名：①非法买卖枪支、弹药、爆炸物罪；②买卖国家机关公文、证件、印章罪。


## 第十三段：伪造公司、企业、事业单位、人民团体印章罪

第二个罪名：**伪造公司、企业、事业单位、人民团体印章罪**。

规律：国家机关的保护最完整（三个动词×三个名词）；**企事业单位的保护不完整**（一个动词×一个名词——只保护“印章”）。

**【例题9】** 有人伪造某高校的大学毕业证，定什么罪？——高校是**事业单位**，大学毕业证属于**证件**，但法条不保护事业单位的证件。司法解释说：定**伪造事业单位印章罪**。因为伪造毕业证上肯定要盖印章（钢印），你伪造印章图案也算伪造印章。

> 📌 如果伪造的毕业证上连印章都没盖，那还没法定罪。当然这种情况比较少。


## 第十四段：伪造、变造、买卖身份证件罪

第三个罪名：**伪造、变造、买卖身份证件罪**。

为什么这个罪也是三个动词？因为身份证件绝对属于**国家机关出具的证件**，保护更完整。

与“伪造、变造、买卖国家机关证件罪”是什么关系？**法条竞合**——后者是一般法条，前者是特殊法条，**特殊法优于一般法**。

**“身份证件”** 不叫“身份证”，包括：
- 身份证
- 护照
- 社会保障卡
- 驾照
- 户口本（多数说认为包括，也能证明身份）

**不包括**：学生证、工作证（仅供内部使用）。

> 📌 **特别提醒：** 买身份证**哪怕是自用**也构成犯罪。


## 第十五段：盗窃、抢夺、毁灭国家机关公文、证件、印章罪

第四个罪名：**盗窃、抢夺、毁灭国家机关公文、证件、印章罪**。

考试考点：三个动词有盗窃、抢夺、毁灭，但**没有抢劫**。如果狗蛋抢劫国家机关的公文，是不是无罪？——不是。抢劫可以**包容评价**为抢夺（盗窃、抢夺、抢劫是台阶关系，不是对立排斥关系）。三层的抢劫可以包容评价成二层的抢夺，所以可以定**抢夺国家机关公文罪**。


## 第十六段：冒名顶替罪

第五个罪名：**冒名顶替罪**。

行为方式：盗用、冒用他人身份，顶替三个事项：
1. **高等学历教育入学资格**（上大学资格）
2. **公务员录用资格**
3. **就业安置待遇**

> 📌 背景：发生了一些冒名顶替上大学的恶劣案件——“偷别人的人生”，性质很恶劣。


## 第十七段：小混混型犯罪——招摇撞骗罪（上）

第三类：小混混型犯罪。

**招摇撞骗罪**的公式：**冒充国家机关工作人员 + 招摇撞骗**。

**第一，国家机关**：不要求必须是真实存在的机关。比如冒充“卫生部副部长”——现在没卫生部了，是卫健委，但老百姓觉得好像有，足以使一般人相信有这个国家机关——构成。如果冒充“大理寺少卿”“河北省节度使”——穿越剧看多了，不足以使一般人相信——不构成。

**第二，国家机关工作人员**：只包括国家机关工作人员。冒充清华大学副校长（事业单位）→ 不构成；冒充中石油副总（国企）→ 不构成；冒充革命烈士家属 → 不构成。

**第三，冒充**：两种都算——老百姓冒充官员算冒充；乡长冒充省长算冒充；省长冒充乡长也算冒充（扩大解释）。


## 第十八段：招摇撞骗罪（下）——招摇与撞骗

**第四，招摇撞骗**：既要求**招摇**，又要求**撞骗**。

**【例题10】** 几个大学生穿着行政夹克，冒充上级领导来大学视察，到食堂视察工作，装模作样说“饭菜要做好、质量要过关”。只招摇，没诈骗（就过个瘾）——不构成招摇撞骗罪。

**撞骗骗什么？** 骗什么都行：骗名誉、骗感情、骗工作、骗钱都行。

**骗钱时**：同时构成**诈骗罪**。招摇撞骗罪和诈骗罪是什么关系？法考认为是**想象竞合**（不是法条竞合），**择一重罪论处**。

> 📌 **法考 vs 法硕的区别：** 法考认为招摇撞骗罪和诈骗罪是想象竞合，不是法条竞合。因为触犯招摇撞骗罪不必然触犯诈骗罪（比如骗感情不骗钱也能构成招摇撞骗罪）。法硕考试认为是法条竞合。


## 第十九段：招摇撞骗罪——罪数问题

罪数问题：
- **冒充军警人员抢劫** → 定**抢劫罪**，**加重处罚**
- **冒充警察招摇撞骗** → 定**招摇撞骗罪**，**从重处罚**
- **冒充军人招摇撞骗** → 独立罪名：**冒充军人招摇撞骗罪**（军人包括武警）

**【例题11】** 狗蛋和小芳玩“仙人跳”：小芳扮卖淫女勾引嫖客，狗蛋穿警服冲进来说“公了还是私了”，嫖客吓得给钱。狗蛋和小芳构成什么罪？——招摇撞骗罪（狗蛋冒充警察从重处罚）+ 诈骗罪 + 敲诈勒索罪 → **想象竞合，择一重罪论处**。


## 第二十段：聚众斗殴罪（上）——相互斗殴的认定

**聚众斗殴罪**：以聚众的方式相互斗殴（不法对不法，不正对不正，狗咬狗）。

怎么区分“相互斗殴”和“一方不法侵害、另一方正当防卫”？
- 先看**谁先动手**
- 看**地点**

**【例题12】** 某地发生案件：因为狗咬人、人把狗打死了，发生纠纷，对方闯到人家家里，主人把闯入者捅死了。如果证据证明是对方上门打人，主人反击 → **正当防卫**，不能说“一片混战就是狗咬狗”。

**【例题13】** 男小三上门挑衅女主人，贴满不雅照，拿棒球棒敲门，要打女主人。女主人拿菜刀反击，把男小三砍成轻伤。——女主人是**正当防卫**，不是相互斗殴。


## 第二十一段：聚众斗殴罪（下）——法律拟制

聚众斗殴罪中一个重要考点：**聚众斗殴中如果过失致人死亡，也要定故意杀人罪**。这叫**法律拟制**。

**【例题14】** 两个黑社会老大（孙红雷演的、张颂文演的）约架聚众斗殴，打起来后听到警车来了跑了。警察赶到现场发现地上躺了一个小弟死了（孙红雷这边的小弟）。无法查明是被谁打死的（一片混战）。

**处理：**
- 如果能找出凶手 → 凶手定**故意杀人罪**
- 双方老大（首要分子）也要定**故意杀人罪**
- 即使是过失弄死的 → 凶手也定**故意杀人罪**（法律拟制），双方老大也要定故意杀人罪
- **死的是谁的小弟不重要**——刑法只管你是不是首要分子

> 💡 讲授者点评：老大不是那么好当的，关键时候要有担当精神，能扛事儿。


## 第二十二段：寻衅滋事罪

**寻衅滋事罪**的行为方式：
1. 随意殴打他人
2. 追逐、拦截、辱骂、恐吓他人
3. 强拿硬要或任意毁损财物
4. 在公共场所起哄闹事

寻衅滋事罪要求带点**流氓动机**（寻求精神刺激等）。

但与故意伤害罪的区分**不是A与非的对立排斥关系**，而是可以**想象竞合**。

**【例题15】** 狗蛋打小方，打成重伤——法官问为什么打？狗蛋说：“我跟他有仇，我要报仇。”→ 定**故意伤害罪**（重伤），判十年。

铁牛也打小方，打成重伤——法官问为什么打？铁牛说：“我出于流氓动机打他，手痒痒。”→ 铁牛既构成**寻衅滋事罪**，又构成**故意伤害罪**（重伤），**想象竞合，择一重罪论处** → 定故意伤害罪（重伤）。

> 💡 **要点：** 不能因为带了流氓动机就只定寻衅滋事罪而规避故意伤害罪。想象竞合，哪个重定哪个。


## 第二十三段：聚众扰乱社会秩序罪——“聚众”的认定

**聚众扰乱社会秩序罪**。

关键考点：什么叫**聚众**？聚众 = **聚集、组织、纠集众人**，不是围观群众多就叫聚众。

**【例题16】** 男男女女在公园大树下光天化日做苟且之事，跳广场舞的大妈围过来看，看到流鼻血，报警了。够不够成聚众淫乱罪？——**不构成**。围观群众是自发的，不是行为人纠集组织的，不叫聚众。

**【例题17】** 狗蛋因老板拖欠工资，爬到铁桥上说要跳桥（其实不跳），围观群众很多导致交通拥堵。小方爬上去谈判，趁握手时把狗蛋推了下去（桥是T型的，狗蛋在铁架上磕碰后摔到没气儿的气垫上，摔成重伤）。

**处理：** 小方构成**故意伤害罪**；狗蛋呢？**不构成**聚众扰乱社会秩序罪——因为围观群众是自发的，不是狗蛋纠集组织的。

> 💡 **要点：** 实务中要注意，不要一看围观人多就说人家在“聚众”。聚众是主动纠集组织，不是被动围观。


## 第二十四段：高空抛物罪（上）——基本构成

**高空抛物罪**。

**第一，多高算高空？** 一般认为**二层楼（三米左右）** 就算。不能太低（低于三米不行，否则姚明吐口香糖都算高空抛物了）。

**第二，高空的“点”** ：相对概念，不限于大楼大厦。**井口往井下扔**也算高空抛物。

**第三，什么叫“高空抛物”？** 必须是**空对地**（从空中往地上扔，或往井下扔）。从地面上扔一个东西抛到空中再掉下来——那是**抛物线**，不叫高空抛物（那是“地对地导弹”）。

**第四，情节犯**：要求**情节严重**，不是只要高空抛物就构成犯罪。

**第五，故意犯罪**：必须**故意**。不小心导致物品坠落 → 不构成高空抛物罪。

**【例题18】** 潘金莲不小心把东西掉下去砸死了西门庆 → **过失致人死亡罪**，不是高空抛物罪。如果改成故意 → 既构成**故意杀人罪**，也构成**高空抛物罪**，**想象竞合，择一重罪**。


## 第二十五段：高空抛物罪（下）——与以危险方法危害公共安全罪的关系

**【高空抛物 vs 以危险方法危害公共安全罪】**

- 扔**一块砖** → 不构成以危险方法危害公共安全罪（最多砸中一个人）
- 从空中朝人群中扔**炸弹** → 构成**以危险方法危害公共安全罪**（危及多数人的可能性）
- 朝楼下人群中**泼洒硫酸** → 构成**以危险方法危害公共安全罪**（危及多数人的可能性）+ **高空抛物罪** + 如果造成伤害结果，还构成**故意伤害罪** → **想象竞合，择一重罪论处**
