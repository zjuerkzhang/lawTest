# 1、正当防卫知识点提纲（法考备考版）

## （一）正当防卫的体系地位

| 层级 | 内容 |
|------|------|
| **上位概念** | 排除违法性的事由（正当化事由） |
| **核心逻辑** | 先有违法性（危害行为），再排除违法性——先做加法，再做减法 |
| **判断顺序** | 客观要件（危害行为）✓ → 排除违法事由✓ → 无罪（正当化） |
| **张飞案结论** | 吼叫本身不是危害行为→客观要件打叉→直接无罪→不需要讨论正当防卫 |

> **注释：** 讲授者引入了四要件犯罪构成体系的概念（客观要件、主观要件等），这是刑法总论的基础理论框架。四要件是指犯罪构成的四个共同要件：犯罪客体、犯罪客观方面、犯罪主体、犯罪主观方面。正当防卫是在客观方面符合危害行为要件后，在违法性层面予以排除。


## （二）正当防卫的成立条件

### 1. 起因条件——制止不法侵害

#### （1）防卫人范围

| 类型 | 说明 | 示例 |
|------|------|------|
| **本人防卫** | 被侵害人自己反击 | 小芳踢飞性侵者 |
| **第三人防卫** | 第三人制止不法侵害 | 狗剩踹飞性侵者（见义勇为） |

**法条依据：** 刑法第20条——“为了使国家、公共利益、本人或者他人的人身、财产和其他权利免受正在进行的不法侵害”——明确包含“他人”，即第三人防卫。

#### （2）不法侵害的法益种类

| 类型 | 说明 |
|------|------|
| 个人法益 | 生命、健康、财产、人身自由等 |
| 社会法益 | 公共秩序等 |
| 国家法益 | 国家利益等 |

**注意：** 不法侵害**不限于犯罪行为**，也包括违法行为。

#### （3）不法侵害的紧急性

| 概念 | 说明 |
|------|------|
| **紧急性** | 来不及寻求公力救济 |
| **无限防卫权** | 对行凶、杀人、抢劫、强奸、绑架等严重危及人身安全的暴力犯罪，造成不法侵害人伤亡的，不属于防卫过当 |

**例题：** 领导贪污→你砍人手→×（无紧急性，应报案）

#### （4）不法侵害的客观性——“剥白菜叶”法

**核心：** 只看客观上有没有“不法侵害”，前面的修饰语全部剥掉。

| 修饰语类型（白菜叶） | 说明 | 是否影响正当防卫认定 |
|------|------|------|
| 作为/不作为 | 不作为也可构成不法侵害（如肇事者不救助） | 不影响 |
| 故意/过失 | **过失的不法侵害**也是不法侵害 | 不影响 |
| 有责任年龄/无责任年龄 | 精神病患者、未成年人的侵害 | 不影响（司法解释立场） |
| 有责任能力/无责任能力 | 同上 | 不影响 |

**重点例题：打猎认错人案（过失不法侵害）**

> 甲打乙腿一枪救狗蛋→乙虽无故意但有过失→乙的行为是**过失的不法侵害**→甲制止乙→**正当防卫**（不是紧急避险）

#### （5）不法侵害的现实性——假想防卫

| 概念 | 定义 | 特征 |
|------|------|------|
| **假想防卫** | 客观上无不法侵害，行为人误以为有而“防卫” | 客观打✗、主观打✓ |
| **处理** | 不构成正当防卫；不构成故意犯罪；有过失→过失犯罪；无过失→意外事件 |

**例题：** 狗蛋听到邻居惨叫以为家暴→冲进去打人→实际是亲热→**假想防卫**


### 2. 时间条件——不法侵害“正在进行”

#### （1）不法侵害的开始

**标准：** 已经开始（着手或直接面临威胁）

**重点考点：设立防卫装置**

| 问题 | 答案 |
|------|------|
| 事前设立防卫装置，事后发挥作用 | **不是事前防卫**（起作用时不法侵害已开始） |
| 成立正当防卫的条件 | ①不危害公共安全；②手段相当 |

> **注释：** “手段相当”涉及防卫限度问题（后面会讲到）——明显超过必要限度造成重大损害的，属于防卫过当。

#### （2）不法侵害的结束

**判断标准（两个都要满足）：**

| 要件 | 说明 |
|------|------|
| ①行为举动结束 | 不法侵害人停止了侵害行为 |
| ②危险性解除 | 再次侵害（反扑）的可能性消除 |

**重点：昆山龙哥案（于海明案）**

| 阶段 | 行为 | 时间条件判断 |
|------|------|------|
| 战略防御 | 龙哥砍人，于海明躲 | ✓ 适时 |
| 战略相持 | 双方抢刀，于海明刺中龙哥 | ✓ 适时 |
| 战略反攻 | 龙哥逃跑，于海明追砍 | **争议焦点** |

**判断方法——观点展示：**

| 观点 | 判断角度 | 结论 |
|------|------|------|
| 少数说 | 事后诸葛亮/上帝视角 | 龙哥不想反扑→事后防卫 |
| **多数说（采纳）** | **行为时一般人角度** | 龙哥往车里跑→有反扑可能性→危险未解除→**防卫适时** |

**理由：** 龙哥往宝马车跑——第一把刀从车里取→可能取第二把刀；即使没刀→可能开车撞人。

**补充：** 龙哥肠子流了一地倒地后→一般人角度无反扑可能性→再砍=事后防卫

#### （3）财产犯罪的特殊处理

| 规则 | 说明 |
|------|------|
| 当场挽回财物 | 视为不法侵害尚未结束 |
| 防卫仍然适时 | 不属于事后防卫 |

**例题：** 抢劫抢包→被害人当场追回→**防卫适时**

#### （4）防卫不适时的处理

| 类型 | 处理 |
|------|------|
| 事前防卫 | 不构成正当防卫 |
| 事后防卫 | 不构成正当防卫 |
| 故意为之 | 定故意犯罪 |
| 有过失 | 定过失犯罪 |
| 无过失 | 意外事件 |


## （三）本讲未涉及但完整的正当防卫成立条件（补充）

根据刑法理论和两高一部《关于依法适用正当防卫制度的指导意见》，正当防卫的成立条件除起因条件、时间条件外，还包括：

| 条件 | 说明 |
|------|------|
| **主观条件** | 具有防卫意图——为了合法权益免受不法侵害 |
| **对象条件** | 必须针对不法侵害人本人 |
| **限度条件** | 没有明显超过必要限度造成重大损害 |

# 3、讲稿切分段落（按逻辑顺序）


**第一段：导入——排除犯罪事由概述**

好，那今天我们就开始讲第九讲，排除犯罪事由的第一个叫排除违法事由。那排除违法事由，我们知道主要有三个：一个是正当防卫，一个是紧急避险，一个是被害人承诺。重要级别也是这样的，一个是正当防卫。那我们先看第一节正当防卫。


**第二段：正当防卫的体系地位——张飞吼退曹军案**

在讲正当防卫的成立条件之前，我们先要讲一个考点，就是正当防卫的体系地位。那要讲正当防卫的体系地位，我们给大家引入一个案件，你给我判断一下。大家知道就是著名的三国里面一个名场面，就在长坂坡，曹操大军要进攻刘备。那个张飞站在桥头大吼一声，要撤退这个曹军的进攻。“我乃燕人张翼德也，谁敢与我决一死战！”他喊的声音很大，结果一下下退了曹军的进攻，并且还把那个夏侯杰给吓得是肝胆俱裂，坠落马下给死了。

**【例题1】张飞吼退曹军案**
张飞这一吼，制止了曹军的不法侵害。他算不算正当防卫？

**解析：** 如果曹军杀张飞，张飞拿长矛直接刺过去，从刘备阵营立场来说是正当防卫。但张飞吼这一声，不算正当防卫。


**第三段：正当防卫的体系地位——原理阐释**

为什么张飞吼不算正当防卫？这就要讲正当防卫的体系地位，它的上位概念叫“排除违法性的事由”。要排除违法性，就说明前面先要存在一个违法性。违法性指的是法益侵害性，也就是说你的行为先要是一个危害行为，先是一个侵害法益的行为，然后再把这个危害性、违法性给排除掉。

张飞拿长矛反击刺人，在客观要件上绝对是个危害行为——警察初步可以把张飞抓了。但到排除违法事由这块，律师可以说：公诉人，我的当事人是正当防卫，因为夏侯杰先不法侵害，所以我们用正当防卫把前面的违法性、危害性给排除掉，那就正当化了，无罪了。但张飞吼了一句，在客观要件里面首先是一个危害行为吗？不是。正常的张飞吼“我乃燕人张翼德也”，这句话本身有什么法益侵害性吗？没有。所以在这块危害行为就打叉了，张飞就无罪了——不需要再分析到正当防卫的问题。

所以张飞无罪的理由是在危害行为打叉，而不是说他是正当防卫。

**核心结论：** 要排除违法性，得先要有违法性，再把它排除掉——先有尘土，再把它扫掉。定罪的顺序是先做加法（看有没有违法行为、有没有违法性），再做减法（看能不能用事由把违法性排除掉）。


**第四段：正当防卫的成立条件——起因条件（防卫人范围）**

成立条件有好几个，我们一个一个来看。先第一个：起因条件。起因条件就是说先要有个不法侵害，然后我去制止。

**要点一：防卫人的范围。** 防卫人既包括受害人被侵害的那个人，也可以包括第三人。

**【例题2】第三人防卫案**
狗蛋在性侵小芳，小芳反击狗蛋——小芳是正当防卫。但狗蛋在性侵小芳，小芳是个弱女子，狗剩路过，英雄救美，见义勇为，把正在实施性侵的狗蛋一脚踹飞了。狗剩这种行为算不算正当防卫？算！因为正当防卫只要求制止不法侵害，至于制止者是谁，在所不问。

**考点提示：** 考试经常考第三人作为防卫人。


**第五段：起因条件——不法侵害的法益种类与紧急性**

**要点二：不法侵害的法益种类。** 既包括个人法益，也包括社会法益、国家法益。但更多的是个人法益。

**要点三：不法侵害的紧急性。** 正当防卫说到底是一个私力救济。现代社会原则上要求公力救济，不允许私力救济。但正当防卫可以私力救济，是因为事态有紧急性——这时候让人家寻求公力救济来不及了。如果事态没有紧急性，你绝不能私力救济、替天行道。

**【例题3】领导贪污案**
你看到领导在贪污公款，你说这是不法侵害，我是第三人，我要制止你的不法侵害，直接用刀把领导手砍了。这是正当防卫吗？不是。因为领导贪污固然是不法侵害，但没有那种紧急性，你完全可以报案，为什么要直接替天行道砍人手呢？


**第六段：起因条件——不法侵害的客观性（“剥白菜叶”理论）**

**要点四：不法侵害的客观性。** 不法侵害只要求是一个客观的不法侵害即可。至于前面加什么修饰语，在所不问。

**【方法论】“剥白菜叶”理论：** 考试会用一些修饰语来干扰你，你就像剥白菜一样把这些“白菜叶”剥掉，留下白菜心——“不法侵害”四个字。只要客观上有个不法侵害，你去制止，就是正当防卫。

“白菜叶”包括：
1. **作为/不作为的不法侵害**——比如司机开车撞伤小芳后不救人还想跑，周围群众制止他跑。群众制止的是司机不作为的不法侵害（司机有救助义务却不救助），算正当防卫。
2. **故意/过失的不法侵害**——故意的不法侵害简单；过失的不法侵害考过一次概念没考案例，一旦考出案例挺难。

**【例题4】打猎认错人案（过失不法侵害）**
甲和乙一起打猎，乙走在前面，看到前方有一头“狗熊”就要开枪射击（其实是狗蛋，长得像熊）。甲在后面知道乙认错了，赶紧喊：“那不是狗熊，那是人！”结果乙是个聋子听不见。眼看乙要扣扳机，甲迫于无奈，朝乙腿上给了一枪，把乙打趴下，狗蛋获救。
问：甲朝乙腿上这一枪，是正当防卫还是紧急避险？

**解析：** 答案是正当防卫。乙虽没有杀狗蛋的故意，但有**过失**——如果把狗蛋打死了就构成过失致人死亡罪。过失的不法侵害也是客观上的不法侵害。甲作为第三人制止乙的不法侵害，就是正当防卫。

3. **无责任年龄人的不法侵害/无责任能力人的不法侵害**——按多数说（也是司法解释立场）属于正当防卫。

**【例题5】精神病患者袭击案**
朋友看完《战狼2》散场，一个男的突然一拳砸过来，朋友反击，两人打在一起。结果一个女孩把男的拉走，说“对不起，我男朋友精神病又犯了”。朋友的反击行为算什么？算正当防卫。（司法解释规定：如果不法侵害没那么严重，还是得先躲；躲无可躲、忍无可忍时可以防卫反击。）


**第七段：起因条件——狗咬人的问题（正当防卫 vs 紧急避险）**

**【例题6】狗咬孙悟空案——情形一**
二郎神的哮天犬去咬孙悟空，孙悟空一棒把狗打死。正当防卫还是紧急避险？**正当防卫。** 因为狗是杨戬不法侵害的工具，杨戬是故意的不法侵害，打狗就是制止杨戬的不法侵害。

**【例题7】狗咬孙悟空案——情形二**
二郎神睡着了，疏忽管理，导致狗跑出来咬孙悟空。孙悟空把狗打死。正当防卫还是紧急避险？**正当防卫。** 二郎神虽没有故意，但存在**过失**（疏忽管理），过失的不法侵害也是客观上的不法侵害。

**【例题8】狗咬孙悟空案——情形三**
流浪狗（或野狗）咬孙悟空，孙悟空一棒打死。正当防卫还是紧急避险？**紧急避险。** 因为野生动物背后没有人的不法侵害（既无故意也无过失），纯粹是单纯的危险。

**延伸：** 《西游记》里天上的神仙故意安排坐骑或不小心让坐骑跑下来变成妖怪吃唐僧，孙悟空打妖怪都属于正当防卫（妖怪背后有神仙做后台老板）。只有野生野长的妖怪，孙悟空打才是紧急避险。


**第八段：起因条件——现实性（假想防卫）**

**要点五：不法侵害的现实性。** 不法侵害要具有现实性。如果没有现实性，就成了**假想防卫**。

**【例题9】假想防卫案**
狗蛋暗恋邻居小芳，有一天听到小芳在家里惨叫，以为小芳又被丈夫家暴，气得冲进去要把丈夫头砸爆。事后查明，人家是在亲热呢。狗蛋算什么？

**解析：** 假想防卫。特点是在“制止不法侵害”这六个字上没有做到主客观相一致——**客观打叉**（客观上没有不法侵害），**主观打钩**（主观上想制止不法侵害）。不构成正当防卫，是假想防卫。

**处理规则：** 假想防卫不可能是故意为之，不可能构成故意犯罪。有过失定过失犯罪，没过失按意外事件处理。


**第九段：时间条件——不法侵害“正在进行”（防卫装置）**

时间条件：所制止的不法侵害必须**正在进行**——已经开始，但尚未结束。

**知识点一：不法侵害的开始——设立防卫装置。**

**【例题10】防卫装置案**
主人在墙院墙上插玻璃碎片（星期一插的），星期五小偷翻墙偷东西手被划伤。主人设立防卫装置算不算事前防卫？

**解析：** 不算事前防卫。防卫装置什么时候起作用？不法侵害开始（翻墙）的时候才起作用。所以防卫时间上是适时的，不属于事前防卫。

**成立正当防卫还需两个条件：**
1. 不能危害公共安全（墙顶插玻璃片，能在上面走的都是“梁上君子”，不危害公共安全）；
2. 手段要相当——如果小偷只想偷个包子，你弄个机关让人头落地，那肯定防卫过当。


**第十段：时间条件——不法侵害的结束（昆山龙哥案）**

**知识点二：不法侵害的结束。**

**【例题11】昆山龙哥案（于海明案）**

分三个阶段：

**第一阶段（战略防御阶段）：** 龙哥开宝马车，嫌于海明骑自行车不让道，拿大砍刀砍于海明，于海明左躲右挡。

**第二阶段（战略相持阶段）：** 龙哥砍人时刀掉地上了，双方都去捡刀，于海明眼疾手快捡起刀，一刀刺中龙哥。

*（这两个阶段的防卫时间条件都是适时的。）*

**第三阶段（战略反攻阶段）：** 龙哥被刺中后开始逃跑，于海明持刀追砍。

**争议焦点：** 龙哥都逃跑了，于海明还追砍，属不属于**事后防卫**？

**判断标准：** 不法侵害的结束有两个要求——
1. 不法侵害的行为举动要结束（龙哥已经逃了，这项满足了）；
2. 不法侵害的**危险性**也要解除——即再次侵害的可能性（反扑的可能性）也要解除。

**观点展示：**
- **少数说（事后诸葛亮角度）：** 从事后、专家角度判断龙哥当时想不想反扑。不想反扑则于海明属于事后防卫。
- **多数说（行为时一般人角度）：** 从行为时一般人角度判断龙哥有没有反扑可能性。

**本案多数说分析：** 龙哥往宝马车里跑——第一把砍刀就是从车里取的，一般人有理由相信他可能再取第二把刀；即使没刀，他也可以开车撞于海明。所以从行为时一般人角度，龙哥有反扑可能性，不法侵害的危险性没有解除，于海明的追砍属于防卫适时，不属于事后防卫。

**补充：** 如果龙哥肠子流了一地倒在地上了，于海明还继续砍——这时候从一般人角度看龙哥已经没有反扑可能性了，再砍就属于事后防卫。


**第十一段：时间条件——财产犯罪的特殊处理**

**知识点三：财产犯罪的特殊处理。** 犯罪人即使取得财物，只要被害人当场能够挽回财物，被害人当场挽回财物的行为仍然属于防卫适时，不属于事后防卫。

**【例题12】抢劫夺回案**
狗蛋抢劫小芳的包包，抢到手就跑，小芳立马追上去把包包夺回来。小芳不属于事后防卫，属于防卫适时——当场来得及挽回财物时，视为不法侵害还没有结束。


**第十二段：时间条件——防卫不适时的处理**

**知识点四：防卫不适时（事前防卫、事后防卫）的处理。** 不构成正当防卫。故意为之定故意犯罪；没故意、有过失定过失犯罪；没过失按意外事件处理。

**总结：** 判断不法侵害是否结束，不光看行为举动有没有结束，还要看危险有没有结束——主要看反扑的可能性有没有。要从**行为时一般人角度**判断，不能从事后诸葛亮、上帝视角、开天眼去判断。
