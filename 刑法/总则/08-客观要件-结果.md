### **第1部分：备考提纲（面向非法学背景考生）**

这份提纲将帮助你梳理核心逻辑，避免在细枝末节上迷失方向。

#### **一、核心概念：什么是刑法上的“结果”？**

刑法中的“结果”是一个广义词，指的是犯罪行为对法律所保护的利益（法益）造成的侵害事实。它有两种形态：
1.  **实害结果**：已经造成的实际损害，比如把人打伤、把钱抢走、把人杀死。
2.  **危险状态**：尚未造成实际损害，但已经产生了威胁法益的危险。

#### **二、犯罪的分类（基于“结果”的角度）**

这是本章的基础，也是选择题的常客。请记住以下两个维度的分类。

| 分类维度 | 类型 | 核心判断标准（是否要求结果/危险） | 典型罪名（务必记忆） |
| :--- | :--- | :--- | :--- |
| **第一组** | **实害犯** | **要求**发生“实害结果”才构成犯罪。 | **生产、销售劣药罪**；过失犯罪（交通肇事罪等） |
| | **具体危险犯** | **要求**发生“紧迫的、具体的危险”才构成犯罪。 | **生产、销售不符合标准的医用器材罪**；放火罪；投放危险物质罪 |
| | **抽象危险犯** | **不要求**实害或具体危险，有行为即推定有危险。 | **生产、销售假药罪**；生产、销售有毒有害食品罪；伪证罪；诬告陷害罪 |
| **第二组** | **行为犯** | 与“抽象危险犯”内核相似，完成行为即告成立。 | （同上，常被混用，但理解上按抽象危险犯更精准） |
| | **结果犯** | 与“实害犯”内核相似，要求实害结果。 | （同上） |

> **【解题口诀】**
> *   结果犯、实害犯，要求实害才既遂。
> *   具体危险犯，要求紧迫危险。
> *   抽象危险犯，有行为就够。
> *   **过失犯罪全是结果犯！**

#### **三、重中之重：结果加重犯**

这是本章乃至刑法总则的核心考点，主观题和客观题均会涉及。

**1. 什么是结果加重犯？**
一个犯罪行为（基本犯）意外导致了更严重的后果（加重结果），法律特别规定要加重刑罚。
*   **公式**：基本犯（故意） + 加重结果（对加重结果至少是过失）= 结果加重犯。
*   **经典模型**：故意伤害罪（基本犯） + 过失致人死亡 = 故意伤害罪致人死亡。

**2. 如何判断一个罪名是否存在结果加重犯？**
**唯一标准**：看刑法**法条是否有明文规定**。

**3. 常考结果加重犯清单（务必烂熟于心）**

*   **第一类：对加重结果持“过失”**
    *   故意伤害罪致人死亡
    *   非法拘禁罪致人重伤、死亡
    *   暴力干涉婚姻自由罪致人死亡
    *   虐待罪致人死亡
    *   抢夺罪致人重伤、死亡（司法解释规定）
    *   **> 重点对比 <**：以下罪名**没有**结果加重犯规定：重婚罪、侮辱罪、诽谤罪、遗弃罪。

*   **第二类：对加重结果“故意或过失”均可**
    *   **抢劫罪致人重伤、死亡**
    *   **强奸罪致人重伤、死亡**
    *   **拐卖妇女、儿童罪致人重伤、死亡**
    *   **放火罪致人重伤、死亡**

**4. 最重要的解题原则：“行为与目的同时存在”原则**

这是区分“结果加重犯”和“数罪并罚”的核心武器。

*   **一句话理解**：一个暴力行为，带着什么目的去实施，它就是什么罪的实行行为。
    *   带着“劫财”目的实施暴力 → 抢劫罪的实行行为 → 致人死伤 → **抢劫罪（结果加重犯）**
    *   带着“伤害”目的实施暴力 → 故意伤害罪的实行行为 → 致人死亡 → **故意伤害罪（结果加重犯）**
    *   带着“报复/泄愤”目的实施暴力 → 与前面的抢劫、强奸无关 → 新的犯罪（如故意伤害/杀人）→ **数罪并罚**

> **【例题实战（核心考点）】**
> **题目**：狗蛋在抢劫小芳财物得手后，因小芳出言不逊，为泄愤将其打成重伤。狗蛋的行为如何定性？
> **解题思路**：
> 1.  **暴力目的是什么？** 是“泄愤/伤害”，不是“劫财”。
> 2.  **该暴力行为是什么罪的实行行为？** 是“故意伤害罪”的实行行为，不是“抢劫罪”的实行行为。
> 3.  **能否认定为抢劫罪致人重伤？** **不能**。因为致人重伤的行为不是抢劫罪的实行行为。
> 4.  **最终结论**：构成**抢劫罪**和**故意伤害罪**，应当**两罪并罚**。

**（一）结果的概念与分类**

好，今天我们开始讲第六讲客观要件的第二个——结果。这个“结果”其实是一个广义的含义。我们前面讲了行为，危害行为要对法益制造危险，其实也就是说，你要制造一个法益侵害事实。不过，这个法益侵害事实包括两种状态：一个是**危险状态**，一个是**实害结果**。

我们先对法益侵害事实进行分类，这是第一节。

理论上通常将其分为两组概念。第一组是 **“危险犯”与“实害犯”** ：

1.  **实害犯（结果犯）**：将一种**实害结果**规定为犯罪的成立条件。这种犯罪也被称为结果犯。
    *   **例题**：生产、销售劣药罪，要构成犯罪，必须造成“对人体健康造成严重危害”的实害结果，比如致人重伤、死亡等。
2.  **具体危险犯**：将一种**紧迫的、具体的危险**作为犯罪的成立条件。
    *   **例题**：生产、销售不符合标准的医用器材罪，不要求造成实害结果，但要求“足以严重危害人体健康”，即制造一种紧迫的危险。放火罪、投放危险物质罪等，也要求造成具体危险才构成犯罪。
3.  **抽象危险犯**：将一种**推定的、较为缓和的抽象危险**作为犯罪的成立条件。这种危险是立法者基于行为本身推定存在的，因此也被称为**行为犯**。
    *   **例题**：生产、销售假药罪。不要求造成实害结果，也不要求具体危险。只要实施了生产、销售假药的行为，立法者就推定其具有抽象危险，即可构成犯罪。
    *   **例题**：狗蛋用面粉冒充假药销售。虽然面粉吃不死人，也没有紧迫危险，但该行为依然构成销售假药罪。

第二组概念是 **“行为犯”与“结果犯”** ：

1.  **行为犯**：不将实害结果作为犯罪成立条件，有行为即构成犯罪。
    *   **常考罪名**：生产、销售假药罪，生产、销售有毒有害食品罪，伪证罪，诬告陷害罪，组织、领导、参加黑社会性质组织罪等。
    *   **重点提示**：成立伪证罪，不要求法官相信伪证并造成错案；成立诬告陷害罪，不要求诬告成功。只要有行为即可。
2.  **结果犯**：将实害结果作为犯罪成立条件。
    *   **常考罪名**：丢失枪支不报罪（要求枪支造成实害后果），滥用职权罪（要求造成重大损失），生产、销售劣药罪。

> **【讲授者提示】**
> 建议优先使用 **“实害犯、具体危险犯、抽象危险犯”** 这组更严谨的概念来分析案件，避免因“行为犯、结果犯”在理论上有多种定义而产生混淆。

**（二）过失犯罪与结果犯的关系**

所有的过失犯罪都是实害犯（结果犯）。因为过失行为要构成犯罪，法条规定必须造成实害结果。
*   **例题**：交通肇事罪、过失致人死亡罪、过失致人重伤罪，均要求造成实害结果才成立犯罪。

**（三）结果加重犯（重点与难点）**

接下来我们看**结果加重犯**，这个概念既是重点又是难点。

1.  **引入案例：鲁智深拳打镇关西**
    *   **案情**：鲁智深只想教训镇关西，却失手将其打死。
    *   **分析**：鲁智深主观上只有伤害故意，对死亡结果是过失。他的行为同时触犯了**故意伤害罪**和**过失致人死亡罪**两个罪名。
    *   **结论**：法律特别规定，此种情况不实行数罪并罚，而是将“过失致人死亡”作为“故意伤害罪”的**加重处罚结果**，最终定为**故意伤害罪（致人死亡）**。这就是结果加重犯。

2.  **结果加重犯的基本原理**

    *   **法定性**：必须有法律的**明文规定**，才能成立结果加重犯。不能仅因一个行为造成了基本犯结果和加重结果，就认定为结果加重犯。
    *   **常考的结果加重犯（分类记忆）**
        *   **第一类：对加重结果持过失心理**。加重结果通常指“重伤”或“死亡”。
            *   **常考罪名**：
                1.  **故意伤害罪致人死亡**
                2.  **非法拘禁罪致人重伤、死亡**
                3.  **暴力干涉婚姻自由罪致人死亡**
                4.  **虐待罪致人死亡**
                5.  **抢夺罪致人重伤、死亡**（司法解释规定）
            *   **对比记忆（非结果加重犯）**：重婚罪致人死亡、侮辱罪致人死亡、诽谤罪致人死亡、遗弃罪致人死亡，因法条无规定，均**不是**结果加重犯。
            *   **理解规律**：立法者通常在有暴力手段的犯罪中规定结果加重犯（如暴力干涉婚姻自由），而在无暴力手段的犯罪中则不作此规定（如重婚罪）。
        *   **第二类：对加重结果既可持过失心理，也可持故意心理**。
            *   **考察频次排序**：
                1.  **抢劫罪致人重伤、死亡**
                2.  **强奸罪致人重伤、死亡**
                3.  **拐卖妇女、儿童罪致人重伤、死亡**
                4.  **放火罪致人重伤、死亡**

    *   **核心原理二：结果加重犯与想象竞合犯的关系**
        *   **原生态结构**：结果加重犯的原生态是**想象竞合犯**（一个行为触犯数个罪名）。
        *   **处理方式**：想象竞合犯按“择一重罪”处理，而结果加重犯是法律的**特事特办**，即不择一重罪，而是将加重结果作为基本罪的加重情节，在基本罪的刑罚基础上从重处罚。
        *   **例题**：鲁智深案，若没有“故意伤害罪致人死亡”的加重规定，则应按想象竞合犯原理，在故意伤害罪和过失致人死亡罪中择一重罪论处。

    *   **核心原理三：因果关系的认定（重点考点——“因”的辨认）**
        *   **基本原则**：结果加重犯要求**基本犯的实行行为**与加重结果之间具有因果关系。
        *   **判断标准：“行为与目的同时存在原则”**
            *   一个暴力行为是什么罪的实行行为，由实施该行为时的**目的**决定。
            *   **例题1（抢劫罪）**：狗蛋抢劫小芳的包，为了压制反抗而将小芳打死。此时，暴力的目的是“劫取财物”，因此该暴力行为是**抢劫罪的实行行为**，构成**抢劫罪致人死亡**。
            *   **例题2（故意伤害罪）**：狗蛋抢劫小芳得手后，因小芳辱骂他，为泄愤将小芳打成重伤。此时，暴力的目的是“泄愤/伤害”，而不是“劫财”，因此该暴力行为是**故意伤害罪的实行行为**，应认定为**抢劫罪**和**故意伤害罪**两罪并罚，而不是抢劫罪致人重伤。
            *   **例题3（强奸罪与故意杀人罪）**：狗蛋欲强奸小芳，因小芳反抗咬断其舌头，狗蛋为泄愤将小芳掐死。此时，掐死行为的目的是“泄愤/杀人”，不再是“奸淫”，该行为是**故意杀人罪的实行行为**。应认定为**强奸罪（未遂）** `[需后续课程知识]` 与**故意杀人罪（既遂）**，实行数罪并罚。
            *   **例题4（强奸既遂后的暴力）**：狗蛋强奸小芳既遂后，因小芳嘲笑其性能力，为泄愤将小芳打成重伤。结论：构成**强奸罪（既遂）**和**故意伤害罪**，两罪并罚。

        > **【讲授者批判的“半桶水”标准】**
        > 有观点认为，在“抢劫既遂前”实施的暴力致人伤亡，一律认定为抢劫罪的结果加重犯。这是错误的。
        > **反例**：狗蛋拦路抢劫时，发现被害人是抛弃自己的前女友，遂放弃取财目的，转而出于报复杀人。该杀人行为发生在“取得财物”之前，但其目的已变为“杀人”，不再是“劫财”，因此应认定为**抢劫罪（中止）** `[需后续课程知识]` 和**故意杀人罪（既遂）**，两罪并罚，而非抢劫罪致人死亡。
