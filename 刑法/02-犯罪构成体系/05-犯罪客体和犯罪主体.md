### **第1步：刑法“犯罪客体与犯罪主体”复习提纲（法考备考专用）**

本提纲基于上述讲稿整理，旨在帮助非法科背景考生快速建立逻辑框架，掌握核心考点。

#### **第一编：犯罪客体（法益）**

**一、核心概念**
-   **犯罪客体（法益）**：法律所保护的利益。犯罪是侵害法益的行为。
    -   *例：盗窃罪保护的法益是财产权；故意杀人罪保护的法益是生命权。*
-   **区分（必考）**：
    -   **犯罪对象**：犯罪行为直接作用的具体物或人（如“手机”）。
    -   **犯罪客体**：对象背后承载的法益（如“手机里的财产权”）。
    -   *注：对象是载体，客体是本质。*

**二、核心功能（解题钥匙）**
-   **法益的解释功能**：通过判断具体罪名的保护法益是什么，来决定某行为是否构成该罪。
    -   *例（非法侵入住宅罪）：保护法益是“居住安宁权”还是“住宅进入许可权”？结论直接影响案件定性。*

**三、最高原则：保护法益 vs 保障人权**
-   **冲突处理规则**：**优先保障人权**。
    -   体现：“存疑时有利于被告人”原则。
    -   例题：肖申克越狱案。多数说认为应定无罪，因为错判在先，优先保障人权。

**四、主观题观点展示模型（背下来）**
| 模型案例 | 观点一（入罪/保护法益） | 观点二（出罪/保障人权） | 多数说 |
| :--- | :--- | :--- | :--- |
| **情夫入宅案** | 保护“进入许可权”，丈夫未同意→构成。 | 保护“居住安宁”，幽会未破坏安宁→不构成。 | 不构成 |
| **长期空房案** | 保护“进入许可权”，擅闯→构成。 | 保护“居住安宁”，长期无人无安宁→不构成。 | 不构成 |
| **肖申克越狱案** | 保护“监狱管理秩序”，越狱→构成。 | 错判在先，越狱天性，保障人权→不构成。 | 不构成 |

#### **第二编：犯罪主体**

**一、自然人犯罪主体**

**（一）身份犯（两大分类）**

1.  **真正身份犯（定罪身份）**
    -   **定义**：必须具有特定身份才能构成**实行犯**（正犯）。
    -   **两个“不是”**：
        -   不是“在犯罪过程中形成的身份”（如黑老大、鸡头、蛇头）→ 不是定罪身份。
        -   不是针对“教唆犯和帮助犯”（如妻子可构成贪污罪的帮助犯）。
    -   **常考点（国家工作人员的认定）**：**看“从事公务”，不看“编制”。** 身份可“瞬时切换”。
        -   *校长/财务处长/会计*（从事公务）→ 是国家工作人员。
        -   *教授/医生*（技术劳动）→ 不是国家工作人员。
        -   *村干部*（协助政府做事）→ 是国家工作人员；*（做村务）→ 不是。

2.  **不真正身份犯（量刑身份）**
    -   **定义**：无身份也能定罪，但**有身份（如国家机关工作人员）要加重处罚**（从重）。
    -   *例：诬告陷害罪。*

**（二）三组“此罪与彼罪”的区分（表格）**
**核心判断标准：是否为国家工作人员（是否从事公务）。**

| 行为类型 | 国家工作人员（从事公务） | 非国家工作人员（非公务） |
| :--- | :--- | :--- |
| **贪钱** | **贪污罪** | **职务侵占罪** |
| **收钱** | **受贿罪** | **非国家工作人员受贿罪** |
| **挪钱** | **挪用公款罪** | **挪用资金罪** |

**二、单位犯罪主体**

**（一）分类（法条原文）**

| 分类 | 定义 | 常考罪名/例子 |
| :--- | :--- | :--- |
| **纯正的单位犯罪** | 只能由单位构成 | 单位行贿罪、单位受贿罪 |
| **不纯正的单位犯罪** | 单位和自然人均可构成 | 走私罪、生产销售伪劣产品罪 |
| **纯正的自然人犯罪** | 只能由自然人构成 | **金融诈骗罪中记三个**：**贷款诈骗罪、信用卡诈骗罪、有价证券诈骗罪** |

**（二）单位犯罪的构成条件（单选题常考）**

| 条件 | 要点 | 备注 |
| :--- | :--- | :--- |
| **主体** | 私营单位需法人资格；国有单位不需；分支机构需满足“以自己名义+归自己所有”。 | 合伙不构成单位犯罪。 |
| **主观** | 体现单位整体意志（集体决策或领导依职权决定）。 | 不限于故意，**过失也可构成**（如工程重大安全事故罪）。 |
| **否定情形** | ① 成立时就是为了犯罪；② 成立后主要活动是犯罪。 | 此时按**个人犯罪**论处（揭开面纱）。 |

**（三）单位犯罪与个人犯罪的“串线”规则（最难、最易混淆的考点）**

| 情形 | 处理规则 | 举例/备注 |
| :--- | :--- | :--- |
| **1. 单位实施纯正个人犯罪**（如杀人、盗窃） | 可“串线”定**个人的**故意杀人罪/盗窃罪。 | 强盛集团杀人案 → 定老大的故意杀人罪。 |
| **2. 单位帮助自然人犯罪** | 单位不犯罪，但**直接责任人**可构成帮助犯。 | 化工厂借毒药案 → 定厂长的帮助犯。 |
| **3. 单位实施不纯正单位犯罪**（如走私） | **禁止“串线”** ，各算各账。单位不构罪，个人也不构罪（不转嫁责任）。 | 2019年考点：走私15万（单位定罪需20万）→ 单位和个人均无罪。 |

**（四）处罚与善后**

| 项目 | 内容 |
| :--- | :--- |
| **处罚原则** | **双罚制**（罚单位+罚个人）为原则；**单罚制**（只罚个人）为例外。 |
| **罚单位** | 只能判**罚金**，不能判没收财产。 |
| **单位没了** | **“真没了”**（破产/注销）：追究个人责任。<br>**“假没了”**（合并/并购）：追究原单位的单位犯罪。 |

**【讲稿正文】**

**一、犯罪客体（法益）的概念与功能**

好，那从今天开始，我们就要开始学习四要件的每一个零部件。我们先看第一个零部件，就是犯罪客体，也是我们的第三讲。

犯罪客体，我们前面已经讲了，主要指的就是法益。你犯罪侵害的一个客体叫什么？叫法益，就是法律所保护的一种利益。比如说，刑法设立一个盗窃罪，保护的客体、保护的法益是什么？那就是财产权，他人的财产权。那刑法设立一个故意杀人罪，它的保护法益是什么呢？那就是生命权。所以我们其实可以给犯罪下一个定义：什么叫犯罪？就是侵害法益的行为。

**二、犯罪客体与犯罪对象的区别**

我们在这里面前面也提醒过，犯罪客体和犯罪对象有所区别。比如说，狗蛋偷了小芳的手机，那这个手机叫犯罪对象，而手机里面蕴含的财产权这个利益，它就是犯罪客体，就是法益。犯罪对象手机是犯罪客体这个法益的一个载体。

**三、法益的解释功能（核心考点）**

接下来我们要注意法益考试怎么考。考试主要考**法益的解释功能**。

什么意思？我们前面讲过，在刑法的解释里面，有一个目的解释。目的解释中的“保护目的”，其实指的就是保护法益。例如，诬告陷害罪的保护法益到底是什么？如果你认为是司法秩序，那么你构成此罪；如果你认为是公民个人的名誉权、人身自由权，而这些权利是可以承诺放弃的，那么可能就不构成此罪。

所以，一个罪的法益确定了，就能决定某个案件到底够不够成这个罪，这就是法益的解释功能。

**（一）例题1：非法侵入住宅罪的保护法益（主观题观点展示）**

主观题考过这么一个案例，原型来自日本：
妻子趁丈夫出差，把情夫叫进家中幽会。事后丈夫控告情夫构成非法侵入住宅罪。

-   **公诉人观点（构成）**：非法侵入住宅罪的保护法益是住宅的“进入许可权”（住宅权）。未经许可擅闯民宅即构成犯罪。本案中丈夫未同意，所以构成。
-   **辩护律师观点（不构成）**：妻子是居住权人之一，她同意了，所以不构成对“进入许可权”的侵害。
-   **法官最终观点（不构成）**：[修正] 如果完全依照民法上的住宅权，会出现“董事会表决”式的困境。刑法要保护更实质的法益——**居住生活的安宁状态**。情夫进入并未破坏这种安宁状态（幽会是温馨气氛），因此不构成本罪。

**（二）例题2：侵入长期无人居住的空房（主观题观点展示）**
狗蛋见邻居出国，房子空着，撬门住了一个月。是否构成非法侵入住宅罪？

-   **多数说（不构成）**：本罪保护法益是**居住生活的安宁状态**。长期空置的房子没有值得刑法保护的安宁状态，故不构成犯罪。**[注释：民法的账另算，需承担侵权赔偿责任。]**
-   **少数说（构成）**：本罪保护法益是**住宅权（进入许可权）**。未经许可擅闯民宅即构成犯罪。

**[注：客观题若考唯一答案，按多数说答——不构成。]**

**四、保护法益与保障人权的冲突（刑法最高原则）**

刑法的任务不仅是打击犯罪、保护法益。制定刑法典更重要的目的是**保障人权**。刑法典既是善良人的大宪章，也是犯罪人的大宪章。

一旦保护法益和保障人权发生冲突，结论是**优先保障人权**。例如“存疑时有利于被告人”原则，背后原理就是优先保障人权。

**（三）例题3：肖申克救赎案（主观题观点展示）**
银行家被冤枉杀妻，判终身监禁，越狱成功后被抓回，是否构成脱逃罪？

-   **观点一（构成，保护法益优先）**：脱逃罪的保护法益是监狱的正常管理秩序。只要是服刑人员，越狱就破坏了秩序，应定罪。
-   **观点二（不构成，保障人权优先，多数说）**：判决本身就是错案，冤枉他人，越狱是人之天性。抓回再定罪是错上加错，应无罪释放，优先保障人权。

**【总结】**
刑法疑难案件的根源多在于保护法益和保障人权的冲突。高水平法官的技艺体现在如何平衡这种冲突。

**五、犯罪主体概述**

好，接下来我们看第四讲：犯罪主体。犯罪主体主要是两个：**自然人**和**单位**。

**六、自然人犯罪（第一节）**

自然人犯罪主体，只要具有侵害法益的能力即可，不要求必须具有责任年龄、责任能力。

自然人犯罪中重要的考点是**身份犯**的问题。

**（一）真正身份犯（定罪身份）**

**1. 定义**：构成犯罪要求行为人具备特定身份（定罪身份）。例如，**贪污罪**的主体必须是国家工作人员，这就是一个定罪身份。

**2. 定罪身份的要求**

-   **① 时间要求**：必须在**开始犯罪时**就具备，在犯罪过程中形成的身份不算。
    -   **例题（判断）**：组织领导参加黑社会性质组织罪中的“组织者”（黑老大），是定罪身份吗？
    -   **分析**：不是。因为老大身份是“奋斗”形成的，不是在开始犯罪时就具备的。同理，组织卖淫罪的“老鸨”、组织偷越国边境罪的“蛇头”也不是定罪身份。
-   **② 主体要求**：定罪身份只针对**实行犯**（正犯），不针对教唆犯、帮助犯。
    -   **例题（判断）**：丈夫（国家工作人员）构成贪污罪实行犯；妻子（非国家工作人员）能否构成贪污罪的教唆犯？
    -   **分析**：可以。定罪身份只要求实行犯具备，帮助犯、教唆犯不要求。

**（二）不真正身份犯（量刑身份）**

定义：什么人都能构成犯罪（定罪无身份要求），但如果具有特定身份，量刑时**从重处罚**。

-   **典型例子：诬告陷害罪**。一般主体可构成，但如果是国家机关工作人员犯本罪，从重处罚。这其中的“国家机关工作人员”就是量刑身份。

**七、重点：国家工作人员的认定（核心高频考点）**

**（一）判断标准：公务说，而非编制说**

刑法看**实质**——看你是否**从事公务**，而不是看你有没有编制。

-   **公务的特征**：具有**公共管理性**和**行政职责性**。
-   **例题（判断）**：杭州西湖边执勤的女交警，若没有编制（合同制），是否是国家工作人员？
-   **分析**：是。因为她从事的是公务（公共管理、行政职责），刑法不看编制。

**（二）具体应用判断**

-   **例题（判断）**：
    1.  国立大学（如浙江大学）的校长、财务处处长、会计出纳，是否是国家工作人员？
    2.  法学院的教授、博导，是否是国家工作人员？
-   **分析**：
    1.  **是**。因为校长、财务处处长、会计出纳都在**从事公务**（管理学校财务等公共事务）。
    2.  **不是**。教授、博导从事的是**教学科研**，属于**技术性劳动**，不是公务。

**（三）实务应用：村干部的身份判断**

**立法解释**规定：村干部**协助政府从事公务**时，视为国家工作人员；处理村内自治事务（村务）时，不是国家工作人员。核心依然是看是否“从事公务”。

**（四）身份的临时可切换性（2016年真题考点）**

因为看“从事公务”与否，国家工作人员身份可以随时切换。

-   **例题（2016年考过）**：某公立医院副院长：
    -   周一：代表医院谈药品采购，收钱。→ 从事公务，构成**受贿罪**（国家工作人员）。
    -   周二：作为主治医师坐诊开药，收医药代表回扣。→ 技术性劳动，非公务，构成**非国家工作人员受贿罪**。

**八、单位犯罪（第二节）**

**（一）单位犯罪的分类**

1.  **纯正的单位犯罪**：只能由单位构成，自然人不能构成。例：**单位行贿罪、单位受贿罪**。
2.  **不纯正的单位犯罪**：单位和个人都能构成。例：走私犯罪、生产销售伪劣产品罪。
3.  **纯正的自然人犯罪**：只能由自然人构成。**[注：金融诈骗罪中的8个罪名，只有3个是纯正的自然人犯罪：贷款诈骗罪、信用卡诈骗罪、有价证券诈骗罪。]** [修正：记忆口诀“贷款、信用、有价”。]

**（二）单位犯罪的成立条件**

1.  **主体条件（法人资格）**
    -   **国有单位**：构成单位犯罪**不要求**法人资格。
    -   **私营单位**：构成单位犯罪**要求**有法人资格。合伙（无法人资格）不构成单位犯罪。
    -   **分支机构/内设机构**（如某银行营业部）：没有独立法人资格，构成单位犯罪需额外满足两个条件：① 以自己名义犯罪；② 违法所得归该机构所有。[修正：子公司有法人资格，可构成；分公司无法人资格，需满足上述条件。]

2.  **主观条件（单位意志）**
    -   必须体现单位整体意志。产生方式：① 单位决策机构形成（如董事会决议）；② 单位领导依职权决定。
    -   **[注：单位犯罪不限于故意犯罪，也可以是过失犯罪。例：工程重大安全事故罪既是单位犯罪，也是过失犯罪。]**

**（三）揭开单位的面纱（否定单位犯罪，定个人犯罪）**

-   **情形一**：成立单位的主要目的是**为了犯罪**（如公司章程写“贩毒”）。
-   **情形二**：单位成立后，**主要活动（主营业务）是犯罪**。

出现上述情形，直接认定为个人犯罪，不按单位犯罪处理。

**九、单位犯罪与个人犯罪的关系（难点）**

成立单位犯罪必须同时满足两个条件：① 体现单位整体意志；② 为本单位谋取非法利益。缺一不可。

**（一）区分单位犯罪与个人犯罪**

-   **例题1（向下斜箭头）**：十五个领导干部集体决策，将单位一百万公款私分（归少数人）。
    -   **分析**：体现了单位意志，但非为单位谋利。→ **个人犯罪（贪污罪）**。若不是私分，而是分给全体职工，则是单位犯罪（私分国有资产罪）。
-   **例题2（向上斜箭头）**：公司会计狗蛋，为暗恋的女老板，擅自做假账为公司逃税（老板不知情）。
    -   **分析**：为单位谋利，但未体现单位意志。→ **个人犯罪（逃税罪）**。

**（二）单位实施纯正的个人犯罪（只能由人构成的罪）**

-   **处理规则**：单位不能构成犯罪，追究单位内部**直接责任人**的个人犯罪。
-   **例题（狂飙强盛集团案）**：强盛集团董事会决议杀人（故意杀人罪是纯正个人犯罪）。单位不能构成“单位杀人罪”，应追究老大、老莫等直接责任人的故意杀人罪。

**（三）单位帮助自然人实施纯正的个人犯罪**

-   **例题**：化工厂集体决策，借氰化钾给狗蛋，助其毒杀情敌。
-   **分析**：化工厂不构成故意杀人罪的帮助犯（因单位无此资格）。但厂里的**直接责任人（如厂长）** 构成故意杀人罪的帮助犯。

**（四）单位实施不纯正的单位犯罪时的“各算各账”规则（难点，2019年考过）**

-   **原则**：对于单位和个人都能构成的犯罪（如走私普通货物物品罪），**各算各的账，不能串线**。
    -   单位定罪数额（如20万） vs 个人定罪数额（如10万）。
-   **例题**：某单位走私15万货物。
    -   **分析**：未达单位犯罪标准（20万），单位无罪。**不能**因为单位不构罪，就转而追究单位内部直接责任人的个人走私罪（因为个人标准是10万，看似够，但行为是单位行为，不允许串线适用标准）。→ **结果：无罪**。

**（五）单位犯罪后的处罚原则**

1.  **原则（双罚制）**：罚单位（只能判处罚金） + 罚个人（主管人员和直接责任人，可判自由刑甚至无期）。
2.  **例外（单罚制）**：只处罚个人，不处罚单位（因为主要是领导瞎搞）。

**（六）单位没了，怎么追责？**

-   **真没了**（被撤销、注销、吊销、破产）：追究**直接责任人的个人责任**。
-   **假没了**（被合并、并购）：追究**原单位的单位犯罪**（即新单位承接原单位的罚金责任等）。

**【单元总结】**
自然人犯罪核心考点是**国家工作人员的认定**（看公务不看编制）。单位犯罪难点在于**单位犯罪与个人犯罪的关系**（特别是各算各账规则）。
