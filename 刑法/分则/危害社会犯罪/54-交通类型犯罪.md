# 破坏型犯罪与交通型犯罪——刑法讲稿整理

## 1：法考备考提纲

以下是基于上述讲稿内容，对照刑法条款整理的知识提纲，供非法科背景的考生备考使用。


### 一、破坏型犯罪（第二节）

#### （一）破坏交通工具罪

| 项目 | 内容 |
|------|------|
| **刑法条款** | 第116条 |
| **犯罪对象** | 汽车（含私家车）、大型拖拉机（扩大解释）；**不包含**摩托车、电动自行车（缩小解释） |
| **危害程度要求** | 必须 **足以发生倾覆危险** |
| **程度太低** | 砸座椅、砸玻璃 → 不构成本罪（可能构成故意毁坏财物罪） |
| **程度适中** | 破坏刹车装置 → 构成本罪 |
| **程度太高** | 大卸八块、车无法上路 → 不构成本罪（只构成故意毁坏财物罪） |
| **主观心态** | 故意（但法考中此罪主观要件不是考查重点） |

**【例题1】** 甲将公交车刹车装置破坏，公交车尚未发车。问：甲是否构成破坏交通工具罪？
**分析**：构成。虽未发车，但刹车装置被破坏后一旦上路即足以发生倾覆危险，不要求已实际行驶。

**【例题2】** 乙将公交车上全部座椅砸坏，价值2万元。问：乙构成何罪？
**分析**：不构成破坏交通工具罪（不足以发生倾覆危险）。若价值较大，构成故意毁坏财物罪。


#### （二）破坏交通设施罪

| 项目 | 内容 |
|------|------|
| **刑法条款** | 第117条 |
| **犯罪对象** | 交通设施（道路、桥梁、隧道等） |
| **"破坏"的两种含义** | ①物理性毁坏（挖坑） ②功能性毁坏（撒钉子妨害通行功能） |
| **罪数处理** | 一个行为同时触犯破坏交通工具罪和破坏交通设施罪 → 想象竞合择一重 |

**【例题3】** 甲在高速公路匝道上撒钉子，扎破多辆汽车轮胎，并在附近开修理店收费修车。问：甲构成何罪？
**分析**：①破坏交通工具罪（轮胎被扎）②破坏交通设施罪（功能性破坏路面通行功能）→ 想象竞合择一重；③诈骗罪（隐瞒有免费修车义务的事实收费）→ 独立行为，与前罪并罚。


#### （三）破坏电力设备罪

| 项目 | 内容 |
|------|------|
| **刑法条款** | 第118条 |
| **核心要件** | 电力设备 **已交付使用**（不要求已通电） |
| **不构成的情形** | 尚未交付使用（如还在工厂里） |


### 二、交通型犯罪（第三节）

#### （一）交通肇事罪

| 项目 | 内容 |
|------|------|
| **刑法条款** | 第133条 |
| **本质** | 交通领域的 **过失犯罪** |
| **成立条件（基本犯）** | ①肇事行为（违反交规）②实害结果（死亡1人/重伤3人/重伤1人+严重情节）③因果关系 |
| **法定刑（基本犯）** | 三年以下有期徒刑或拘役 |

**1. 行为主体：不限于司机**

| 主体类型 | 是否构成交通肇事罪 | 说明 |
|---------|-----------------|------|
| 司机 | ✅ | 驾驶过失 |
| 车主（出借车辆给醉酒者） | ✅ | 监督过失（各定各的罪，不成立共犯） |
| 指使闯红灯的领导 | ✅ | 指挥过失（各定各的罪，不成立共犯） |

**【例题4】** 甲明知乙醉酒，仍将车借给乙。乙醉驾撞死人。问：甲是否构成交通肇事罪？
**分析**：构成。甲有监督过失。但甲不构成乙的交通肇事罪的共犯，各定各的交通肇事罪。

**2. 行为地点：公共交通领域**

| 地点类型 | 罪名 |
|---------|------|
| 公共交通领域（公路/水路） | 交通肇事罪 |
| 公共交通领域外（驾校训练场） | 过失致人死亡罪 |
| 铁路 | 铁路运营安全事故罪 |
| 航空 | 重大飞行事故罪 |

**3. 法定刑升格条件**

| 升格条件 | 法定刑 | 关键要件 |
|---------|--------|---------|
| **肇事后逃逸** | 三年以上七年以下 | **明知**自己肇事后为逃避追究而逃跑 |
| **因逃逸致人死亡** | 七年以上十五年以下 | 逃逸不救人 → 不作为犯罪 |

**【特别提示】** 这两个升格条件都是 **主观题高频考点**！

**4. 连环碾压案（主观题核心模型）**

**模型一（可查明因果关系）：**
1. 甲撞乙（死）+撞丙（重伤）→ 逃逸 → 5分钟后丁碾压丙 → 丙死
2. **结论**：甲 → 交通肇事罪（撞死乙）+ 因逃逸致人死亡（丙）；丁 → 交通肇事罪
3. **原理**：三因一果（甲撞+甲不救+丁碾压），死亡结果分配给不作为（因逃逸致人死亡）

**模型二（无法查明死亡时间）：**
1. 甲撞乙 → 逃逸 → 10分钟后丙碾压 → 发现死亡，无法查明死亡时间
2. **口诀**："死得越早对兄弟们越有利"
3. 按最早时间认定（甲撞时乙即死亡）→ 丙无罪（碾压尸体）；甲为肇事后逃逸（三年以上七年以下），非因逃逸致人死亡

**5. 不救人的三个档次（等价性）**

| 行为 | 定性 |
|------|------|
| 单纯跑路，人死 | 因逃逸致人死亡（相当于因遗弃致人死亡） |
| 把人藏到草丛中后跑路，人死 | **不作为的故意杀人罪** |
| 把人扔水沟淹死 | **作为方式的故意杀人罪** |

**6. 因逃逸致人死亡的主观要件**

对死亡结果：既可以是 **过失**，也可以是 **故意**（间接故意）。

**7. "共犯"问题的做题方法**

| 指使者身份 | 处理 |
|-----------|------|
| 乘车人/单位主管人员/车辆所有人/承包人 | 直接定 **交通肇事罪的共犯**（司法解释特殊规定） |
| 其他人（如路人） | 按正常原理：遗弃罪教唆犯 + 窝藏罪 → 想象竞合择一重 |


#### （二）危险驾驶罪

| 项目 | 内容 |
|------|------|
| **刑法条款** | 第133条之一 |
| **主观心态** | **故意犯罪** ✅ 有共犯 |
| **法定刑** | 拘役（最高6个月）+ 罚金 |

**1. "道路"的范围（扩大解释）**

- 公路、城市道路
- 单位辖区内道路（校园、小区）——需 **具有公共性**（允许社会车辆通行）
- 广场、公共停车场、公共停车库内的道路

**2. 醉酒驾驶入罪新标准（2025/2026重要考点！）**

| 情形 | 是否定罪 |
|------|---------|
| 80mg/100ml + **严重情节** | ✅ 定罪 |
| 80~150mg/100ml + 无严重情节 | ❌ 不定罪 |
| ≥150mg/100ml | ✅ 定罪 |
| 80mg/100ml + **较轻情节**（短距离挪车、接替驾驶、紧急避险等） | ❌ 不定罪 |

**3. 紧急避险**

- 不得已自己酒驾送医（偏僻地区无其他交通工具）→ 紧急避险 → 不定罪
- 能叫到救护车仍自己酒驾送医 → 不构成紧急避险，但情节较轻 → 不定罪

**4. 共犯**

- 明知他人醉酒，仍提供机动车 → **危险驾驶罪的帮助犯**
- 与交通肇事罪的区别：危险驾驶罪是故意犯罪，有共犯

**5. 罪数**

- 醉驾→撞死人→危险驾驶罪+交通肇事罪→**重罪吸收轻罪**→定交通肇事罪


#### （三）妨害安全驾驶罪

| 项目 | 内容 |
|------|------|
| **刑法条款** | 第133条之二（2020年《刑法修正案（十一）》新增） |
| **适用场景** | 行驶中的公共交通工具 |
| **行为方式** | ①乘客打司机/抢方向盘 ②司机打乘客（行驶中互殴） |
| **罪数** | 若造成更严重后果→想象竞合择一重（交通肇事罪/以危险方法危害公共安全罪/故意杀人罪等） |

### 一、开场：破坏型犯罪概述

好，接下来我们看破坏型犯罪。第二节，破坏型犯罪，主要是三个罪名。第一个是破坏交通工具罪。这几个罪名都算是二三线罪名，考的频率比较低，但偶尔也会考一次。我们注意几个点就可以了。


### 二、破坏交通工具罪

**（一）犯罪对象的范围**

破坏交通工具罪中，交通工具肯定包括汽车，这个汽车也包括私家汽车——你把人家私家车的刹车装置破坏了，一上路就会酿成车祸，也会危害公共安全。同时，汽车还可以扩大解释为包括大型拖拉机。

**（二）排除对象（缩小解释）**

**`[修正]`** 这里的交通工具 **不包括** 摩托车，也不包括电动自行车（电瓶车）。因为破坏这些交通工具的危害程度没那么大，所以不包括——这属于缩小解释。

**（三）破坏程度的要求——"足以发生倾覆危险"**

**`[修正]`** 本罪要求破坏达到 **足以发生倾覆危险** 的程度——就是车可能车毁人亡。

破坏程度有讲究：
- **程度太低**：砸坏公交车几个座椅、乘客座位玻璃——不足以造成车毁人亡的危险 → **不构成**破坏交通工具罪。（如果毁坏价值大，可定故意毁坏财物罪。）
- **程度适中**：破坏公交车刹车装置 → 有危险 → **构成**破坏交通工具罪。
- **程度太高**：把公交车大卸八块、轮子全拆了，车已经躺在地上没法上路 → 不可能危害道路安全 → **不构成**破坏交通工具罪，只构成故意毁坏财物罪。

**【讲授者提示】** 破坏程度"太低不行、太高也不行"，有个"度"的把握。**`[注]`** 讲授者用邻居摆满月酒、不能表现得比亲爹还开心来类比"度的把握"，属于活跃课堂气氛。**这个知识点考过。**


### 三、破坏交通设施罪

**（一）基本理解**

破坏交通设施罪的对象是道路等交通设施。比如在道路上挖坑，也算破坏。

**（二）重点例题：高速公路撒钉子案**

**【例题1】狗蛋在高速公路出口外约一两百米处开汽车修理店，因客源少，在高速公路出口匝道上撒了大量钉子。过往车辆轮胎被扎后停靠，狗蛋为车主修车并收取费用。问：狗蛋构成何罪？**

**分析：**
1. **破坏交通工具罪？** 撒钉子让过往车辆轮胎被扎，属于破坏交通工具 → 可构成。
2. **破坏交通设施罪？** 撒钉子是否"破坏"了高速公路路面？

**【关键知识点】** "破坏/毁坏"有两种含义：
- **物理性毁坏**：挖坑——物理层面破坏路面。
- **功能性毁坏（效用性毁坏）**：撒钉子虽然没有物理挖坑，但妨害了道路的通行功能，与挖坑没有本质区别 → 也属于"破坏"，构成破坏交通设施罪。

3. **罪数处理**：一个行为构成两个罪（破坏交通工具罪 + 破坏交通设施罪）→ **想象竞合，择一重罪论处**。

4. **是否构成诈骗罪？** 狗蛋隐瞒了自己撒钉子弄坏车辆、有义务免费修车的事实，收取修车费 → **构成诈骗罪**。但诈骗罪是独立行为，与前面的破坏行为是前后两个行为 → **两罪并罚**。


### 四、破坏电力设备罪

**（一）核心考点**

破坏电力设备罪要求电力设备 **必须已经交付使用**，但 **不要求已经通电**。

- 未交付使用（如还在工厂里的变压器）→ 破坏 → **不构成**本罪。
- 已交付使用但尚未通电 → 破坏 → **构成**本罪。

**【讲授者提示】** 这个知识点 **2025年考过一次**。**`[注]`** 此处的"二五年"指2025年。


### 五、交通型犯罪——引入

接下来看第三节，交通领域的犯罪。这是本讲最重要的一节，因为里面有一个"一哥"罪名——**交通肇事罪**。


### 六、交通肇事罪

**（一）本质理解**

交通肇事罪的本质是 **交通领域的过失犯罪**。用过失犯罪的成立条件来判断：**①过失行为 ②损害结果 ③二者之间有因果关系**。

**（二）行为主体——不限于司机**

**【例题2】你的哥们喝得醉醺醺来你家，借你的玛莎拉蒂去兜风。你明知他醉酒，仍把车钥匙扔给他。他因醉驾撞死人，构成交通肇事罪。问：你（出借者）是否构成交通肇事罪？**

**分析：** 构成。你违反了管理义务（对危险物的监督过失），他违反了驾驶过失，各定各的交通肇事罪。**`[注]`** 注意：不构成交通肇事的共同犯罪（过失犯罪不成立共犯）。

**【结论】** 躺在床上也可能构成交通肇事罪，不限于司机。

**（三）行为地点——必须为"公共交通领域"**

- **公共交通领域内**（公路交通 + 水上交通）→ 交通肇事罪。
- **公共交通领域外**（如驾校内部训练场）开车撞死人 → **过失致人死亡罪**。

**【讲授者提示】** 2025年考了 **水上交通** 的交通肇事罪（开船撞船）。

**（四）交通肇事罪与相关罪名的管辖范围（海陆空分工）**

| 交通领域 | 管辖罪名 |
|---------|---------|
| 陆路（公路/道路） | **交通肇事罪** |
| 水路（水上交通） | **交通肇事罪** |
| 铁路（火车相撞） | **铁路运营安全事故罪** |
| 航空（飞行事故） | **重大飞行事故罪** |

**`[注]`** 讲授者提到温州高铁追尾事故（多年前），属于铁路运营安全事故罪，超出本讲主题，特此注释。

**（五）交通肇事罪的成立条件（基本犯：三年以下）**

1. **过失行为（肇事行为）**
2. **实害结果**：死亡1人，或者重伤3人，或者重伤1人+严重情节
3. **因果关系**：过失行为与实害结果之间有因果关系

**（六）法定刑升格条件一：肇事后逃逸（三年以上七年以下）**

**定义**：为逃避法律追究而逃跑。

**前提条件**：**明知自己肇事了**。如果不知道肇事了，不算肇事后逃逸。

**【例题3】某人醉驾，撞死一人，另将一人卡在底盘下拖行约一公里（被拦停），伤者最终轻伤。司机称：当时醉酒，完全不知道自己撞了人，也不知道车下有人。问：是否构成"肇事后逃逸"？**

**分析：** 不构成"肇事后逃逸"，因为要求明知自己肇事为前提。**`[修正]`** 但醉驾本身构成危险驾驶罪；撞死人构成交通肇事罪（基本犯，三年以下）；拖行行为因不知情不构成故意杀人罪，过失致人轻伤不构成犯罪。**`[注]`** 讲授者此处以"假如给定条件是这个版本"为前提进行实体法分析，强调事实认定不同则结论不同。

**（七）法定刑升格条件二：因逃逸致人死亡（七年以上十五年以下）**

**本质**：因逃逸不救人导致人死亡——**不作为犯罪**。

**不作为犯罪成立条件**：①作为义务（来自先前肇事行为）→ ②履行能力 → ③不履行→结果可避免性。

**1. 核心难点：因果关系——连环碾压案模型**

**【模型一：因果关系可查明】**

**【例题4】甲驾车不慎撞倒乙（当场死亡）和丙（重伤），丙倒在路中央，甲逃逸。五分钟后，丁驾车不慎碾压到丙，丙死亡。问：甲、丁如何定罪？**

**分析：**
- **丁**：与死亡结果有因果关系，且"不慎"表明有过失 → **构成交通肇事罪**。
- **甲**：需判断甲的行为与丙的死亡是否有因果关系。

**介入因素判断（两步走）：**
- 第一步：丁的碾压是否异常？→ 不异常（把人撞晕在路中央不管，被后车碾压是大概率事件）
- 第二步：不异常 → **甲的前两个行为（不慎撞 + 逃逸不救）与丙的死亡有因果关系**。

**三因一果**：①甲不慎撞（重伤丙） ②甲逃逸不救（不作为） ③丁碾压 → 共同导致丙死亡。

**`[修正]`** 量刑处理：甲已因撞死乙成立交通肇事罪（一个死亡结果就够了），所以丙的死亡结果不再用于肇事行为，而用于 **因逃逸致人死亡**（七年以上十五年以下）。丁构成交通肇事罪。

**【模型二：无法查明死亡时间】**

**【例题5】甲驾车不慎撞倒乙，乙倒在路中央，甲逃逸。十分钟后丙驾车不慎碾压过去。二十分钟后救护人员发现乙死亡，但无法查明死亡时间。问：甲、丙如何定罪？**

**分析：** 可能的死亡时间有三种：
- ①甲撞时当场死亡
- ②甲逃逸期间死亡（丙碾压前）
- ③丙碾压后死亡

**`[修正]`** **口诀："死得越早对兄弟们越有利"** 。
- 按最早时间点认定：甲撞时乙即死亡。
- **丙**：碾压的是尸体 → **无罪**。
- **甲**：定罪上肯定构成交通肇事罪；量刑上，因无法证明是逃逸期间死亡，不能认定为"因逃逸致人死亡"（七年以上十五年以下），只能认定为"肇事后逃逸"（三年以上七年以下）→ 对甲有利。

**2. 等价性问题——不救人的三个档次**

| 档次 | 行为方式 | 定性 |
|------|---------|------|
| **第一档（最轻）** | 单纯跑路，不救人 | **因逃逸致人死亡**（七年以上十五年以下）——相当于"因遗弃致人死亡" |
| **第二档（加重）** | 把人搬到路边草丛中藏匿后跑路 | **不作为的故意杀人罪** |
| **第三档（最重）** | 把人扔到水沟里淹死 | **作为方式的故意杀人罪** |

**`[修正]`** 关键区分：搬到草丛中虽属积极举动，但不具有"通常的致命危险"，不是作为方式的杀人；仍为不作为方式的杀人。扔到水沟里具有通常的致命危险，属于作为方式的杀人。

**`[注]`** 讲授者在此回顾了总则中"作为与不作为的区分标准"（是否具有通常的致命危险），属于总则知识点在分则中的应用。同时讲授者提到遗弃罪主体不限于家庭成员（有扶助义务即可），超出本讲主题，特此注释。

**3. 主观要件——因逃逸致人死亡的主观心理**

**要求**：明知自己肇事了。

对"致人死亡"的结果，既可以是 **过失**，也可以是 **故意**：

| 情形 | 主观心理 | 是否构成因逃逸致人死亡 |
|------|---------|---------------------|
| 以为丙死了（实际没死），不救离去，丙死 | 过失 | ✅ 构成（考过） |
| 明知丙重伤、不救会死，仍逃离 | 间接故意 | ✅ 构成（未考过） |

**（八）交通肇事罪中的"共犯"问题**

**1. 共同过失肇事——各定各的交通肇事罪，不成立共犯**

| 类型 | 示例 | 分析 |
|------|------|------|
| **监督过失** | 明知兄弟醉酒，仍将车借给他开 → 兄弟撞死人 | 出借者构成**监督过失**的交通肇事罪；兄弟构成**驾驶过失**的交通肇事罪。**各定各的，不成立共犯** |
| **指挥过失** | 领导指使司机闯红灯 → 撞死人 | 领导构成**指挥过失**的交通肇事罪；司机构成交通肇事罪。**`[修正]`** 领导不构成交通肇事罪的教唆犯（教唆犯只存在于故意犯罪中） |

**`[注]`** 讲授者强调：选项中一旦出现"交通肇事罪的帮助犯/教唆犯/间接正犯"，本身就是错的（因为交通肇事罪是过失犯罪，不存在共犯形态）。

**2. 指使逃逸——核心难点**

**【例题6】甲驾车不慎撞死乙、重伤丙。甲欲救丙，路人丁指使甲："别救人，快跑！"甲听从逃逸，丙因未获救死亡。问：甲、丁如何定罪？**

**分析（正常原理）：**
- **甲**：交通肇事罪（撞死乙）+ 因逃逸致人死亡（丙死亡）= 七年以上十五年以下。
- **丁**：指使甲不救人 → **遗弃罪的教唆犯**（因逃逸致人死亡本质是遗弃罪）+ **窝藏罪**（指使犯罪分子逃逸）。一个行为触犯两罪 → **想象竞合，择一重罪论处**。

**司法解释特殊规定（考点！）** ：

如果指使逃逸者是以下 **四种人**，不按正常原理，**直接定交通肇事罪的共犯**：
①单位主管人员 ②车辆所有人 ③承包人 ④**乘车人**（最常考）

**【做题步骤】** 先看指使者身份：
- 是乘车人/单位领导等四种人 → **直接定交通肇事罪的共犯**（特殊规定）。
- 是其他人（如路人丁）→ 按正常原理：遗弃罪教唆犯 + 窝藏罪，想象竞合择一重。

**`[注]`** 讲授者指出该司法解释在法理上有争议（交通肇事罪为过失犯罪，理论上不应有共犯），但司法解释具有法律效力，需作为特殊规定对待。


### 七、危险驾驶罪

**（一）犯罪故意**

**`[修正]`** 危险驾驶罪是 **故意犯罪**（与交通肇事罪相反）。

**（二）"道路"的认定——扩大解释**

**`[修正]`** 按新的司法解释，"道路"不限于公路、城市道路，还包括：
1. **单位辖区内的道路**（如校园、居民小区）——但需 **具有公共性**（允许社会车辆通行）。
2. **广场、公共停车场、公共停车库**内的道路。

**（三）重点：醉酒驾驶的新规定（未考过，重点关注！）**

| 情形 | 是否定罪 | 说明 |
|------|---------|------|
| **80mg/100ml + 严重情节** | ✅ 定罪 | 严重情节包括：严重超员/超载/超速、毒驾、客运、高速公路驾驶、驾驶重型载货汽车等 |
| **80mg/100ml ~ 150mg/100ml + 无严重情节** | ❌ 不定罪 | 以前一刀切定罪，新规提高门槛 |
| **≥150mg/100ml** | ✅ 定罪 | 即使无严重情节也定罪 |
| **80mg/100ml + 较轻情节** | ❌ 不定罪 | 见下列三种情形 |

**较轻情节不定罪的三种常考情形：**
1. **紧急避险**（见下文详述）
2. **短距离驾驶**（挪车、停车入位、短距离驶出等）
3. **短距离接替驾驶**（如代驾坐地起价，车主无奈短距离开回家）——证据需能证明

**`[注]`** 讲授者提到：以前停车入位醉驾被定罪的案例（男朋友帮女朋友停车入位刮蹭后报警），新规下不定罪；代驾中途坐地起价、车主短距离开回家被查的，新规下不定罪。

**（四）紧急避险的特殊问题**

| 情形 | 是否构成紧急避险 | 处理 |
|------|----------------|------|
| 能叫到救护车/出租车，仍自己酒驾送医 | ❌ 不符合"不得已"条件 | 不构成紧急避险，但情节较轻 → **不定罪** |
| 不能很快叫到救护车/出租车（偏僻地区），自己酒驾送医 | ✅ 符合紧急避险 | **不构成本罪** |

**（五）危险驾驶罪的主观要件**

**`[修正]`** 只要求认识到 **自己喝了酒**，不要求认识到精确的酒精含量。

**【例题7】狗蛋喝高后在车内开空调取暖（发动机启动），等老婆来接，无驾驶意图。交警查酒驾发现其醉驾。问：是否构成危险驾驶罪？**

**分析：** 不构成。没有醉酒驾驶机动车的意图。但需要有证据（如微信聊天记录）证明。

**（六）共犯问题**

危险驾驶罪是 **故意犯罪** → **有共犯**（帮助犯、教唆犯、间接正犯均可）。

**【例题8】明知兄弟喝高，仍将车借给他开。兄弟构成危险驾驶罪（实行犯），出借者构成危险驾驶罪的帮助犯。**

**（七）罪数问题**

**`[修正]`** 醉酒驾驶发展至撞死人：
- 同时构成 **危险驾驶罪** + **交通肇事罪**。
- 处理原则：**重罪吸收轻罪** → 定 **交通肇事罪**。
- 原因：交通肇事罪更重（最高十五年），危险驾驶罪最重仅拘役六个月。

**`[注]`** 讲授者提及"第二阶段背诵卷会详细总结罪数图表"，属于课程安排提示。


### 八、妨害安全驾驶罪

**（一）背景条件**

**行驶中的公共交通工具**（公交车、旅游大巴等）。

**（二）行为方式**

1. **乘客**对驾驶员 **使用暴力** 或 **抢控驾驶操纵装置**（如打司机、抢方向盘）。
2. **驾驶员**对乘客 **使用暴力**（行驶中与乘客互殴）。

**（三）司机正当防卫的限制**

当乘客打司机时，司机 **不能** 在行驶中丢开方向盘与乘客对打（危害全车人安全）。应 **先靠边停车**，停车后再处理。

**（四）罪数问题**

妨害安全驾驶罪可能演变为更重的罪：

| 行为程度 | 可能构成的罪名 | 处理 |
|---------|--------------|------|
| 打司机/抢方向盘，车辆失控压死行人 | 妨害安全驾驶罪 + 交通肇事罪 | 想象竞合择一重 |
| 程度更严重（如以危险方法危害公共安全） | 以危险方法危害公共安全罪 | 想象竞合择一重 |
| 抢方向盘想同归于尽 | 故意杀人罪 | 想象竞合择一重 |


### 九、总结回顾

交通型犯罪共三个罪名：

| 顺序 | 罪名 | 性质 | 重点 |
|------|------|------|------|
| **一哥** | 交通肇事罪 | 过失犯罪（最重） | 知识点最多：成立条件、两个升格条件、共犯问题 |
| **二哥** | 危险驾驶罪 | 故意犯罪 | 重点：醉酒驾驶新司法解释 |
| **三哥** | 妨害安全驾驶罪 | — | 注意罪数问题 |
