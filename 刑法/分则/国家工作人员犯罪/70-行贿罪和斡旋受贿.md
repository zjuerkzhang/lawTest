# 第1部分：知识提纲与考点梳理


## 一、行贿罪知识提纲

### （一）法条依据

《中华人民共和国刑法》第389条：

- **第1款**：为谋取不正当利益，给予国家工作人员以财物的，是行贿罪。
- **第2款**：在经济往来中，违反国家规定，给予国家工作人员以财物，数额较大的，或者违反国家规定，给予国家工作人员以各种名义的回扣、手续费的，以行贿论处。
- **第3款**：因被勒索给予国家工作人员以财物，没有获得不正当利益的，不是行贿。

### （二）构成要件

| 要件 | 内容 |
|------|------|
| **主体** | 一般主体（自然人） |
| **主观方面** | 故意，且**具有谋取不正当利益的目的** |
| **客观方面** | 给予国家工作人员财物 |
| **对象** | 国家工作人员 |

### （三）“不正当利益”的认定

根据司法解释，“谋取不正当利益”是指：
- 行贿人谋取的利益违反法律、法规、规章、政策规定；或者
- 要求国家工作人员违反法律、法规、规章、政策、行业规范的规定，为自己提供帮助或方便条件；或者
- 违背公平、公正原则，在经济、组织人事管理等活动中，**谋取竞争优势**

> **注意：** 不正当利益**不限于非法利益**，也包括不公平的竞争优势（如跑官卖官）。

### （四）行为类型与既遂标准

| 类型 | 定义 | 既遂/构罪标准 |
|------|------|--------------|
| **主动送钱** | 主动为谋取不正当利益而送钱 | 财物送出即既遂，不要求实际谋得利益 |
| **被动送钱** | 因被勒索而给钱 | 必须**实际获得不正当利益**才构罪 |

### （五）与受贿罪的关系（对合犯）

行贿罪与受贿罪是对合犯（对向犯），但**并非必然同时成立**——一方构成犯罪时，另一方可能不构成犯罪。

**典型情形：**
- 被勒索送钱+未获利益 → 行贿方不构成犯罪，但受贿方仍构成
- 谋取正当利益而送钱 → 行贿方不构成犯罪，但受贿方仍构成
- 官员不知情收钱 → 行贿方构成犯罪，但受贿方不构成

### （六）罪数问题

**原则：** 行贿罪 + 谋取不正当利益所构成的其他犯罪 → **并罚**

**例外：** 如果并罚会出现重复处罚 → 只定一罪（重罪）


## 二、斡旋受贿知识提纲

### （一）法条依据

《中华人民共和国刑法》第388条：

> 国家工作人员利用本人职权或者地位形成的便利条件，通过其他国家工作人员职务上的行为，为请托人谋取不正当利益，索取请托人财物或者收受请托人财物的，以受贿论处。

### （二）构成要件

| 要件 | 内容 |
|------|------|
| **主体** | 国家工作人员（中间人/斡旋者） |
| **行为方式** | 利用本人职权或地位形成的便利条件 |
| **行为内容** | 通过**其他国家工作人员**的职务行为 |
| **谋取利益** | 必须为请托人谋取**不正当利益** |
| **财物** | 索取或收受请托人财物 |

### （三）成立与既遂

- **成立条件**：许诺为请托人实施斡旋行为（许诺谋取不正当利益），基于此索要或收受钱财
- **既遂标准**：收到钱即既遂（不要求实际实施斡旋行为，也不要求事办成）

### （四）三大模型对比

| | 模型一（乙转交丙60万） | 模型二（乙告知丙自己收钱） | 模型三（乙隐瞒，丙猜出） |
|---|---|---|---|
| **丙（终端）** | 普通受贿60万 | 受贿100万（对乙收的钱负责） | 受贿100万（猜出即明知） |
| **乙（中间人）** | 斡旋受贿40万 + 共犯 + 行贿（想象竞合/牵连犯择一重） | 斡旋受贿100万 + 共犯（想象竞合择一重） | 仅斡旋受贿100万 |
| **甲（行贿人）** | 两个行贿行为→连续犯→累计100万 | 两个行贿罪→想象竞合择一重 | 两个行贿罪→想象竞合择一重 |
| **考试重点** | 等号原理+连续犯 | 第三人收钱原理 | **2023年主观题** |

### （五）与普通受贿的区分

| | 普通受贿 | 斡旋受贿 |
|---|---|---|
| **法条** | 第385条 | 第388条 |
| **行为方式** | 利用本人职务上的便利 | 利用职权或地位形成的便利条件 |
| **与终端人的关系** | 有隶属、制约关系 | 无隶属、制约关系 |
| **谋取利益** | 正当或不正当均可 | **必须是不正当利益** |
| **典型情形** | 上级指示下级 | 同级协调、下级说情 |

## 一、引入：行贿罪概述

好，接下来我们看第四节——行贿罪。

前面把受贿罪讲完以后，许多同学说：“哇，受贿罪简直是迷宫一样，问题怎么那么多呀？”但是呢，你多逛两遍，慢慢就熟练了。这就跟打CS（反恐精英）一样，我以前上学的时候也喜欢打，刚开始也分不清警匪，也是很菜的，人家嫌我是猪队友。但是我自己勤学苦练，后来也很熟练了，成了骨干队员。所以谁一开始都是菜鸟，只要坚持不懈，终成大老。受贿罪再复杂，知识点再多，你多练两遍也就熟悉了。

受贿罪这个大头过去以后，接下来就没有那么复杂了。接下来我们看**行贿罪**。

> **【注释】** 行贿罪规定于《中华人民共和国刑法》第389条：“为谋取不正当利益，给予国家工作人员以财物的，是行贿罪。”

行贿罪就是：**为谋取不正当利益，给予国家工作人员以财物**。


## 二、行贿罪的构成要件（一）——“为谋取不正当利益”

### （一）主客观双重判断标准

这里面第一个问题就是“为谋取不正当利益”，这一点很重要。

“为谋取不正当利益”的要求有两个层面：
1. **主观上**：要求具有谋取不正当利益的目的；
2. **客观上**：要求该利益本身具有不正当性。

### （二）例题一：“认识错误案”

> **【例题一】**
>
> 某政府应当给甲的企业补偿50万元（这笔钱是确定要给该企业的，不需要竞争）。但甲老板误以为自己的企业不符合补偿条件，带着谋取不正当利益的目的，给主管官员送钱，希望官员给他补偿。官员收钱后把事儿办了。
>
> **问：** 甲老板是否构成行贿罪？
>
> **分析：** 官员收钱构成受贿罪（受贿罪中“为他人谋取利益”既包括正当利益也包括不正当利益）。但甲老板不构成行贿罪——虽然他主观上有谋取不正当利益的目的，但客观上他的利益是正当的（按照规定他应当得到这50万元）。【修正：原文表述“当政府他应当给人家假的企业补偿五十万元”中的“假的企业”应理解为“甲的企业”，为语音识别错误】

### （三）不正当利益的范围：不限于非法利益

不正当利益不限于非法利益，既包括非法利益，也包括**获取不公平的竞争优势**。例如“跑官卖官”——想通过行贿获得职务晋升，就属于谋取不公平的竞争优势，也属于不正当利益。

**注意：** 如果公民请求国家工作人员**依法办事**，则属于谋取正当利益，不构成行贿罪。

> **【例题二】**
>
> 某建筑公司给政府盖了大楼，政府一直拖欠工程款。建筑公司老板给政府领导送钱，希望赶紧结清工程款。领导收钱后把工程款结了。
>
> **问：** 建筑公司老板是否构成行贿罪？
>
> **分析：** 不构成。因为老板谋取的是“要求依法办事”——结清合法的工程款属于正当利益。但官员收钱仍然构成受贿罪。


## 三、行贿罪的行为类型

行贿的行为类型有两种：**主动送钱**和**被动送钱**。

### （一）主动送钱

> **【例题三】**
>
> 老板想申请一个项目，但他知道该项目在环保方面是违规的、不符合条件。为了谋取这个不正当利益，他主动给官员送钱。
>
> **问：** 是否构成行贿罪？既遂标准是什么？
>
> **分析：** 构成行贿罪。**钱送出去，行贿罪就既遂了**。至于事后官员有没有给他办成事、他有没有实际谋取到不正当利益，在所不问。

### （二）被动送钱（因被勒索而给钱）

> **【例题四】**
>
> 老板的项目在环保方面违规。官员主动向老板索贿：“你如果不给我送100万，我绝对不批，这个项目就给你卡死。”老板被迫送钱。送钱后，事儿没办成，项目黄了，老板没有获得实际的不正当利益。
>
> **问：** 老板是否构成行贿罪？
>
> **分析：** 不构成。根据【修正：原文“法条规定这会儿不构成”】《刑法》第389条第三款的规定，**因被勒索而给予国家工作人员财物，没有获得不正当利益的，不构成行贿罪**。也就是说，被动给钱要构成行贿罪，必须**实际获得不正当利益**。


## 四、行贿罪中送钱的时间问题——事前与事后

我们在讲受贿罪的时候讲过“事后受贿”：官员给老板办事时没有私心杂念，公事公办把事儿办完了。事后老板感谢他、送了钱，官员收了钱——官员仍然构成受贿罪。

那么，老板送钱的行为是否构成行贿罪？

**多数说认为：构成行贿罪。** “为谋取不正当利益而送钱”，既包括为谋取**未来**的不正当利益而送钱，也包括为**已经谋取**的不正当利益而送钱。只要达成了权钱交易，送钱方就构成行贿罪。


## 五、行贿罪的既遂标准

行贿罪的既遂标准是：**国家工作人员客观上占有了你送来的财物**，行贿罪即告既遂。

> **【例题五】**
>
> 老板把现金放进一个毛绒玩具（蛋仔）里面，送给局长小芳。小芳不知道里面有现金，收下了玩具。
>
> **问：** 老板是否构成行贿罪？局长是否构成受贿罪？
>
> **分析：** 老板构成行贿罪且既遂——因为官员客观上占有了该财物。但局长不构成受贿罪——因为他不知道里面有现金，没有受贿的故意。


## 六、行贿罪的数额问题——“等号原理”

行贿罪的数额要**等于**受贿罪的数额。这是一个“等号原理”（类似于贪污罪中“贪污数额=国家损失数额”的等号原理）。

> **【例题六】（主观题曾考）**
>
> 局长甲给老板乙办过事。局长甲要装修房子，装修公司报价100万。
>
> 老板乙对局长甲说：“你就给装修公司付40万就行，剩下60万你不用管，我来付。”局长甲答应了。
>
> 老板乙又对装修公司老板丙说：“我给你支付30万，以后我给你介绍一个大工程，剩余那30万你能不能给免掉？”丙答应了。
>
> 最后：局长甲出了40万，老板乙出了30万，装修公司免了30万。局长甲获得了60万的财产利益（100万装修费-自己出的40万）。
>
> **问：** 局长甲的受贿金额是多少？老板乙的行贿金额是多少？
>
> **分析：**
> - 局长甲的受贿金额 = 60万（获得的财产利益）
> - 老板乙的行贿金额 = **也是60万**（与受贿金额画等号）
>
> **注意：** 老板乙实际只支出了30万，但他的行贿数额不是按实际支出算，而是按官员受贿的数额算——这就是等号原理。【修正：原文“老板乙的实际支出只有30万，少出了30万”——实际上乙少出了30万（本应承担60万，实际只付了30万），但行贿数额仍按60万计算】


## 七、行贿罪与受贿罪的关系（认定问题）

行贿罪和受贿罪是**对合犯（对向犯）** 。但**并不意味着一方构成犯罪，另一方必然构成犯罪**——一方构成犯罪时，另一方可能不构成犯罪。

### 情形一：老板不构成行贿罪，官员构成受贿罪

- **被勒索且未获不正当利益**：老板因被勒索给官员财物、未获得不正当利益→老板不构成行贿罪；但官员索要钱财到手→构成受贿罪。
- **谋取正当利益**：老板为谋取正当利益（如催要合法工程款）给官员送钱→老板不构成行贿罪；但官员收钱→构成受贿罪。

### 情形二：老板构成行贿罪，官员不构成受贿罪

- **官员不知情**：老板把钱放到玩具里送给官员，官员不知情收下→老板构成行贿罪；但官员不知道→不构成受贿罪。

**结论：** 行贿罪和受贿罪并不要求同时构成。


## 八、行贿罪的罪数问题

行贿方构成行贿罪，谋取到不正当利益，如果该不正当利益本身也构成一个犯罪，怎么办？

**原则：与行贿罪并罚。**

> **【例题七】**
>
> 公司老板找税务局局长送钱，希望局长少征税款。局长收钱后办了事。
>
> **分析：**
> - 局长构成两个罪：受贿罪 + 徇私舞弊不征少征税款罪 → 两罪并罚
> - 老板构成两个罪：行贿罪 + 逃税罪 → **两罪并罚**【修正：原文表述“也要并罚”】

**例外：如果并罚会出现重复处罚，则不能并罚，只能定一个重罪。**

> **【例题八】**
>
> 狗蛋给户籍警察送3万元，让警察给自己办一个假户口。警察收钱后办了。
>
> **问：** 狗蛋除了行贿罪，是否还构成买卖国家机关证件罪？
>
> **分析：** 不需要再定买卖国家机关证件罪。因为送3万元给警察就相当于“买”了一个假户口，如果再定买卖国家机关证件罪，就属于**重复处罚**。此时只定一个行贿罪即可。【修正：原文“送三万给这个警察，就相当于是买了一个假户口”】

> **【注释】** 《最高人民法院、最高人民检察院关于办理行贿刑事案件具体应用法律若干问题的解释》第6条规定：“行贿人谋取不正当利益的行为构成犯罪的，应当与行贿犯罪实行数罪并罚。”讲稿中提到的“如果并罚会出现重复处罚则不能并罚”是司法实践中的例外处理规则。


## 九、过渡：从两方关系到三方关系——斡旋受贿的引入

贿赂犯罪中，除了行贿方（老板）和受贿方（官员）两者之间的情况，还有**中间人**介入的三角关系——这就是**斡旋受贿**。


## 十、斡旋受贿概述

### （一）定义与基本模型

斡旋受贿，就是有一个**中间人（斡旋者）** 介入的受贿形态。【注释】《刑法》第388条规定：“国家工作人员利用本人职权或者地位形成的便利条件，通过其他国家工作人员职务上的行为，为请托人谋取不正当利益，索取请托人财物或者收受请托人财物的，以受贿论处。”

> **【例题九】**
>
> 企业老板想找税务局局长少收税款，但他不认识税务局局长。他认识财政局长，就给财政局长送钱，让财政局长去找税务局局长说情办事。
>
> **分析：** 财政局长是中间人，他收这笔钱就属于**斡旋受贿**（以受贿罪论处）。

### （二）斡旋受贿的特点

- 中间人（斡旋者）必须是**国家工作人员**
- 谋取的必须是**不正当利益**
- **成立条件**：许诺为请托人实施斡旋行为（许诺为他谋取不正当利益），基于此索要或收受钱财
- **既遂标准**：收到钱即既遂。至于中间人是否实际实施了斡旋行为、是否找了终端办事人、终端办事人是否把事办成——**在所不问**


## 十一、斡旋受贿的共犯问题——三大模型

**共同前提事实：**

> 甲（请托人/行贿人）为了让税务局局长丙（终端办事人）为自己非法减免税款，找到本县财政局长乙（中间人），给乙100万，说：“这笔钱你看着办，只要把事儿办成就行。”乙答应办事，收了这100万。

### 模型一：乙给丙送钱（乙转交60万给丙）

> **【模型一】**
>
> 乙收了甲100万后，给丙送了60万。丙收了钱，许诺办事。

**分析：**

1. **丙**：构成普通受贿罪，既遂数额60万。

2. **乙（对丙送钱的行为）** ：
   - 构成丙的受贿罪的**共犯**
   - 构成**行贿罪**（与甲构成行贿罪的共同正犯）
   - 一个行为触犯两罪 → **想象竞合**，择一重罪论处

3. **乙（收甲钱的行为）** ：
   - 构成**斡旋受贿型受贿罪**
   - 既遂数额 = **40万**（100万-60万）
   - 【修正】理由：乙收下100万时，钱的去向还是待定状态。当乙给丙60万，表明乙只想收甲40万。

4. **乙的罪数**：收钱行为（斡旋受贿）与送钱行为（行贿+共犯）是**原因与结果的牵连犯** → 择一重罪论处

5. **甲**：
   - 甲送钱时对钱的去向没有明确指示（“你看着办”），说明甲有**概括故意**——既有给乙行贿的故意，也有给丙行贿的故意
   - 甲对乙构成行贿罪：数额 = **40万**（等号原理：行贿数额=乙的受贿数额40万）
   - 甲对丙构成行贿罪（与乙共同正犯）：数额 = **60万**（等号原理：行贿数额=丙的受贿数额60万）
   - 甲有两个行贿行为 → 构成**连续犯**，定一个行贿罪，数额**累计** = 40万+60万 = **100万**【修正：原文“也可以两罪并罚，问题也不大”】

**【修正说明】** 讲稿在此处特别做了更正：原教材（第401页）认为甲是一个送钱行为构成两个行贿罪、想象竞合。**现更正为**：甲其实有两个行贿行为（甲自己送钱给乙是一个行贿行为；乙代表甲送钱给丙是另一个行贿行为，要算到甲头上），所以是两个行贿罪，按连续犯处理，数额累计。


### 模型二：乙告知丙自己收了钱，丙没收钱但办事

> **【模型二】**
>
> 乙收了甲100万后，去找丙时说：“丙局，我收了甲100万，托我来找你办事。我家里缺钱，你看你能不能别收这个钱，让我都收下来，但事儿你能不能给办了？”丙说行，没问题。丙没收钱，但把事儿办了。

**分析：**

1. **丙**：构成受贿罪，既遂数额**100万**。
   - **原理：** 受贿罪的“收钱”，既包括为自己收钱，也包括**为第三人收钱**。
   - 类比：官员让行贿人把钱送给自己的情妇，情妇收了，官员知道后仍办事——官员构成受贿罪既遂，要对情妇收的钱负责。
   - 本案中，丙知道乙收了甲100万，仍愿意办事 → 丙要对乙收的100万负责 → 构成受贿罪既遂100万

2. **乙（针对丙）** ：
   - 构成丙的受贿罪的**共犯**（数额100万）
   - **不构成行贿罪**（乙没有给丙送钱的意图）

3. **乙（收甲钱的行为）** ：
   - 构成**斡旋受贿型受贿罪**，数额**100万**

4. **乙的罪数**：收甲钱的行为触犯了两个罪（斡旋受贿罪 + 丙受贿罪的共犯）→ **想象竞合**，择一重罪论处

5. **甲**：
   - 甲对丙构成行贿罪：数额**100万**
   - 甲对乙构成行贿罪：数额**100万**
   - 两个行贿罪 → **想象竞合**，择一重罪论处
   - 【注意】甲只送出去一份100万，现在说甲对丙既遂100万、对乙既遂100万——这是**重复评价**，但不是**重复处罚**（因为择一重罪论处）。原则是**禁止重复处罚**，不是禁止重复评价。


### 模型三：乙隐瞒收钱事实，丙猜出来但仍办事【2023年主观题考点】

> **【模型三】（2023年主观题真题模型）**
>
> 乙收了甲100万后，去找丙办事时隐瞒了自己收钱的事实，说：“甲是我表弟，挺困难的，你看能不能支持一下？”丙是“老江湖”，猜出来乙收了甲100万，但碍于面子，仍然把事儿办成了。

**分析：**

1. **丙**：构成受贿罪（不管他是**明知**还是**猜出来**，只要知道乙收了钱还办事，就要对乙收的100万负责）→ 既遂数额100万

2. **乙（针对丙）** ：
   - **不构成**丙受贿罪的共犯（乙隐瞒了，没有帮丙受贿的故意）
   - **不构成**行贿罪（乙没有给丙送钱的意图）

3. **乙（收甲钱的行为）** ：
   - 构成**斡旋受贿型受贿罪**，数额**100万**

4. **甲**：
   - 甲对丙构成行贿罪：100万
   - 甲对乙构成行贿罪：100万
   - 两个行贿罪 → **想象竞合**，择一重罪论处


## 十二、斡旋受贿与普通受贿的区分

> **【注释】** 斡旋受贿与普通受贿的核心区别在于：斡旋受贿中，行为人与被利用的国家工作人员之间**没有职务上的隶属、制约关系**；如果有隶属、制约关系，则属于普通受贿。

**区分标准：**

| 情形 | 中间人身份 | 与终端办事人的关系 | 构成何种受贿 |
|------|-----------|-------------------|-------------|
| 老板找**财政局长**→找**税务局长** | 同级 | 无隶属制约关系 | **斡旋受贿** |
| 老板找**县长**→找**税务局长** | 上级 | 有隶属制约关系（指示） | **普通受贿** |
| 老板找**税务局科长**→找**税务局长** | 下级 | 无隶属制约关系（说情） | **斡旋受贿** |

**总结口诀：**
- **上级找下级** → 普通受贿
- **同级找同级** → 斡旋受贿
- **下级找上级** → 斡旋受贿
