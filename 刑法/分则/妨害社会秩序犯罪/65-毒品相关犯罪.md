# 第1部分：法考备考提纲

> **使用说明**：以下提纲基于上述讲稿内容整理，对照《刑法》相关条文，面向非法学背景的法考备考者。**加粗**为重点内容。

## 一、走私、贩卖、运输、制造毒品罪（《刑法》第347条）

### （一）走私毒品罪

| 知识点 | 内容 |
|--------|------|
| **既遂标准-陆运** | 越过国（边）境线 |
| **既遂标准-空运** | **飞机降落机场**（非进入领空，非过海关） |
| **既遂标准-海运** | **抵达港口**（非进入领海，非过海关） |

### （二）贩卖毒品罪

| 知识点 | 内容 |
|--------|------|
| **贩卖=有偿转让** | 无偿转让不构成 |
| **不要求牟利目的** | 跳楼价卖也构成 |
| **贩卖方式** | 钱物交易、物物交换均可 |
| **不同毒品交换** | 贩毒者→贩卖毒品罪；吸毒者自吸交换→不定贩卖（但可定非法持有） |
| **代购-为贩毒者代购** | **贩卖毒品罪的帮助犯** |
| **代购-为吸毒者代购（收钱）** | 看**牟利目的**：有则贩卖毒品罪 |
| **代购-为吸毒者代购（收货）** | 看**贩卖目的**：有则贩卖毒品罪 |
| **既遂标准** | **货交付即既遂**，不要求收到货款 |
| **居间介绍** | 为贩毒者介绍货源/买家→帮助犯；为吸毒者介绍→一般不构成贩卖毒品罪帮助犯 |

### （三）运输毒品罪

| 知识点 | 内容 |
|--------|------|
| **与非法持有毒品的区分** | **较长距离位移**即运输毒品罪（新标准），不再要求贩卖目的 |
| **着手** | 开始搬运毒品 |
| **既遂** | 离开原存放地发生较长距离位移 |
| **分段运输** | 各段负责人**不构成**共同犯罪 |
| **同行运输（无配合）** | **不构成**共同犯罪 |
| **同行运输（有配合）** | **构成**共同犯罪 |
| **集中派活** | 各自负责各自任务，**不构成**共同犯罪 |

### （四）制造毒品罪

| 知识点 | 内容 |
|--------|------|
| **制造方式** | 提炼、精制、变种、调制（广义理解） |
| **掺杂掺假** | **不属于**制造毒品 |
| **分装** | **属于**制造毒品环节 |
| **既遂标准** | **制造出来即既遂** |
| **不能犯 vs 未遂犯** | 方法完全错误→**手段不能犯→无罪**（客观主义） |

### （五）主观故意

| 知识点 | 内容 |
|--------|------|
| **认识对象** | 认识到是**毒品**即可，不要求认识具体品种 |
| **名与实** | 认识到**实质功能**（能致瘾）即可，不要求知道名称 |

### （六）麻精药品

| 知识点 | 内容 |
|--------|------|
| **为治病自用** | **不定毒品犯罪** |
| **向贩毒者/吸毒者贩卖** | 贩卖毒品罪 |
| **医疗目的无证经营** | 不定毒品犯罪（可定妨害药品管理罪） |
| **管理人员向吸毒者提供** | 非法提供麻精药品罪 → 与贩卖毒品罪想象竞合 |

### （七）数量

| 知识点 | 内容 |
|--------|------|
| **定罪** | **无论数量多少**都构成犯罪 |
| **同一批货** | 不重复计算 |
| **不同批货/同种毒品** | 数量累加 |
| **不同种毒品** | 折算后累加 |

### （八）特别再犯（《刑法》第356条）

| 知识点 | 内容 |
|--------|------|
| **条件** | 因毒品犯罪被判刑，又犯本节之罪 |
| **后果** | **从重处罚** |

> ⚠️ **主观题考点**：贩卖毒品罪的既遂标准（不要求收到货款）；运输毒品罪与非法持有毒品罪的区分（新司法解释的“位移说”）；代购毒品的定性（收钱看牟利目的/收货看贩卖目的）。


## 二、非法持有毒品罪（《刑法》第348条）

| 知识点 | 内容 |
|--------|------|
| **作用** | **堵截罪名**——查不出其他毒品犯罪时适用 |
| **数量要求** | 鸦片200克以上/海洛因或冰毒10克以上等 |
| **持有** | 自己能够控制的地方即可，不要求随身携带 |
| **吸毒者囤货** | 量大→非法持有毒品罪 |

> ⚠️ **主观题考点**：非法持有毒品罪的“兜底/堵截”功能。


## 三、容留他人吸毒罪（《刑法》第354条）

| 知识点 | 内容 |
|--------|------|
| **容留** | 允许他人在自己管理的场所吸毒 |
| **共有场所** | 室友在共有宿舍吸毒→**不构成**；外人在你宿舍吸毒→**构成** |

> **【注释】** 容留他人卖淫罪的原理与此相同（《刑法》第359条）。

# 第2部分：讲稿整理（分段·修正版）


## 一、毒品犯罪概述

好，那接下来我们就看第七节——**毒品犯罪**。毒品犯罪是我们这一讲相当重要的一节了，它的地位和前面讲的妨害司法类的犯罪几乎是平起平坐的。

这里面最重要的罪名是一个**选择性罪名**，叫**走私、贩卖、运输、制造毒品罪**（《刑法》第347条）。


## 二、走私毒品罪

这个罪可以先拆出一个**走私毒品罪**。什么叫走私？我们都知道。

**【修正】** 音频中“既遂”多次被误识别为“计税”“继随”，以下统一修正为“既遂”。

**（一）既遂标准——分海陆空**

1. **陆运**：越过国（边）境线就算既遂。例如从缅甸走私毒品到中国境内，只要越过国境线，就算既遂。

2. **空运**：飞机**降落机场**算既遂。既不是进入我国领空（太早），也不是出了海关（太晚）。

   > **例题**：狗蛋从非洲坐飞机走私毒品到广州，何时既遂？
   > - A. 飞机进入我国领空
   > - B. 飞机降落白云机场 ✅
   > - C. 降落以后出了海关
   >
   > **答案**：B。

3. **海运**：**抵达港口**算既遂。既不是进入领海（太早），也不是过了港口海关（太晚）。

   > **例题**：狗蛋从菲律宾走私船运毒品到深圳港，何时既遂？
   > - A. 进入我国领海
   > - B. 抵达深圳港码头 ✅
   > - C. 过了港口海关
   >
   > **答案**：B。


## 三、贩卖毒品罪

**（一）贩卖的含义——有偿转让**

贩卖=**有偿转让**。无偿转让叫“白送”/赠与，不构成贩卖毒品罪。

**（二）不要求牟利目的**

有偿转让不要求有牟利目的。跳楼价卖、低于成本价卖，没有牟利目的，依然构成贩卖毒品罪。牟利目的是贩卖的常见心理，但不是**必备要件**。

**（三）贩卖方式**

1. **钱物交易**：一手交钱，一手交货。
2. **物物交换**：用手机、AK47等去换毒品，也算贩卖毒品（还可能构成非法买卖枪支罪，想象竞合）。

**（四）不同种类毒品交换的问题**

> **例题（2024年考过）** ：甲有海洛因，乙有冰毒，双方交换。甲是吸毒者想尝鲜，乙是贩毒者想多一个贩卖品种。如何处理？
>
> **分析**：
> - **乙**：构成贩卖毒品罪（想把冰毒卖出，换来的海洛因也想贩卖）。
> - **甲**：为自吸而购买毒品，**不构成贩卖毒品罪**；但事后一直持有的话，可定**非法持有毒品罪**。
>
> **结论**：为自吸而购买毒品，不定贩卖毒品罪。

**（五）代购毒品问题**

**第一步：看为谁代购**

| 为谁代购 | 结论 |
|---------|------|
| 为**贩毒者**代购 | 构成贩卖毒品罪的**帮助犯** |
| 为**吸毒者**代购 | 往下看第二步 |

**第二步：为吸毒者代购——区分收钱还是收货**

| 情形 | 判断标准 | 结论 |
|------|---------|------|
| **收钱** | 看有无**牟利目的** | 有牟利目的=职业代购→贩卖毒品罪；无牟利目的=友情代购→不构成 |
| **收货**（分点货） | 看有无**贩卖目的** | 有贩卖目的（囤货日后卖）→贩卖毒品罪；自用→不构成 |

> **口诀：收钱看牟利目的，收货看贩卖目的。**

**（六）贩卖毒品罪的既遂标准**

**只要求把货交付给对方**，不要求收到货款。哪怕对方给的是砖块、是假钞，只要货已交付，就既遂。

> **例题（电影场景）** ：毒贩交货后打开箱子发现是砖块，对方机枪扫射，毒贩货也没了、命也没了。贩卖毒品罪既遂了吗？
>
> **答案**：**既遂**。只要求卖掉/交付货物，不要求收到货款。

**（七）共犯问题——居间介绍**

| 情形 | 结论 |
|------|------|
| 贩毒者甲委托乙介绍**货源** | 乙构成贩卖毒品罪的**帮助犯** |
| 贩毒者甲委托乙介绍**买家** | 乙构成贩卖毒品罪的**帮助犯** |
| 吸毒者甲委托乙介绍**卖家**（自吸） | 甲不构成贩卖毒品罪→乙也不构成贩卖毒品罪的帮助犯；但若甲持有毒品数量大构成非法持有毒品罪，乙可构成该罪的帮助犯 |
| 甲在贩毒者和吸毒者之间居间介绍促成交易 | 甲构成贩毒者一方的贩卖毒品罪帮助犯 + 可能构成非法持有毒品罪的帮助犯 → **想象竞合** |

**（八）居间倒卖与帮助交付**

| 情形 | 结论 |
|------|------|
| 贩毒者→甲→吸毒者（甲倒卖） | 甲是贩卖毒品罪的**实行犯** |
| 贩毒者让甲去**交付**毒品给吸毒者 | 甲是贩卖毒品罪的**帮助犯**（跑腿） |


## 四、运输毒品罪

**（一）与非法持有毒品罪的区分——新司法解释标准**

以前的理论标准：运输毒品罪要有**贩卖目的**，没有贩卖目的则定非法持有毒品罪。

**但实务中出了问题**：毒贩被抓后声称“为了自吸，没有贩卖目的”，当场吸食，导致无法定运输毒品罪（轻罪变重罪）。

**新司法解释的标准**：**只要让毒品发生较长距离的位移**，就构成运输毒品罪，不再考虑是否有贩卖目的。

> **注意**：从一楼搬到三楼不算“较长距离”。一般认为超过一公里左右可认定（具体标准为经验判断，考试不会考精确数字）。

**（二）运输毒品罪的着手与既遂**

- **着手**：为了运输而开始搬运（如把毒品往车上搬）。
- **既遂**：毒品**离开原存放地**发生较长距离的位移。

> **例题**：从上海运毒品到杭州，途中在嘉兴被查——既遂（远超一公里）。
>
> **例题**：运到杭州没找到接头人，又运回上海——**仍然是既遂**（又发生了一次较长距离位移）。

**（三）共犯问题**

| 类型 | 含义 | 是否构成共同犯罪 |
|------|------|----------------|
| **分段运输** | 甲运第一段（上海→苏州），乙运第二段（苏州→南京） | **不构成**，各自只对自己那一段负责 |
| **同行运输**（无配合） | 甲乙各自开车、一前一后、无配合 | **不构成**，各自独立 |
| **同行运输**（有配合） | 开同一辆车、互相掩护 | **构成**共同犯罪 |
| **集中派活** | 老大派甲去苏州、乙去杭州、丙去南京 | **不构成**，各自负责各自任务 |


## 五、制造毒品罪

**（一）制造方法的广义理解**

1. **提炼**：从原材料中提炼（如从罂粟花中提炼鸦片）。
2. **精制**：提高纯度。
3. **变种**：用化学方法将一种毒品变成另一种。
4. **调制**：针对特定人调制毒品。

**不属于制造毒品的情形**：
- 为了隐秘运输、欺骗购买者或增重，在毒品中**掺杂掺假**（加入非毒品物质）——**不属于制造毒品**。
- **分装毒品**（将大批毒品分装小袋）——**属于**制造毒品的一个环节。

**（二）既遂标准**

**制造出来就算既遂**，没制造出来就是未遂。

**（三）未遂犯与不能犯的区分（重要考点）**

> **例题**：狗蛋让富婆小芳投资100万“制造新型毒品”，花一年时间造出半吨，结果一点毒品成分都没有——方法是完全错误的（初中化学都没学好）。
>
> **分析**：这是**手段不能犯**，应做**无罪处理**（客观主义立场）。若按主观主义会定未遂犯，按半吨量刑可判死刑，显然不合理。

> **【注释】** 讲授者在此处引入了**主观主义 vs 客观主义**的刑法理论之争。这是刑法总则层面的理论问题，超出了毒品犯罪的具体范畴。简单说：主观主义看重行为人的犯罪意图，客观主义看重行为的客观危害。法考通常采取客观主义立场。


## 六、主观故意问题——对毒品的认识

毒品犯罪是**故意犯罪**，要求主观上认识到是毒品。

**（一）不要求认识到具体品种**

> **例题**：狗蛋以为贩卖的是海洛因，实际上是鸦片——**构成贩卖毒品罪**。只要求认识到是毒品，不要求认识到具体品种（鸦片/海洛因都是下位概念）。

**（二）认识到实质功能即可**

> **例题（2022年考过）** ：狗蛋出售含大麻素的电子烟，知道能让人精神成瘾，但不知道这叫“毒品”——**构成贩卖毒品罪**。只要求认识到毒品的**实质功能/特性**（能让人精神成瘾），不要求知道具体名称。

> **口诀：认识到“实”即可，不要求认识到“名”。**


## 七、麻醉药品和精神药品（麻精药品）问题

麻精药品具有**药品和毒品的双重属性**。

**（一）为治病而购买麻精药品——不定毒品犯罪**

> **案例**：大学生患抑郁症，因疫情封控无法外出买药，从境外网站购买管制类精神药品自用，未报关被查获，按数量可判死刑。
>
> **处理**：**无罪**（走私毒品罪不构成）。因为毒品犯罪的保护法益是**国民健康**，为自用治病没有将毒品扩散到社会，没有侵犯国民健康。
>
> **【注释】** 讲授者在此处强调了**法益解释论**的方法——不能机械适用法条，要深入理解法条保护的法益。这是刑法解释学的重要方法。

**（二）相关司法解释规定**

1. 明知对方是贩毒分子或吸毒者，向其贩卖麻精药品 → **贩卖毒品罪**。
2. 出于医疗目的，未取得药品证件而生产/进口/销售麻精药品 → **不定毒品犯罪**（可定妨害药品管理罪）。
3. **为给自己治病**而携带/邮寄麻精药品进出境 → **不定毒品犯罪**。
4. 依法管理麻精药品的人员：
   - 出于医疗目的非法贩卖 → **不定毒品犯罪**（多数说可定非法经营罪）
   - 向吸毒者**无偿提供** → **非法提供麻醉药品精神药品罪**
   - 向吸毒者**有偿提供** → 非法提供麻精药品罪 **+** 贩卖毒品罪 → **想象竞合，择一重罪**（一般定贩卖毒品罪）
   - 明知对方是贩毒分子而提供 → 贩卖毒品罪的**帮助犯**


## 八、数量问题

**（一）定罪不要求数量**

走私、贩卖、运输、制造毒品罪，**无论数量多少**，都构成犯罪。

> **注意**：非法持有毒品罪**有数量要求**（轻罪，需达到一定数量才构成犯罪）。

**（二）数量计算规则**

| 情形 | 计算规则 |
|------|---------|
| 同一批货、同一种毒品 | **不重复计算**，定一个选择性罪名 |
| 不同批货、同一种毒品 | **数量累加** |
| 不同种毒品 | **折算成统一单位**（如以海洛因为标准）后累加 |

> **【注释】** 具体折算标准可参考《最高人民法院关于审理毒品犯罪案件适用法律若干问题的解释》。


## 九、特别再犯制度（《刑法》第356条）

因犯走私、贩卖、运输、制造、非法持有毒品罪被判过刑，又犯本节规定之罪的，**从重处罚**。

与累犯相似但有区别，了解即可。


## 十、非法持有毒品罪

**（一）兜底作用**

查不出来是为了贩卖、运输、走私，但持有的量达到较大标准 → 定非法持有毒品罪。

能查出来是贩卖/运输/走私 → 优先定那些罪。非法持有毒品罪起**堵截**作用。

**（二）“持有”的认定**

不要求随身携带、装在口袋、拿在手里，只要保存在**自己能够控制的地方**就算持有。

> **例题（2025年考过）** ：甲有5克海洛因，乙有5克海洛因让甲保管，甲家里共10克→甲构成非法持有毒品罪的**实行犯**；乙构成该罪的**共犯**（贡献了5克，5+5=10达到标准）。

**（三）吸毒者囤货**

为自吸而购买毒品，购买行为本身不构成犯罪，但**囤货量大** → 非法持有毒品罪。


## 十一、容留他人吸毒罪（《刑法》第354条）

**（一）“容留”的含义**

允许他人在自己管理的场所吸毒或卖淫。

**（二）共有场所的问题（重要考点）**

| 情形 | 是否构成容留他人吸毒罪 |
|------|---------------------|
| 室友在自己**共有的宿舍**吸毒，你允许 | **不构成**（对方也是场所主人） |
| **隔壁同学**到你宿舍吸毒，你允许 | **构成**（你是场所主人，对方是外人） |

> **【注释】** 讲授者在此处同时提及了**容留他人卖淫罪**，以说明“容留”和“共有场所”的原理是相通的。容留他人卖淫罪规定于《刑法》第359条，超出毒品犯罪范畴，但原理可类比理解。

## 十三、真题演练（2017年卷）

> **题目**：关于毒品犯罪，哪些选项是正确的？
>
> **A项**：甲容留未成年人吸食、注射毒品，构成容留他人吸毒罪。
>
> **→ 正确**。容留未成年人或成年人都能构成该罪。
>
> **B项**：以随身携带藏有毒品的行李入关，被现场查获，构成走私毒品罪的既遂。
>
> **→ 正确**。入关意味着（空运）飞机已降落或（海运）船已靠码头或（陆运）已越境，已既遂。
>
> **C项**：丙乘广州到北京的火车运输毒品，到武汉时被查获，构成既遂。
>
> **→ 正确**。已发生较长距离位移。
>
> **D项**：丁以牟利为目的容留刘某吸食毒品，并向他出卖毒品，构成容留他人吸毒罪和贩卖毒品罪，应当数罪并罚。
>
> **→ 正确**。两个罪性质不同，应当并罚。
