# 讲稿整理：侵犯人身自由的犯罪（第一部分——非法拘禁罪）

## 1：法考备考提纲（非法条科班人士适用）

### 一、基础信息

| 项目 | 内容 |
|---|---|
| **罪名** | 非法拘禁罪 |
| **刑法条文** | 《刑法》第238条 |
| **保护法益** | 他人人身自由 |
| **行为本质** | 非法剥夺他人人身自由（不是“限制”） |
| **基本刑** | 三年以下有期徒刑、拘役、管制或者剥夺政治权利 |

### 二、构成要件（认定犯罪的四个角度）

#### 1. 行为对象：他人（有自由意志的自然人）

#### 2. 行为方式：非法剥夺人身自由

- “剥夺”≠“限制”，程度更重
- 范围判断标准：参照**监狱大小**（大约一个校园范围）
- 如果只是限制不能出区/市/国 → 属于“软禁”，不构成拘禁罪（但可能涉及其他）

#### 3. 主观要件：故意（明知自己剥夺他人自由而为之）

#### 4. 时间要求（司法实践）：一般要求**持续24小时以上**才值得定罪处罚（讲稿中提到）

### 三、欺骗手段与拘禁的认定

| 情形 | 是否构成拘禁 | 理由 |
|---|---|---|
| 骗入电梯 + 断电，被害人客观上出不去，主观上也认为出不去 | ✅ 构成 | 客观剥夺 + 主观认识 |
| 骗入房间 + 门没锁，被害人知道能出去，但自己选择不走 | ❌ 不构成 | 客观未剥夺，主观未认识 |

### 四、结果加重犯（第238条第2款第一句）

> **公式：非法拘禁罪 + 过失致人重伤/死亡 = 结果加重犯（加重处罚）**

#### 必须同时满足三个条件：

| 条件 | 含义 | 考试重点 |
|---|---|---|
| **①因果关系** | 重伤/死亡必须是拘禁行为导致的 | 有介入因素（如自杀）时，要判断因果关系是否中断 |
| **②主观为过失** | 对重伤/死亡结果只能是**过失** | 如果是故意→不适用结果加重犯 |
| **③拘禁行为本身** | 暴力行为必须带着**拘禁的目的** | 如果带其他目的→不适用第一句 |

### 五、“使用暴力致人伤残死亡”条款（第238条第2款第二句）

#### 观点展示：

- **少数说**：“致人伤残死亡”指**故意** → 本条是注意规定（废话条款）
- **多数说（法考采此说）** ：“致人伤残死亡”指**过失** → 本条是**法律拟制**（特事特办），即使用拘禁外的暴力过失致人伤残死亡，按故意伤害/杀人罪处理

#### 第一句 vs 第二句 区分表：

| 比较项 | 第一句（结果加重犯） | 第二句（法律拟制） |
|---|---|---|
| 暴力性质 | 拘禁行为的暴力 | 拘禁**以外**的暴力 |
| 暴力目的 | 带着**拘禁**目的 | 带着**拘禁之外**目的（泄愤、教训等） |
| 对结果心态 | 过失 | 过失 |
| 最终罪名 | 非法拘禁罪（加重处罚） | 故意伤害罪 / 故意杀人罪 |

### 六、四个行为模型（考试核心）

> **【记忆口诀】** 一行为看心态（过失加重犯，故意想象竞合）；两行为看关系（拘禁内暴力定故意杀/伤，拘禁外独立行为则并罚）。

#### 模型一：拘禁行为本身过失致死
- 如：绳子捆太紧勒死
- 定：非法拘禁罪过失致人死亡（结果加重犯） ✅

#### 模型二：拘禁行为本身故意致重伤
- 如：为拘禁故意掰断胳膊
- 定：非法拘禁罪 + 故意伤害罪 → **想象竞合择一重**（一般定故意伤害罪重伤） ❌不能定结果加重犯

#### 模型三：拘禁后，拘禁外暴力过失致死（法律拟制）
- 如：拘禁后扇耳光泄愤，过失扇死
- 定：**故意杀人罪**（只定此罪，不再并罚非法拘禁罪） ⚠️ **不并罚**

> 🔴 **【主观题考点·重要】** 模型三——为什么不定非法拘禁罪过失致人死亡？为什么不同时并罚非法拘禁罪？考试可能考分析论证，核心是：这是法律拟制，且并罚会违反禁止重复评价原则。

#### 模型四：拘禁后，另起犯意故意杀人
- 如：拘禁后心生杀意，故意杀死
- 定：**非法拘禁罪 + 故意杀人罪 → 两罪并罚**（多数说） ✅ 要并罚

### 七、常见错误提醒

| 错误认识 | 正确理解 |
|---|---|
| “只要骗了人就是拘禁” | 要客观上剥夺 + 被害人认识到出不去 |
| “致人死亡=结果加重犯” | 要查明：①因果关系 ②主观过失 ③是否拘禁行为本身 |
| “第二句和第一句差不多” | 第二句是法律拟制（过失→故意犯罪），定罪完全不同 |
| “三号模型也要并罚” | ❌ 不并罚，只定故意杀人罪（否则重复评价） |

### 八、名词解释（非科班专用）

| 术语 | 简单解释 |
|---|---|
| **结果加重犯** | 犯了A罪，结果导致了更严重的后果（重伤/死亡），法律要加重惩罚。前提是对严重后果不是故意的，而是过失。 |
| **法律拟制** | 法律“特事特办”——本来按道理应该定A罪，但法律规定按B罪处理。不是常识，是立法者特别规定的。 |
| **注意规定** | 法律“提醒一下”——即使没这个规定，本来也应该这么办。删掉也不影响。 |
| **想象竞合** | 一个行为同时触犯了两个罪名，只按判罚更重的那个罪来处理。 |
| **并罚** | 两个不同的行为犯了两个不同的罪，两个罪都要处罚，合并执行。 |
| **禁止重复评价/重复处罚** | 同一个犯罪事实不能被用来定罪两次，也不能被处罚两次。 |

## 3：切分段落（逻辑分层整理）

### 第一部分：本节概述与罪名体系

好，那接下来我们就看第三节：侵犯人身自由的犯罪。这一节其实是我们人身犯罪里面最重要的一节，这一节一共有五个罪名，还都挺重要。如果按重要顺序排的话：①绑架罪，②非法拘禁罪，③拐卖妇女儿童罪，④拐骗儿童罪，⑤收买被拐卖的妇女儿童罪。大致能分为两组：一组是绑架罪和非法拘禁罪；第二组是拐卖类的那三个罪。

我们先看第一个——非法拘禁罪，因为它是一个打底的罪名、基础罪名。


### 第二部分：非法拘禁罪——什么叫“拘禁”（剥夺 vs 限制）

非法拘禁罪，你首先得知道什么叫拘禁。基本定义是：**非法剥夺他人人身自由**。注意，这里用的是“剥夺”。有的时候说“限制”——限制人身自由还达不到拘禁罪的程度，拘禁叫“剥夺”，这里面是一个程度的问题。

大家想一想：

- 狗蛋把你绑在柱子上动不了 → 肯定算拘禁（剥夺）；
- 把你关在一个房间 → 依然是剥夺自由，依然是拘禁；
- 把你关在一个大楼里，不让你出这个大楼 → 依然是拘禁；
- 把你关在一个校园里，不让你出这个校园 → 算不算拘禁？这时候就有问题了；
- 能出校园但不能出海淀区 / 能出海淀区但不能出北京市 → 这能不能算拘禁？
- 如果这也算，不让你出国算不算？把你拘禁在中华人民共和国境内？再推下去，把你拘禁在地球上？

【讲授者分析】拘禁要求“剥夺”，这个范围以什么为准？大致来说，**以你的校园为准**——如果不让你出一个大学校园，我们认为那就是拘禁；如果不让你出海淀区，那不叫拘禁，叫**软禁**（限制自由）。为什么大致以校园为准？其实就是**以监狱为准**。有的监狱跟校园一样大，把你关在监狱里就是合法剥夺自由。所以我们就以监狱的范围大小来大致衡量。

> **【结论】** 拘禁=剥夺自由（范围参考监狱/校园大小）；软禁=限制自由（如限制出海淀区）。


### 第三部分：欺骗手段与拘禁的认定（两个对比案例）

#### 【例题1——构成非法拘禁】

狗蛋追求小芳，想创造单独相处的机会，就把小芳骗到电梯里，然后让小弟把电梯电闸关了。电梯停了打不开。小芳问怎么回事，狗蛋骗她说电梯出故障了，在检修，可能得两个小时，耐心等候，“幸好有我在你身边陪着你”。结果一直骗，在电梯里待了一个晚上。

**问：** 狗蛋这种欺骗算不算非法拘禁？

> ⚠️ **【讲授者注释】** 非法拘禁罪的时间要求一般是**二十四小时**才值得定罪处罚。此处先不考虑时间问题。

**答：算。** 因为虽然骗了小芳，但客观上你断了电闸，人家出不去；主观上小芳也认识到自己出不去了。只要认识到这些，就构成非法拘禁。

#### 【例题2——不构成非法拘禁】

狗蛋追求小芳，发现小芳喜欢“洋洋”。狗蛋把小芳骗到一个房间，说：“洋洋的弟弟已经把洋洋约到这个房间了，他过一会儿就来，你必须在这儿等，死等，可不能走，一走就错过了。”但是——**门没锁**，小芳看到了自己可以自由进出，但为了等洋洋，一直不敢出门，怕错过，一直在等。

**问：** 狗蛋算不算非法拘禁？

**答：不算。** 区别在于：客观上狗蛋没有把小芳拘禁起来，门是打开的，可以自由进出；小芳主观上也认识到可以自由进出。所以不算非法拘禁。

> **【核心规则】** 非法拘禁的认定，要求**客观上剥夺自由** + **被害人主观上认识到无法自由离开**。如果门没锁、被害人知道自己能走，即使因其他原因没走，也不构成拘禁。


### 第四部分：非法拘禁罪的结果加重犯（第238条第2款第一句）

接下来看《刑法》第238条。第一款讲非法剥夺他人人身自由。第二款第一句：“犯前款罪，致人重伤的，……致人死亡的，……”——这就是**非法拘禁罪致人重伤、非法拘禁罪致人死亡**，即**结果加重犯**。

考试喜欢考总论里结果加重犯的原理，主要有三个点：

#### 考点一：因果关系的辨认（因的辨认 + 因果关系辨认）

##### 【例题3——构成结果加重犯】

狗蛋追求小芳，小芳不答应。狗蛋把小芳绑在柱子上，门一关：“明天早上我来问话。”第二天一看，小芳死了。死因：**绳子勒得太紧，导致死亡**。

**问：** 狗蛋构不构成非法拘禁罪过失致人死亡（结果加重犯）？

**答：构成。** 导致死亡的原因是绳子勒太紧，而绳子勒就是非法拘禁罪的实行行为（为了拘禁）；对死亡结果是过失。所以构成非法拘禁罪过失致人死亡，结果加重犯。

##### 【例题4——介入因素切断因果关系（不构成结果加重犯）】

狗蛋把小芳绑在柱子上拘禁起来，“明天我来问话”。第二天一看，小芳死了。死因：**小芳咬绳自尽**（誓死不答应做女朋友）。

**问：** 狗蛋构不构成非法拘禁罪致人死亡？

**答：不构成。** 死亡结果与拘禁行为之间**没有因果关系**。因为介入了被害人自身行为（自杀），而自杀属于**异常的介入因素**；且咬绳自尽对死亡作用更大，所以死亡结果是自杀导致的，因果关系被切断。狗蛋不构成结果加重犯。

> **【规则】** 介入因素两步走判断标准：①介入因素是否异常？②哪个因素对结果作用更大？

#### 考点二：主观要件——对加重结果只能是过失

结果加重犯的完整表述是：**非法拘禁罪 过失 致人重伤/死亡**。对加重结果，**只能是过失**。

##### 【例题5——过失致重伤 → 结果加重犯】

狗蛋强行把小芳往车里拉（人家不愿意），小芳激烈反抗，狗蛋一直拉小芳胳膊，结果突然把胳膊拉断了（重伤）。狗蛋对重伤是**过失**。

**问：** 怎么定？

**答：** 可以定**非法拘禁罪过失致人重伤**（结果加重犯），加重处罚。因为拉胳膊往车里拉就是拘禁行为，拘禁行为又过失导致人重伤。

##### 【例题6——故意致重伤 → 想象竞合，不是结果加重犯】

狗蛋强行把小芳往车里推，小芳激烈反抗，狗蛋怒了，直接把小芳胳膊**咔嚓掰折了**，然后扔到小芳怀里：“上车吧。”小芳不敢反抗，抱着胳膊进车里被拘禁了。狗蛋对重伤是**故意**。

**问：** 怎么定？能不能定非法拘禁罪致人重伤（结果加重犯）？

**答：** ①构成**故意伤害罪（重伤）**；②也构成**非法拘禁罪**（掰胳膊带着拘禁目的）。一个行为触犯两个罪 → **想象竞合，择一重罪**（故意伤害罪重伤更重）。❌ **不能定结果加重犯**，因为结果加重犯要求对加重结果是**过失**，这里是故意。

> **【核心规则】**
> - 对重伤/死亡结果是**过失** → 非法拘禁罪结果加重犯（第238条第2款第一句）
> - 对重伤/死亡结果是**故意** → 非法拘禁罪 + 故意伤害/杀人罪，想象竞合


### 第五部分：第238条第2款第二句——“使用暴力致人伤残死亡”的理解（观点展示）

接下来看条文**第二款的第二句**：“使用暴力致人伤残、死亡的，依照故意伤害罪、故意杀人罪定罪处罚。”

这里存在**观点展示（争议）**：

#### 第一种观点（少数说）——“致人伤残死亡”指故意

认为这里的“致人伤残死亡”指的是**故意**致人伤残死亡。因为结论是定故意伤害罪、故意杀人罪，那前提当然只能是故意。按照这种观点，这个条文就是个**注意规定**（正常办事，删掉也没关系），没什么特别之处。

#### 第二种观点（多数说）——“致人伤残死亡”指过失

认为这里的“致人伤残死亡”指的是**过失**。理由有二：

1. 如果是故意致人伤残死亡→定故意伤害/杀人，这就是句“正确的废话”，立法者没必要提醒法官，法官又不是小学生；
2. 立法者用语习惯——故意弄死/弄伤直接叫“故意杀人罪”“故意伤害罪”；**叫“致人”什么什么的，指的都是过失**（如过失致人死亡罪、过失致人重伤罪）。

> **【结论·多数说】** 这里的“致人伤残死亡”指**过失**。因此，本条属于**法律拟制（特事特办）**——使用暴力**过失**致人伤残死亡的，竟然按**故意犯罪**来处理。

#### 区分第一句与第二句的标准

两种都是过失致人重伤/死亡，什么时候定第一句（非法拘禁罪结果加重犯），什么时候定第二句（故意伤害/杀人罪）？

**区分标准在于：**

| | 第一句 | 第二句 |
|---|---|---|
| 条文用语 | “犯前款罪” | “使用暴力” |
| 暴力性质 | **拘禁行为本身**的暴力 | **拘禁以外**的暴力 |
| 判断标准 | 带着**拘禁的目的** | 带着**拘禁之外的目的**（如泄愤、教训） |
| 定性 | 非法拘禁罪结果加重犯 | 故意伤害罪/故意杀人罪（法律拟制） |

> **【原理】** 行为与目的同时存在原则。暴力行为到底是哪个罪的实行行为，看带着什么目的。

#### 【例题7——第一句的适用（拘禁本身的暴力）】

狗蛋把小芳绑在柱子上（绳子勒），第二天发现绳子勒太紧勒死了。狗蛋对死亡是过失。

**分析：** 绳子勒的暴力目的是**为了拘禁** → 拘禁罪的实行行为 → 过失致死 → 定第一句：**非法拘禁罪过失致人死亡**（结果加重犯）。

#### 【例题8——第二句的适用（拘禁以外的暴力）】

狗蛋把小芳拘禁了一天一夜。第二天去问话，刚凑到跟前，小芳朝他连珠炮一样吐痰。狗蛋气坏了，想**扇耳光教训一下**，结果扇到太阳穴，一耳光把小芳扇死了。狗蛋对死亡是过失。

**分析：** 扇耳光的暴力目的是**教训（拘禁以外的目的）**，不是拘禁 → 拘禁以外的暴力 → 过失致死 → 定第二句：**故意杀人罪**（法律拟制）。不能定非法拘禁罪过失致人死亡。

> ⚠️ **【注意】** 此处“定故意杀人罪”是**法律拟制**的结果，不是正常的故意杀人罪。


### 第六部分：四个行为模型总结

| 模型 | 案情 | 行为数量 | 定性 | 备注 |
|---|---|---|---|---|
| **一号模型** | 绳子捆绑拘禁，过失勒死 | 一个行为（拘禁行为） | **非法拘禁罪过失致人死亡**（结果加重犯，第一句） | 暴力带拘禁目的 |
| **二号模型** | 为拘禁大力反扭胳膊，故意扭断致重伤 | 一个行为 | **非法拘禁罪 + 故意伤害罪，想象竞合择一重** | 对重伤是故意，不能定结果加重犯 |
| **三号模型** | 拘禁后，为泄愤扇耳光，过失扇死 | 两个行为 | **定故意杀人罪（法律拟制，第二句）** | 拘禁罪被吸收，不再并罚 |
| **四号模型** | 拘禁后，故意杀人 | 两个行为 | **非法拘禁罪 + 故意杀人罪，两罪并罚**（多数说） | 后面的故意杀人是正常犯罪 |

> **【特别注意】三号模型为什么不与非法拘禁罪并罚？**
>
> 三号模型里，非法拘禁罪 + 过失致人死亡 → 法律拟制为故意杀人罪。这个结论的得出**已经用到了非法拘禁罪这个背景条件**。如果定了故意杀人罪之后再和非法拘禁罪并罚，就等于把非法拘禁罪**重复评价、重复处罚**了，违反**禁止重复处罚原则**。所以只能**最终定一个故意杀人罪**。
>
> 而四号模型里，后面的故意杀人是**独立的一个新行为**，没有“借用”前面的非法拘禁罪来拟制，所以可以并罚。这个考点（四号模型要并罚）考过，三号模型不并罚这个点没考过但需注意。


### 第七部分：讲授者补充说明

> 【讲授者补充】有同学会问：三号案例里前面已经构成的非法拘禁罪要不要并罚？还是只定一个故意杀人罪？
>
> **答：只定故意杀人罪，不再并罚。** 原理如上述（禁止重复评价）。四号案例则要并罚（考过）；三号案例不并罚（没考过但要掌握）。
