# 刑诉法简易程序与速裁程序讲稿整理


## 第一部分：讲稿知识点的提纲


### 一、简易程序与速裁程序的感性认识（导入）

**（一）简易程序——五步俱全**
- 刑事诉讼五步：开庭 → 法庭调查 → 法庭辩论 → 被告人最后陈述 → 评议和宣判
- 简易程序五步一个不缺，只是相对简化

**（二）速裁程序——五步不全**
- 对接**认罪认罚从宽制度**产生（注释：认罪认罚从宽制度，指犯罪嫌疑人、被告人自愿如实供述自己的罪行，承认指控的犯罪事实，愿意接受处罚的，可以依法从宽处理）
- 删除最费时间的**法庭调查**和**法庭辩论**两步
- 因为被告人"又认罪又认罚"，什么都承认，调查和辩论没有必要
- 速裁程序比简易程序更精简

> **核心提示：** 简易程序与速裁程序的共性和区别是**历年必考重点**。


### 二、简易程序的适用条件

> 📌 **讲授人标注：本节需要背诵**

**（一）积极条件（可以适用简易程序）**

口诀：**"基层认罪清楚同意可以简易"**

| 条件要素 | 含义 |
|---------|------|
| 基层 | 只有基层人民法院管辖的案件才能用简易程序 |
| 认罪 | 被告人承认自己所犯罪行，对指控的犯罪事实无异议（注：只要求认罪，不要求认罚，量刑有不同看法也可用简易） |
| 清楚 | 案件事实清楚，证据确实、充分 |
| 同意 | 被告人对适用简易程序没有异议 |
| 可以 | 符合条件**可以**适用，并非"应当"或"必须"——法院裁量决定 |

**考点细节：**

1. **"基层"的考点** —— 中级法院一审的案件不能用简易程序
   - 中院管辖范围：国（危害国家安全）、恐（恐怖活动）、无死（可能判无期/死刑）、缺（缺席审判）、没收（违法所得没收）、政权（颠覆政权）、期货（期货犯罪）【注：口诀为"国恐无死，缺没收政权，期货中院收"】
   - 例题1：大学教师将国家秘密卖给境外组织，危害国家安全犯罪，由中院一审，即使只判三年也不能用简易程序。
   - 例题2：持枪抢劫公交车，在**县法院**受审，即使可能判十五年有期徒刑，只要在基层法院审，仍有可能适用简易程序。

2. **"认罪"的考点** —— 只要求认罪（事实），不要求认罚（量刑）

3. **"同意"的考点** —— 谁同意？
   - ✅ 被告人同意即可
   - ❌ **被害人不同意不影响**适用简易程序
   - 例题：张三故意伤害李四，张三认罪态度好，李四不同意用简易程序——不影响，因为只要求被告人同意。
   - **对未成年被告人的特殊要求——"三同意"** ：（注释：未成年人案件的特殊规定）
     - 未成年人本人同意 + 法定代理人（父母/监护人）同意 + 辩护律师同意 → 缺一不可

4. **"可以"的考点** —— 是"可以"适用，不是"应当"适用。即使全部符合条件，法院也可以选择用普通程序。

**（二）消极条件（不能适用简易程序）**

口诀：**"盲精重大，可能无罪，不可简易"**

逐项拆解：
- **盲**：被告人是盲、聋、哑人
- **精**：被告人是尚未完全丧失辨认或控制自己行为能力的精神病人（注释：原文"精神病"应理解为"尚未完全丧失辨认或控制自己行为能力的精神病人"）
- **重大**：有重大社会影响的案件
- **可能无罪**（包括三种情形）：
  1. 共同犯罪中部分被告人不认罪
  2. 辩护人作无罪辩护
  3. 被告人认罪但经审查可能不构成犯罪

> 📌 **重要提示：** 未成年人**不在**消极条件中！未成年人**可以**用简易程序（但需"三同意"）。

**例题：** 下列哪一情形不得适用简易程序？
- A. 未成年人案件——✅可以用（需三同意）
- B. 共同犯罪案件——✅有可能用（口诀无"共同犯罪"）
- C. 有重大社会影响——❌不得用（口诀"重大"）
- D. 被告人没有辩护人——✅有可能用（口诀无此限制）


### 三、简易程序的程序性规定

**（一）程序的启动**

| 主体 | 行为 | 法律效果 |
|------|------|---------|
| 检察院 | 可以建议适用简易程序 | ❌ 建议不等于必须用 |
| 被告人/辩护人 | 可以申请适用简易程序 | ❌ 申请不等于必须用 |
| 法院 | 决定是否适用 | ✅ **最终决定权在法院** |

> **例题：** 检察院向法院建议适用简易程序审理，法院应当适用。——❌ 错，法院说了算。

**（二）当庭确认制度（重点）**

- 审判长/独任审判员**应当当庭询问**被告人对指控犯罪事实的意见
- 应当告知被告人适用简易程序的法律规定
- **确认被告人是否真正愿意**适用简易程序
- ⚠️ **开庭前的同意≠开庭时的同意**，当庭确认不可省略

> **例题：** 被告人已签署认罪认罚具结书，法官无需当庭再询问是否同意适用简易程序。——❌ 错，当庭询问不可省略。

**（三）审判组织（与民诉法的重要区别）**

| 可能判刑 | 审判组织 |
|---------|---------|
| 三年以下 | 可以独任，也可以合议 |
| 超过三年 | **应当**组成合议庭 |

> 刑诉中简易程序以**合议庭为主流**，与民诉法简易程序只能独任不同。

**（四）公诉人出庭**

- 检察院**应当派员出庭**
- 规律：只要是**开庭审理**的一审案件，检察院必须派员出庭
- 一审必须开庭（事实审）→ 简易程序也是一审 → 必须开庭 → 检察官必须来

**（五）庭审特点**

- 被告人认罪 → 定罪方面简化，可以不展开辩论
- 量刑方面**可以**重点调查和辩论
- 五步俱全，只是简化

**（六）审限**

| 情形 | 审限 |
|------|------|
| 一般情况 | 受理后**20日**内审结 |
| 可能判超过三年 | 可延长至**一个半月** |

**（七）宣判**

- **一般应当**当庭宣判（非强制）
- 复杂案件可定期宣判


### 四、简易程序转为普通程序（"简转普"）

> 📌 **讲授人标注：需要背诵**

口诀：**"无罪、无责、不清、不认，由简转繁，重新审判"**

| 转化理由 | 含义 |
|---------|------|
| 无罪 | 被告人行为可能不构成犯罪 |
| 无责 | 被告人可能不负刑事责任 |
| 不清 | 案件事实不清、证据不足 |
| 不认 | 被告人当庭对起诉指控的事实予以否认 |

**程序转化规则：**

1. **转化方向：只能由简转繁，不能由繁转简**
   - ✅ 速裁→简易 / 速裁→普通 / 简易→普通（均可）
   - ❌ 普通→简易 / 普通→速裁（不可以）
   - 原理：程序越精密对被告人保护越好，由简转繁有利于被告人

2. **转化后必须重新审判**（从头开始，不能接着审）

3. **转化不需要检察院撤诉再起诉**
   - 法院自己决定转普通即可，检察院的公诉没有"毛病"
   - ⚠️ 讲稿中特别强调：这是法条没有明确规定但容易考到的点

> **例题：** 简易程序审理中发现被告人不认罪，法院应当让检察院撤诉后按普通程序重新起诉。——❌ 错，法院直接转化即可，不需要检察院撤诉再起诉。

**（七）被告人最后陈述——不可省略**

- 被告人最后陈述是**基本人权**，**绝对不能省略**
- 简易程序也要有，速裁程序也要有
- ⚠️ 考试中常见陷阱："简易程序简化了，所以不需要最后陈述"——❌ 错


### 五、速裁程序

**（一）速裁程序的性质定位**

- 对接**认罪认罚从宽制度**
- 被告人认罪认罚+同意适用，可以用速裁
- 本质上是认罪认罚从宽制度的**配套程序**

**（二）速裁程序的适用条件**

口诀：**"三年罪罚清楚同意一人速裁"**

| 条件要素 | 与简易程序的对比 |
|---------|----------------|
| **三年**以下 | 简易：基层（无刑期限制） |
| **罪罚**双认 | 简易：只要求认罪 |
| 事实清楚 | 相同 |
| 同意 | 相同 |
| **一人**独任审判 | 简易：以合议庭为主流 |

**速裁程序的核心特征：**
- 由审判员**一人独任审判**（与简易不同，简易可以合议）
- 必须**又认罪又认罚**（简易只要求认罪）
- 仅限**可能判三年以下**的轻微案件（简易无此限制）

**（三）速裁程序的消极条件（不能适用）**

口诀：**"盲精重大可能无罪，多了小孩未赔"**

> 与简易几乎相同，额外增加两项：
> - **小孩**（未成年人）：速裁不能用于未成年人
> - **未赔**（未达成调解和解协议）：附带民事诉讼赔偿问题没解决，不能用速裁

**为什么未成年人不能用速裁？**
- 未成年人案件需要充分保障其合法权益，需要教育、挽救、感化
- 庭审不能太潦草，速裁"五步不全"（无调查、无辩论），太快了
- 简易程序虽然简化但五步俱全，所以未成年人可以用简易（三同意）

**为什么"未赔"不能用速裁？**
- 附带民事诉讼的赔偿问题需要调查、辩论，会拖慢速裁的效率
- 民事赔偿问题没解决，速裁"速"不起来

**（四）速裁程序的通知和送达**

- 在**开庭前**通知检察院、被告人、辩护人等即可
- 可以采用**简便方式**通知
- ⚠️ **不受法定通知/送达期限限制**（不受开庭10日前送达起诉书副本等限制）
- 但应当记录在案

> 📌 简易程序和速裁程序在通知送达方面都**不受法定时间限制**，只要开庭前通知即可。

> **注意：** 考试中如果说"没有在法定时间内通知和送达，违反了诉讼程序"——❌ 错，这是合法的，因为程序简化是应有之义。

**（五）法庭调查和辩论**

- **一般不进行**法庭调查和辩论
- 因为事实清楚 + 认罪认罚

**（六）集中开庭、串案审理**

- 法院可以**集中时间**开庭审理多个速裁程序案件
- 例：一个上午审多个速裁案件（盗窃、帮信、危险驾驶等），每个案件约10分钟

**（七）速裁程序的审限（重点！）**

| 情形 | 审限 |
|------|------|
| 一般情况 | 受理后**10日**内审结 |
| 可能判超过一年 | 可延长至**15日** |

> 🔥 **高频考点：危险驾驶罪的审限陷阱**

危险驾驶罪法定最高刑为**拘役六个月**，不可能超过一年。
→ 因此，用速裁程序审危险驾驶罪，审限只能是**10天**，不能延长到15天！

> **例题：** 张三危险驾驶罪，法院用速裁程序审理，审限最长不超过10天。——✅ 对（危险驾驶最高拘役六个月，达不到一年）

**（八）速裁程序的宣判**

- **应当当庭宣判**（比简易更严格；简易是"一般应当"）

**（九）速裁程序转为普通/简易程序（"速转普/简"）**

口诀基本同简易：**"无罪、无责、不清、不认，由简转繁，重新审判"**

速裁的"不清"有两层含义：
1. 不**情愿**（违背意愿认罪认罚）
2. 不**清晰**（案件复杂、疑难、重大）

**速裁 → 简易 的两种常见情形：**
1. 认罪认罚，但发现可能判**超过三年** → 不符合速裁（三年以下）→ 转为简易
2. 认罪但**不认罚**（对量刑有异议）→ 不符合速裁（需罪罚双认）→ 可转为简易（简易只要求认罪）

> ⚠️ 如果出现"无罪、无责、不清、不认"四种情况，**既不能用速裁，也不能用简易，只能转普通**。

> **例题：** 速裁程序中被告人突然翻供不认罪，法院决定转为简易程序继续审理。——❌ 错，不认罪既不能用速裁也不能用简易，应转为普通程序重新审判。


### 六、自诉案件与速裁/简易程序的关系

> 🔥 **核心规则：自诉不速裁**

| 程序 | 自诉案件能否适用 |
|------|----------------|
| 简易程序 | ✅ 可以适用（自诉调和撤烦减） |
| 速裁程序 | ❌ **不能适用** |

**理论原因：**
- 认罪认罚从宽制度发生在**被告人与公诉人**之间（"控辩协商"）
- 速裁程序对接认罪认罚从宽制度 → 速裁只能适用于**公诉案件**
- 自诉案件没有检察官（公诉人），不存在"控辩协商"的基础

> **例题：** 诽谤罪自诉案件中，被告人认罪认罚并同意适用速裁程序。——❌ 错，自诉不速裁。


### 七、简易程序与速裁程序的共性（9个共同点）

| 序号 | 共性 |
|------|------|
| 1 | 审理法院都是**基层法院**（中院不能用） |
| 2 | 都是一审程序 |
| 3 | 都要求**认罪**（速裁还额外要求认罚） |
| 4 | 都要求被告人**同意** |
| 5 | 都可能由**一人独任**审判（简易判三年以下可独任；速裁必须独任） |
| 6 | 检察院**可以建议**适用（但决定权在法院） |
| 7 | 检察院**应当出庭**（一审必须开庭，开庭必须出庭） |
| 8 | 都**必须有被告人最后陈述**（不可省略） |
| 9 | 要求**身份明确**（身份不明=事实不清，不能适用） |


### 八、简易程序与速裁程序的区别（9个区别）——🔥 高频考点

| 区别项 | 简易程序 | 速裁程序 |
|--------|---------|---------|
| **未成年人** | ✅ 可以用（三同意） | ❌ 不能用 |
| **刑期限制** | 无（基层即可） | ✅ 三年以下 |
| **认罪/认罚** | 只要求**认罪** | 要求**罪罚双认** |
| **审判组织** | 以合议庭为主流 | 必须**一人独任** |
| **法庭调查/辩论** | 有（简化），五步俱全 | 一般**没有**，五步不全 |
| **当庭宣判** | 一般应当 | **必须**当庭宣判 |
| **审限** | 20日～一个半月 | 10日～15日 |
| **程序转化中的"不清"** | 事实不清、证据不足 | 违背意愿 + 重大疑难复杂 |
| **自诉案件** | ✅ 可以适用 | ❌ **自诉不速裁** |


### 九、判决、裁定、决定（第五节，非重点）

| 对比项 | 判决 | 裁定 | 决定 |
|--------|------|------|------|
| **适用主体** | 仅法院 | 仅法院 | 公检法均可 |
| **解决的问题** | 实体问题（定罪量刑） | 主要是程序问题（个别实体：减刑、假释裁定） | 程序事项 |
| **形式** | 必须书面 | 书面或口头 | 书面或口头 |
| **救济方式** | 上诉/抗诉（10日） | 上诉/抗诉（5日） | 作出即生效，不能上诉/抗诉 |
| **数量** | 可有多个（生效的最终只有一个） | 可有多个 | 可有多个 |

> **例题：** 关于判决和裁定的区别，下列哪一选项正确？
> - A. 判决解决实体，裁定解决程序 → ❌ 裁定也解决少量实体（减刑、假释）
> - B. 一案中只能有一个判决 → ❌ 可以有多个，生效的最终只能有一个
> - C. 判决只能书面，裁定只能口头 → ❌ 裁定书面/口头均可
> - D. 不服判决与不服裁定的上诉期限不同 → ✅ 对（判决10日，裁定5日）


## 第二部分：讲授人提到的考点及2026年预估考点

### 🔥 讲授人明确提及的"历年必考/常考点"

| 知识点 | 可能考试的方式 | 举例 |
|--------|-------------|------|
| **简易与速裁的共性与区别** | 判断某一特征属于简易还是速裁；或判断某程序适用是否正确 | 问："下列哪项是速裁程序独有的特点？" 选项包括"五步俱全""要求认罪认罚""可适用自诉案件""由合议庭审判"→选"要求认罪认罚" |
| **简易程序积极条件（基层认罪清楚同意可以简易）** | 判断某案能否用简易程序 | 题干设置"中院审理""被害人不愿意""被告人是盲人"等陷阱，判断是否正确适用 |
| **"基层"陷阱（管辖级别）** | 判断中院管辖案件能否用简易 | 问："危害国家安全犯罪能否适用简易程序？"→不能，因属中院管辖 |
| **"同意"的主体（被告人≠被害人）** | 判断被害人不同意是否影响适用简易 | 题干："被害人不同意适用简易程序，法院应转为普通"→错，应看被告人态度 |
| **未成年人简易"三同意"** | 判断未成年人简易程序的条件 | 问："未成年人简易需哪三方同意？"→本人+法定代理人+辩护律师 |
