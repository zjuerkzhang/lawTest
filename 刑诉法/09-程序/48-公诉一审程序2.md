# 一、讲稿知识点的提纲

> **说明**：以下提纲基于讲稿内容整理，对照《中华人民共和国刑事诉讼法》及最高人民法院《关于适用〈中华人民共和国刑事诉讼法〉的解释》（以下简称《高法解释》）相关条款。标注“【讲稿原文】”的内容直接来源于讲授者表述；标注“【注】”的内容为讲授者引入的超出本主题范畴的补充说明或编者对照法条的注释。


## （一）庭审五步概述

**1. 法庭审判的五个步骤**

法庭审判分为：**开庭** → **法庭调查** → **法庭辩论** → **最后陈述** → **评议宣判**

**2. 重点掌握的两步**

每年必考的重难点主要是：**法庭调查**和**评议宣判**。其中法庭调查需要重点学习，宣判虽然没有需要背的内容但考点较多。


## （二）第一步：开庭

**1. 开庭地点**

- 开庭审理主要在法院审判庭
- 也可以在**其他适宜的场所**设置法庭（如到当事人家中、田间地头开庭），体现司法为民【讲稿原文】
- **【注】** 《刑事诉讼法》未明确限定开庭场所必须为法院审判庭，实践中为方便当事人可以在适宜场所开庭。

**例题**：大俊醉酒驾车涉嫌危险驾驶罪，因车祸瘫痪在家修养，某县法院可以到大俊家中开庭。（可以）

**2. 旁听禁止人员**

- 精神病人、醉酒的人、未经法院批准的未成年人、其他不宜旁听的人员
- 证人、鉴定人、有专门知识的人、调查员、侦查员**不得旁听案件**【讲稿原文】
- **【注】** 证人不得旁听，即使作证完毕后也不能到旁听席旁听，因为可能有二次出庭的可能【讲稿原文】。

**3. 被害人/辩护人不到庭的处理**

| 情形 | 处理规则 |
|------|----------|
| 被害人及诉讼代理人不到庭 | 不影响开庭审理的，法院**可以**开庭审理（公诉案件中被害人的控诉职能一般被检察院吸收） |
| 辩护人不到庭 | **被告人同意**的，法院可以开庭审理；但**应当法律援助的对象除外** |
| 应当法援的对象 | 包括**盲聋哑、未完全丧失辨认或控制能力的精神病人、可能判处无期徒刑或死刑、未成年人、缺席审判案件**等（口诀：王金卫、吴死缺、申台飞——即“盲聋哑、未死缺、未成年”）【讲稿原文】。即使被告人同意没有律师，法院也**应当**主动为其提供法律援助 |

**4. 公开审理**

公开审理要公开宣布原因（一般了解即可）【讲稿原文】。


## （三）第二步：法庭调查（核心重点）

### 1. 一般发问规则——“三个先后”

讲授者归纳了三个核心原则【讲稿原文】：

**（1）先说后问**

- 法庭调查开始后，**先**由公诉人宣读起诉书（“自报家门”），**然后**再进入发问环节
- 【注】《高法解释》第195条规定：审判长宣布法庭调查开始后，应当先由公诉人宣读起诉书

**（2）先控后辩**

- 发言、发问、举证、质证，都是**先控方、再辩方**
- **关键考点**：控方是**大控方**，包括：
  - 公诉人
  - 被害人及其法定代理人、诉讼代理人
  - 附带民事诉讼原告人及其法定代理人、诉讼代理人
- 公诉人问完 → 被害人问 → 附民原告人问 → **全部问完**后才轮到辩方【讲稿原文】
- 【注】《高法解释》第198条：公诉人讯问后，被害人及其法定代理人、诉讼代理人可以补充发问；附带民事诉讼原告人及其法定代理人、诉讼代理人可以就附带民事部分发问

**（3）先言后物**

- 举证时一般**先出示言词类证据**（证人证言、被告人供述、鉴定意见等），**再出示实物类证据**（物证、书证、电子数据等）
- **但必须遵循“先控后辩”的大原则**，完整顺序为：**控言 → 控物 → 辩言 → 辩物**【讲稿原文】

**例题**：法庭调查中，公诉人请求出示一把匕首（控物），辩护人请求宣读一份证人证言（辩言），谁先谁后？答：**控物在前**（先控后辩原则），所以匕首先出示。

**判断题**：公诉人向被告人发问后，辩护人也可以向被告人发问。（**错误**，因为控方还包括被害人和附民原告人，他们都问完才轮到辩方）【讲稿原文】

### 2. 一般出庭规则（证人、鉴定人等如何到庭）

**（1）出庭的两种方式**

| 方式 | 说明 |
|------|------|
| **申请出庭** | 控辩双方可以申请法庭通知证人、鉴定人等出庭，但**法院审查认为有必要**的才准许 |
| **依职权出庭** | 法院可以**依职权**通知证人、鉴定人、有专门知识的人、调查人员、侦查人员或其他人员出庭【讲稿原文】 |

- **关键考点**：“法院想让谁来就让谁来”——不仅限于证人和鉴定人，还包括见证人、值班律师、专家辅助人等【讲稿原文】
- 【注】《高法解释》第202条：公诉人可以提请通知证人、鉴定人出庭；控诉一方举证后，辩方也可以申请

**（2）证人出庭补助**

- 证人出庭作证支出的住宿、交通、就餐费应给予补助
- **谁通知的谁给补助**（审判阶段法官通知的，法院给补助）【讲稿原文】

**（3）证人保护**

- 证人、鉴定人、被害人因出庭作证，本人或其近亲属人身安全面临危险的，法院**应当**采取不公开真实姓名等保护措施
- **注意**：保护的是**证人**，不是**见证人**（见证人未目击案件事实，一般不会遭受报复）【讲稿原文】

### 3. 证人调查规则

**（1）证人可以不出庭的情形**

- 庭审期间身患严重疾病或行动极为不便
- 居所远离开庭地点且交通极为不便
- 身处国外短期无法回国
- 有其他客观原因确实无法出庭

- **关键理解**：以上情形只是**可以不出庭**，不代表**可以不作证**——可以通过书面证言或远程视频等方式作证【讲稿原文】

**（2）证人拒不到庭的后果（超级高频考点）**

**核心法条**：《刑事诉讼法》第193条

| 考点 | 规则 |
|------|------|
| **可以强制谁** | **只能强制证人**（不能强制被害人、鉴定人、侦查员等） |
| **除外对象** | **被告人的配偶、父母、子女除外**（注意是“被告人”不是“被害人”） |
| **强制方式** | 由**院长签发强制证人出庭令**，由**法警**执行（不是拘传、不是传唤、不是公安执行） |
| **拒绝出庭/作证的处罚** | 训诫；情节严重的，经院长批准，处**十日以下**司法拘留 |
| **不服拘留** | 向**上一级**法院申请复议，复议**不停止执行**【讲稿原文】 |

**高频考点细节**：
- **被告人**的配偶、父母、子女除外（**被害人**的配偶、父母、子女**可以**强制）【讲稿原文】
- 除外的仅限**配偶、父母、子女**（第一继承顺位），**兄弟姐妹**、祖父母等**可以**强制【讲稿原文】
- 拘留是**10天以下**，不是15天【讲稿原文】

**例题1**：大军因诈骗受审，法官通知大军的弟弟小军出庭作证，小军无正当理由不来，法院可以强制小军到庭。（**可以**，兄弟姐妹不在除外范围内）【讲稿原文】

**例题2**：同上，法院经院长决定对小军处15天司法拘留。（**错误**，应为10天以下）【讲稿原文】

**（3）询问证人的规则**

- 证人出庭后，**一般先向法庭陈述证言**（先自己说），再接受发问【讲稿原文】
- 谁找的证人，**谁先发问**（控方证人控方先问，辩方证人辩方先问）
- 【注】《高法解释》第212条：向证人、鉴定人发问，应当先由提请通知的一方进行

**判断题**：证人出庭后，应当首先由提请通知的一方发问，再由对方发问。（**错误**，证人应先自我陈述，再接受发问）【讲稿原文】

### 4. 鉴定人调查规则

**（1）鉴定人拒不出庭的后果（高频考点）**

**核心法条**：《刑事诉讼法》第187条

- 经法院通知，鉴定人拒不出庭作证的，**鉴定意见不得作为定案的根据**
- 因不可抗力或其他正当理由无法出庭的，法院可以**延期审理**或**重新鉴定**

**关键辨析——证人与鉴定人的区别**：

| | 证人 | 鉴定人 |
|---|------|--------|
| 义务 | 应当**作证**（可书面） | 应当**出具鉴定意见**（可书面） |
| 是否必须出庭 | 看法院是否通知 | 看法院是否通知 |
| 经通知拒不到庭的后果 | 庭外证言为**传闻证据**，可补救、可印证后使用 | 鉴定意见**直接排除**，不得作为定案根据 |
| 为什么不同 | 证言内容通俗易懂 | 鉴定意见涉及专业技术，专家不来解释无法查清 |

【讲稿原文】

**例题1**：法庭通知鉴定人出庭说明情况，鉴定人拒不出庭，鉴定意见不得作为定案的根据。（**正确**）【讲稿原文】

**例题2**：法庭通知鉴定人出庭，鉴定人因正当理由来不了，法庭应当裁定终止审理。（**错误**，应为**延期审理**，不是终止）【讲稿原文】

**（2）申请有专门知识的人出庭（专家辅助人）**

- 申请有专门知识的人出庭，**不得超过两人**
- 有**多种类**鉴定意见的，可以**相应增加**人数
- 即：每个鉴定意见最多2名专家，N个鉴定意见可请2N名专家【讲稿原文】

**例题**：被告人对公诉人出具的ABO血型鉴定及足迹鉴定有意见（2个不同种类的鉴定意见），最多可以申请2名有专门知识的人出庭发表意见。（**错误**，2个鉴定意见可申请4人）【讲稿原文】

**（3）申请重新鉴定**

- **当法辩诉**（当事人及其法定代理人、辩护人、诉讼代理人）有权申请重新鉴定【讲稿原文】
- 需说明理由，法庭认为**有必要**的，应当同意并宣布休庭，可决定延期审理【讲稿原文】

### 5. 其他调查规则

**（1）证据偷袭（控方出示开庭前未移送的证据）**

- 辩方提出异议的，审判长要求公诉人**说明理由**
- 理由成立且**有必要**出示的，**应当准许**
- 辩方需要作辩护准备的，法庭**可以宣布休庭**，确定准备辩护的合理时间
- 【注】《高法解释》第272条

**（2）法庭调取的证据也应质证**

- 审判人员庭外调查核实取得的证据，**应当经过当庭质证**，才能成为定案的根据【讲稿原文】
- **与民诉法的区别**：民诉中法官依职权调取的证据可直接认定；刑诉中**原则上必须质证**【讲稿原文】
- 【注】《高法解释》第63条：证据未经当庭出示、辨认、质证等法庭调查程序查证属实，不得作为定案的根据

**（3）单独质证**

- 对可能影响定罪量刑的**关键证据**，如有争议，可**单独拿出来重点举证质证**【讲稿原文】

**（4）补充侦查（审判阶段）**

- 公诉人发现需要补充侦查，**建议**延期审理的，合议庭**可以**同意（不是必须）【讲稿原文】
- 延期**不得超过两次**
- **法院不可要求检察院补充侦查**（受制于被动消极中立、不告不理），但**可以建议**【讲稿原文】

**判断题**：检察院建议法庭延期审理的，合议庭应当同意。（**错误**，是可以同意，不是应当）【讲稿原文】

**（5）发现新的量刑证据的处理**

| 情形 | 处理方式 |
|------|----------|
| **合议庭发现**检察院遗漏了自首、坦白、立功等量刑材料 | **应当通知**检察院**补充移送** |
| **被告人提出**新的立功线索 | **可以建议**检察院**补充侦查** |

【讲稿原文】

**（6）被告人当庭认罪认罚**

- 侦查、审查起诉阶段未认罪认罚，**当庭认罪**的，**可以**从宽处理
- **不需要休庭**（休庭不是法定理由），当场调查是否自愿、真实、合法即可【讲稿原文】

**【主题一：庭审五步概述】**

那讲完庭前审查就该什么呢？大家来看咱们教材二百一十九页第三，看到法庭审判了没有？这个法庭审判从现在开始正式开庭了。这个正式开庭有几步，一共由五步。来看咱们这段话，第二段话写着的。根据刑事诉讼法及相关司法解释规定，法庭审判分为**开庭**，是第一步；**法庭调查**，第二步；**法庭辩论**，第三步；**最后陈述**，第四步；**评议宣判**，这算一起吧，算第五步，一共五个步骤。

来同学们抬头看大屏幕，下面咱们要学的这个叫庭审五步。这五步里注意，刚才说了开庭、调查、辩论、最后陈述、评议宣判，不是平均重要的。每年必考的重难点主要是两步，最主要是两步。第一个是**法庭的调查**，就是怎么举证、怎么质证、怎么调查证人证言、怎么调查鉴定意见等等。那么第二步呢，是咱们最后那个叫**评议和宣判**。就这两步相对最最重要。下面咱们开始学习。


**【主题二：开庭——开庭地点】**

我们先来看第一步啊，**开庭**。那么开庭并不是一个特别核心的重点，但是里面有几个法条呢，也考过，咱们适当注意。

现在看这个第一个叫**开庭的地点**，咱们在哪儿开庭啊？你看，开庭审理主要是在法院，咱们有审判庭。那么但也可以在其他适宜的场所设置法庭，画一下“其他适宜的场所”，这个考过。怎么考呢？就说咱们的法院开庭啊，那必须得是在法院的审判厅里啊，对吧？那不能在其他乱七八糟地方去开庭啊——不是这样的。有的时候呢，咱们是为了方便当事人，体现一种司法为民吧。有时候咱们的法官，大家有没有听说过叫“带着国徽去审判”，就是咱们的法院的法官啊，扛着国徽，扛着打印机，扛着各种设备，咱们呢去就当事人去，到他家里去，到田间地头，咱们去开庭。

你说老师还可以这样吗？来，请同学们看一眼大屏幕啊，这个大屏幕上是这个网上公开的一个资源，一个图片啊，大家来看，你看这就是相当于是法官，你看中间审判长，两边是人民陪审员，然后这边是公诉人，这边是辩护人，这边坐的是被告人，你看在一张桌子上，后边呢还有个书记员，呃，还有法警，这相当于是到了被告人的家中来开庭的，那显然是家里，你看那边还露着厨房呢，应该是吧？这是为了一种司法为民方便被告人啊，因为有的时候被告人在一些刑事案件里面，比如说像一些危险驾驶、交通肇事，那有可能在这一起犯罪里他是涉嫌犯罪，但他本人也可能因为这个汽车的撞击呀，或者等等原因，可能自己身体不方便甚至瘫痪，那么这种情况下，为了方便被告人接受审理，咱们到他家里开庭，这个也可以的。

所以回到咱们刚才这个知识点上来，来回来咱们看这个教材啊。那么所以咱们不仅可以在法院开庭，在其他的适宜场所也是允许的。来咱们做道小题看一下：大俊醉酒驾车发生车祸，涉嫌危险驾驶罪，某县法院决定开庭审理时发现大俊因车祸已经瘫痪了，目前在家中休养，某县法院可以到大俊的家中开庭，可不可以？咱们说没问题，可以，并不是非得在法院的审判庭。好，很简单啊。


**【主题三：开庭——旁听禁止】**

来咱们往下看，下面咱们来看第二，**旁听禁止**，就是什么人不让听啊。精神病人、醉酒的人、未经法院批准的未成年人以及其他不宜旁听的人员。你心想这脑子有病啊，醉酒，这不得闹事儿吗？小孩是为了保护他，还比较弱小，因为有些像暴力杀人放火的案件，那他听了以后晚上要做梦的呀，是吧？但这里面有一点啊，是**未经法院批准的未成年人**，因为有些典型的像什么盗窃案、诈骗案，有时候咱们还可能组织一些这个中小学的学生，是吧？可能还来听一听，受一下法制教育，这个是可以的，经过批准行，但是没有经过批准，小孩是不能旁听的啊。

来往下看，第二，尤其重点是这个第二段，**证人、鉴定人、有专门知识的人、调查员、侦查员不得旁听案件**，尤其喜欢考的是**证人**。那么当然证人为什么不让旁听什么原因啊？因为证人啊，他可能虽然了解了案情，不一定了解的那么全面，可能只是其中的某一个片段啊。那么也就意味着他对这个被告人不一定有过于强烈的这个爱或者是憎啊。但是如果允许他旁听，他完整听了这个庭审，很可能听着听着对这个被告人产生了过于强烈的憎恨呢，或者怜悯呢这种主观情绪。如果带着这个情绪，他再作证，有可能他当庭会改变自己的证言，就不利于咱们查清事实了。

这比较简单哈。但多说一个细节，考试会这么改：说证人张三啊，他出庭作证，但是等张三出庭作证完毕之后，作完证了，那可以退到旁听席上旁听，怎么样？作完证了可以听吧？**不行**，你就记住只要是证人，反正就不让听。那为什么呢？因为也许待会儿调查其他证据的时候，他还有二次出庭的可能，就算一审不用出庭了，还有二审，也许还让他出庭，反正是证人就不能旁听就对了。注意几个啊。


**【主题四：开庭——被害人/辩护人不到庭的处理】**

来咱们下看，第三个是**被害人和辩护人不到庭的处理**。哎，它相对重要，可以标一个小重点，也不用背。什么意思？开庭审判了，结果发现被害人没来怎么办？来看一下。

第一，**被害人没来**：被害人及诉讼代理人经过传唤或经过通知不到庭，不影响开庭审理的，法院可以开庭审理。说的精简一点，不用背，就是被害人不来，你爱来不来无所谓，接着审就行了。那为什么呢？因为在公诉案件里面，这个被害人的控诉职能一般主要是被谁吸收了？一般主要是被检察院公诉人吸收了，所以只要是公诉人到了就可以，被害人不来也没什么事儿啊。

那么往下看，**辩护人不来怎么办**？辩护人经通知未到庭，被告人同意的话——这几个字“被告人同意”——法院可以开庭审理，但被告人属于**应当法律援助的对象**除外。是什么意思？开庭审判发现辩护律师没来，那怎么办？没事儿，往下审吧？不可以。辩护人没来可能会伤害到被告人的有效辩护，所以这时候咱们得问问被告人的态度，你得问他，你说被告人，你律师不来怎么办呢？你听他说啥？如果他说，哎，没事儿，这事儿我都清楚，我也认罪，不来就不来无所谓，那咱们就直接往下审了。如果他说不行啊法官，没有律师我都不敢说话了，那咱们得休庭，给他去找律师来。

好，如果他同意说不用律师，咱们不是可以接着往下审吗？除非是什么对象，除非他是**应当法援的**。大家还记不记得在辩护专题里提到过什么是应当法援的对象呀？**盲聋哑、未完全丧失辨认或控制能力的精神病人、可能判处无期徒刑或死刑、未成年人、缺席审判案件**——应当法援【修正：讲稿原文为“王金卫、吴死缺、申台飞”，此为讲授者使用的记忆口诀，对应“盲聋哑、未死缺、未成年”】。就是如果他是这种对象，哪怕被告人同意没有律师，咱法院也不能同意，也得主动给他找免费的律师。

好，所以咱们精简一下：**被害人不来，爱来不来无所谓；辩护人不来呢，要征得被告人的同意才行**。那么除非他是什么对象，除非是应当法援的对象，那么就算被告人同意没有律师，我们也得给他去找免费的律师。注意这个。

好，我们再往下，什么公开审理要公开宣布原因什么的，一般看看就算了。这个开庭就把刚才的一、二、三理解熟悉就足够了啊。


**【主题五：法庭调查——一般发问规则（先说后问）】**

来，我们继续往下看，请翻到二百三十页。二百三十页看第二步叫**法庭调查**，来标重点符号。咱们说这个庭审的五步最核心的一个是调查，还有后面一个宣判。调查要好好学。

来，咱们先开始啊。嗯，首先这个法庭调查，先看第一个是**一般的发问规则**。那调查开始是交叉辩论，你问我，我问你，怎么说话？这个顺序是啥呢？来，咱们看看这个发言顺序，有个括号一二三四五六，我们先走马观花过上一遍，完全不用背，你先看一下哈：

第一，审判长宣布法庭调查开始后，要先由**公诉人宣读起诉书**。

二，公诉人宣读起诉书以后，审判长应当**询问被告人对起诉书指控的事实和罪名有没有意见**。

第三，附带民事诉讼存在的，公诉人宣读起诉书以后，由**附带民事诉讼原告人或者其法定代理人、诉讼代理人宣读附带民事诉讼的那个诉状**。

那么第四，在审判长主持下，**被告人、被害人可以就起诉书中指控的犯罪事实分别陈述**。

第五，审判长主持下，**公诉人可以就起诉书中指控的犯罪事实询问被告人**，根据案件情况就证据问题对被告人询问发问，可以在举证质证环节进行。

那么第六，经审判长准许，**被害人及其法定代理人、诉讼代理人可以就公诉人询问的事实补充发问**；附带民事诉讼原告人及法代诉代可以就附带民事部分向被告人发问；**被告人的法代、辩护人，附带民事诉讼被告人及法代诉代，也可以在控诉方、附带民事原告方就某个问题询问发问以后，向被告人发问**。

我的天呐，这是啥呀？是啊，这是什么问来问去的？我该怎么办呢？考试里还真喜欢考怎么办。来跟老师学，教你三个词你就做不错题了。哪三个词呢？不管是怎么说、怎么问，遵循三个规则：**先说后问、先控后辩、先言后物**。

来，我们慢慢说。先说什么叫做**先说后问**啊。大家看大屏幕，那什么叫做先说？是这样的，就是咱们的控辩审三方，法官往这儿一坐啊，公诉人一坐，辩护人、被告人这么一坐，往这儿一坐，不是上来就说你干没干、你快点说你是坏蛋吗？不是上来就问的，先干什么？你得先自报家门嘛。

咱们都知道像法庭上，大家可能看过一些模拟法庭或正式庭审，法官往这儿一坐啊，那么“本院今日公开开庭审理什么什么涉嫌什么什么一案，由审判长谁谁谁、审判员谁谁谁、人民陪审员组成合议庭依法公开开庭审理”，这是在干嘛？这叫自报家门，我来干什么了？我来审案的，对不对？法庭调查开始，法官一般说“下面请公诉人宣读起诉书”，是不是这么个程序啊？公诉人开始读了啊，“某某某检察院起诉书，被告人姓名年龄，哪年哪月哪日，在哪儿涉嫌盗窃什么财物，共计多少元，根据刑法刑事诉讼法的规定构成盗窃罪，请求法院依法判处。起诉书宣读完毕。”是不是读了个起诉书？这干嘛呢？自报家门，我今天是来指控的，他有罪，我是来干这个的，对吧？

法官一般会问往下怎么问，“被告人对公诉人指控听清了没有？那么对公诉人指控你有什么意见？”就让他说说你是同意还是不同意，你是认罪还是不认罪，这是在干什么？控辩审三方往这儿一坐，其实不一定大家都谁和谁都认识，可能是陌生人，咱们往这儿一坐呢，先大家先自报家门，你是干什么的？你是谁？你来做什么？先说一说。

然后下一步法官会说“下面公诉人可以就起诉书中指控的犯罪事实向被告人发问”，这时候才开始问。公诉人会说：“被告人，现在问几个问题，先问你如实回答，听清了没有？好，你当天几点到达现场？到了以后你上楼没有？上了以后你做了什么？”就是一问一答的方式，所以叫**先说后问**，先自报家门，说清楚自己来干什么了、认还是不认，下一步再相互的进行发问。

其实你说这个很好记，法律不外乎生活嘛。但是想想咱们同学们啊，不管你是上班的同事还是在大学里的同学，咱们有时候刚到大学开学或者刚到一个单位去工作，往往可能都挺陌生的，这时候可能会有个老大哥或者有个老大姐，他可能干什么呢？组织咱们在一起吃个饭嘛，团建一下吃饭啊。那说好大家咱们坐到一起了，今天很开心啊，有几个新的朋友咱们互相认识认识是吧？咱们坐到这儿来这样吧，你告诉我大家往这儿桌子上一坐，先干什么？是先说还是先问？你觉得呢？对吧？如果是先问，大家都还不认识很陌生，往这儿一坐，你在旁边先问“嘿嘿嘿，你喜欢什么颜色？”人家是不是觉得你是变态呀？对吧？所以你上来得先说，一般可以说好从我开始介绍一下每个人姓名，家乡来自哪里，喜欢什么有什么爱好，是不是得说呀？“我来自于北京，我叫什么，我希望大家都关照”，“我来自于山东，我叫什么，我喜欢怎么样，希望大家都关照”，是不是？哎介绍了一圈，大家都熟络了，那下面是不是可以自由活动互相问了，“哦听说你喜欢这个汽车是吧？请问你喜欢哪个牌子的？是跑车呀还是轿车？哦你喜欢这个东西哈，你喜欢什么颜色的？”你再问一下喜欢什么颜色，是不是顺理成章啊？就这道理，你得先说再问。


**【主题六：法庭调查——一般发问规则（先控后辩）】**

好，这是第一点啊，来往下看。第二点叫什么？叫**先控后辩**。来，慢慢来。第二个叫先控后辩，啥意思？就是发言和发问，包括举证质证，都是**先控方再辩方**。那道理简单，谁主张谁举证。你说我有罪，是不是？你先说话呗，你先拿证据呗。

但是这个先控和后辩，后辩呀，里面有个隐藏的考点，咱们需要讲。什么考点呢？我问句话你判断：法庭调查开始啊，公诉人向被告人发问之后，辩护人也可以向被告人继续发问，怎么样？哎，先控后辩嘛，对不对？**不对**。哎呦，为什么不对呢？来，这个先控后辩，它的考点在于，请把这个**控方理解为大控方**。

啥叫大控方？就是控方里包含这么几位：第一个肯定是**公诉人**嘛，他肯定是控方呀，对不对？好，公诉人问完，注意控方不算问完了。大家如果见过咱们的法庭或参加过，你想一下，就是控方不就检察官坐的座位吗？请问检察官那个座位除了有检察官，好像还有一些人和他们坐在一起。请问谁和检察官肩并肩坐在一起？还有谁？还有本案的**被害人及法代及诉代**（法定代理人、诉讼代理人），就算是被害人一方吧。啊，被害人一方，这是控方，咱们说他也履行辅助的控诉职能啊，对吧？就是说还有谁？还有**附民原告**，就是附民原告人算一方吧，及法定代理人及诉讼代理人。

你说老师，那被害人不就是附民原告人吗？他不是要损失吗？有的时候被害人和附民原告人是重合的，有的时候他不一定重合。那咱们举个例子啊，比如说左老师，我喝了酒以后开车危险驾驶嘛，那么在拐弯的时候，不仅把一个行人给挂倒了，就把人撞了一下，然后我还失控了，撞到了旁边的街上，把人家邻街的商铺老板的一个商铺的玻璃门给撞碎了。你看，我撞伤了一个行人，我还把人门给撞碎了——被我撞伤的那个行人可以作为被害人吧，对吧？但是那个商铺老板的门是被我给撞碎了，人家也可以在追究我危险驾驶罪的同时，让我赔他那个门，他就可以成为叫附民原告人，就这个道理。

好，那么公诉人问完，被害人问，被害人问完，附民原告人问——他们仨全问完了，才算控方问完了，才轮得到辩方。所以回到咱们刚才这个案例，说“公诉人向被告人发问完毕之后啊，辩护人可以紧接着发问”，为什么错了呢？因为公诉人问完，还轮不到辩护人。公诉人完，你得看被害人问不问；被害人问完，你得看附民原告人问不问；他们都问完了，才轮到辩方问呢。好，这个叫先控后辩。


**【主题七：法庭调查——一般发问规则（先言后物）】**

好，别着急，再来一个，还一个叫**先言后物**。这个是什么意思呀？就是不论控方还是辩方，你在举证的时候，一般来讲哈，就大概率一般是先举**言词类证据**，再出示**实物类证据**。比如说不管是控方还是辩方，一般比如公诉人举证，你先得宣读一下证人证言呐、被告人的供述啊、鉴定意见呀——言词类的，然后再出示有关的什么物证啊、书证啊、电子数据啊，所以叫先言词的、再实物的，就这个道理。

你说老师，这个好像挺简单的，先言后物哈，其实也有一个隐藏的考点。那么在考试当中，他喜欢给你出**排序题**。同学们，下面请排个顺序哈：

一，在庭审中，公诉人请求向法庭出示一把匕首，就一把刀——**控物**。
二，辩护人向法庭请求宣读一份证人证言——**辩言**。

来吧，现在做排序题。一个是先一后二，一个是先二再一，怎么选？你说老师哦，先言后物嘛，选B啊，选B二和一，对不对？**不对，选A**。你说老师不是得先言后物吗？所以咱们要讲，不然做题容易做错的。

来，这个先言后物，你再怎么出示言词和实物证据，也得遵循一个大的前提，是不是叫**先控后辩**？来，咱们刚才讲过，是不是得先控方拿证据，然后再辩方拿证据，对吧？先控后辩，别着急，慢慢来。

那么轮到你控方拿证据的时候，控方拿证据，因为控方有好多证据嘛，你不能一股脑全甩出来吧，你是不是得分类来拿出来吗？所以他先拿控方的什么证据？先拿控方的**言词类证据**，就宣读证言啊、被害人陈述啊等等；然后再拿控方的什么证据？再拿控方的**实物证据**，什么物证啊、书证啊、电子数据啊，就这些。

好，控方把证据拿完了，咱们法官得问“请问辩方有什么证据向法庭出示吗？”控方拿完还得问辩方吧。如果辩方也有好多证据，他也得遵循先言后物的这个顺序。所以那一会儿轮到辩方了，那辩方呢，也得先出示你辩方的言词证据，然后再出示你辩方的实物证据。这就叫所谓的先言后物，没问题。

但这个先言后物你发现没？得遵循先控后辩的大原则。所以这几个证据的出示，如果非得排个顺序，你发现这个顺序是什么？是**控言—控物—辩言—辩物**，这是它的大顺序。

好，那如果是这样的话，来往下看，公诉人请求出示一把匕首，这个叫什么来着？这个叫**控物**，对吧？控方的实物证据吧。那下面这个辩护人请求宣读个证言，这个叫**辩言**。这能看明白哈？控物和辩言。那你告诉我这俩谁在前谁在后啊？是不是控物在辩言的前头啊？因此刚才这个题应该是选A而不是选B。

所以刚才再回到咱们这个教材上来，上面的一二三四五六，你背过它也没用，你就大概看看就算了。但是把刚才老师讲的这三个先后一定把握好，你做题就丢不了分——**先说后问、先控后辩、先言后物**。


**【主题八：法庭调查——一般发问规则（练习）】**

好嘞，那咱们往下找哈，我们做个小练习试一试。呃，请往下看咱们这个测试题。在法庭调查阶段，公诉人就起诉书中指控的事实向被告人发问后，辩护人也可以向被告人发问，对吧？咱们刚才提到过这个是错的，因为你要把这个控方理解为是大控方，所以公诉人问完还得看被害人问不问，还得看附民原告人问不问。所以说公诉人问完不是说马上就轮到辩护人发问了啊——这就错了。

好，这是咱们的发言发问顺序，把它把握好。


**【主题九：法庭调查——一般出庭规则】**

下面翻到二百三十一页，咱们来看这个第二**一般出庭规则**，就是像证人、鉴定人他们是怎么来到法庭上的，是只要是证人就得来吗？他不一定。

请看一下。第一，**申请**：控辩双方可以申请法庭通知这个证人等等人出庭。但是画一个小词什么呢？你看后半句，**法院经过审查认为有必要的**——画仨字“有必要”——不是咱们想让谁来就让谁来，到底来不来，法院说了算啊。

来，下面第二，是**依职权**：法院可以依职权通知证人、鉴定人、有专门知识的人、调查人员、侦查人员或其他人员出庭。第一点呢，就是法院他依职权，为了调查清楚这个事实和证据，他可以主动的让证人、鉴定人到庭，这个是可以的。

这个看来不难，但是考点会这么干的。排除看我，我来问你来答啊：

请问，如果在庭审中，法官在必要时，能不能请**值班律师**出庭说明情况？再来，法庭在必要时，为了查清事实哈，能不能请**见证人**出庭说明情况？我没说证人，我说是见证人。你说老师，这没有啊，不对吧？来，听我说，**都可以**。

第一个，你说通知值班律师出庭——不对不对，老师，我学过，值班律师不能出庭辩护的，是吧？谁让他出庭辩护了？他出庭就是他辩护来的？不是。我可能让他出庭干什么？我问问，当时审查起诉时，嫌疑人认罪认罚，你见证拒绝了，他真的是自愿吗？你把当时情况说一下——我只是问一下认罪认罚的情况呀，我没让他辩护啊，对吧？

第二，见证人，那我就问一下，当时警察勘查现场的时候，你见证人看到什么了？当时程序合法吗？他跟你说什么了？我了解了解，可不可以？我是想调查取证合法性啊。那行还是不行？**行**。为什么行？请看这个依职权哈，就是括号二，依职权，法院可以依职权通知证人、鉴定人……后面“**其他人员**”——旁边写句话，**法官想让谁来就让谁来**，所以不仅仅限于证人和鉴定人，他想让谁来就能让谁来，包括见证人、值班律师、专家辅助人等等人，都行。

好，这是出庭的两个方式：申请和依职权。把它把握好啊。


**【主题十：法庭调查——出庭补助与证人保护】**

来，咱们下面看这个命题角度里注意几个点。这个括号二，证人出庭作证，应当对支出的住宿、交通、就餐费给予补助。**公检法谁通知的，谁给补助**。提前咱们也接触过这个，就是谁找的谁给钱。比如在侦查阶段，是公安局找证人作证，就公安局给钱。那审判阶段，法官找的证人，法官给钱。这个考试里特别爱考，他会说“审判阶段啊，法官通知证人作证，那应当由检察院给补助”——就是错的。

好，咱们再往下这个第三，证人包括鉴定人、被害人，因为出庭作证，本人或其近亲属的人身安全面临危险的，法院呢应当采取不公开真实姓名等保护措施去保护他的一些安全。咱们前面其实也提到过，证人的安全应当得到保障，尤其是那个国控黑毒的那种案件，证人应该是主动保障人家，对吧？

但是注意一个细节，这里是**不包括见证人的**啊。就是不能说因为我是个见证人，所以请保证我的安全。我们保证的是证人的安全，见证人并没有目击案件事实，见证人一般也不会直接遭受犯罪分子的这个报复和侵害，因为见证人只是在目睹侦查人员的收集证据的活动和过程，是个旁证而已。所以咱们是保护证人，但不是保护见证人。这个注意即可。


**【主题十一：法庭调查——一般出庭规则（练习）】**

好，就看到这儿，下面做两个小练习吧。

第一个：在法庭审理过程中，被告人大俊申请法庭通知证人大漂亮出庭作证，法庭应当准许。是被告人想让谁来谁就来吗？不是，以申请出庭，法院要审查出庭的必要性的，不是百分百同意的。

下面第二：在庭审中，法官对一份鉴定意见产生质疑，有权通知有专门知识的人出庭对鉴定意见提出意见，可不可以？**可以**，你就记住，法官想让谁来就让谁来是可以的。所以第二题是对的。

好，这是出庭的方式，以申请和以职权啊。


**【主题十二：法庭调查——证人调查规则（可以不出庭的情形）】**

来，咱们再往下看。第三，叫**证人调查规则**，因为咱们在法庭调查当中啊，除了调查一些什么物证书证，其实最主要的是调查证人证言。待会儿还会讲再调查鉴定意见，这两个是重难点。

来，咱们先看怎么调查证人证言这块哈。括号一**可以不出庭**，这个不用背，只需要看看熟悉就行了。就是证人要出庭，什么时候他可以不来呢？你看这个一二三四：

圈一，他**严重疾病**；
第二呢，**住的比较远，交通还不便利**；
第三呢，**他在国外一时半会儿回不来**。

这时候他就可以不出庭了。但是这个什么住的远呀、在国外很简单。我想说的是，亲们，是不是因为住的远、身体不好、在国外，所以就不用作证了，就豁免了作证的义务是吗？**不是的**。在咱们国家，证人不可能被豁免作证的义务的，他只是**可以不出庭作证**。你说老师，那不出庭作证还怎么作证？你可以把你看到的证言写在纸上呀，你可以远程视频作证呀——只是你肉身可以不来而已，但不代表他可以不作证了。这个注意就行了。


**【主题十三：法庭调查——证人调查规则（证人拒不到庭的后果·核心考点）】**

好，咱们再往下看这个括号二，**证人拒不到庭的后果**。来，把括号二标重点符号，超级喜欢考啊，但是别害怕，不用背的，但它特别喜欢考。来，我们把这段话好好看一下哈。

经人民法院通知，证人没有正当理由不出庭作证的，**人民法院可以强制其到庭**，把他抓来。但是**被告人的配偶、父母、子女除外**。强制证人到庭的，应当由**院长签发强制证人出庭令**。

好，再往下，证人没有正当理由拒绝出庭，或出庭以后呢拒绝作证，咱们要**训诫**他。那么**情节严重**的，经院长批准，处**十天以下的拘留**。咱们说这个拘留不是刑事拘留了，这个叫司法拘留啊。

再往下，被处罚人对拘留决定不服的，可以**向上一级法院申请复议**。但是这个复议**不停止执行**。

好，这两段话要求大家得熟练，不用去背它。但是这两段话的可考的角度特别特别多。来，下面我慢慢的说，都用问答的方式，咱们把这两段话给他整透了哈。

来，第一，我来问你回答。法庭调查开始，如果经过法庭通知，向证人、鉴定人、专家辅助人等等，如果经过通知他拒不到庭，那法庭必要时是可以强制他们到庭的，对不对？**不对**。为什么？**只能强制证人**，不能强制被害人，不能强制鉴定人，不能强制侦查员等其他人——只能抓证人。你说老师，那鉴定人不来怎么办？不来就不来呗，不来大不了鉴定意见作废就是了。但是对鉴定人不能抓，也不能抓被害人。你说老师，被害人不来怎么办？咱们前面刚学过，不来就不来呗，反正被害人的控诉职能一般被检察院吸收了。所以咱们只能是强制证人，这是第一个点。

来继续哈，法庭调查开始，如果这个证人经过通知他就是不来的话，那咱们的法庭必要时可以**拘传**证人到庭怎么样？把他抓来嘛，拘传，对不对？**不行**。那改一下，那必要时咱们可以**强制传唤**证人到庭怎么样？强制传唤，抓来——**全错**。对证人前面讲过，对证人既不能拘传，也不能传唤。拘传针对的是被告人——是个强制措施；传唤针对当事人——但也不含证人。所以对证人一般叫**通知**。但是你不是要把他抓来，是根据什么呢？是根据法条写着呢，叫**强制证人出庭令**——咱们是靠这个命令把他抓来，但既不叫拘传，也不叫传唤。好，这个点把握好哈。

还没完，继续往下。如果法官签发了强制证人出庭令，要尽快叫**同级公安局**执行，把证人抓来，对不对？**不对**。这个命令不是叫公安局执行，而是叫法院中的**司法警察**，就是法警执行，不是公安执行。这是执行主体。把这个把握好。

来，再继续啊，再继续。法庭调查开始，注意听。法官发现本案**被害人**的妈妈，注意听着身份哈，被害人的母亲是个案件的关键目击者，是个证人。咱们通知被害人他们的妈妈出庭来作证，不知道出现什么情况，这个被害人他妈妈打死都不来，怎么都不来。那请问必要时咱们可以把他妈妈抓来，对不对？**对的，可以抓**。你说啊老师写着呢“被告人的配偶父母子女除外”啊，父母除外了啊——很好，考试中真这么干，他就读你被告人被害人啥啥分不清楚。刚才我说了好几遍，是**被害人**的妈妈，不是被告人的妈妈。那什么意思？**被害人他妈可以抓，被告人他妈不能抓**。你说啊老师，这是怎么会这样？不都是伟大的母亲吗？为什么会这样？

给你讲一下背后的原因，什么原因？为什么被告人的妈妈不能抓呢？是因为呀，我们是不希望在法庭上看到亲情撕裂的惨象。你想象一下，庭审开始了，被告人在那儿耷拉脑袋在那儿坐着呢，是不是？他的八十多岁的老母亲拄着拐杖被法警搀扶到法庭之上作证，对吧？他妈妈说：“法官大人，我养这儿子很不容易，但不要顾我的感受，把他判死刑吧。”是挺厉害，大义灭亲啊。你告诉我，给人的一种观感是什么？这是母亲撕儿子，或者爸爸撕女儿，女儿撕母亲，儿子撕爸爸，丈夫撕妻子——这干嘛呢？古代大家知道是不是有亲亲得相守呢，或亲亲相隐呢？所以咱们认为应当照顾这个至亲之间的亲情人伦关系，所以是**被告人的**配偶父母子女除外，而不是被害人的。为什么人家被告人的妈妈不想撕自己儿子，那被害人他妈还是有比较强烈的撕被告人的冲动的吧。所以被害人的母亲如果不来，是真的可以强制到庭的。注意看是被告人还是被害人呢？

来继续，考点角度很多啊，再来再来啊。请听，法庭调查开始，法官发现本案被告人他**姐姐**，是案件的关键目击者，咱们通知被告人的姐姐到庭，可能他姐姐为了保护他弟弟啊，打死都不来，咱们可以把他的姐姐抓来，怎么样？**可以**。你说哎不对，刚才不说除外配偶父母子女除外吗？是配偶父母子女除外，**不含兄弟姐妹**。那什么意思？说白了就是**第一继承顺位**的在里边，第二继承顺位或者现在咱们根据民法典，包括什么孙子女外孙子女都被排除出去了，是吧？所以我们只包括什么呢？**第一继承顺位的**，认为是最至亲的配偶父母子女除外，不含什么祖父母外祖父母啊，还有不含那个什么兄弟姐妹，这个必要时是可以抓的啊。

好，这是这个细节，别着急，还没完，再接着说啊。如果法庭通知证人到庭，而证人呢无正当理由拒不到庭，如果情节非常严重的话，经过院长决定可以拘留他**十五天**，怎么样？**错**。是拘**十天以下**的司法拘留，不是十五天，是十天啊。

好的，就把咱们刚才这些玩意儿，你可把握好，不用背。但是考试的时候，刚才这几个角度全都出现过，弄明白就可以不丢分了。好嘞，这个点咱们说到这里。


**【主题十四：法庭调查——证人调查规则（练习）】**

下面请翻到二百三十二页，二百三十二页包括这些细节和记忆逻辑都帮你讲明白了。咱们下面做几个小练习，我们试一试好吧？请看这个二百三十二页中间部分，这个测试题：

第一，大军因诈骗在县法院受审，法官通知大军的弟弟小军出庭作证，小军为了保护大军呢，无正当理由就是不来，法院可以强制小军到庭，把他弟弟抓来怎么样？咱们说**可以**，因为是配偶父母子女除外，但是**不含兄弟姐妹**的——好，兄弟姐妹是可以抓的。

来，再往下第二，大军因诈骗在县法院受审，法官通知大军的弟弟小军出庭作证，小军为了保护大军无正当理由就是不来，法院认为情节严重，经过院长决定对小军可以处十五天的司法拘留。咱们说这个**也不对**，是**十天**而不是十五天。

好，就大概这个意思理解就可以了。


**【主题十五：法庭调查——询问证人的规则】**

好，咱们就先做到这儿啊。那么往下看一个知识点，括号三**询问证人的规则**。那证人来了，咱们不得问他吗？请问谁先说话，谁先问啊？这个也喜欢考，不用背。

咱们看一下，证人出庭后啊，画一下，**一般先向法庭陈述证言**。什么意思？证人出庭不是马上先接受发问，先自己说一说，法官会问他：“证人，你可以把你当时了解的案情先说一说吗？”他先自己描述一下，先说一遍。

那么说完了以后呢，往后看。然后经过审判长许可，**由申请通知证人出庭的一方发问**。发问完毕后呢，对方也能问。就看到这儿。什么意思？**谁找的证人，谁先问**。这一边不是完全遵循像大家说的，不管是谁找的证人都是得公诉人先问——不是这样的。我们知道要先控后辩，这个没错。但是谁找的证人，谁先发问。

当然可能说老师，那如果万一是辩护人找的证人，那不就辩护人先发问，这不违背了先控后辩吗？先说到这儿，我就跟你讲一下，**根本不违背先控后辩**。为什么这么讲？同学们抬头看一眼，咱们说这个举证是先控方然后后辩方，是这意思吧？那么先是先控方举证，现在等于话筒在人家控方这儿呢，就是发言权在这儿呢。那这种情况下他可以发言，所以他有可能怎么样呢？请求证人出庭，请证人出庭，这叫什么？这叫**控方证人**。也就是人家公诉人举证出示了一个控方证人，当然是人家控方先问，是人家的证人啊，能理解吧？

那过一会儿听我说。那么等控方把各种证据出示完了，人家没证据了，是不是才轮到你辩方说话呢？是不是后辩啊？这时候话筒才传到你辩方这儿了，是该你说话了。所以这时候你有可能请证人出庭，这时候叫什么证人？这时候叫**辩方证人**，对吧？那么既然能让你辩方找证人来，证明现在话筒在你这儿呢，已经轮到你说话了。既然轮到你说话，当然是你先问了，它是不违背大的先控后辩的规则的，理解了哈？

好的，所以回到咱们刚才这个知识点，总之两个细节什么呢？第一个**证人出庭之后并不是马上接受发问，他先自己说说**，这是第一点。第二点，如果接受发问是谁先问呢？**谁找的谁先问**——控方证人控方先问，辩方证人辩方先问，就这意思。好，理解即可。


**【主题十六：法庭调查——询问证人规则（练习）】**

我们再往下说。啊，下面咱们翻到二百三十三页上方有一道题，我们试一下啊：证人出庭后呢，应当首先由提请通知的一方发问，再由对方发问，这个对吗？咱们说**不对**啊，为什么呢？证人来了并不是马上就接受发问的，他一般先自我做个陈述，然后再接受谁申请的谁先问。所以这道题是错的。

**【主题二十一：法庭调查——其他调查规则（证据偷袭）】**

好的，呃，下面咱们看第五点，翻到二百三十四页，就是一些**其他的调查规则**。等于刚才咱们讲的是怎么调查证人证言、怎么调查鉴定意见。下面呢，除了证言和鉴定意见，还有一些其他的证据可能也需要调查，咱们把它汇总在一起了啊。也没有需要背的，主要是理解熟悉的。

咱们看第一个，**控辩双方证据偷袭**——啥叫证据偷袭来着？请看，公诉人申请出示**开庭前未移送人民法院**的证据——什么叫要出示一个未送到法院的证据啊？如果公诉人把证据都移送到法院，我们知道辩护人是拥有阅卷权的，也就意味着咱们到法院是能查阅到这些证据，是可以阅卷的。那了解了证据，咱们根据证据是不是形成制作自己的辩护思路和策略，对吧？结果呢，到了庭审中，他突然拿出来一个咱们见都没见过的证据，这不是出其不意吗？这叫证据的偷袭了。

来再往后，辩护方提出**需要对新证据做辩护准备**的——好，既然我挡不住他，你让他出示了，但是这个新证据我从来没见过，没做过辩护的准备，那咱们可以申请法庭说能不能给我几天时间。来往后，法庭**可以宣布休庭**，那咱们可以晚几天开庭呗，给你准备时间，并确定准备辩护的合理时间。

**【主题二十二：法庭调查——其他调查规则（法庭调取证据须质证等）】**

好，再往下看，第二个**法庭调取的证据也应质证**。哎，这个点是什么意思来着？来往右看，对公诉人、当事人及法代、辩护人、诉代补充的——这不重要，是后边这半句啊——**审判人员庭外调查核实取得的证据，应当经过当庭质证，才能成为定案的根据**。就画在这儿。

这点是和民诉法很大的区别：在民诉法里，如果一个证据不是原告被告拿出来的，是法官依职权自己调取的，那么对这个证据法庭就直接认定就行了；但在刑诉法里**不允许**，哪怕这个证据不是控辩双方拿出来的，是法官找来的，那对这个证据原则上也得拿到法庭上听取双方的辩论意见，也就是**质证为原则**。啊，好很简单。

但考点是什么？考点是**法院不可要求检察院补侦**，这是绝对不行的。为什么？因为法院受制于被动消极中立、不告不理。那证据不足，不足就不足呗，不足怎么了？不足大不了**疑罪从无**呗。你不能说检察官，你证据不够啊，来快点快点，快去补侦，赶紧补侦，要不然咱弄不死他——那不相当于控审不分吗？所以你充其量能建议他，你说我建议你看能不能补一下，你这证据不行，但是**不能要求命令**他去补侦。注意即可。

好，就说到这儿啊。那么再往下看，有一个测试题咱们做一下：检察院建议法庭延期审理的，合议庭应当同意。哎，就是刚才讲的，是不是检察院想延期就他说了算呀？**不是的**，到底同意不同意，法院说了算，也可以同意，也可以不同意啊。


**【主题二十四：法庭调查——其他调查规则（发现新的量刑证据）】**

来再往下，第五，**发现新的量刑证据的处理**，这个确实考过，所以咱们不用背。但是咱们说一下它的区分啊，请看有两段话：

第一段，审判期间，合议庭发现被告人可能有自首、坦白、立功等法定的一些什么情节——量刑相关的情节。但是检察院移送的材料中呢，没有相关的材料，就是漏了。那咱们**应当通知检察院**，你再指定时间，你给我**补充移送**过来呗，拿过来。

再往下第二段，审判期间**被告人提出新的立功线索**的，就是原来没有是新东西。那法院**可以建议检察院补充侦查**。

那这个玩意儿他会怎么考呢？来，我画个图你就知道了，他就看同样是因为发生什么事儿了，就是遗漏了一些新的有关的量刑的材料吧。自首立功和量刑相关是遗漏了。那么如果发现有遗漏，咱们该怎么办？注意你得看**是谁发现的**：

如果是**合议庭主动发现**的，合议庭发现检察院遗漏了，该给我拿过来你没拿过来怎么办？——叫**应当通知补充移送**。

但如果是**被告人提出**的，不是合议庭发现的——是**可以建议补充侦查**。

哎，完全这仨词都不一样【修正：讲稿原文中讲授者对比了“应当/可以”“通知/建议”“移送/补侦”三组对应关系】，请做好区分。考试就会考——说合议庭如果在庭审中突然发现公诉人该移交一些自首立功的量刑材料没有移送，那咱们可以建议检察院补充侦查，对吗？**就不对**。所以把握好它的对应关系就可以了。好这个熟悉就行啊。


**【主题二十五：法庭调查——其他调查规则（当庭认罪认罚）】**

好，这个点咱们就说到这里，下面翻到第二百三十五页往上看，还有一个第六，**被告人当庭认罪认罚怎么办**，也很简单。

看看：被告人在侦查、审查起诉阶段没有认罪认罚，**但当庭认罪**——什么意思，之前不认罪，当庭突然反悔他认了——那往下看，那么愿意接受处罚的法院怎么办？**应当根据查明的事实，就定罪和量刑听取双方的意见，依法作出裁判**。

什么考点呢？就是第一点啊，既然庭前不认罪，庭审中认罪，咱们早就学过，这还能不能给他从宽呀？**可以的**，因为关键是看庭审阶段的态度，如果真诚悔罪可以从宽——这是第一点。

第二点，同学们如果当庭认罪认罚，之前不认怎么就认了呢？来，休庭，先中断下来，咱们聊一聊——**用不用休庭？不用休庭**。这考过，说认罪认罚咱们就休庭——没这说法，**不用休庭**。他认了你就按照他认的这个方式，咱们当场调查不就得了吗？看他是不是自愿的、真实的、合法的；如果是自愿的，根据现存证据咱们给他从宽就行了——这个不是休庭的法定理由。这个是当熟悉就可以了。


**【主题二十六：法庭调查——总结】**

好的，咱们总结一下。内容刚才学了不少，但都不需要背的。来咱们看着这个结构总结，大家来看大屏幕，咱们学了庭前审查，然后学了庭审五步，咱们学的刚才是叫**法庭调查**，没问题吧？

来同学们告诉我法庭调查里咱们重点学了什么呀？

来第一个是**一般的发问规则**对吧，发问是三个先后——注意是什么来着？是**先说后问、先控后辩、先言后物**，对吧？

第二个呢是**一般的出庭规则**，就有关证人鉴定人是非得来吗？要么一申请，要么一职权，对不对？

另外咱们学了**调查证人证言那些规则**——就是证人必须出庭吗？如果他不来，能不能抓呀？对吧？证人来了，谁先说话谁后说话，谁先问呢？这是关于证人的规则。

另外咱们学了一个**鉴定人的规则**，比如说鉴定人如果让他来他就是不来，鉴定意见还能不能用啊？对吧？如果有人要申请重新鉴定，行不行啊？那针对一个鉴定意见，找几个专家可以发表质疑呢？这是相关的程序。

另外一个是什么？就是咱们说的是**其他方面啦**——其他的一些证据调查规则，比如说控方证据偷袭咱们该怎么办呢？对吧？再比如说这个法庭自己庭外调取的证据，要不要质证啊？等等的一些细节吧。
