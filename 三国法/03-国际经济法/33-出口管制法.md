# 一、讲稿知识点的提纲

> **使用说明**：以下提纲基于讲稿内容整理，关键术语和法条依据已结合《中华人民共和国出口管制法》（2020年10月17日通过，2020年12月1日起施行）进行核对与补充。


## （一）出口管制法在法考中的定位

- **“一法三条例”** ：法考中中国对外贸易管理法律制度要求掌握**一法三条例**——一法即《出口管制法》（2020年出台，纳入大纲）；三条例即反倾销条例、反补贴条例、保障措施条例。
- **对外贸易法**：自2023年取消外贸主体资格限制后，对外贸易法不再具有可考点。


## （二）适用范围

### 1. 客体适用范围——管制什么

- 出口管制法适用于与**管制物项**相关的**货物、技术和服务**的出口。
  - **注意**：不能因为法律叫“出口管制法”就以为只管“货物”出口，技术和服务也在管制范围内。
- **管制物项**包括：
  - **两用物项**：既有民事用途，又有军事用途或者有助于提升军事潜力，特别是可以用于设计、开发、生产或者使用大规模杀伤性武器及其运载工具的货物、技术和服务。
  - **军品**：用于军事目的的装备、专用生产设备以及其他相关货物、技术和服务。
  - **核**：核材料、核设备、反应堆用非核材料以及相关技术和服务。
  - **其他**与维护国家安全和利益、履行防扩散等国际义务相关的物项。
- 管制物项还包括物项相关的**技术资料等数据**。

### 2. 行为适用范围——什么行为受管制

- **出口**：从中国境内向境外转移管制物项。
- 中国公民、法人和非法人组织向外国组织和个人提供管制物项。
- **过境、转运、通运、再出口**：管制物项的过境、转运、通运、再出口，同样适用出口管制法。
  - **注释**：“过境”指由境外启运，通过中国境内陆路向境外运输；“转运”指由境外启运在中国境内换装运输工具后运往境外；“通运”指由船舶、航空器载运进境并由原装运输工具载运出境；“再出口”指由境外运至中国境内、在中国境内停留但未进入市场流通、后再被运至境外。
- 从海关特殊监管区域和保税监管场所向境外出口。

**例题**：某中国企业拟向境外出口一批可用于制造导弹零部件的机床设备（两用物项），同时附带提供设备安装调试的技术服务。问：该出口行为是否受《出口管制法》调整？

**分析**：受调整。因为（1）该机床设备属于两用物项（既有民事用途又有军事用途）；（2）出口不仅包括货物本身，还包括相关的技术服务，均在管制范围内。


## （三）管制制度

### 1. 清单为基础的出口许可证制度

国家实行统一的出口管制制度，通过制定管制清单、实施出口许可等方式进行管理。

#### （1）三种清单

| 清单类型 | 说明 |
|---------|------|
| **出口管制清单**（常规清单） | 商务部公布，一般每五年调整一次。凡列入该清单的即为管制物项，出口须申请许可证。 |
| **临时管制清单** | 对管制清单以外的物项实施临时管制，有效期**不超过二年**。期满前评估，决定取消、延长（每次不超过2年，延长不超过2次）或列入常规清单。 |
| **禁止出口清单**（黑名单） | 禁止相关管制物项出口，或禁止向特定目的国家和地区、特定组织和个人出口。 |

#### （2）许可申请的触发情形

- 出口管制清单所列管制物项或临时管制物项 → 必须申请许可。
- 清单之外的货物、技术和服务，出口经营者**知道或应当知道**存在以下风险的，也应申请许可：
  - 危害国家安全和利益；
  - 被用于设计、开发、生产或使用大规模杀伤性武器及其运载工具；
  - 被用于恐怖主义目的。

**例题**：某物质已被列入出口管制清单，企业欲出口该物质。问：企业应当如何操作？

**分析**：应当向国家出口管制管理部门申请出口许可证。如果该物质被列入禁止出口清单，则无法获得许可证。

### 2. 最终用户和最终用途的风险管理制度

- **含义**：是否颁发许可证，需**个案审查**——评估将管制物项出口给特定国家、地区、组织或个人是否危害中国的国家安全、主权、社会公共利益等。
- **两个环节**：
  - **颁发许可证前**：风险评估——出口经营者须说明并证明最终用户是谁、最终用途是什么。
  - **颁发许可证后**：核查——追踪确认是否用于承诺的最终用户和最终用途。
- 擅自改变最终用户或用途、向第三国再出口再转让的，相关组织或个人可能被列入**黑名单**。

### 3. 军品出口的特别管制（管制最严格）

- **出口专营制度**：从事军品出口的经营者，须获得**军品出口专营资格**并在核定经营范围内经营。
- **出口许可证制度**：军品出口前，须**申领军品出口许可证**。
  - **注释**：军品出口实行“专营资格+个案许可”双重管控。核的出口同样实行专营制度；两用物项出口则无专营要求。


## （四）核心考点总结

出口管制法核心就两大方面【讲稿原文】：

| 方面 | 内容 |
|------|------|
| **管制什么** | 与管制物项（两用物项、军品、核等）相关的货物、技术、服务的出口 |
| **怎么管** | ①清单为基础的许可证制度；②最终用户/最终用途风险管理制度（评估+核查）；③军品最严（专营+许可证）|
