# 讲稿整理与知识点提炼

## 第一部分：讲稿知识点的提纲

### 主题一：法律原则与法律规则的总分关系

1. **基本等式**：法律规范 = 法律规则 + 法律原则
2. **总分关系**（核心理解）：
   - 原则 = 总体要求（"母"）
   - 规则 = 具体要求（"子"），是原则内容的具体化
   - 原则是"规则之母"，规则是原则内容的具体化
3. **例题（讲授者举例）** ：
   - 民法合同领域：合同双方协商一致可以订立、解除、变更、转让合同
   - 背后基础：意思自治基本原则
   - 说明：具体规则（协商一致的各种效力）是基本原则（意思自治）在合同各领域的具体表现
4. **命令性质的区别**：
   - 原则：**最佳化命令**（告诉你最好怎么办）
   - 规则：**确定性命令**（给你确定性指示）

### 主题二：法律原则的功能

1. **指导功能**：原则是规则的基础，任何对规则的理解都要服从原则的基本精神，指导规则的理解、实施和适用
2. **裁判功能**：在疑难案件中，法律原则可以作为案件裁判的依据

### 主题三：经典案例——李格斯诉帕尔默案（Riggs v. Palmer）

> **【讲授者明确提到的案例，需完整保留】**

- **时间地点**：1882年，美国纽约州
- **基本案情**：
  - 帕尔默（孙子/被告）是家族唯一的男性继承人，祖父是纽约州巨富，立遗嘱将全部遗产留给帕尔默
  - 祖父退休后环球旅行，邂逅年轻女子并准备再婚
  - 孙子帕尔默担心：（1）遗产份额因继祖母生活需要而减少；（2）继祖母可能生下新的男性继承人，导致自己唯一继承人地位不保
  - 帕尔默将祖父毒死，后被其姑姑李格斯告发
  - 刑事部分：谋杀罪成立，判终身监禁
  - 民事部分争议：帕尔默能否按照原遗嘱继承遗产？
- **两派意见**：
  - **格雷法官**（反对派）：遗嘱合法有效，应严格遵循遗嘱继承法规则，帕尔默应有继承权（"一码归一码"）
  - **厄尔法官**（主张派）：帕尔默的行为违反了一条法律原则——"**任何人不能从自己的过错行为中获益**"，应剥夺其继承权
- **最终结果**：厄尔法官一派意见占上风，帕尔默被剥夺继承权
- **该案的历史意义**：
  - 法律原则走进司法审判的"第一案"
  - 经过德沃金的反复论证，法律规范既包括规则也包括原则这一观点被法律界接受
  - 两个直接启发：（1）继承法中增加"继承人故意伤害被继承人或其近亲属的，丧失继承权"的规定；（2）提醒法律体系除了明确具体的规则外，还有相对宽泛的总体原则存在

> **注释**：讲授者提到的"任何人不能从自己的过错行为中获益"（No one shall profit from his own wrong）是一条重要的法律原则，在英美法系和大陆法系均有体现。此处案例涉及遗嘱继承与法定继承的关系，属于民法继承编范畴。

### 主题四：法律原则的分类

| 分类维度 | 类型 | 区分标准 | 举例 |
|---------|------|---------|------|
| 普遍性程度 | **公理性原则** | 普遍性程度高，放之四海而皆准，大多数国家和地区都有 | 法律面前人人平等、人民主权、意思自治、罪刑法定、依法行政 |
| | **政策原则** | 普遍性程度低，针对性强，仅特定国家和地区有 | 坚持党的领导、一国两制、计划生育（中国特有） |
| 覆盖面大小 | **基本原则** | 覆盖面大，多个法律部门共同适用 | 法律面前人人平等（民、刑共通） |
| | **具体原则** | 覆盖面相对小，特定领域适用 | 物权法定原则（仅物权领域） |
| 内容性质 | **实体性原则** | 与实体法相关，与诉讼无关 | 罪刑法定（刑法）、诚实信用（民法/行政法） |
| | **程序原则** | 诉讼中的基本要求 | 回避、谁主张谁举证、原告就被告、上诉不加刑、无罪推定 |

> **讲授者特别提示**：法律规则的分类考试频率远高于法律原则的分类，规则分类属于"必考知识点"。

### 主题五：法律规则与法律原则的区别（核心考点）

| 区别维度 | 法律规则 | 法律原则 |
|---------|---------|---------|
| **内容上** | 明确具体；**只针对行为的共性**（适用条件高度一般化） | 宽泛抽象；**既针对共性也针对个性**（能关照特殊情况） |
| **适用范围** | 小（只适用于某一类具体行为） | 大（覆盖更广领域） |
| **适用方式** | **全有全无**（all or nothing）；互斥关系，非此即彼 | **权衡强度/分量**；兼顾关系，可以同时考量 |

**具体阐释**：

1. **内容维度**（考试重点）：
   - 规则明确具体→只针对一类具有共性的行为（如故意杀人罪不论手段动机，只要符合构成要件即以故意杀人罪论处）
   - 原则宽泛抽象→既能针对共性也能针对个性
   - **核心推论**：原则能够实现对"个性"的关照，允许结合具体情况做具体判断
   - 疑难案件（"二般案件"）= 个性化因素很强的案件 → 需要用原则来处理

   > **【讲授者生活化例题】** ：复习要求对比——"早上八点到中午十二点，下午两点到六点，晚上七点半到十点四十必须复习理论法"（规则，明确具体，不照顾个性）vs "拿出足够多的时间复习理论法"（原则，宽泛抽象，可结合个人情况调整）。个性化的复习方案只能在原则下得到满足。最好的学习方案是"因材施教"——这就是原则作为"最佳化命令"的内涵。

2. **适用范围维度**：
   - 规则适用范围小 → 数量多（民法典一千多条）
   - 原则适用范围大 → 数量少（一个部门法几条即可覆盖所有领域）

3. **适用方式维度**（考试重点）：
   - **规则全有全无**：相互矛盾的规则不可能同时适用一个个案。例：同一行为不可能既是正当防卫又是故意杀人（罪与非罪互斥）。
   - **原则权衡强度**：两个原则冲突时可以同时考虑兼顾，按分量轻重权衡，分量轻的仍需兼顾。

   > **【讲授者生活化例题】** ：父母对在外上学的孩子提出两条原则性要求——"好好学习"和"保重身体"。两个要求需同时兼顾（以好好学习为主，兼顾保重身体），而非非此即彼。类比"多快好省建设社会主义"——多、快、好、省四条原则需要兼顾，操作中若只抓多和快而忽略好和省，会造成灾难。

### 主题六：如何判断一个法条是规则还是原则——"三看"标准

> **【讲授者明确提示：做题方法，需完整保留】**

| 判断标准 | 操作方法 |
|---------|---------|
| **一看内容** | 法条内容是否明确具体？还是宽泛抽象？适用范围窄还是宽？ |
| **二看位置** | 法条位置靠前还是靠后？（总分结构，原则靠前，规则靠后） |
| **三看部门法知识** | 熟悉部门法中的基本原则及其条文表述 |

**判断示例**：
- "合同双方协商一致可以变更合同" → 内容明确、范围窄 → 规则
- "民事活动应当遵守公序良俗" → 内容宽泛、范围广 → 原则

### 主题七：法律原则的适用条件（重点）

**基本逻辑**：规则压缩自由裁量权，原则放大自由裁量权。我们希望自由裁量权受到限制，因此原则适用需要严格条件，**规则优先适用，原则是"替补"** 。

#### 理论化表述（三个条件）：

| 序号 | 条件 | 含义 |
|------|------|------|
| 1 | **穷尽规则** | 找不到规则时，原则填补规则漏洞 |
| 2 | **个案正义** | 适用规则会导致不正义的裁判结果时，可用原则替代规则（初步理由） |
| 3 | **更强理由** | 必须充分论证（≠充分论证），说明为何在个案中用原则替代规则是恰当且必要的 |

#### 通俗化表述（两句话）：

| 情形 | 含义 | 对应理论 |
|------|------|---------|
| **规则不在** | 没有规则可用 | 穷尽规则 |
| **规则不行** | 有规则但适用结果不恰当 | 个案正义 + 更强理由 |

> **讲授者重要说明**：正义标准太模糊，如果法官可以轻易以自己所理解的"正义"为由抛弃规则，法律的确定性和稳定性将遭到严重破坏。例外越少越好——如果例外太多，原则和规则就颠倒了。

**讲授者补充案例——泸州遗赠案（"二奶继承案"）** ：
- 案情：男子死后将遗产留给"二奶"，原配起诉，法官以公序良俗原则否定遗嘱效力
- 影响：遗嘱继承领域的确定性秩序出现"裂缝"；公证遗嘱的效力受到质疑；全国范围内遗嘱公证业务量大幅下降
- 教训：为个案正义而创设规则例外需要极其慎重，必须充分论证

> **注释**：泸州遗赠案是中国司法实践中适用公序良俗原则的经典案例，属于民法继承编范畴。该案引发了关于"法官造法"、规则与原则关系、法律确定性与个案正义之间张力的广泛讨论。

### 主题八：法律权利与法律义务

#### 权利的特点（四个）：

1. **权利法定**（最核心）：任何法律权利的存在都要有明确法律依据
   - > **【讲授者例题——接吻权案件】** ：女士过马路遭遇车祸门牙被撞掉，安装假牙后影响接吻，起诉司机要求赔偿"接吻权"受损。法院判决败诉——法律中有身体权但没有"接吻权"，违反权利法定原则。
2. **自主性**：权利主体按自己愿望决定是否行为（行为模式为"可为"）
3. **利益性**：权利是为保护一定利益而设的法律手段
4. **关联性**：权利与义务相关联（无无权之义务，无无义务之权利）

#### 义务的特点：

1. 指向应然行为和未来行为（尚未做的行为）
   - > **例**：借500元，还钱义务存在于还钱之前——义务因履行而消失
2. 义务需要强制履行（不能放弃）

#### 权利和义务的分类：

| 分类标准 | 类型 | 说明 |
|---------|------|------|
| 规定主体 | **基本权利义务** | 宪法规定 |
| | **普通权利义务** | 宪法以外部门法规定 |
| 义务主体是否特定 | **绝对权（对世权）** | 义务主体不特定，如物权 |
| | **相对权（对人权）** | 义务主体特定，如债权 |
| 主体范围 | **个体权利义务** | 针对个人 |
| | **集体权利义务** | 针对群体 |
| | **国家权利义务** | 针对国家（国家一般称"权力"而非"权利"） |

> **注释**：讲授者在此处区分了"权利"（right）和"权力"（power）的概念，涉及法理学中权利与权力的关系问题，超出当前主题范畴但值得注意。

#### 权利与义务的关系（五个维度）：

| 维度 | 内容 |
|------|------|
| 结构上 | 紧密联系，相互对应 |
| 数量上 | **一一对应、总量相等**（针对社会整体，非个体） |
| 产生发展上 | 浑然一体（原始社会）→ 分裂对立（阶级社会早期，奴隶主享受权利、奴隶履行义务）→ 相对一致（社会主义社会，人民成为国家主人，权利与义务相一致） |
| 价值上 | 权利代表**自由**，义务代表**秩序** |

> **提示**：讲授者指出这部分"大概看一看就行"，主要凭部门法常识即可应对，但"权利法定"需要划重点。

### 【切片一】法律原则与法律规则的总分关系

那接下来我们就要强调的是法律原则。呃，我再次强调那个等式啊，法律规范等于法律规则加法律原则。法律规则代表的是其中一类东西，一种类型的法律规范，而法律原则是另外一种类型。

那当然这个时候就会有一个问题了：老师，那法律规则和法律原则之间是个啥关系呢？当然你可以看它的概念了，是吧？但是如果用最粗暴的语言来解释它们的关系的话，大家记住两个字就可以了：它俩什么关系呢？**总分关系**。

原则是个总体要求，规则是个具体要求，而这个具体要求是哪儿来的呢？就是把那个总体要求细化以后的结果。也可以形象地表达：**原则是规则之母，规则是原则内容的具体化**。

我们举个例子吧。比如说，你们在学到民法的时候，讲到合同部分的时候，老师会强调：法律当中规定，合同双方协商一致可以订立合同，合同双方协商一致可以解除合同，合同双方协商一致可以约定合同内容，合同双方协商一致可以变更合同内容，合同双方协商一致还可以转让合同权利。那为什么合同双方协商一致能干这么多事儿？为啥？因为有意思自治这个基本原则摆在这儿。后面那些内容都是意思自治这个基本原则在合同的订立、履行、解除领域当中的具体表现而已。

一个是总体要求，一个是具体要求。当我们把一个总体要求拆分细化以后，就带来了一个一个的具体要求。也就是说，把原则拆分之后就带来了规则。

但不管是规则还是原则，它们都是法律规范，它们都是我们应当服从的法律层面的要求。并且如果我们把规则和原则都视为是一种命令的话，那你要知道，这两种命令的性质是不一样的。**原则是一种最佳化命令**——把"最佳化命令"划上。而规则不是一种最佳化命令，而是一种**确定性命令**，它给你的是一个确定性的指示，而原则会告诉你最好怎么办。我在后面讲到法律规则和法律原则区别的时候，你就能够知道为什么原则是最佳化命令了。我们先在这打个基础。

---

### 【切片二】法律原则的功能

好了，这是这个问题——原则和规则的关系，就是一个总分关系。

那紧接着第二个问题呢，就是关于法律原则的功能、它的价值。它的价值呢，其实主要在于两个词：

第一个叫**指导**。因为原则是规则的基础嘛，任何对规则的理解都要服从原则的基本精神，原则可以指导规则的理解、实施和适用。总来指导分嘛，没问题。

第二个叫**裁判**。在一些特殊的案件，说得直白一点，就是在疑难案件当中，法律原则也可以成为案件裁判的依据，来应对疑难案件的处理需要。

两个东西：第一个是指导功能，第二个是裁判功能。我们后面还会再提到它。

### 【切片三】经典案例——李格斯诉帕尔默案（Riggs v. Palmer）

讲到这儿以后，你会发现我后面给大家引用了一个案例，叫**李格斯诉帕尔默案**。这个案件是非常有名的，也可以说这个案件是**法律原则走进司法审判的第一案**。也正是从这个案件以后——特别是经过德沃金的反复论证——法律规范既包括规则也包括原则这个现在看起来像是常识的东西，才真正被我们法律人去接受。所以说它非常重要。这个案件提示了我们法律原则的存在和法律原则的重要性。

大概案情非常简单：

这个案件首先发生在**1882年的美国纽约州**。它是一个很奇特的遗嘱继承案——里克斯诉帕尔默嘛，你一看就知道帕尔默是被告。但我要提醒你，帕尔默虽然是被告，但他可不是一个一般的被告。帕尔默是个富三代——他爷爷特别有钱，是当时纽约州的巨富。如果当时美国有福布斯排行榜的话，他爷爷杀到全美前五十问题不大。帕尔默这个孙子很幸福，一辈子也不用干啥事，就安静地当孙子。

并且帕尔默的祖父对帕尔默特别喜欢，原因非常简单——帕尔默是他们家族里头唯一的男性继承人。李格斯是他姑姑，他爹死得早，他就成了他们家独苗。老外也重男轻女。并且生前的时候，他祖父就给帕尔默大量的零花钱，让他过得很滋润，并且很早的时候就立下了遗嘱：死了以后，遗产全部都留给这个孙子。

**[此处插入背景]** 正常来讲这是一个富三代很乏味的故事，但是后面有了波澜。这个老头立完遗嘱以后，从自己创办的企业退休了，开始享受晚年生活。他是个巨富，享受生活的方式和一般人不一样——开启了环球旅行。结果在旅行过程当中邂逅了一个年轻貌美的姑娘。老头焕发第二春了，准备和这个姑娘结婚。

喜讯传到家乡以后，大多数人都很开心，只有一个人不开心——就是这个孙子帕尔默。这个孙子经过评估以后发现，爷爷再婚这件事对他百害而无一利：

第一，他爷爷和这个小奶奶岁数差别太大（二十八 vs 八十二），肯定爷爷先走。爷爷走了以后小奶奶还要生活，生活就得花钱，钱从遗产里出，所以他的遗产份额会减少。

第二，万一爷爷和小奶奶再生个孩子，给他搞出个小叔叔来，他唯一男性继承人的地位就不保了。

这个孙子越想越紧张，越想越害怕，最后干了一件丧心病狂的事——**把他爷爷给毒死了**。**[修正]** 他把他爷爷干掉以后，事儿还办得不利索，被发现了，被他姑姑李格斯告发了。

对这个案件的审判分两个部分：

- **刑事部分**没啥好说的——谋杀罪成立，被判终身监禁。
- **民事部分**比较有争议：帕尔默把他祖父毒死了，还能不能按照之前已经订立的遗嘱继续继承遗产？

**[修正]** 我要提醒你，这个案件在当前的中国、当前的美国，在大多数国家都不是问题，因为我们现在的继承法当中都会有一个规定：如果继承人故意伤害被继承人或其近亲属，自动丧失继承权。但是这个案件是在一百多年前，这个规定是在这个案件以后才加上的，当时可没有这样的例外情况。按照当时的纽约州法律，老头所订立的遗嘱就是一个合法有效的遗嘱，帕尔默就应该有继承权。

围绕这个案件的审判，法官意见分成两派：

- **格雷法官**为代表的一派认为：一码归一码，刑事部分已经判了终身监禁，但遗嘱是当事人当时真实的意思表示，没有任何更改的迹象，钱该给他还是给他。得严格遵守遗嘱，你不能违反法律的规定。

- **厄尔法官**为代表的一派认为：帕尔默的行为虽然依照遗嘱继承法的规则有继承权，但他的行为却违反了一条法律原则、一条总体的法律精神——叫做"**任何人都不能从自己的过错行为当中获益**"。违法行为不可能产生合法收益。帕尔默谋杀祖父是违法行为，如果因为违法行为导致他能够继承遗产，那就产生了合法收益，这是矛盾的。

最终厄尔法官这一派的意见占了上风，以"任何人不能从自己的过错行为当中获益"这个原则为由，剥夺了帕尔默的继承权。最后这哥们儿人财两空。

自打这个案件以后，有两个直接启发：

1. 提醒我们**不能低估人性的恶**。所以说后来继承法当中都会加这么一条——如果继承人故意伤害被继承人或其近亲属，自动丧失继承权。
2. 提醒我们在法律体系当中，除了有非常确定的、明确的、具体的、详细的、细致的规则以外，还有**相对宽泛的总体的原则**存在。

这就是法律原则适用的第一案。我们后面可能还会用到这个案件，大家有一个大概的了解。这个案件毫无疑问是非常有名的。

### 【切片四】法律原则的分类

好了，明白了这个事儿以后，接下来我们来看法律原则所涉及到的具体的知识点。

首先第一个知识点相对比较简单，叫做**法律原则的分类**。我们刚才讲过规则的分类，现在又说原则的分类。我提醒你一下，从备考考试的角度来讲，**法律规则的分类**要相对更加重要，原则的分类没有规则分类考试频率那么高，但是也得把握。它很简单，听一下就可以了。

#### 分类一：公理性原则 vs 政策原则

区分标准——**普遍性**程度。

**公理性原则**：普遍性程度比较高，中国有、外国有，放之四海而皆准。你只要有法律，就会有这样的要求。
- 你只要有现代的宪法，就一定会有人民主权
- 你只要有民法，就会有意思自治
- 你只要有刑法，就会有罪刑法定
- 你只要有行政法，就会有依法行政

**政策原则**：普遍性程度比较低。政策强调的不是普遍性，而是**针对性**，要因时因地解决具体问题。只有某个特定的国家和地区才有。

举例：
- 公理原则：法律面前人人平等
- 政策原则：坚持党的领导、一国两制、计划生育

**[关于计划生育原则的详细论述]**
老师，咱们中国现在还有计划生育原则吗？现在都放开三胎了，生四五个都没关系了。但我要告诉大家——**依然是有计划生育的**。计划生育的宪法表达是"使得人口的增长同社会经济的发展相适应"。计划生育的重点不在于生育、不在于生几个，而在于**国家对你生育这件事是有介入的**。

人口过多时，计划生育体现为对生育的抑制；人口较少时，体现为对生育的强制或鼓励。国家会有各种各样的方式引导——舆论层面的引导、延长产假、加强生育补贴、降低婚育门槛等。未来这种压力会变得更加直接。什么时候才没有计划生育呢？很简单——国家在生育问题上完全不介入，没有积极正面的鼓励，也没有反向消极的限制。但不管怎么样，我们现在依然是有计划生育的。

#### 分类二：基本原则 vs 具体原则

区分标准——**覆盖面**大小。这是个相对标准。

覆盖面大的叫基本原则（多个法律部门都有），覆盖面相对小的叫具体原则。

- 法律面前人人平等 → 民法、刑法都有 → 基本原则
- 物权法定原则 → 仅物权领域 → 具体原则
- 诚实信用原则 → 物权、合同、婚姻、继承所有民事活动都要遵循 → 民法中的基本原则

#### 分类三：实体性原则 vs 程序原则

区分标准——是否和诉讼有关。

- 实体性原则：实体法上的要求，和诉讼无关 → 罪刑法定、诚实信用
- 程序原则：诉讼中的基本要求 → 回避、谁主张谁举证、原告就被告、上诉不加刑、无罪推定

**[再次强调]** 法律规则的分类考试频率比原则的分类高得多得多，规则分类可以理解为必考知识点。

### 【切片五】法律规则与法律原则的区别（核心重点）

接下来第二个问题，是关于**法律规则和法律原则的区别**。这应该说是法律原则当中相对比较重要的知识点，难度也会相对更大。总共涉及到三点区别：

#### 区别一：内容上——规则明确具体 vs 原则宽泛抽象

最精简的表述：**规则明确具体，原则宽泛抽象**。

规则是相对比较细致的要求（确定性命令），原则是偏向于笼统的、宏观的、相对模糊的要求（最佳化命令）。

**[核心推论——考试重点]**

正是因为规则明确具体，所以规则**只针对一类具有共性的行为**，或者说它针对行为的共性。

也正是因为原则宽泛抽象，所以原则**既能够针对行为的共性，也能够针对行为的个性**。

**简记：规则明确具体只共性，原则宽泛抽象共性加个性。**

解释为什么规则只针对共性：规则所设定的适用条件是高度一般化的，具有普遍适用性。比如故意杀人罪这个规则，不管你是张三杀李四还是王五杀赵六，不管你是情杀仇杀还是变态杀人，不管你是拿刀捅、拿斧头剁、拿车撞还是拿毒药毒，只要符合故意杀人罪所设定的构成要件，通通以故意杀人罪论处。它的条件高度一般化，不会因人而异。

解释为什么原则能关照个性：正是因为原则在内容上宽泛抽象、很模糊，给了我们比较大的选择空间，可以结合具体情况做出具体判断。

**【讲授者生活化例题——复习要求的对比】**

假如说有两个关于理论法的复习要求：

- **要求一**：理论法非常重要，从明天开始，早上八点到中午十二点、下午两点到六点、晚上七点半到十点四十，必须复习理论法。
- **要求二**：理论法非常重要，从明天开始，要拿出足够多的时间来复习理论法。

哪个是规则？哪个是原则？很明显要求一是规则（明确具体），要求二是原则（宽泛抽象）。

每个人的复习基础、对学科的敏感度都不一样，个性化的复习需求只有在宽泛抽象的原则之下才能得到满足——前面规则说得太死，条件太具体，没有选择空间；后面原则告诉你要"足够多的时间"，可以具体问题具体分析，结合自己情况判断。

这就是**原则能够实现对个性关照的原因**。

**[进一步推论]**

最好的学习方案永远是四个字——**因材施教**。贴合个性打造的方案效果最好。这也是为什么原则是最佳化命令——所谓"最佳"就是能够实现在具体情况当中的最佳权衡。

**[与司法审判的关联]**

常规案件用规则，疑难案件用原则。疑难案件就是"二般案件"——情况特殊的案件、个性化因素很强的案件。原则能够针对疑难案件审判，就是因为它能实现对特殊情况的关照。

**总结区别一：规则明确具体只共性，原则宽泛抽象共性加个性，特别是原则能够实现对个性的关照——这个点大家尤其注意。**

#### 区别二：适用范围上——规则小 vs 原则大

规则内容明确具体 → 适用范围小，只适用于某一类具体的行为。
原则宽泛抽象 → 适用范围更大。

故意杀人罪这个规则只针对故意杀人行为，抢劫强奸一概不管。但罪刑法定这个原则，不管刑法分则任何罪名的适用，都需要服从罪刑法定的基本精神。

这也可以解释为什么一个部门法当中规则数量很多而原则数量很少——原则适用范围大，只要有几条原则就能把所有需要调整的领域都覆盖到；规则适用范围小，范围不够，数量来凑。

#### 区别三：适用方式上——规则全有全无 vs 原则权衡强度/分量

**规则——全有全无（all or nothing）**

要用这个规则就全都用，要不用就全都不用。两个相互矛盾的规则不可能同时适用一个个案。

例：张三把李四捅死了，这件事不可能既是正当防卫又是故意杀人——罪和非罪不可能同时成立。这就是互斥关系，有A就不能有B，有B就不能有A。

**原则——权衡强度/分量**

两个原则发生矛盾时，不是互相排斥，而是可以同时考虑兼顾的。原则本身有分量的轻重之分，发生竞争时要权衡哪个分量重、哪个分量轻，按分量重的去行动。但分量轻不代表没分量，还是要考虑它的要求，要兼顾。

**【讲授者生活化例题——好好学习 vs 保重身体】**

父母对孩子提出两条原则性要求："好好学习"和"保重身体"。这两条都是宽泛模糊的原则性要求。

父母的意思是希望两个要求**同时考虑**，以好好学习为主，兼顾保重身体。原则性的要求必须兼顾。如果非此即彼地处理——天天学习搞坏身体，或者天天保重身体啥都没学到——对个人而言都是灾难。

**类比"多快好省建设社会主义"** ：多、快、好、省四条原则需要兼顾。但由于"好"和"省"太模糊，操作中相对清楚的是"多"和"快"，后两项原则没兼顾，造成国民经济灾难。

原则能否兼顾看似矛盾的原则性要求，是检验一个人成熟程度的标志。马克思曾经说过：一个人是否成熟的标志，在于看他头脑当中能不能容纳两个互相矛盾的思想。

### 【切片六】判断规则与原则的"三看"标准

讲完了规则和原则的几点区别以后，大家可能对差异有了更清楚的认识。但如果让你做题，可能还是需要更清晰的判断标准。在过去的真题中经常有一种题目：给你一个法条，让你判断它表达的到底是规则还是原则。

怎么具体判断？三个参考标准——**"三看"**，可以同时考虑：

| 标准 | 操作方法 |
|------|---------|
| **一看内容** | 法条内容是否足够清晰、明确具体？还是宽泛抽象？适用范围窄还是宽？ |
| **二看位置** | 看法条序号靠前还是靠后？多数法律遵循"总分结构"，原则靠前、规则靠后 |
| **三看部门法知识** | 熟悉部门法中的基本原则有哪些、条文如何表达，对照判断 |

**判断示例：**
- "合同双方协商一致可以订立合同/变更合同" → 内容清晰、范围窄 → 规则
- "民事活动应当遵守公序良俗/善良风俗" → 宽泛模糊、所有民事活动都要遵守 → 原则

**[强调]** 三个标准可以同时考量。

### 【切片七】法律原则的适用条件

**[讲授者详细讲授——重点]**

为什么强调原则的适用条件而不特别强调规则的适用条件？因为规则明确具体，条件本身就很清晰；原则宽泛抽象、比较模糊。

明确具体的要求压缩自由裁量权，宽泛抽象的要求放大自由裁量权。我们当然是希望法官的自由裁量空间**越小越好**——如果越大越好，那就意味着"法官想怎么判就怎么判是最好的"，这是我们无法接受的。

因此结论：**出于限制自由裁量权的考量，必须给法律原则的适用设定严格条件。规则优先适用，原则是"替补"，而且替补出场要有严格条件。**

#### 理论化表述（三个条件）：

| 条件 | 含义 |
|------|------|
| **穷尽规则** | 找不着规则的情况下，才可考虑原则。原则发挥填补规则漏洞的功能 |
| **个案正义** | 有规则但适用规则导致不正义的裁判结果——有了用原则替代规则的初步理由 |
| **更强理由** | 仅有"个案正义"不够，还必须充分论证：这样的选择为什么是恰当的、必要的 |

#### 通俗化表述（两句话）：

| 情形 | 含义 |
|------|------|
| **规则不在** | 没有规则可用 → 穷尽规则（原则填补漏洞） |
| **规则不行** | 有规则但适用结果不恰当 → 个案正义 + 更强理由（原则替代规则） |

#### 为什么需要"更强理由"（充分论证）？

"正义"这个标准太模糊了——不同的人可以有完全不同的理解。如果法官可以轻易以自己所理解的"正义"为由去抛弃一个法律规则，法律的确定性、稳定性将遭到严重破坏。

法官用原则替代规则，实际上就是为这个规则创造了"例外"。例外**越少越好**——例外太多，原则变成例外、例外变成原则，就颠倒了。

> **规则在99.99%的个案中都能实现正义裁判结果，不能为了0.01%的特殊个案轻易破坏规则的权威性。**

#### 讲授者补充案例——泸州遗赠案（"二奶继承案"）

你们学民法的时候老师肯定讲过——四川那个"二奶继承案"。一个男的死了，把遗产留给"二奶"，原配起诉到法院，法官以公序良俗原则判决遗嘱无效，否定了"小三"的继承资格。

这个案件的法官就是用公序良俗原则给"遗嘱继承优先于法定继承"创造了一个例外。这个案件潜在影响非常大：

1. 过去订立遗嘱时，只要保证形式合法、意思表示真实，就能自信遗产会按意愿分配。但自打这个案件以后，订立遗嘱时不得不多考虑——谁知道法官会不会以模糊的公序良俗标准否定遗嘱？
2. 那个男子的遗嘱是经过公证的。公证遗嘱都可以被否定，没公证的效力更可疑；公证本身的意义也受到质疑。
3. 自打那个案件以后，全国范围内遗嘱公证业务量**大幅降低**。

一个规则一旦被创设了例外，有了裂缝，带来的潜在影响可能远超想象。所以我们必须在绝大多数案件中有效维护规则及其带来的秩序，不能轻易否定。

**结论：个案正义是原则替代规则的初步理由，更强理由（充分论证）是附加条件，二者同时成立，原则才能替代规则。**

### 【切片八】法律权利与法律义务

**[讲授者提示：这部分相对简单，主要凭部门法常识即可应对]**

最后一个关于法的要素的问题——**法律权利和法律义务**。

#### 权利的特点（四个）：

1. **权利法定**（最核心）：任何法律权利的存在都要有明确法律依据，得到国家认可和保障
   - > **例题——"接吻权案件"（真题）** ：一位女士过马路遭遇车祸，门牙被撞掉，安装假牙后影响接吻。她起诉司机要求赔偿"接吻权"受损。如果你是法官会不会支持？不会。因为法律中有身体权，但**没有"接吻权"**——违反权利法定原则。判决败诉。
2. **自主性**：权利主体按自己愿望决定是否行为（行为模式为"可为"），权利可以放弃
3. **利益性**：权利是为保护一定利益而设的法律手段
4. **关联性**：权利与义务相关联——没有无权利的义务，也没有无义务的权利

#### 义务的特点（两个）：

1. 义务指向**应然行为和未来行为**（尚未做的行为）
   - 例：借500块钱，还钱的义务存在于还钱**之前**。钱还完了，义务就消失了。
2. 义务**需要强制履行**（不能放弃）

#### 权利和义务的分类：

| 分类标准 | 类型 | 说明 |
|---------|------|------|
| 规定主体 | 基本权利义务 | 宪法中规定 |
| | 普通权利义务 | 宪法以外部门法规定 |
| 义务主体是否特定 | 绝对权（对世权） | 义务主体不特定，如**物权** |
| | 相对权（对人权） | 义务主体特定，如**债权** |
| 主体范围 | 个体权利义务 | 针对个人 |
| | 集体权利义务 | 针对群体 |
| | 国家权利义务 | 针对国家（国家称"权力"而非"权利"） |

> **[注释]** 此处讲授者区分了"权利"（right）和"权力"（power）的概念，属于法理学中权利与权力关系的范畴。

#### 权利与义务的关系（五个维度）：

| 维度 | 内容 |
|------|------|
| 结构上 | 紧密联系，相互对应 |
| 数量上 | 一一对应，**总量相等**（针对**社会整体**，非个体） |
| 产生发展 | 浑然一体（原始社会）→ 分裂对立（阶级社会早期，奴隶主享受权利、奴隶履行义务）→ 相对一致（社会主义社会，人民成主人） |
| 价值上 | 权利代表**自由**，义务代表**秩序** |

> **[提示]** 讲授者指出这部分"大概看一看就行"，主要凭部门法常识即可应对，但**权利法定必须划上，要有深刻印象**。

### 【切片九】例题讲解

#### 第一题

> 贾和乙是夫妻，因外出打工将女儿小林交给贾母照顾两年，但从来没支付过抚养费。后来甲乙闹离婚，都不愿意抚养小林。贾母把甲乙告上法庭，要求支付抚养费两万元。法院认为贾母对孙女没有约定或法定的抚养义务，但因小林父母健在且不抚养，判决甲乙支付贾母抚养费。关于该案，下列哪一项是正确的？

**选项分析：**

A. 判决是规范性法律文件
- **[修正]** 错。判决书是典型的**非规范性法律文件**——针对特定对象（当事人）有效。民法典、刑法典才是规范性法律文件（针对不特定一般人）。

B. 甲乙对小林的抚养义务是相对义务
- **[讲授者分析]** 父母对子女的抚养义务针对特定对象（子女），义务主体特定 → **相对义务**（正确）

C. 判决在原被告之间不形成法律权利和法律义务
- **[修正]** 错。判决后甲乙要支付两万抚养费（义务），贾母有领取抚养费的权利（权利）。

D. 小林是民事诉讼法律关系主体
- **[修正]** 错。诉讼中原告是贾母，被告是甲乙，小林未参与诉讼，不是诉讼参与主体。

#### 第二题

> 下列哪一项属于积极义务的范畴？

积极义务 → 行为模式为"**应为**"（应当做）
消极义务 → 行为模式为"**勿为**"（不要做）

**选项判断：**
- A. 赡养父母 → **应当做** → 积极义务 ✓
- B. 刑讯逼供 → **不要做** → 消极义务
- C. 依法纳税 → **应当做** → 积极义务 ✓
- D. 紧急避险 → **可以做** → 权利（可为）

**答案：A和C**
