# 1、讲稿内容提纲（对照民事诉讼法）

## 督促程序（支付令程序）知识提纲

### 一、督促程序的概念

督促程序，是指人民法院根据债权人的申请，向债务人发出支付令，催促债务人在法定期限内清偿债务的法律程序。它是一种**非讼程序**，不解决实体纠纷。

**适用场景：** 债权债务关系明确、没有纠纷，但债务人不履行债务的情形。


### 二、相关法律依据

| 法律文件 | 条文 | 主要内容 |
|---------|------|---------|
| 《民事诉讼法》 | 第221条 | 申请支付令的条件 |
| 《民事诉讼法》 | 第222条 | 法院5日内通知是否受理 |
| 《民事诉讼法》 | 第223条 | 15日内发出支付令；债务人15日内清偿或提异议；不履行可申请执行 |
| 《民事诉讼法》 | 第224条 | 异议成立→终结督促程序→支付令失效→转入诉讼程序（申请人不同意起诉的除外） |
| 《民诉法解释》 | 第429条 | 申请支付令的七项受理条件 |
| 《民诉法解释》 | 第431条 | 支付令可以留置送达 |
| 《民诉法解释》 | 第432条 | 终结督促程序的三种情形 |
| 《民诉法解释》 | 第433条 | 债务人向其他法院起诉不影响支付令效力 |
| 《民诉法解释》 | 第436条 | 向主债务人发出的支付令对担保人没有拘束力 |
| 《民诉法解释》 | 第438条 | 缺乏清偿能力、延缓期限、变更方式等不构成异议 |
| 《督促程序规定》 | 第4条 | 支付令对担保人没有拘束力 |
| 《督促程序规定》 | 第7条 | 缺乏清偿能力等不影响支付令效力 |


### 三、申请支付令的条件（五大条件）

| 序号 | 条件 | 说明 |
|------|------|------|
| 1 | 请求给付的标的为**金钱或有价证券** | 其他物的给付或行为给付不适用 |
| 2 | 金钱或有价证券**已到期且数额确定** | 未到期或数额不确定不适用 |
| 3 | 债权人**没有对待给付义务** | 双方互负义务未履行的不适用 |
| 4 | 支付令**能够送达**债务人 | 可直接送达、留置送达，**不得公告送达** |
| 5 | 债权人**未申请诉前保全** | 已申请诉前保全的应在30天内起诉或仲裁 |

> **例题：** 花瓶买卖合同——未交付花瓶时不能申请支付令（有对待给付义务）；已交付花瓶后可以申请（无对待给付义务）。


### 四、管辖法院

- **级别管辖：** 一律由**基层人民法院**管辖，不受标的额限制
- **地域管辖：** **债务人住所地**基层人民法院
- 多个法院都有管辖权的，债权人可向其中一个申请；向多个申请的，由**最先立案**的法院管辖


### 五、法院的审查与处理

| 情形 | 处理 |
|------|------|
| 符合条件 | 受理之日起**15日内**发出支付令 |
| 不符合条件 | **裁定驳回**申请 |
| 申请书不符合要求 | 通知限期补正 |


### 六、支付令的效力

- **生效时间：** 支付令**作出之日**起发生法律效力（催促债务人还钱）【讲稿强调】
- **强制执行效力：** 债务人收到后**15天内**不还钱也不提异议 → 产生强制执行效力

> **重要考点：** 支付令“作出即生效”与“15天后可强制执行”是两个不同的效力层次！


### 七、债务人的异议

| 要点 | 规则 |
|------|------|
| **形式** | 必须**书面**，口头无效 |
| **期限** | 收到支付令之日起**15日内** |
| **内容** | 必须是对**债权债务本身**的异议 |
| **不构成异议的情形** | 缺乏清偿能力、要求延缓履行期限、要求变更履行方式 |
| **向其他法院起诉** | **不影响**支付令效力 |
| **向作出支付令的法院起诉** | **视为**书面异议【讲稿总结】 |

**异议的后果：**
- 法院**形式审查**（不进行实体审查）
- 异议成立 → **裁定终结督促程序** → 支付令**自行失效** → **转入诉讼程序**（但申请方不同意起诉的除外）


### 八、督促程序的终结（支付令失效）

| 情形 | 依据 |
|------|------|
| 债权人就同一债权债务关系又提起诉讼 |  |
| 发出支付令之日起**30日内无法送达**债务人 |  |
| 债务人收到支付令前债权人撤回申请 |  |
| 债务人提出书面异议（形式审查成立） |  |


### 九、支付令与担保人

| 规则 | 说明 |
|------|------|
| 向**主债务人**发出的支付令，**对担保人没有拘束力** |  |
| 债权人**不能**申请法院向担保人发出支付令 | 最高法院认为不行（讲稿内容） |
| 债权人就担保关系单独提起诉讼的，支付令**自法院受理案件之日起失效** |  |

> **记住一句话：支付令跟担保人没关系！**


### 十、支付令与仲裁协议

| 情形 | 规则 |
|------|------|
| 存在仲裁协议，债权人申请支付令 | **可以申请**，法院应当受理（仲裁协议不禁止非讼程序） |
| 债务人提出异议后 | 终结督促程序，按仲裁协议**申请仲裁**（不能转为诉讼） |

> **关键原理：** 仲裁协议只禁止**诉讼**，不禁止**督促程序**等非讼程序。


### 十一、起诉行为对支付令效力的影响

| 谁起诉 | 向哪个法院 | 效果 |
|--------|-----------|------|
| **债权人**（申请人）起诉 | 任何法院 | **终结督促程序，支付令失效**（不论起诉债务人还是担保人） |
| **债务人**起诉 | **作出支付令的法院** | **视为书面异议** |
| **债务人**起诉 | **其他法院** | **不影响**支付令效力 |

# 3、讲稿切分与整理

## 【第一部分】督促程序的基本概念与流程

**专题二十三：督促程序（支付令程序）**

【概念引入】先通过一个例子来理解什么是督促程序。

**例题1：** 左林欠我十万块钱。就这十万债权债务纠纷，起诉左林是我的权利。但现在左林是那种“认账但不还钱”的人——债权债务没有纠纷。那我有必要通过诉讼程序来解决吗？没必要。那我怎么办？我可以向法院申请，由法院向左林发出一张支付令。

【支付令的流程与效力】支付令发给左林之后：

**第一，** 如果左林在收到支付令之后十五天之内把钱还我了——没事了。

**第二，** 如果左林对债权债务有异议，他可以在收到支付令之日起十五天之内向法院提出**书面异议**。法院审查异议成立——说明债权债务有纠纷。督促程序不解决纠纷，那就终结督促程序，支付令失效，同时转为诉讼程序解决纠纷。

**第三，** 如果十五天一过，左林既不还钱又不提出异议——十五天一过，就**强制执行**支付令，实现我的权利。

【重要考点】支付令什么时候发生法律效力？

> ❗ **注意：** 支付令**作出之日**起就发生法律效力——发生“催促债务人还钱”的法律效力。只不过等了十五天，债务人不还钱也不提出异议，才产生**强制执行效力**。这两个效力不一样！


## 【第二部分】申请支付令的条件

**【修改说明】** 原文中“再看到一百啊二百八十七，啊二程序要点”为语音转文字错误，结合上下文应指讲义页码/章节编号，修正为“再看到讲义，程序要点”。

再看到讲义，程序要点——申请支付令的条件，要求满足以下条件：

**【条件一】** 请求给付的标的为**金钱或者有价证券**。

**【条件二】** 请求给付的金钱或者有价证券已经**到期且数额确定**。

**【条件三】** 债权人**没有对待给付义务**。（注：讲稿中表述为“债权人没有对它给付义务”，应为“对待给付义务”之语音转文字错误，予以修正。）

> **例题2（对待给付义务）：** 我跟左林签订花瓶买卖合同，约定将我家古董花瓶二十万卖给左林——我把花瓶给左林，左林给我二十万。
>
> 合同签订后，**我没有交付花瓶**，左林没有给钱。我能不能申请法院向左林发出支付令？**不行。** 因为我还有一个交付花瓶的**对待给付义务**没有履行，不符合督促程序的适用条件。
>
> 但如果**我把花瓶交付给左林之后**，左林还是没给钱——我可以申请支付令。我已经交付了花瓶，没有对待给付义务了。

**【条件四】** 支付令**能够送达**给债务人。

- **直接送达**——可以。
- **留置送达**——可以。债务人拒绝签收，但把文书留置在其住处，债务人知道支付令，知道提出异议的权利。
- **公告送达**——**不准！** 为什么？公告送达，债务人不一定会去看公告，公告期满视为送达，十五天一过没提异议就强制执行——这合适吗？不合适！所以支付令**不适用公告送达**。（考试考过好多次！）

> **【注释】** 此处讲授者引申讲解了送达制度的基本分类（直接送达、留置送达、公告送达），这超出了督促程序的主题范畴。在民事诉讼法中，送达方式包括直接送达、留置送达、委托送达、邮寄送达、转交送达、公告送达等。督促程序中之所以排除公告送达，是因为必须保证债务人切切实实收到支付令、知道提出异议的权利。

**【条件五】** 债权人**没有向法院申请诉前保全**。如果债权人已经申请了诉前保全，应当在保全之日起三十天之内起诉或者申请仲裁，不能申请支付令。


## 【第三部分】支付令与担保人的关系

**【修改说明】** 原文“所以第一点啊，向债务人发出的支付令，对担保人王五没有约束力，对吧？所以第一点啊……”存在重复，合并处理。“最高法院认为啊，不也不允许向担保人发出支付令啊”修正为“最高法院认为，不允许向担保人发出支付令”。

> **例题3（担保关系）：** 债权人张三，债务人李四，借款十万。王五为这十万提供连带保证责任。李四不还钱，张三申请法院向李四发出支付令。
>
> **问：** 这个支付令对担保人王五有约束力吗？
>
> **答：** 没有！你都没向担保人王五发，担保人王五都不知道这事，对他有什么约束力？

**问题延伸：** 债权人张三能不能申请法院向担保人王五发出支付令？

**答：** 司法解释没说，但**最高法院认为不行**。因为申请支付令的前提是申请人和被申请人之间权利关系明确。担保权利关系必须依附于主债权债务关系，没有那么简单明确。

> **记住一句话：支付令跟担保人没关系！**
> - 第一，向债务人发出的支付令，**对担保人没有约束力**。
> - 第二，债权人**不能**申请法院向担保人发出支付令。


## 【第四部分】管辖法院

申请支付令由哪个法院管辖？

- **级别管辖：** 一定是**基层法院**——不管标的有多大！
- **地域管辖：** 一定是**债务人住所地**法院。

> **例题4：** 我申请法院向左林发出支付令，要求左林归还借款十万——由**债务人左林住所地基层法院**管辖。
>
> 我申请法院向左林发出支付令，要求左林还我**一百个亿**——还是**债务人左林住所地基层法院**管辖！（不管标的多大）

法院审查，认为符合条件的，**十五天之内**发出支付令；不符合条件的，申请不成立的，**裁定驳回**。


## 【第五部分】督促程序的终结（支付令失效的情形）

下列情形，法院应当裁定终结督促程序，已发出支付令的，支付令失效：

**【情形一】** 法院受理支付令申请后，**债权人就同一债权债务关系又提起诉讼的**——（重点！）

> **关键结论：** 只要法院受理申请后（或已发出支付令后），**债权人起诉**——不管他起诉**债务人**还是起诉**担保人**——就终结督促程序，支付令失效。
>
> 为什么？债权人自己都认为债权债务有纠纷了，督促程序不解决纠纷，就终结吧。而且既然已经起诉了，诉讼程序本身就能解决纠纷。

**【情形二】** 法院发出支付令之日起**三十天之内无法送达**债务人的——终结督促程序，支付令失效。

**【情形三】** 债务人收到支付令前，**债权人撤回申请**的——终结督促程序，支付令失效。


> **真题示例（大山公司欠五月公司五千万，海伦公司提供担保）：**
>
> 债权人=五月公司，债务人=大山公司，担保人=海伦公司。因到期未付，五月公司申请法院对大山公司发出支付令。
>
> **考点一：** 五月公司向债务人大山公司发出的支付令，对担保人海伦公司有没有约束力？**没有。**
>
> **考点二：** 支付令发出后，五月公司将海伦公司诉至法院（起诉担保人）。——只要债权人起诉，不管起诉债务人还是担保人，法院都应当**终结督促程序，支付令失效**。
>
> **选项分析：**
> - A. 支付令对大山公司有约束力，对海伦公司没有约束力——✅对
> - B. 支付令对大山公司、海伦公司都有约束力——❌错
> - C. 五月公司对海伦公司提起诉讼，不影响支付令效力——❌错
> - D. 五月公司对海伦公司提起诉讼，支付令失效——✅对
>
> **答案：A和D。**


## 【第六部分】支付令的效力与债务人的异议

支付令**自作出之日起**就发生法律效力（催促债务人还钱）。

债务人在收到支付令之日起**十五天之内**，要么还钱，要么提出书面异议。

- 十五天内还钱——没事了。
- 十五天内不还钱也不提异议——**强制执行**。
- **十五天内提出书面异议——重点！**

### 关于异议的几个要点：

**第一，** 债务人提出书面异议后，法院**形式审查**——只看：
- 提出异议没有？
- 是不是书面形式？
- 是不是对**债权债务本身**的异议？

如果是——异议成立，**终结督促程序，支付令失效，转入诉讼程序**。但**申请方当事人不同意起诉的除外**（因为申请人是债权人，是否起诉他有处分权）。

> **【注释】** 此处讲授者提到“形式审查”与“实体审查”的区别，是民事诉讼法的基本概念。形式审查指仅对程序性要件进行审查（如是否书面、是否在法定期限内等），不涉及实体权利义务的判断；实体审查则需要对案件事实和证据进行实质性审理判断。督促程序作为非讼程序，不解决实体纠纷，因此只做形式审查。

**第二，** 异议必须**书面**——口头异议无效。

**第三，** 异议必须是对**债权债务本身**的异议。如果债务人对债权债务本身没有异议，只是提出：

- “我确实欠钱，但没偿还能力”——不构成异议
- “我确实欠钱，但能不能缓两个月？”——不构成异议
- “我确实欠钱，能不能用车抵债？”——不构成异议

> 为什么？你对债权债务本身没有异议，只是对履行能力、期限、方式有意见，不影响支付令的效力。

**第四，** 债务人收到支付令后，**不在法定期间内提出书面异议，而向其他法院起诉的——不影响支付令效力**。

> 言下之意：债务人向**作出支付令的法院**起诉——视为书面异议。


## 【第七部分】起诉行为对支付令效力的影响（总结）

**如果是债权人（申请人）起诉：**
- 说明债权人自己认为债权债务有纠纷 → 终结督促程序，支付令失效
- 不论起诉债务人还是起诉担保人，都一样
- 既然已经起诉，通过诉讼方式解决纠纷

**如果是债务人起诉：**
- 向**作出支付令的法院**起诉 → **视为书面异议**
- 向**其他法院**起诉 → **不影响支付令效力**


## 【第八部分】仲裁协议与支付令（拓展）

> **2025年考题（考点预测）：**
>
> 甲公司和乙公司住所地均在H市H地区。甲公司乙公司签订借款合同，约定“发生纠纷，H仲裁委仲裁”（仲裁条款）。后乙公司逾期未还借款，甲公司向H市H地区法院申请支付令（H市H地区是债务人乙公司住所地的基层法院）。H地区法院应当如何处理？

**分析：** 仲裁条款是纠纷解决条款，意思是“如果发生纠纷，只能去仲裁，不能去起诉”。但债权人申请支付令的前提是——**我认为债权债务没有纠纷**。督促程序本身**不解决纠纷**。所以仲裁条款和申请支付令**没关系**！

> **结论：** 仲裁条款只禁止当事人通过**诉讼程序**解决纠纷，但不禁止当事人通过**特别程序、督促程序**等非讼程序实现权利。

**所以：** 法院应当**受理**，受理后向乙公司发出支付令。

**拓展：** 如果债务人乙公司在十五天内提出书面异议呢？

- 异议成立 → 终结督促程序，支付令失效
- 那能不能转为诉讼程序？**不能！** 因为有仲裁协议，不能通过诉讼方式解决纠纷
- 怎么办？终结督促程序后，双方当事人**根据仲裁协议去申请仲裁**解决纠纷

> **【注释】** 此处讲授者引入了“仲裁协议”这一法律概念。仲裁协议是指当事人约定将争议提交仲裁而非诉讼解决的协议。根据《仲裁法》，有效的仲裁协议排除法院的诉讼管辖权。但在督促程序中，由于督促程序是非讼程序（不解决实体纠纷），仲裁协议不影响债权人申请支付令。只有当债务人提出异议、债权债务确实存在纠纷时，才需要按仲裁协议去申请仲裁。
