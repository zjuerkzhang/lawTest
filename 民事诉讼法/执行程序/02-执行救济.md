# 第1部分：法考备考提纲

> **说明**：以下提纲基于讲稿内容整理，结合《民事诉讼法》（2023年修正）第236条（执行行为异议）、第238条（案外人异议）及《民诉法解释》第301条（三撤与再审的择一关系）等相关规定。


## 一、执行救济体系概览

```
执行救济
├── 对执行行为的异议（民诉法第236条）
│   ├── 主体：当事人、利害关系人
│   ├── 事由：执行行为违法（程序问题）
│   └── 救济：向上级法院申请复议
│
└── 案外人对执行标的的异议（民诉法第238条）
    ├── 主体：仅案外人
    ├── 事由：对执行标的主张实体权利
    └── 异议裁定后：
        ├── 判执相同（原判有错）→ 申请再审
        └── 判执不同（与原判无关）→ 执行异议之诉
            ├── 中止后：申请人执行异议之诉
            └── 驳回后：案外人执行异议之诉
```


## 二、对执行行为的异议（民诉法第236条）

| 项目 | 内容 |
|------|------|
| **法律依据** | 《民事诉讼法》第236条 |
| **提出主体** | 当事人、利害关系人 |
| **异议事由** | 认为执行行为违反法律规定（程序违法） |
| **提出方式** | 书面异议 |
| **审查期限** | 收到书面异议之日起15日内 |
| **审查结果** | 成立→裁定撤销或改正；不成立→裁定驳回 |
| **救济途径** | 向上一级法院申请复议（10日内） |

**例题**（2023年主观题考点）：唯一住房抗辩——高档小区160平米不构成“生活必需居住用房”，异议不成立，裁定驳回。


## 三、案外人对执行标的的异议（民诉法第238条）

| 项目 | 内容 |
|------|------|
| **法律依据** | 《民事诉讼法》第238条 |
| **提出主体** | 仅案外人（当事人以外的人） |
| **异议事由** | 对执行标的主张实体权利 |
| **提出方式** | 书面异议 |
| **审查期限** | 收到书面异议之日起15日内 |
| **审查结果** | 成立→裁定中止执行；不成立→裁定驳回 |
| **救济途径** | ①认为原判决、裁定错误的→**申请再审**；②与原判决、裁定无关的→**执行异议之诉**（15日内） |


## 四、执行异议之诉

| 项目 | 内容 |
|------|------|
| **性质** | 诉讼程序（非执行程序），一审普通程序，可上诉 |
| **前置程序** | 必须先提“案外人对执行标的的异议” |
| **适用情形** | 判执不同（与原判无关） |
| **证明责任** | 案外人就“对执行标的享有足以排除执行的民事权益”承担证明责任 |

### 两种类型

| | 申请人执行异议之诉 | 案外人执行异议之诉 |
|------|-------------------|-------------------|
| **触发条件** | 法院裁定**中止**执行 | 法院裁定**驳回**异议 |
| **原告** | 申请执行人（张三） | 案外人（王五） |
| **被告** | 案外人（王五） | 申请执行人（张三） |
| **被执行人** | 不反对→无独三；反对→共同被告 | 不反对→无独三；反对→共同被告 |
| **诉讼请求** | 确认案外人**不享有**排除执行的权利（消极确认之诉） | 确认自己**享有**排除执行的权利（积极确认之诉） |


## 五、两种异议的对比

| 对比项 | 对执行行为的异议 | 案外人对执行标的的异议 |
|--------|------------------|------------------------|
| **法律依据** | 民诉法第236条 | 民诉法第238条 |
| **提出主体** | 当事人、利害关系人 | 仅案外人 |
| **异议事由** | 执行行为违法（程序问题） | 对执行标的主张实体权利 |
| **是否主张实体权利** | 否 | 是 |
| **是否产生实体纠纷** | 否 | 是 |
| **救济方式** | 向上级法院申请复议 | 再审或执行异议之诉 |


## 六、案外人救济制度：三撤、案外人异议、再审的关系

### 基本关系图

```
                   案外人救济
                        │
        ┌───────────────┴───────────────┐
        │                               │
   第三人撤销之诉              案外人对执行标的的异议
   （针对生效裁判）              （执行中提出）
        │                               │
        │                    ┌──────────┴──────────┐
        │                    │                     │
        │              判执相同              判执不同
        │           （原判有错）          （与原判无关）
        │                    │                     │
        └────────┬───────────┘              执行异议之诉
                 │
           ⚠️ 三撤与再审
           不能同时进行
         （民诉法解释第301条）
```

### 两个模型的快速判断

| | 模型一（判执不同） | 模型二（判执相同） |
|------|-------------------|-------------------|
| **典型情形** | 判钱、执行房 | 判房、执行房 |
| **能否提三撤** | ❌ 不能 | ✅ 可以 |
| **能否提案外人异议** | ✅ 可以 | ✅ 可以 |
| **异议后救济** | 执行异议之诉 | 申请再审 |
| **三撤与再审的关系** | 不涉及 | 二选一（掐头去尾） |

## 一、执行救济概述

我们看到第三节，执行救济。执行救济这一章有两个问题：第一个叫**对执行行为的异议**，这个很简单；第二个是**案外人对执行标的的异议**，这个比较复杂。

来，我们先讲简单问题——对执行行为的异议。


## 二、对执行行为的异议

### （一）基本概念与程序

大家把讲义翻到第三百一十页。什么叫对执行行为的异议？执行要依法执行，法院的执行行为有没有可能违法？有可能。这个时候，**当事人或者利害关系人**认为法院的执行行为违法，就可以向法院提出**书面异议**，要求法院纠正这个违法的执行行为。

法院对异议进行审查——认为成立的，裁定撤销或者改正；认为不成立的，裁定驳回。对这个裁定不服的，可以**向上一级法院申请复议一次**。这个叫对执行行为的异议。

### （二）例题一：唯一住房异议（2023年主观题考点）

> **例题**：张三起诉李四要求支付货款三百万，法院判决支持。判决生效后，张三申请对李四强制执行。执行中发现李四家没钱，但在某市高档小区有一套一百六十平米的房子，价值三百八十万。法院查封了这套房子，准备拍卖变卖。
>
> 这时被执行人李四提出：根据民事诉讼法及司法解释，对于被执行人本人及其所扶养家属生活必需的居住用房不能执行。这套房子是我名下的唯一住房，是生活必需的居住用房，你们不能执行——执行行为违法了。
>
> **问题**：这叫不叫对执行行为的异议？法院应否支持？

**分析**：这叫对执行行为的异议。但这个异议**不成立**——题目说得很清楚：高档小区、一百六十平米。一百六十平米是什么概念？国家收豪宅税，认定豪宅的标准是**一百四十四平以上**，一百六十平是豪宅，不能叫“生活必需”。所以法院应当**裁定驳回**。驳回之后，李四对裁定不服的，可以向上一级法院申请复议一次。

> **【修正】** 原文中“撤销改判”应为“撤销改正”；“一成不成立”应为“异议不成立”；“生了一句价”语义不明，调整为“每每讲到于此，就声泪俱下”。

### （三）例题二：评估程序异议

法院驳回李四的异议后继续执行，准备拍卖房子。拍卖前组织评估机构估价，估出市场价一百二十万，法院以一百二十万作为保留价开始拍卖。

这时被执行人李四又提出：评估机构怎么评估的？我房子明明是三百八十万，评估成一百二十万，评估程序违法、评估错了。

**分析**：法院在拍卖中组织的评估，是执行中的一种行为、一种程序。李四认为评估程序违法，**属于对执行行为的异议**。法院审查——异议成立的撤销改正，异议不成立的驳回；对裁定不服的向上一级法院申请复议。

### （四）例题三：拍卖程序异议（恶意抬价）

拍卖过程中，经过多轮竞价，王五以五百八十万拍下房子。成交后王五搬进去，发现同户型最多卖三百多万。一调查发现：申请人张三、被执行人李四以及几位执行局的法官也注册账号参加竞拍，恶意抬价，导致成交价远高于市场价。

王五认为法院主持的拍卖程序违法，希望撤销拍卖。

**分析**：这是王五作为**利害关系人**，认为法院的拍卖程序违法，**可以提出对执行行为的异议**。法院审查——异议成立的撤销改正，异议不成立的驳回；对裁定不服的向上一级法院申请复议。

### （五）补充：复议的总结归纳（七个复议）

> **【注释】** 以下内容涉及“复议”这一救济方式在不同情形下的适用，属于对民事诉讼中复议制度的系统梳理，超出了“执行救济”本身的范畴，但有助于理解执行行为异议中“向上级法院申请复议”的定位。

我们在民事诉讼中讲过一个救济方式叫**复议**。有些是向作出文书的法院申请复议（**同级复议**），有些是向上一级法院申请复议（**上级复议**）。

**三个同级复议**：申请回避、申请保全、申请先予执行。

**四个上级复议**：罚款、拘留、执行管辖异议、执行行为异议。

**记忆规律**：同级复议是“我找法院帮个忙，法院不帮，好好商量”——回避、保全、先予执行都是我申请的；上级复议是“法院要告我，我不干，他非要告”——罚款、拘留、执行管辖异议、执行行为异议都是法院主动来找我的麻烦。


## 三、案外人对执行标的的异议

### （一）基本概念

案外人对执行标的的异议是重点也是难点。它的原理和逻辑其实非常清楚。

**举例**：张三申请执行李四的一套房子，在执行过程中，案外人王五说：“不能执行，这房子是我的。”这就是**案外人对执行标的的异议**。

### （二）案外人在不同阶段主张权利的三种方式

王五在不同阶段可以分别以何种方式主张权利？

| 阶段 | 王五的救济方式 |
|------|----------------|
| 诉讼中 | 以**有独立请求权的第三人**身份参加诉讼 |
| 判决生效后（执行前） | 提出**第三人撤销之诉** |
| 执行中 | 提出**案外人对执行标的的异议** |

> **【注释】** “有独立请求权的第三人”是民事诉讼当事人制度中的概念，指对当事人双方的诉讼标的，认为有独立请求权而参加诉讼的第三人。“第三人撤销之诉”是2012年民事诉讼法新增的制度，指因不能归责于本人的事由未参加诉讼的第三人，有证据证明生效裁判损害其民事权益的，可以自知道权益受损之日起六个月内向作出裁判的法院提起撤销之诉。

### （三）两种执行情形的区分（核心考点）

**情形一（原判有错→申请再审）** ：张三起诉李四**争议房屋所有权**，法院判决房屋归张三所有（**判房**）。张三申请执行，执行的也是这套房子（**执行房**）。执行中王五对房屋主张权利。

→ **判的跟执行的一样**。这种情况下，法院生效判决已经判了房子归谁，王五要维护权利，必须**干掉这份生效判决**→ **申请再审**（原判有错）。

**情形二（与原判无关→另行起诉→执行异议之诉）** ：张三起诉李四要求**归还借款一百万**，法院判决李四还钱一百万（**判钱**）。张三申请执行，李四没钱，就执行李四的房子（**执行房**）。执行中王五对房屋主张权利。

→ **判的跟执行的不一样**。这种情况下，法院生效判决根本没判房子，房子到底是谁的是一个**新的争议**→ **另行起诉**（与原判无关）→ **执行异议之诉**。

### （四）执行异议之诉

**1. 概念区分（极易混淆！）**

- **案外人对执行标的的异议**：执行中案外人提出的异议（如王五说“房子是我的”）
- **执行异议之诉**：异议被裁定中止或驳回后，另行提起的诉讼

> **【提醒】** 这两个概念一定要说准，不要混着说，否则越混越乱。

**2. 诉讼主体与类型**

**（1）法院裁定中止执行后**（谁慌了？申请人张三慌了）

- 谁起诉：**申请人张三**起诉做原告
- 告谁：告**案外人王五**
- 被执行人李四：不反对→**无独三**；表态反对→**共同被告**
- 诉讼名称：**申请人执行异议之诉**
- 诉讼请求：请求确认案外人王五对房屋**不享有**足以排除执行的权利→继续执行（**消极确认之诉**）

**（2）法院裁定驳回异议后**（谁慌了？案外人王五慌了）

- 谁起诉：**案外人王五**起诉做原告
- 告谁：告**申请人张三**
- 被执行人李四：不反对→**无独三**；表态反对→**共同被告**
- 诉讼名称：**案外人执行异议之诉**
- 诉讼请求：请求确认自己**享有**足以排除执行的权利→不许执行（**积极确认之诉**）

**3. 证明责任**

在整个执行异议之诉中，**由案外人王五**对执行标的是否享有足以排除执行的权利**承担证明责任**。


## 四、两种异议的区分

### （一）形式区别

| | 对执行行为的异议 | 案外人对执行标的的异议 |
|------|------------------|------------------------|
| **提出主体** | **当事人或利害关系人**均可 | **仅案外人**可提 |

**规律**：考试中发现异议是**申请执行人或被执行人**（当事人）提的→一定是**执行行为异议**。案外人提的→两种都有可能。

### （二）本质区别

- **对执行行为的异议**：异议人**只认为执行程序违法**，**没有主张实体权利**→不产生实体纠纷→执行中就能解决→**上级复议**
- **案外人对执行标的的异议**：案外人**主张了实体权利**（“这东西是我的”）→产生实体纠纷→执行中不能解决→**诉讼程序**解决（再审或执行异议之诉）

### （三）例题：区分两种异议

**情形A**：申请执行左邻五十万，法院判决左邻归还五十万。执行时法院扣押了左邻家一张纯红木床（价值五十万）。被执行人左邻跳出来：“根据民诉法规定，生活必需用品不能执行，这床是我的生活必需用品。”

**分析**：谁提的？**被执行人左邻**（当事人）→一定是**对执行行为的异议**。左邻只认为执行行为违法，没有主张实体权利。

**情形B**：同样的执行，**案外人李佳**跳出来：“不能执行，那床是我的。我跟左邻签订了买卖合同，已支付全部价款，只是没搬走。”

**分析**：谁提的？**案外人李佳**。李佳主张了什么？**实体权利**（“床是我的”）→ **案外人对执行标的的异议**。法院审查→成立的中止，不成立的驳回→与原判无关→**提起执行异议之诉**。


## 五、案外人救济制度（难点：三撤、案外人异议、再审的关系）

### （一）基本分析思路

**第一步**：找到案外人（如王五），看他对**什么东西**主张权利（如房子）。

**第二步**：看**判决判了什么**？判房子了吗？
- 判了房子→侵犯王五权利→王五**可以提第三人撤销之诉**
- 没判房子→没侵犯王五权利→王五**不能提三撤**

**第三步**：看**执行执行了什么**？执行房子了吗？
- 执行了房子→侵犯王五权利→王五**可以提案外人对执行标的的异议**
- 没执行房子→没侵犯王五权利→王五**不能提案外人异议**

### （二）两个基本模型

**模型一（判钱、执行房——判执不同）** ：

张三起诉李四归还借款一百万→判决还钱一百万（**判钱**）→执行时李四没钱→执行李四的房（**执行房**）→案外人王五对房屋主张权利。

- 判决没判房子→**不能提三撤**，不能申请再审
- 执行了房子→**可以提案外人对执行标的的异议**
- 异议终止/驳回后→判执不同→**与原判无关**→**执行异议之诉**

**模型二（判房、执行房——判执相同）** ：

张三起诉李四争议房屋所有权→判决房屋归张三所有（**判房**）→执行这套房（**执行房**）→案外人王五对房屋主张权利。

- 判决判了房子→**可以提三撤**
- 执行了房子→**可以提案外人对执行标的的异议**
- 两条路都能走！

### （三）模型二的两条路（“掐头去尾”规则）

> **【注释】** 以下“掐头去尾”规则的法律依据是《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》**第301条**。该条规定：第三人提起撤销之诉后，执行法院对第三人提出的执行异议应予审查；第三人不服驳回执行异议裁定，申请再审的，人民法院不予受理。同时，案外人对驳回执行异议裁定不服、认为原裁判错误的，应当申请再审，提起第三人撤销之诉的，不予受理。简言之：**三撤和再审不能同时进行，只能二选一。**

**写三个制度**（从左到右）：**三撤 → 案外人对执行标的的异议 → 再审**

**第一条路（掐头——把三撤摁住）** ：

案外人提出案外人对执行标的的异议→法院终止/驳回→**申请再审**（不能提三撤）

**第二条路（去尾——把再审摁住）** ：

案外人提出第三人撤销之诉→在三撤中希望中止执行→可以提供担保，也可以**提出案外人对执行标的的异议**→法院终止/驳回后→**不能申请再审**，继续打三撤（不能同时搞再审）

> **【核心原理】** 掐头去尾的本质就是：**三撤和再审不能同时进行**。留三撤就不留再审，留再审就不留三撤。

### （四）配套例题

**例一**：法院终审判决陈某清偿张某二十万债务（**判钱**），进入执行后法院对陈某的古董花瓶进行执行（**执行花瓶**）。执行中案外人安某对花瓶主张权利。

**分析**：判钱、执行花瓶→**模型一**→只能提案外人对执行标的的异议→终止/驳回后→**执行异议之诉**。不能提三撤，不能申请再审。

**正确选项**：A（有权提案外人对执行标的的异议）、C（终止/驳回后可提起执行异议之诉）

**例二**：张某与陈某因古董花瓶所有权发生争议，法院判决花瓶归张某所有（**判花瓶**），张某申请执行花瓶（**执行花瓶**）。执行中案外人安某对花瓶主张权利，提出了**第三人撤销之诉**。

**分析**：判花瓶、执行花瓶→**模型二**→安某提了三撤→**去尾**（留头不留尾）→在三撤中可提供担保中止执行，也可提案外人对执行标的的异议→但不能申请再审。

**正确选项**：A（可提供担保中止执行）、B（可提案外人对执行标的的异议）、D（不能申请再审）

**例三**：张某与陈某因古董花瓶所有权发生争议，法院判决花瓶归张某所有（**判花瓶**），张某申请执行花瓶（**执行花瓶**）。执行中案外人安某对花瓶主张权利，提出了**案外人对执行标的的异议**。

**分析**：判花瓶、执行花瓶→**模型二**→安某提了案外人异议→**掐头**（留尾不留头）→终止/驳回后→**申请再审**（不能提三撤，不能提执行异议之诉）。

**正确选项**：C（可以申请再审）
