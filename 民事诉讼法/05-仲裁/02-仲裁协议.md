### 第1步：法考备考提纲（非科班友好版）

本提纲结合《仲裁法》及司法解释相关精神整理，对照讲稿内容提取。

#### 第一部分：仲裁协议基础速记

| 概念 | 核心要点 | 备注/注释 |
| :--- | :--- | :--- |
| **仲裁协议的定义** | 双方当事人达成的、将纠纷提交仲裁解决的书面合意 | **仲裁制度的基础**，约束力的来源 |
| **形式要求** | **书面形式**（口头无效） | 合同条款、单独协议、其他书面都可 |
| **内容三要素** | ① 请求仲裁的意思表示<br>② 仲裁事项（须可仲裁）<br>③ 选定的仲裁机构 | **缺一不可！** 三要素完整才有效 |
| **不可仲裁事项** | 身份关系纠纷（婚、收、监、抚、继）；劳动纠纷；农村土地承包纠纷；体育仲裁 | 看到这些→不能搞民商事仲裁 |

#### 第二部分：选定的仲裁机构——“明确、具体、唯一”规则

| 约定情形 | 处理规则 | 举例/口诀 |
| :--- | :--- | :--- |
| 约定的机构**不存在** | **无效** | 约定“甲县仲裁委”→无效（县没有） |
| 名称不准确但**能确定** | **有效** | “广州市仲裁委”→实际是“广州仲裁委”，有效 |
| 约定**两个以上**仲裁机构 | 协议选一个；选不出来→**无效** | “广州或长沙”→选不出来就无效 |
| 约定“**某地**”的仲裁机构 | 该地只有一个→**有效**；该地有两个以上→选不出来就**无效** | “位于广州的”→唯一，有效；“位于北京的”→三个，选不出来无效 |
| **或裁或审**条款 | **无效**（但首次开庭前不异议→视为有效） | “仲裁或起诉”→无效 |

#### 第三部分：仲裁协议效力的核心规则

**1. 对法院的效力（或裁或审原则）**

| 时间节点 | 处理方式 | 关键点 |
| :--- | :--- | :--- |
| 法院**受理前**发现有仲裁协议 | **不予受理** | 不属于法院主管 |
| 法院**受理后**，首次开庭前提出仲裁协议 | **驳回起诉** | 有效仲裁协议排斥法院主管 |
| 首次开庭前**未提出**异议 | **视为放弃仲裁协议**，法院继续审理 | 应诉管辖 |
| 仲裁协议**无效** | 法院**继续审理** | 不妨碍法院管辖 |

**⏰ 黄金时间节点：首次开庭前**（法槌敲响之前）

**2. 独立性**
- 仲裁条款效力**独立于**合同主文。合同不成立、无效、被撤销→仲裁条款不当然无效。

**3. 相对性（⭐绝对重点！）**

| 规则 | 内容 | 法考提示 |
| :--- | :--- | :--- |
| **原则：相对性** | 仲裁协议只约束**签约双方** | 只要看纠纷双方有无仲裁协议 |
| **扩张一：合并/分立** | 对**继承人**有效 | 另有约定除外 |
| **扩张二：死亡** | 对**继承人**有效 | 另有约定除外 |
| **扩张三：转让** | 对**受让人**有效 | 但受让人明确反对/不知道除外 |

#### 第四部分：跨学科融合考点（客观题/主观题潜在方向）

> **融合考点一：代位权诉讼 + 仲裁协议**
> - 债权人与相对人之间**没有**仲裁协议 → 代位权诉讼**属于法院主管**，法院继续审理。
> - 债务人与相对人之间有仲裁协议，不影响代位权诉讼。但债务人/相对人可另行申请仲裁，导致代位权诉讼**中止**。
> - **原理：仲裁协议效力相对性**（债权人不是债务人与相对人之间仲裁协议的一方）。

> **融合考点二：股东代表诉讼 + 仲裁协议**
> - 小股东提起股东代表诉讼，公司与被告之间有仲裁协议 → 该仲裁协议对**小股东没有约束力**（小股东不是仲裁协议一方）。
> - 小股东与被告之间没有仲裁协议 → 属于法院主管，应去法院起诉。
> - 管辖：无特殊规定 → **一般地域管辖（原告就被告）**。
> - **原理：仲裁协议效力相对性**（2025年《仲裁法》最终未采纳扩张至股东代表诉讼的条款）。

#### 第五部分：仲裁协议效力的确认程序

| 事项 | 规则 |
| :--- | :--- |
| **确认主体** | 仲裁机构/仲裁庭 **或** 法院 |
| **找哪个法院** | 中院（级别）+ 申请人住所地/被申请人住所地/仲裁协议签订地/仲裁机构所在地（地域） |
| **冲突处理** | 法院确认优先；但仲裁机构先受理并已作出决定的，法院不再受理 |
| **异议时间** | **仲裁庭首次开庭前** |
| **超时后果** | 视为仲裁协议有效/视为存在仲裁协议，之后不准再主张无效 |

#### 第一部分：仲裁协议的重要性与基础概念（引入）

**第1段**
我们看到讲义第353页，专题二十八——**仲裁协议**。这是绝对的重点。怎么说呢？仲裁制度如果考一道题，这道题一定在仲裁协议里；考两道题，大概率两道题都在仲裁协议里，或者至少有一道在仲裁协议里。为什么？法院作为国家审判机关，根据法律授权当然有权管当事人的纠纷，判决当然约束当事人。但仲裁机构是民间组织、群众组织，凭什么约束当事人？约束力从哪来？就来源于当事人通过一份**书面的仲裁协议**，对仲裁机构进行授权，明确表达愿意接受仲裁。所以，**仲裁协议是仲裁制度的基础，是仲裁约束力的来源**。

---

#### 第二部分：仲裁协议的形式与内容（讲义正文）

**第2段（形式要求）**
看到第354页。仲裁协议的形式：必须以**书面形式**订立，口头的仲裁协议无效。书面形式可能体现为：
1. **合同中的仲裁条款**。比如买卖合同中最后一条：“因履行本合同发生纠纷，双方应友好协商，协商不成的，一致同意提交广州仲裁委仲裁。”
2. **单独的仲裁协议书**。比如买卖合同中没写仲裁条款，但双方单独达成一份协议：“因履行某某合同发生纠纷，无法协商解决，现一致同意提交广州仲裁委仲裁。”
3. **其他书面形式**也行。总之，只要是书面就行。

**第3段（内容三要素——总述与演示）**
仲裁协议应当包含以下**三个方面的内容**：
1. **请求仲裁的意思表示**
2. **仲裁事项**
3. **选定的仲裁机构**

我给大家演示一份标准的仲裁协议：“双方当事人因履行本合同发生的**一切纠纷**，一致同意提交**广州仲裁委仲裁**解决。”大家分析这句话：
- “仲裁解决” → 请求仲裁的意思表示；
- “因履行本合同发生的一切纠纷” → 仲裁事项；
- “提交广州仲裁委” → 选定的仲裁机构。
三个内容，记住了。

#### 第三部分：仲裁协议三要素详解（重点展开）

**第4段（要素一：请求仲裁的意思表示）**
当事人在仲裁协议中应当**明确、肯定地**表达出愿意通过仲裁方式解决纠纷。

**第5段（要素二：仲裁事项的可仲裁性）**
约定的仲裁事项**必须具有可仲裁性**。`[注释：可仲裁性指该事项属于法律允许提交仲裁的范围，即限于财产纠纷]`

> **【例题1】** 张三因遗产继承纠纷，在协议中约定将该纠纷提交广州仲裁委仲裁。该仲裁协议是否有效？
> **【分析】** 无效。遗产纠纷属于身份关系，不能仲裁。

> **【例题2】** 张三与甲公司签订劳动合同，约定“因履行本合同发生的一切纠纷，提交广州仲裁委仲裁”。该仲裁协议是否有效？
> **【分析】** 无效。劳动纠纷应搞劳动仲裁，不能搞民商事仲裁。

---

#### 第四部分：选定的仲裁机构——明确、具体、唯一（核心考点）

**第6段（总述）**
仲裁中没有管辖制度，全国仲裁机构无级别高低之分，受理案件不受地域限制。所以，去哪个仲裁机构，必须由当事人在仲裁协议中**明确约定**，并且要求约定的仲裁机构**明确、具体、唯一**。司法实践中对此有越来越明确的规定，是考试重点，逐一讲解。

**第7段（情形一：约定的仲裁机构必须存在）**
仲裁协议中约定的仲裁机构必须真实存在。

> **【例题3】** 买卖合同中约定“发生纠纷由甲县仲裁委仲裁”或“由东城区仲裁委员会仲裁”。该仲裁协议是否有效？
> **【分析】** 无效。仲裁机构最低设在地级市，区和县没有仲裁机构。约定的机构不存在。

**第8段（情形二：名称不准确但能确定）**
约定的仲裁机构名称不准确，但**能够确定具体仲裁机构**的，仲裁协议有效。

广州的仲裁机构准确名称是“广州仲裁委员会”（中间没有“市”字）。如果约定“由广州市仲裁委员会仲裁”，虽然严格讲没有“广州市仲裁委员会”，但大家都知道约定的是广州仲裁委，只是名称不准确，仲裁协议有效。

再比如北京的“中国国际经济贸易仲裁委员会”（简称贸仲），名称很复杂。如果约定“由中国国际仲裁委员会仲裁”或“中国经济仲裁委员会仲裁”，名称不准确，但大家都知道指的是贸仲，仲裁协议有效。

还有深圳的仲裁机构，以前叫“深圳仲裁委”，后来和“贸仲华南分会”合并，现在叫“深圳国际仲裁院”。当事人可能约“深圳仲裁委”、约“贸仲华南分会”、约“贸仲深圳分会”——不管怎么约，只要能确定指的是那一个仲裁机构，仲裁协议就有效。

**第9段（情形三：约定两个以上仲裁机构）**
约定两个以上仲裁机构，比如“由广州仲裁委**或者**长沙仲裁委仲裁”——约定不明确。怎么办？当事人可以协议在这两个当中选一个。选得出来就有效；选不出来，仲裁协议无效。

**第10段（情形四：约定“某地”的仲裁机构）**
当事人约定“由某地的仲裁机构仲裁”：
- 该地**只有一个**仲裁机构的，该仲裁机构视为约定的仲裁机构。
- 该地**有两个以上**仲裁机构的，当事人可以协议选择其中一个；不能达成一致的，仲裁协议无效。

比如约定“由位于**广州**的仲裁机构仲裁”——广州只有一个（广州仲裁委），视为约定的就是它，有效。但如果约定“由位于**北京**的仲裁机构仲裁”——北京有三个仲裁机构（北京仲裁委员会、中国国际经济贸易仲裁委员会、中国海事仲裁委员会），约定不明确，当事人要协议选一个；选不出来，仲裁协议无效。

**第11段（情形五：或裁或审条款——既约定仲裁又约定诉讼）**
当事人约定“既可以向仲裁机构申请仲裁，也可以向法院起诉”的条款（即**或裁或审条款**），**无效**。

> **【重要规则】** 但一方向仲裁机构申请仲裁，另一方在**仲裁庭首次开庭前**没有提出异议的除外。也就是说：或裁或审条款无效，但如果一方拿着这个无效条款去申请仲裁，另一方在首次开庭前没提异议，就视为仲裁协议有效，仲裁委有权继续仲裁。

#### 第五部分：仲裁协议的效力（核心法条解析）

**第12段（效力的三个层面）**
有效的仲裁协议产生以下效力：
1. **对当事人**：限制纠纷解决方式的选择权——只能去仲裁，不能起诉。
2. **对仲裁机构**：授予对案件的管辖权。
3. **对法院**：**排斥法院的主管**（或裁或审原则的体现）。

**第13段（法条解析——四种情形）**
两个重要法条（大意）：当事人达成仲裁协议，一方向法院起诉的，法院不予受理（仲裁协议无效或法律另有规定的除外）。如果一方起诉时没声明有仲裁协议，法院受理后，另一方在**首次开庭前**提交仲裁协议的，应当**驳回起诉**（仲裁协议无效或法律另有规定的除外）；如果在首次开庭前未对法院受理提出异议，视为放弃仲裁协议，法院继续审理。

我来读出**四个意思**，逐一举例：

> **【情形一：受理前发现】** 甲公司与乙公司买卖合同中有仲裁条款（广州仲裁委）。甲公司去法院起诉。法院立案前一看，有仲裁协议——不属于法院主管。法院应当**裁定不予受理**。

> **【情形二：受理后发现，首次开庭前提出有效的仲裁协议】** 甲乙之间没有合同仲裁条款，但有单独的仲裁协议书（广州仲裁委）。甲公司去法院起诉，法院受理前没发现仲裁协议，受理了。首次开庭前，乙公司拿出仲裁协议。法院一看，有效仲裁协议——不属于法院主管。法院应当**裁定驳回起诉**。

> **【情形三：受理后发现，但仲裁协议无效】** 甲乙之间有仲裁协议，约定“由东城区仲裁委仲裁”。（东城区没有仲裁机构，协议无效。）甲公司起诉，法院受理了。首次开庭前，乙公司拿出这份仲裁协议。法院一看，仲裁协议无效——那当事人之间没有有效的仲裁协议，不妨碍法院管辖。法院**继续审理**。

> **【情形四：受理后发现，但首次开庭时才提出】** 甲乙之间有有效的仲裁协议（广州仲裁委）。甲公司起诉，法院受理了。乙公司在**首次开庭时**（法槌敲响之后）才拿出仲裁协议。晚了！`[修正：原文“首次开庭时”]` 应当在**首次开庭前**提出。被告在首次开庭前没提出异议，视为放弃仲裁协议，法院**继续审理**（应诉管辖）。

**关键时间节点**：提出仲裁协议对抗法院管辖，最迟在**首次开庭前**（即法官说“现在开庭”的法槌敲响之前）。实践中，被告通常是在收到法院送达的**应诉通知书**和起诉状副本后，在提交答辩状期间就提出了。

#### 第六部分：仲裁条款效力的独立性

**第14段**
**仲裁条款效力的独立性**：仲裁条款虽然表现为合同中的条款，但其效力**独立于合同主文**而存在。不会因为合同不成立、未生效、被撤销或无效，而导致仲裁条款不成立、未生效、无效或被撤销。`[注释：这是仲裁法的一项基本原则，来源于《仲裁法》第19条]`

#### 第七部分：仲裁协议效力的相对性及其扩张（重点+跨学科融合考点）

**第15段（相对性原则）**
仲裁协议是一个协议，效力具有**相对性**——只对协议的双方当事人有约束力，对当事人之外的其他人没有约束力。**这是原则，是重点！**

**第16段（三种扩张情形——例外）**
但根据法律和司法解释，在以下三种情形下，仲裁协议对非签约方也有约束力（相对性的扩张）：

1. **合并、分立**：当事人订立仲裁协议后合并、分立的，仲裁协议对其权利义务的**继承人**有效（另有约定的除外）。
   > **【例】** 甲公司与乙公司有仲裁协议。后甲公司与丙公司合并为丁公司。仲裁协议对丁公司有约束力。

2. **死亡**：当事人订立仲裁协议后**死亡**的，仲裁协议对承继其仲裁事项权利的**继承人**有效（另有约定的除外）。
   > **【例】** 张三与李四有仲裁协议。张三死后，其子张小三继承合同权利。仲裁协议对张小三有约束力。

3. **债权债务转让**：债权债务全部或部分**转让**的，仲裁协议对**受让人**有效，但另有约定、受让人明确反对、或受让人不知道有单独的仲裁协议的除外。
   > **【例】** 甲公司将合同权利义务转让给丙公司。仲裁协议对丙公司有约束力。但如果丙公司在受让时明确说“仲裁条款我不接受”，或者根本不知道甲、乙之间还有个单独的仲裁协议，那仲裁协议对丙就没有约束力。

**第17段（核心方法论）**
不管题目多复杂，你只需要去看：**纠纷双方当事人是谁？他们之间有没有仲裁协议？**有，就去仲裁；没有，就去起诉。就这么简单。

#### 第八部分：跨学科融合考点（仲裁协议效力的相对性应用）

**第18段（融合考点一：仲裁协议与代位权诉讼）**

> **【法条链接】** `[注释：此处对应《民法典合同编通则司法解释》第36条]` 债权人提起代位权诉讼后，债务人或者相对人以双方之间的债权债务关系订有仲裁协议为由，对法院主管提出异议的，法院不予支持。但是，债务人或者相对人在首次开庭前，就债务人与相对人之间的债权债务关系申请仲裁的，法院可以依法中止代位权诉讼。

**推导过程（坚持相对性）**：
- 案情：张三（债权人）对李四（债务人）有100万债权，李四怠于行使对王五（相对人）的100万债权。张三提起**代位权诉讼**（原告：张三；被告：王五；第三人：李四）。
- 问题：李四和王五之间有仲裁协议。李四或王五说“我们有仲裁协议，法院不能管”，对不对？
- **分析**：仲裁协议是李四和王五之间的。张三**不是**该协议的一方当事人，不受该协议约束。张三和王五之间**没有**仲裁协议。所以代位权诉讼**属于法院主管**，法院应当**继续审理**，不能驳回起诉。这就是相对性。
- 但同时，李四和王五可以在代位权诉讼首次开庭前，根据他们之间的仲裁协议去申请仲裁。如果去了，代位权诉讼的审理需要以李四和王五之间债权债务关系为依据，所以法院可以**中止**代位权诉讼，等待仲裁结果。

**第19段（融合考点二：仲裁协议与股东代表诉讼）**

> **【例题4·跨学科】** X公司（多彩公司）与Z市刘记集团签订合作协议，约定“与该协议有关的一切纠纷由A仲裁委仲裁”。后刘记集团侵害多彩公司利益，但多彩公司控股股东不愿追究。小股东丁某履行**股东代表诉讼**（股东派生诉讼）程序，代多彩公司对刘记集团请求赔偿。问：本案的主管如何确定？管辖如何确定？

**主管问题分析**：
- 仲裁协议是**多彩公司与刘记集团**之间的。小股东丁某**不是**仲裁协议的一方当事人，不受仲裁协议约束。
- 丁某与刘记集团之间**没有**仲裁协议。所以该纠纷**属于法院主管**，丁某应当去法院起诉。
- `[注释：2025年《仲裁法》修订过程中，曾有个征求意见稿试图规定仲裁协议对行使股东派生诉讼的股东也有约束力，但最终通过的《仲裁法》删除了该条。因此，仍严格坚持仲裁协议效力的相对性。]`

**管辖问题分析**：
- 法律对股东代表诉讼**没有特殊地域管辖规定**，因此适用**一般地域管辖**——**原告就被告**。
- 被告是刘记集团，被告住所地在Z市（仁怀市`[修正：原文“认识”]`），所以由Z市法院管辖。

#### 第九部分：仲裁协议效力的确认程序

**第20段（确认主体）**
当事人对仲裁协议效力有争议的，可以：
1. 请求**仲裁机构或仲裁庭**作出决定；
2. 请求**法院**作出裁定。

找法院，找**哪个**法院？**级别管辖**：一律找**中级人民法院**（为什么？反复强调：仲裁找中院）。**地域管辖**：四个地方的中院都可以——**申请人住所地**、**被申请人住所地**、**仲裁协议签订地**、**约定的仲裁机构所在地**的中院。记法：两个人（申请人、被申请人的住所地）+ 两个仲裁协议相关地（签订地、约定的仲裁机构所在地）。

**第21段（冲突处理规则）**
一方找仲裁机构，一方找法院——**法院确认优先**。但如果仲裁机构**先于**法院接受申请，**并且已经作出决定**的，法院就不再受理了（给仲裁机构留点面子）。

**第22段（异议提出的时间——首次开庭前）**
当事人对仲裁协议效力有异议，应当在**仲裁庭首次开庭前**提出。
- 一方拿无效仲裁协议去申请仲裁，另一方首次开庭前没提异议→视为仲裁协议有效。之后不准再主张无效。
- 双方**根本没有**仲裁协议，一方非要去仲裁，另一方首次开庭前没提“不存在仲裁协议”→经仲裁庭说明并记录在案，**视为存在仲裁协议**，仲裁机构有权继续仲裁。之后不准再以“不存在仲裁协议”为由申请撤销或不予执行裁决。

**第23段（特别提示：确认仲裁协议效力不是“诉”）**
当事人向法院申请确认仲裁协议无效——这是不是**确认之诉**？**不是！** 确认之诉的前提是它得是一个“诉”，要求法院解决实体权利纠纷。确认仲裁协议效力只是一个**特殊的对仲裁的司法审查程序**，不解决当事人间的民事权利纠纷。所以**不讨论诉的分类**，不能说它是确认之诉。`[注释：此为民事诉讼法学中“诉”的理论范畴，超出仲裁法本身，但法考常考]`

#### 第十部分：实务拓展——主合同仲裁条款对补充协议的适用

**第24段（基本原则）**
主合同中的仲裁条款对**补充协议**是否有约束力？这其实很简单，只是实践中被搞复杂了。

补充协议就是对主合同的未尽事项进行补充约定、对不明确事项进行明确解释。补充协议本身就是主合同的一部分。所以：补充协议中没有约定纠纷解决方式的，就适用主合同的纠纷解决方式。主合同有仲裁条款，就适用于补充协议。

**第25段（例外——名为补充协议实为独立合同）**
实践中出的问题：有些“补充协议”约定的其实是**另外一码事**——是一个**独立的合同**。那既然是独立的合同，纠纷解决方式就各有各的。主合同的仲裁条款不适用于这个“补充协议”。

**如何区分？看内容。**
- **是真正的补充协议**：在对主合同的结算方式、验收方式等事项进行补充和解释。→ 主合同的仲裁条款适用。
- **是独立的合同**：主合同约定“修教学楼”，“补充协议”约定“买猪肉、买菜”。→ 完全是两码事，主合同的仲裁条款不适用。

> **【例题5·实务】** A学校与B建筑公司签订《建设工程施工合同》，约定B公司承建A学校的学生宿舍楼，合同中约定“因履行合同发生纠纷由丙市仲裁委员会仲裁”。后来A学校与B公司就**工程款的计算及支付方式**达成补充协议，补充协议中未约定仲裁条款。后来因工程款支付发生纠纷，应如何处理？
> **【分析】** 补充协议约定的是工程款的计算和支付方式——这是对主合同的补充和解释，是主合同的一部分。补充协议未作明确约定的，适用主合同的约定。所以主合同中的仲裁条款对补充协议有约束力，应去丙市仲裁委申请仲裁。
