# 第1部分：备考提纲

## 民事诉讼法执行程序——特殊执行措施备考提纲

> **适用对象**：非法学背景、备考法考的考生
> **说明**：本提纲基于讲稿内容整理，法律条款标注依据讲稿中提及的内容及公开司法解释。不确定之处已标注。


### 一、执行中变更追加当事人

#### （一）可以变更追加谁为被执行人

> **法律依据**：《最高人民法院关于民事执行中变更、追加当事人若干问题的规定》

| 被执行人类型 | 可追加的主体 | 承担责任的范围 | 法律依据 |
|------------|------------|--------------|---------|
| 自然人死亡/宣告死亡 | 遗产管理人、继承人、受益人 | 遗产范围内 | 《变更追加规定》第10条 |
| 法人/非法人组织合并 | 合并后存续或新设的法人/非法人组织 | 对合并前债务承担责任 | 《变更追加规定》第11条 |
| 法人/非法人组织分立 | 分立后新设的法人/非法人组织 | 对分立前债务承担连带责任 | 《变更追加规定》第12条 |
| 个人独资企业 | 出资人 | 对企业债务承担责任 | 《变更追加规定》第13条 |
| 合伙企业——普通合伙人 | 普通合伙人 | 对合伙企业债务承担责任 | 《变更追加规定》第14条 |
| 合伙企业——有限合伙人 | 未足额出资/抽逃出资的有限合伙人 | 未足额出资/抽逃出资范围内 | 《变更追加规定》第14条 |
| 法人——股东 | 未足额出资/抽逃出资的股东 | 未足额出资/抽逃出资范围内 | 《变更追加规定》第17-19条 |
| 一人公司 | 不能证明财产独立的股东 | 对公司债务承担责任 | 《变更追加规定》第20条 |


#### （二）对追加裁定不服的救济——核心考点

> **基本原理**：
> - 复议仍在执行中，**不解决实体纠纷**
> - 另行起诉跳出执行程序，**解决实体纠纷**

**判断规则**：

| 情形 | 救济方式 | 理由 |
|------|---------|------|
| 只要有这个身份就得承担责任 | **上级复议** | 不解决实体争议 |
| 不仅要身份还要满足实体条件才承担责任 | **另行起诉** | 有实体争议 |

**具体适用**：

| 追加情形 | 救济方式 |
|---------|---------|
| 法人/非法人组织合并分立后主体 | **上级复议** |
| 个人独资企业出资人 | **上级复议** |
| 法人股东（未足额出资/抽逃出资） | **另行起诉** |
| 一人公司股东（不能证明财产独立） | **另行起诉** |
| 合伙企业普通合伙人 | **上级复议** |
| 合伙企业有限合伙人（未足额出资/抽逃出资） | **另行起诉** |


### 二、执行中的分配制度

#### （一）三种制度的适用对象与规则对比

| 制度 | 适用对象 | 适用条件 | 分配规则 |
|------|---------|---------|---------|
| **参与分配** | 公民（自然人）、其他组织（非法人组织） | 财产不足以清偿所有债权 | **按比例受偿** |
| **执行转破产** | 法人 | 资不抵债、符合破产条件 | **按比例受偿**（破产程序） |
| **执行竞合** | 所有类型 | 财产足以清偿所有债权，但特定标的物变价款不足 | **先到先得**（按查封顺序） |


#### （二）参与分配——详细规则

**1. 适用条件**
- 被执行人为**公民（自然人）或者其他组织（非法人组织）**
- 被执行人的财产**不能清偿所有债权**
- 申请参与分配的债权人**已经取得执行依据**
- 申请时间：执行程序开始后、财产执行终结前

**2. 优先受偿权**：对特定财产享有优先受偿权的人，优先受偿权**不受影响**。

**3. 分配方案异议程序**

```
法院制作分配方案 → 送达所有当事人
    │
    ├── 无人异议 → 按方案分配
    │
    └── 有人异议（如甲）
            │
            ├── 其他人不反对 → 按甲的异议修改方案后分配
            │
            └── 有人反对（如丁）→ 分配方案异议之诉
                    │
                    └── 异议人甲（原告）诉反对人丁（被告）
```


#### （三）执行转破产——详细规则

**1. 适用条件**
- 被执行人为**法人**
- 执行中发现**资不抵债**（符合破产条件）
- 经**债权人之一或债务人同意**

**2. 程序**
- 执行法院（A区法院）发现资不抵债
- 经债权人或债务人同意
- A区法院**裁定中止执行**
- 移送**债务人住所地法院**（B区法院）按破产程序处理

**3. 结果**

| 结果 | 处理 |
|------|------|
| 转成功（受理破产） | 解除查封措施 → 宣告破产 → 执行终结 → 按比例分配 |
| 没转成功（不受理破产） | 恢复执行 → 按查封扣押冻结**先后顺序受偿**（先到先得） |

**4. 制度精髓**：通过“先到先得”倒逼**后顺位债权人**同意转破产，从而激活破产法。


#### （四）执行竞合——三句话规则

| 规则 | 含义 |
|------|------|
| **物权对抗债权** | 基于所有权、担保物权等物权，优先于普通金钱债权受偿 |
| **登记的对抗没登记的** | 办理查封登记的，优先于未办理登记的 |
| **先下手为强** | 首封优于二封，二封优于三封（按查封先后顺序） |

> **注意**：
> - 查封登记不是生效要件，只是**对抗要件**——没办理登记不影响查封效力，只是**不具有对抗效力**
> - 禁止**重复查封**，但允许**轮候查封**


### 三、对被执行人到期债权的执行（代位申请执行）

> **法律依据**：《最高人民法院关于适用〈民事诉讼法〉的解释》第499条；《执行工作规定》第61条

#### （一）基本流程

```
申请执行人或被执行人申请
    │
    ▼
法院向第三人（次债务人）发出履行到期债务的通知
    │
    ├── 第三人十五天内履行 → 结案
    │
    ├── 第三人十五天内提出异议 → 不得强制执行，不审查异议
    │
    └── 第三人十五天内不履行也不异议 → 强制执行第三人
```

#### （二）第三人的异议

**1. 构成异议的情形**：
- 对债权债务本身有异议（如“我已经还了”）
- 异议可以书面或口头

**2. 不构成异议的情形**：
- “我不欠申请执行人的钱”（第三人与申请执行人无直接法律关系）
- 缺乏清偿能力、要求延缓履行期限、变更履行方式等

**3. 异议的效力**：
- 只要第三人提出异议 → **法院不得强制执行**
- 法院**对异议不审查**
- 申请执行人**不能**请求对异议部分强制执行

**4. 对生效法律文书确定的到期债权的异议**：
- 第三人否认生效法律文书确定的到期债权 → **不予支持**
- 必须通过法定程序（再审、撤销仲裁裁决等）否认

**5. 只能代位一次**


### 四、对共有物的执行

#### （一）基本规则

- 对共有物**可以查封扣押冻结**（有被执行人的份额）
- 查封后需要**析产分割**

#### （二）析产分割方式

| 方式 | 说明 |
|------|------|
| **协议分割** | 共有人协议 → **须经申请执行人同意**才有效 |
| **析产诉讼** | 协议不成 → 共有人或申请执行人（代位）提起诉讼 |

#### （三）析产诉讼的管辖

- **不能由执行法院管辖**
- 属于物权纠纷中的共有纠纷
- **有不动产** → **不动产所在地法院专属管辖**
- **没有不动产** → **一般地域管辖**（原告就被告）

#### （四）诉讼期间执行状态

- 析产诉讼期间 → 执行**中止**（等待分割结果）


### 五、对特定物的执行

> **法律依据**：《执行工作规定》第57条

#### （一）基本规则

| 情形 | 处理 |
|------|------|
| 原物存在 | **必须执行原物**（不能执行其他财产） |
| 原物毁损灭失 | **折价赔偿**（实体纠纷） |
| 协议折价赔偿 | 可以 |
| 协议不成 | 就折价赔偿问题**起诉** |
| 起诉后执行状态 | **执行终结**（不是中止！原物已无法执行） |

> **注意**：不管物理上毁损灭失还是法律上执行不能（如卖给了第三人），都要折价赔偿

#### （二）与执行和解的结合

- 折价赔偿达成的协议 = **执行和解协议**
- 义务人拒不履行 → **不能恢复执行**（原物已灭失）→ **只能就和解协议起诉**

## 备考提示

1. **变更追加当事人**：核心是区分“上级复议”和“另行起诉”——判断标准是“有无实体争议”。

2. **三种分配制度**：先判断“财产是否足以清偿所有债权”——不够→参与分配（自然人/非法人组织）或执行转破产（法人）；够→执行竞合。

3. **到期债权执行**：记住“第三人一提出异议就停止执行、不审查”；但有两种情况不叫异议；对生效法律文书确定的债权不能否认。

4. **特定物执行**：⚠️ **几乎每年都考**。记住三点——（1）必须执行原物；（2）原物灭失→折价赔偿（实体纠纷→协议或起诉→执行终结）；（3）不能执行其他财产。2021和2022连续两年考了与执行和解结合的题目。

5. **案外人对执行标的的异议**：记住“原判有错→再审；与原判无关→执行异议之诉”。执行标的可以是实物也可以是权利（股权、债权）。

# 第2部分：讲稿切分与整理

## 第一节 执行中变更追加当事人

### 一、基本概念与解决路径

我们讲执行的第四节——特殊执行措施。一方面呢，是执行中这个被执行人呢有一些特殊情况；第二个呢，是对特殊的标的怎么执行的问题。

来看到第一个啊——执行中变更追加当事人。它解决的问题呢，是在执行中这个被执行人不能清偿债务了。那根据实体法的规定，有一些主体要对这个被执行的债务承担责任吧。我们就变更追加这样的主体为被执行人，在他应当承担责任范围之内继续执行，对吧？

内容在三百二十三页上面那个表格。我们总共两个问题啊：一、可以追加变更谁为被执行人；二、对追加一个裁定不服的怎么救济。

**【修正说明】** 原文“我们总共两个问题啊，一可以追加变更谁为被执行人。第二对追加一个裁定不服的怎么救济？”——改为更规范的表述。


### 二、可以追加变更谁为被执行人

其实这个问题很简单，就是根据实体法的规定，谁对被执行的债务承担责任，就变更追加谁为被执行人，在他应当承担责任范围之内继续执行。

**第一种情况：被执行人是自然人**

如果被执行人是自然人死亡或者宣告死亡的，那他的遗产管理人、继承人、受益人，应当在遗产范围之内承担责任吧。那就变更追加他的遗产管理人、继承人、受益人为被执行人，在他取得的遗产范围之内继续执行。

**第二种情况：被执行人是法人或非法人组织**

如果是被执行人是法人或者非法人组织合并分立了，那合并分立后的法人或者非法人组织要对合并分立前的债务承担责任吧。那就变更追加合并分立后的法人或者非法人组织为被执行人继续执行。

**第三种情况：被执行人是个人独资企业**

如果被执行人是个人独资企业不能清偿债务，那个人独资企业的出资人要承担责任的呀。那就变更追加出资人为被执行人吧。

**第四种情况：被执行人是合伙企业**

如果被执行人是合伙企业不能清偿债务的——注意，这个合伙企业里边有两种合伙人，一个叫普通合伙人，一个叫有限合伙人。那普通合伙人一定要对合伙企业债务承担责任，那就追加变更普通合伙人为被执行人，对吧？那有限合伙人只有没有足额出资、抽逃出资的才用承担责任，那我们就追加变更没有足额出资、抽逃出资的有限合伙人为被执行人，在他没有足额出资、抽逃出资部分承担责任，对吧？

**第五种情况：被执行人是法人（公司股东）**

如果被执行人是法人不能清偿债务的，他的股东一般不用承担责任吧？但是如果股东没有足额出资、抽逃出资，是要在没有足额出资、抽逃出资范围内承担责任的吧？我们就变更追加没有足额出资、抽逃出资的股东为被执行人，那在他没有足额出资、抽逃出资的范围内继续执行。

**第六种情况：被执行人是一人公司**

如果被执行人只有一个股东的公司，他不能清偿债务，那他的股东一般不用承担责任，但是如果股东不能证明自身财产独立于公司财产的，要对公司债务承担责任吧？那我们要追加变更这样的股东为被执行人，继续执行，对吧？

**【注释】** 以上各类追加变更的具体情形，规定在《最高人民法院关于民事执行中变更、追加当事人若干问题的规定》第十条至第二十五条中。其中个人独资企业出资人、合伙企业普通合伙人、未足额出资或抽逃出资的股东及一人公司股东等均可被追加为被执行人。

那所以呢，到底追加变更谁，其实这并不是一个程序法的问题吧，这是个实体法的问题，好，不说了啊。


### 三、对追加裁定不服的救济——核心考点

那么在民事诉讼当中，在程序当中，我们重点关注一个什么问题呢？救济。

什么意思？比如说我是申请人，他是被执行人，他不能清偿债务了，那我申请法院变更追加你为被执行人，那法院就有可能裁定变更追加你为被执行人，有可能驳回我的申请，对不对？那我们法院如果裁定变更追加你为被执行人，你有没有可能不服？有可能吧？那法院驳我的申请呢，我有没有可能不服？有可能吧？那要不要给咱们救济啊？要嘛。

**【修正说明】** 原文有重复和语序混乱之处（“这个去被，啊，就难受了啊，这个就没法被了啊”），根据上下文逻辑修正为连贯表述。

这个救济——**前边那堆是上级复议，后边那堆是另行起诉**，并且这个分界点呢，还是那个合伙企业里边。

#### （一）基本原理

**什么时候上级复议，什么时候另行起诉？**

复议还在执行当中，在执行当中是不解决实体纠纷的，对吧？而另行起诉呢，是跳出执行程序搞了一个诉讼，那诉讼是要解决纠纷的，对不对？它的基本的区别在这里吧。

#### （二）以合伙企业为例理解规则

咱们以那个合伙企业为例。那如果被执行人是合伙企业不能清偿债务，那这个时候他里边有两种合伙人，一个叫普通合伙人，一个叫有限合伙人，对不对？

**普通合伙人**——是不是一定要承担责任的？只要你是普通合伙人，你就得承担责任，就可以追加你为被执行人，对吧？所以呢，这个时候追不追加，我们只看你是不是普通合伙人——是就要追加，不是就不能追加，**没有什么实体争议要解决**。所以对裁定不服的怎么办？**上级复议**。

**有限合伙人**——是不是一定要承担责任的？不是。这个有限合伙人只有在没有足额出资、抽逃出资的情况下才应承担责任，对吧？所以虽然你是有限合伙人，那你有没有足额出资啊，有没有抽逃出资啊，你抽逃多少出资了呀？**这个是有实体争议的**。那执行不解决实体争议，那就怎么办？那就**另行起诉**嘛。

#### （三）一般规则总结

所以根据实体法的规定：

- **如果被追加那个人，只要他有这个身份，他就得承担责任**——追加与否只看他有没有这个身份，有就追加，没有就不能追加，**不解决实体争议**，对裁定不服——**上级复议**。

- **如果被追加那个人，不仅要这个身份，而且还得满足一定的实体条件他才承担责任**——追加与否不只要看他有没有这个身份，还要看他是否满足这个实体条件，那是否满足这个实体条件，这个就有实体纠纷了——对裁定不服就得**另行起诉**。

#### （四）各种情形逐一分析

**1. 法人或非法人组织合并分立**

如果被执行人是法人或者非法人组织合并分立了，我们裁定变更追加合并分立后的法人或者非法人组织为被执行人吧。请问合并分立后的法人或者非法人组织，对合并分立前的债务是不是一定要承担责任的？是吧？所以只要你是合并分立后的法人或者非法人组织，你就得承担责任，就可以追加变更你为被执行人。要不要解决争议？不用。对裁定不服怎么办？**上级复议**。

**2. 个人独资企业出资人**

如果被执行人是个人独资企业不能清偿债务的，他的出资人是不是一定要承担责任的？是啊，只要你是出资人，就得承担责任，就可以追加变更你为被执行人。要不要解决实体争议？不需要。对裁定不服怎么办？**上级复议**。

**3. 法人股东（未足额出资/抽逃出资）**

如果被执行人是法人不能清偿债务的，那这个时候法人的股东是不是一定要承担责任？不是。这个股东只有在没有足额出资、抽逃出资的情况下才承担责任。那么请问这个股东有没有足额出资啊？有没有抽逃出资呀？抽逃多少出资呀？**这个是有实体争议的**。对裁定不服就得**另行起诉**。

**4. 一人公司股东**

如果被执行人是只有一个股东的公司，他不能清偿债务，那请问他的股东是一定要承担责任的吗？不是。只有在不能证明自己财产独立于公司财产的情况下才承担责任。那这个股东能不能证明自己财产独立于公司财产呢？**这个是有实体争议的**吧？那对这个裁定不服的要怎么办？**另行起诉**。

#### （五）本节小结

第一个，追加变更谁——这是根据实体法规定，谁对被执行的债务要承担责任，你就追加变更谁为被执行人。

第二个，关键看被追加变更那个人：
- 只要有这个身份就得承担责任 → 不解决实体争议 → 对裁定不服**上级复议**
- 不仅要身份还要满足实体条件 → 有实体争议 → 对裁定不服**另行起诉**


## 第二节 执行中的分配制度

那执行中的分配制度总共是三个制度啊：第一个叫**参与分配**，第二个叫**执行转破产**，第三个叫**执行竞合**。

### 一、参与分配

#### （一）什么是参与分配

比如说啊，债权人甲乙丙丁分别拿着生效判决来申请强制执行张三。甲拿着生效判决执行张三两百万，乙拿着生效判决执行张三三百万，丙拿着生效判决执行张三四百万，丁拿着生效判决执行张三一百万。那总共要执行多少钱？一千万。结果咱们把张三家里边翻了个底朝天，翻出六百万——**不足以清偿所有的债务**吧？那此时对所有的债权人甲乙丙丁要不要平等保护？要嘛。那怎么办？这六百万拿出来大家**按比例分**，这个就叫参与分配。

大家发现这个参与分配制度和哪个制度有点像啊？和法院的**破产制度**有点像，对吧？注意啊，我只是说有点像，它本质上是不同的。

**破产**只适用于**法人**，而**参与分配**适用于除法人之外的**自然人和非法人组织**。这个能搞清楚啊，它和破产制度的适用对象不一样啊。

**【注释】** 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第五百零六条规定：“被执行人为公民或者其他组织，在执行程序开始后，被执行人的其他已经取得执行依据的债权人发现被执行人的财产不能清偿所有债权的，可以向人民法院申请参与分配。”参与分配申请应当在执行程序开始后、被执行人的财产执行终结前提出。

#### （二）优先受偿权不受影响

在参与分配过程当中，对被执行人张三的某个财产享有优先受偿权的人，他的优先受偿权是否受影响啊？不受。他可以直接参加参与分配主张优先受偿，对吧？没问题——优先受偿权不受影响。

#### （三）分配方案与异议程序

这个分配程序复不复杂？不复杂。你想想，这个债权人甲乙丙丁的债权都是生效法律文书所确定的，对吧？然后呢，这个被执行人张三家里有六百万也是确定的，对不对？那此时你算一下嘛：用六百万来清偿一千万的债，那所以此时只能清偿**百分之六十**，对不对？那好啊：

- 甲债权两百万，拿百分之六十——拿一百二十万
- 乙债权三百万，拿百分之六十——拿一百八十万
- 丙债权四百万，拿百分之六十——拿二百四十万
- 丁债权一百万，拿百分之六十——拿六十万

那么就分完了嘛，对不对？所以这个程序并不复杂。

**程序如下：**

**第一步**：法院先做一个**分配方案**——计算所有债权是多少、被执行人财产是多少、清偿比例是多少、各债权人分别拿多少。

**第二步**：法院把方案给**所有的当事人**看（包括债权人甲乙丙丁以及债务人张三）。

**第三步——三种结果：**

1. **大家都没有异议** → 按照方案分。

2. **有人提出异议（如甲），其他人不反对** → 把甲的异议给没有提出异议的其他人看 → 大家不反对 → 按照甲的异议修改方案后分。

3. **有人提出异议（如甲），有人反对（如丁）** → 甲和丁之间产生了纠纷（方案改不改）→ 执行不解决纠纷 → 甲做**原告**，反对人丁做**被告**，提起诉讼解决纠纷 → 这个叫做**分配方案异议之诉**。

**【修正说明】** 原文“这个叫做分配方案异议之诉”后有一段重复内容“说清楚了，来我再来一遍啊……”，删去重复部分。

#### （四）例题

**【例题一】** 甲乙公司分别根据法院的生效判决申请对张某强制执行，执行中发现张某的财产不足以清偿其对甲乙公司的债务。

- 被执行人是**张某**（自然人） → 适用**参与分配**
- 法院根据甲公司的申请制作了分配方案
- 乙公司认为该方案侵犯了自己的优先受偿权，向法院提出异议
- 法院将乙公司的异议送达给甲公司和张某
- 甲公司和张某**没有回复**（没反对）→ 按照乙公司的异议修改方案后分配

**答案**：选“按照乙公司的异议修改方案后分配”的选项。

**【例题二】** 甲向法院申请执行郭某的财产，乙丙丁向法院申请参与分配。

- 被执行人是**郭某**
- 法院根据财产状况和各债权情况制定了分配方案
- **甲、乙**认为分配方案不合理，向法院提出异议
- 法院根据甲、乙的异议对方案修正后，**丙、丁反对**

甲、乙说要改，丙、丁说不能改——甲、乙想要改怎么办？**甲、乙起诉丙、丁**。甲、乙做**原告**，反对人丙、丁做**被告**，提起**分配方案异议之诉**。

- A、B选项说“复议”——错
- C、D选项说“起诉”——没问题
- 谁起诉？应该是**异议人甲、乙起诉反对人丙、丁**
- 所以选**D**

**【修正说明】** 原文“A B选项说负意，对不对？错”根据上下文，应为“复议”。


### 二、执行转破产

#### （一）什么是执行转破产

举个例子：债权人甲乙丙丁分别申请**A区法院**来执行**天南公司**（法人），天南公司住所地在**B区**。甲执行两百万，乙执行三百万，丙执行四百万，丁执行一百万——总共一千万。结果把天南公司翻了个底朝天，翻出六百万——**不足以清偿所有债务**了。

这个时候就满足了破产法规定的条件——**法人资不抵债**，满足破产条件了。

那此时执行法院**A区法院**就可以把案件移送给债务人天南公司住所地**B区法院**，由B区法院按照**破产程序**处理——这个就叫**执行转破产**。

#### （二）执行转破产的程序

1. **管辖**：由**债务人天南公司住所地法院**（B区法院）管辖。

2. **启动条件**：破产需要债权人（如甲乙丙丁之一）或债务人（天南公司）申请。执行转破产虽然不需要申请，但**需要经过债权人之一或债务人同意**。

3. **程序**：A区法院发现被执行人天南公司资不抵债 → 经过债权人或债务人同意 → A区法院**裁定中止执行** → 将案件移送给B区法院 → B区法院按照破产程序处理。

#### （三）转成功与没转成功

**转成功了**（B区法院受理破产案件）：
- A区法院已采取的**查封扣押冻结措施** → **解除**
- B区法院受理后裁定**宣告天南公司破产**
- A区法院的执行**不能再继续进行** → **执行终结**
- 由B区法院按照破产程序**按比例分配**

**没转成功**（如B区法院不受理破产案件）：
- A区法院应当**恢复执行**
- 对已查封扣押冻结的财产 → 按照**查封扣押冻结的先后顺序受偿**（**先到先得**）

**【修正说明】** 原文“那恢复执行，对天南公司的财产已经查封扣押冻结的怎么办呢？按照查封扣押冻结的先后顺序收藏啊，先到先得”——“收藏”应为“受偿”。

#### （四）执行转破产制度的精髓——为什么这样设计？

为什么没转成功就按照先后顺序“先到先得”？

这个执行转破产制度的目的是为了**激活破产法**。实践中破产法适用很少——据统计，当年全国共注销法人**六十万家**，而同年全国各地法院受理的破产案件**不到两千件**。

为什么适用很少？因为破产法要求债权人之一或债务人申请：
- **债权人**不会申请——本来债务人就资不抵债，一申请破产公告一出，所有债权人都来了，自己的债权被稀释
- **债务人**不会申请——本来资金困难只来几个债权人还能应付，一申请破产所有债权人都来了，雪上加霜

那执行转破产怎么激活呢？

虽然需要债权人或债务人同意，但他们基于上述考虑**不会同意**。那不同意就转不成，恢复执行，**按照查封扣押冻结的先后顺序受偿**：

- 第一个查封的甲：两百万全部得到清偿，开心走了
- 第二个查封的乙：三百万全部受偿，开心走了
- 第三个查封的丙：只剩一百万，拿一百万走，不太开心
- 第四个查封的丁：没了，一分钱拿不到

**丁就怒了**：“停，大家都别走，**我同意转破产**！”——只要丁一同意，执行转破产，破产法就被激活了。

所以：**先到先得**，后来的债权人一分钱拿不着，还不如按破产程序**按比例受偿**。后来的债权人一定会同意转破产——破产法就被激活了。


### 三、执行竞合

#### （一）什么是执行竞合

举个例子：债权人甲和乙分别申请法院来执行张三。甲执行一百万，乙执行一百万——总共两百万。被执行人张三家里特别有钱，一套房子值一百二十万，还有商铺、股权等，清偿甲乙两笔债务**绰绰有余**。只不过甲乙都看上了张三这套房子，这套房子变价款一百二十万——**不足以清偿所有债务**。

那**就这个房子的变价款**，甲乙按照什么顺序拿、谁先拿谁后拿——这个叫**执行竞合**。

#### （二）参与分配/执行转破产 vs 执行竞合的本质区别

**参与分配和执行转破产**：被执行的财产**不足以清偿所有债务**，所有债权人最终**不能**得到完全受偿。

**执行竞合**：被执行人财产清偿所有债务**绰绰有余**，所有债权人最终**都能**得到完全受偿。只不过就**那个特定的标的物**（如房子）的变价款不足以满足全部需要——就这个特定标的物的变价款按照什么顺序受偿。

#### （三）执行竞合的分配规则——三句话

**第一句话：物权对抗债权**

基于所有权、担保物权等物权，**优先于**普通的金钱债权受偿。

**第二句话：登记的对抗没登记的**

法院查封扣押冻结已登记的不动产、特定动产及其他财产权，应当办理登记手续。**未办理登记手续的，不得对抗其他已经办理登记手续的查封扣押冻结**。

也就是说，查封扣押冻结的登记只是取得**对抗效力**——不是生效要件。没办理登记，**不影响**查封扣押冻结的效力，只是**不具有对抗效力**而已。

**第三句话：先下手为强**

法院查封扣押冻结，**禁止重复查封冻结**，但是可以**轮候查封冻结**。

什么叫重复查封？什么叫轮候查封？

甲申请A区法院查封张三的房子——A区法院下达查封裁定、张贴公告、办理查封登记。乙又申请B区法院来查封这个房子——B区法院**不能重复查封**，但可以做一个**轮候查封**：告诉房屋登记管理机关“只要A区法院的查封一旦解除，我们的查封马上跟上”。

- A区法院先查封 → **首封**
- B区法院轮候查封 → **二封**
- C区法院再轮候查封 → **三封**

房屋变价款怎么受偿？**首封先拿，有剩的二封再拿，二封拿了有剩的三封再拿**——按照查封扣押冻结先后顺序受偿。**首封优于二封，二封优于三封**——先下手为强。


#### （四）例题

**【例题一】** 张三将房屋抵押给银行贷款一百万，已进行抵押登记。张三向甲公司借款六十万逾期不还，甲公司起诉张三要求归还六十万，法院判决支持。甲公司申请强制执行，法院在张三众多财产中发现了该房屋，查封了房屋并办理了查封登记。后来银行向法院申请实现担保权，法院裁定准许拍卖变卖房屋。经拍卖房屋变价款一百二十万元。

银行要从房子变价款中拿一百万。甲公司也要从房子变价款中受偿六十万。房子变价款一百二十万，不能满足银行和甲公司的需要。

这一百二十万怎么拿？

**三句话：物权对抗债权。**

- 银行是基于**担保物权**（抵押权）要求受偿 → **物权**
- 甲公司只是基于**普通债权**要求受偿 → **债权**

**物权对抗债权** → 银行先从一百二十万中拿一百万走 → 甲公司拿剩下的二十万 → 甲公司六十万没得到完全清偿，再去执行张三别的财产。

**问题一**：该房屋已办理抵押登记手续，甲公司申请对张三强制执行过程中，法院能否查封房屋？**可以**。对担保财产可以查封扣押冻结，但不影响担保权的优先受偿权。

**问题二**：房屋变价得款一百二十万，银行和甲公司如何受偿？**银行先于甲公司受偿**，银行受偿一百万，甲公司只能受偿二十万。

**【例题二】** 甲向A区法院起诉张三要求归还借款一百万，申请对张三的房屋进行保全。A区法院作出裁定查封房屋，并在房屋上张贴了封条，但**一直没有办理查封登记**。乙向B区法院起诉张三要求支付八十万，申请对张三的该房屋进行保全，B区法院查封了该房屋并**已经办理了登记手续**。

A区法院不是已经查封了吗？但**没办理登记手续**，不具有对抗效力。B区法院能不能去查封？**可以**。登记的对抗没登记的 → B区法院的查封先受偿。

后来A区法院判决支持甲的诉讼请求，B区法院判决支持乙的诉讼请求，甲乙均申请强制执行。张三除该房屋外还有其他诸多财产（清偿甲乙绰绰有余）。房屋变价得款一百二十万。

谁先拿？**登记的对抗没登记的**：B区法院的查封登记了，A区法院的查封没登记 → B区法院先受偿。B区法院帮**乙**查封的 → **乙**先受偿八十万 → 剩四十万给**甲**受偿 → 甲的一百万只受偿四十万，差六十万再去执行张三别的财产。

**【例题三】** A区法院判决张三向甲清偿一百万，判决生效后甲申请A区法院强制执行。法院在张三众多财产中发现房屋价值约一百二十万。但发现乙向B区法院起诉张三归还借款八十万一案中，B区法院已经做出了保全裁定并对房屋予以查封，并已办理查封登记。

B区法院已经先查封了 → A区法院**不能重复查封** → 只能做**轮候查封**。

- B区法院的查封 → **首封**
- A区法院的查封 → **二封**

**先下手为强** → B区法院先受偿。B区法院帮**乙**查封的 → **乙**先受偿。等乙起诉张三的案件作出终审判决后，乙从房屋变价款中优先受偿，受偿完后有剩的，甲再受偿。


### 四、三种分配制度的关系

**【生活化比喻】**

**参与分配和执行转破产** = 被执行人的所有财产不足以满足所有债权，所有债权人最终都**吃不饱**。就像二十年前物质生活不好，大家都不一定吃得饱，家里好不容易做只鸡，我放学回来端起盘子说“我先拿到我先吃”——不行！大家都吃不饱，我得放下，**大家按比例分，雨露均沾**。

- 被执行人是**除法人之外的自然人和非法人组织** → **参与分配**（按比例）
- 被执行人是**法人** → **执行转破产**（按比例）

**执行竞合** = 被执行人的财产能够满足所有债权，所有债权人最终都**吃得饱**。就像现在物质生活丰富了，家里做了一大桌大餐，我放学回来端起鸡说“我先拿到我先吃”——可以！大家都吃得饱的情况下你先吃呗，没鸡了还有牛肉、螃蟹、鱼、虾。**先到先得**。


## 第三节 对被执行人到期债权的执行

### 一、基本概念

比如说，张三拿生效判决申请执行李四一百万。在执行时发现李四没钱，但是李四对第三人**王五**享有一百万**到期债权**。

被执行人李四对王五享有的一百万到期债权——是不是被执行人的**财产权利**？是。可不可以执行？可以。

怎么执行？申请执行人张三或者被执行人李四可以向法院提出申请，由法院给第三人**王五**发出一个**履行到期债务的通知**。

**【注释】** 对被执行人到期债权的执行，又称**代位申请执行**。法律依据为《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第四百九十九条以及《最高人民法院关于人民法院执行工作若干问题的规定》第61条。

### 二、履行通知的效力

王五收到通知后——

**第一，不准再把钱还给李四了**。为什么？因为你要还给李四，李四转手就把钱转移跑了。

如果王五**不听招呼**非要把钱还给李四：

- **程序上**：妨碍法院执行 → **罚款、拘留**，构成犯罪追究刑事责任
- **实体上**：导致钱无法追回 → 在无法追回范围之内，王五和李四承担**连带责任**

**【修正说明】** 原文“王五，你不是爱还钱吗？那行，刚才还的不算，对吧？重新还”——根据上下文修正为清晰表述：“在无法追回范围之内，第三人王五跟被执行人李四承担连带责任”。

### 三、王五的三种应对方式

**第一种**：王五在**十五天之内**直接把钱还给张三 → 没事了。

**第二种**：王五在**十五天之内**对债权债务有异议的，向法院提出异议。

- 异议可以**书面**，可以**口头**（口头提出的执行人员应记入笔录）
- 只要王五提出异议 → 法院**对王五不再强制执行**，法院**对异议不审查**——因为执行不解决纠纷
- 王五提出异议后，申请执行人**不能**请求对异议部分强制执行

**第三种**：十五天一过，王五**不还钱也不提出异议** → 不提异议说明债权债务没有争议 → 十五天一过就可以对王五**强制执行**。

### 四、两种不构成异议的情况

1. 王五说：“法官，**我不欠张三的钱**。”——这不叫异议。为什么？王五本来就不欠张三的钱，欠的是**李四**的钱。第三人提出自己与**申请执行人**之间没有直接债权债务关系的，**不构成异议**。

2. 王五说：“法官，我确实欠这一百万，但是我**缺乏清偿能力**/**要求延缓履行期限**/**变更履行方式**。”——对债权债务本身没有异议，只是提出履行能力、期限、方式等问题，**不构成异议**。

### 五、对生效法律文书确定的到期债权的异议

看好了：张三申请执行李四一百万。执行时李四没钱，但李四对王五享有一百万到期债权——这个到期债权是一份**生效仲裁裁决**确定的（裁决王五向李四支付一百万货款）。

法院向王五发出履行到期债务的通知。王五提出异议：“法官，那个生效仲裁裁决认定是错误的，所以我不欠李四这一百万。”

**这个异议不支持**。为什么？因为这是**生效法律文书确定的到期债权**——你必须履行，你不能否认。如果要否认，必须通过法定程序：
- 法院生效判决确定的 → **再审、第三人撤销之诉**
- 仲裁裁决确定的 → **撤销仲裁裁决程序**

**【修正说明】** 原文“王五收到通知后，那就向法院提出异议，说法官，那个生效仲裁裁决认定的是错误，所以我不欠李四这一百万。哎，请问对这个异议不支持啊？不支持”——根据上下文修正为清晰表述。

再看另一种情况：王五说：“法官，这份仲裁裁决认定一百万没问题。但是我已经在收到履行通知之前一个星期**把这一百万还给李四了**，我已经清偿了，所以我不欠李四的钱。”

**这个叫异议**——王五有没有否认生效仲裁裁决确定的到期债权？没有。他只是提出**已经履行了**。所以只要王五提出这个异议，法院**不再对王五强制执行**，法院**不审查**。

### 六、代位申请执行只能代位一次

如果王五在十五天之内不还钱也不提出异议，我们强制执行王五。在执行王五的时候，王五说：“法官，我也没有钱，案外人赵六欠我一百万，你们去找赵六吧。”

**能不能去找赵六？不能**。因为你要去找赵六，赵六说“我也没有钱，案外人王二麻子欠我一百万，你们去找王二麻子吧”——代位代位没完没了。

所以**代位申请执行只能代位一次**，不准再代位。

### 七、真题实例

**【真题】** 某法院判决乙公司向甲公司支付三十万货款，甲公司申请执行。在执行中发现乙公司没有可供执行的财产，但是乙公司对案外人**丙公司**有三十万债权。甲公司申请法院向丙公司发出了履行到期债务的通知。

- 申请执行人：**甲公司**
- 被执行人：**乙公司**
- 执行根据：法院判决乙公司向甲公司支付三十万货款
- 执行标的：乙公司对丙公司的三十万到期债权

丙公司收到通知后提出异议：“该笔欠款**已经归还**了。”——这是对债权债务**实质的异议**。只要丙公司提出异议 → 对丙公司**不再强制执行**，法院**不审查**。

**A选项**：甲公司可以申请法院对丙公司强制执行 → **不对**（丙公司提出异议了）
**B选项**：不能申请对丙公司强制执行 → **对**

同时，案外人**丁公司**向法院主张：“乙公司已经将该笔债权**转让给自己**了，自己是这笔债权的受让人。”

丁公司是什么人？是这个执行案件的**案外人**。本案执行标的是乙公司对丙公司的三十万到期债权。丁公司对这个执行标的（债权）主张自己的权利 → 这叫**案外人对执行标的的异议**。

**【注释】** 案外人对执行标的的异议，规定在《民事诉讼法》第二百三十八条（2023年修正）：案外人对执行标的提出书面异议的，法院应当审查，理由成立的裁定中止执行，理由不成立的裁定驳回。案外人、当事人对裁定不服，认为原判决、裁定错误的，按审判监督程序办理；与原判决、裁定无关的，可以自裁定送达之日起十五日内提起诉讼。

案外人对执行标的的异议——法院审查：认为成立的**终止执行**，认为不成立的**裁定驳回**。终止驳回之后怎么办？
- **原判有错的** → **再审**
- **与原判无关的** → **执行异议之诉**

本案判决判的是**三十万货款**（钱），执行的是**债权**。判的和执行的不一样 → **与原判无关** → **执行异议之诉**。

**C选项**：丁公司提出案外人异议后被驳回后，应当申请再审 → **不对**
**D选项**：丁公司提出案外人异议后被驳回后，应当提起执行异议之诉 → **对**

**答案：B和D。**

**【命题分析】** 这个题出得好在哪里？
1. 把**案外人对执行标的异议**和**对被执行人到期债权的执行**两个看似毫不相关的考点综合在一道题中
2. 执行标的从**实物**变成**权利**（股权、债权）——案外人对此主张权利也是案外人对执行标的的异议
3. 考的都是基本规则——对被执行到期债权的执行考的是“第三人提出异议就不能执行”；案外人对执行标的的异议考的是“原判有错再审、原判无误另诉”


## 第四节 对共有物的执行

### 一、基本概念

张三申请执行李四三十万。执行时发现李四没钱，但是李四有一辆车。法院扣押了这辆车。扣押之后发现这辆车其实是李四与案外人**王五共有的汽车**。

**问题一**：对被执行人李四与案外人王五共有的汽车，能不能查封扣押冻结？**可以**——因为里边有被执行人李四的份额。

**问题二**：扣了之后干什么？对这个车进行**析产分割**——哪些份额属于李四的（可以执行），哪些份额属于王五的（不能执行）。

### 二、析产分割的方式

这个车到底哪些份额是李四的、哪些份额是王五的——这是一个**实体的纠纷**。执行**不解决纠纷**。

怎么办？

**方式一：协议分割**。共有人李四和王五协议。但担心他们搞鬼——比如约定“车百分之一归李四，百分之九十九归王五”——损害申请人张三的利益。所以**协议分割必须经过申请人张三同意后有效**。

**方式二：析产诉讼**。协议不成的，就析产分割问题提起诉讼：
- 共有人**李四和王五**可以提起析产诉讼（但他们没有积极性）
- **申请人张三**也可以**代位提起析产诉讼**（最积极）

在诉讼期间，车哪些份额归谁还不知道 → 执行**中止**，等析产诉讼的审理结果。

### 三、析产诉讼的管辖

析产诉讼由哪个法院管辖？

- **不能由执行法院管辖**（最高法院认为析产诉讼跟执行没有关系）
- 析产诉讼是对共有物进行分割 → 属于**物权纠纷**下的**共有纠纷**
- **有不动产的** → **不动产所在地法院专属管辖**
- **没有不动产的** → **一般地域管辖**（**原告就被告**，被告住所地法院）


## 第五节 对特定物的执行

### 一、基本规则

法院判决李四将**这幅名贵字画**交付给张三——判决指向的是**特定物**（这幅名贵字画）。

**第一，执行标的为特定物的，必须执行原物**——执行必须严格以生效法律文书为根据，判的是交付这幅画，就只能执行这幅画，不能去执行别的东西。

**第二，原物毁损灭失的，折价赔偿**。

执行中发现这幅画已经毁损灭失了（如李四家失火烧了）→ 折价赔偿。折价赔偿到底赔多少？画值多少钱？——这是**实体的纠纷**。执行**不解决纠纷**。

怎么办？
- **协议折价赔偿**
- **协议不成的** → 就折价赔偿问题**提起诉讼**

**第三，执行应当终结还是中止？**

就折价赔偿问题起诉了 → 执行应当**终结**还是**中止**？

- 中止是为了**等**——等什么？执行标的为特定物要执行原物，现在原物已经毁损灭失了，**没有办法执行了**
- 所以是**执行终结** → 你们就折价赔偿问题另行起诉，法院判多少赔多少

### 二、例题

**【例题一】** 邓某有幅名画，张某出价一百万购买遭拒。张某找到吴某让吴某向邓某购买。吴某与邓某签订买卖合同，约定吴某出价一百万，邓某把画卖给吴某。后来邓某得知真相拒绝履行合同。吴某起诉邓某，法院判决邓某向吴某交付这幅画。邓某拒不履行，吴某申请强制执行。邓某**把画撕了**，表示愿意退还一百万。吴某说不行，还得赔我五十万违约金。双方无法达成协议。

实质：判决交付**这幅画**（特定物）→ 执行标的为特定物，要执行原物 → 执行中画被撕了（**原物毁损灭失**）→ 折价赔偿 → 折价赔偿是实体纠纷 → 执行不解决纠纷 → 协议不成 → 就折价赔偿问题起诉 → 法院裁定**执行终结**。

**命题分析**：题目前三行都是**无关信息**（命题老师在讲故事、增加阅读难度）——真正有效信息就是“判决交付画，执行中画被撕了”。

- A：法院当执行中止 → **不对**
- B：法院当执行终结 → **对**
- C：法院当裁定赔偿一百万 → **不对**
- D：法院当裁定赔偿一百五十万 → **不对**

**C、D为什么错？**
1. 执行标的为特定物必须执行原物，**不能执行别的钱**
2. 赔一百万还是一百五十万是**实体纠纷**，执行**不解决纠纷**

**答案：B。**

**【例题二】** 甲与乙公司签订古董花瓶买卖合同，约定甲将古董花瓶卖给乙，乙支付五十万。乙支付价款后，甲拒不履行合同。乙起诉甲要求交付花瓶。法院判决支持乙的诉讼请求。甲拒不履行，乙申请强制执行。在执行中发现**花瓶打碎**。

判决指向**花瓶**（特定物）→ 执行标的为特定物，执行原物 → 执行中花瓶打碎（**原物毁损灭失**）→ 折价赔偿 → 实体纠纷 → 执行不解决纠纷 → 协议或起诉 → 执行终结。

后来甲乙达成和解协议，约定甲向乙赔六十万。甲**拒不履行**协议。

问题：甲不履行协议，乙可以怎么办？

你们就折价赔偿问题达成的协议 → 是在执行中达成的协议 → 叫**执行和解协议**。

执行和解的规则：
- 和解协议履行完毕 → **执行终结**
- 义务人**拒不履行**和解协议 → 权利人可以**申请恢复对原判决的执行**，也可以**就执行和解协议起诉**

但本案特殊：恢复对原判决的执行——原判决判的是甲交付花瓶（**特定物**），执行标的为特定物要执行原物，现在花瓶已经毁损灭失了，**还能不能执行？不能**。所以**不能恢复执行**。

甲拒不履行和解协议 → **只能就和解协议起诉**。

- A：可以就和解协议起诉，要求甲赔六十万 → **对**
- B：可以申请恢复原判决的执行 → **不对**（原物灭失，无法执行）
- C：法院可以执行甲五十万的财产 → **不对**（不能执行别的财产+实体纠纷不解决）
- D：法院可以执行甲六十万的财产 → **不对**（不能执行别的财产+实体纠纷不解决）

**答案：A。**

**【命题分析】** 这个题把**执行和解**和**执行特定物**两个考点真正融合在了一起。2021年考过，2022年原封不动又考了一遍。

**【例题三】** 甲与乙公司签订买卖合同，以十万价格购买了一个雕像工艺品。后来乙公司觉得价格便宜拒绝履行合同。甲起诉乙公司要求履行合同，乙公司主张合同显失公平请求撤销合同。一审二审法院均认为乙的抗辩理由成立，判决撤销合同驳回甲的诉讼请求。甲申请再审，再审法院经审理后认为甲的诉讼请求成立，撤销一审二审判决，**改判乙公司向甲交付工艺品**。甲申请执行，但执行中发现乙公司把工艺品卖给了丙，丙将其捐赠给了博物馆。

前边一审二审都是**无关信息**（命题老师在讲故事）——真正有效信息：生效判决判的是**乙公司向甲交付工艺品**（特定物）。

执行标的为特定物，要执行原物。但执行中发现工艺品现在是**博物馆的**，不是被执行人乙公司的了——**还能不能执行？不能**。

不管物理上毁损灭失还是法律上执行不能——乙公司都得**折价赔偿**。折价赔偿是**实体纠纷**——执行不解决纠纷——**协议或起诉**——**执行终结**。

- A：甲和乙公司友好协商，乙公司同意赔十八万 → **对**（协议折价赔偿）
- B：甲可以另行起诉乙公司要求赔偿，法院执行终结 → **对**（折价赔偿问题起诉，执行终结）
- C：甲可以申请继续对该工艺品采取执行措施 → **不对**（工艺品已是博物馆的，不能执行）
- D：甲可以申请法院执行乙公司价值十万的其他财产 → **不对**（不能执行别的财产+实体纠纷不解决）

**答案：A和B。**
